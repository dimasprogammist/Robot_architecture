# Контроль качества

## 1. Общая цель

После редакторской обработки учебник должен быть:

- понятным;
- последовательным;
- технически корректным;
- практически полезным;
- непротиворечивым;
- единообразным технически;
- разнообразным методически.

---

# 2. Проверка структуры

Проверить:

- последовательность разделов;
- последовательность уроков;
- корректность order;
- отсутствие потерянных уроков;
- отсутствие дублирующихся ID;
- соответствие файлов разделам;
- отсутствие случайных файлов.

---

# 3. Проверка содержания

Проверить:

- фактические ошибки;
- противоречия;
- пропуски;
- повторение;
- чрезмерную поверхностность;
- чрезмерную сложность;
- плохие определения;
- плохие примеры.

---

# 4. Проверка педагогики

Для каждого урока определить:

- что должен понять читатель;
- достаточно ли объяснение;
- соответствует ли глубина месту урока;
- логичен ли порядок объяснения;
- не требует ли урок знаний, которые появляются позже;
- нет ли ненужного повторения.

---

# 5. Проверка практики

Если урок практический:

- соответствует ли количество заданий теме;
- соответствуют ли задания уровню;
- требуют ли они размышления;
- не копируют ли они примеры;
- есть ли автоматическая проверка там, где она нужна;
- есть ли подсказки;
- не слишком ли сложны задания.

---

# 6. Проверка визуализации

Проверить:

- нет ли чрезмерного количества схем;
- помогают ли схемы пониманию;
- нет ли декоративных схем;
- не проще ли объяснить информацию текстом.

---

# 7. Проверка Markdown

Проверить:

- YAML;
- заголовки;
- code blocks;
- ссылки;
- списки;
- таблицы;
- внутренние ссылки;
- изображения.

---

# 8. Проверка глобальных связей

Проверить:

- единообразие терминологии;
- одинаковое значение терминов;
- отсутствие противоречивых объяснений;
- отсутствие повторного объяснения фундаментальных понятий;
- корректное использование знаний предыдущих уроков.

---

# 9. Финальный аудит

После завершения редактирования необходимо выполнить отдельный аудит, который не должен просто доверять предыдущим решениям.

Нужно заново спросить:

> Если бы я впервые увидел этот учебник сейчас, смог бы я понять его структуру и пройти его последовательно?

---

# 10. Критерий приёмки

Изменение принимается, если оно:

- улучшает понимание;
- устраняет реальную проблему;
- не создаёт новую проблему;
- соответствует архитектуре курса;
- соответствует стилю;
- технически корректно.

Если улучшение сомнительно — лучше сохранить исходный материал и зафиксировать проблему для дальнейшего рассмотрения.
