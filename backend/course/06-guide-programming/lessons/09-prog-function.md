# Функции

Функция — именованный алгоритм с границей: входы (следующий урок), шаги внутри, снаружи вызов по имени. Подпрограмма старше Python: не копировать код и думать глаголами.

Объявление: «есть действие `normalize_speed`». Вызов: «сделай сейчас». Пока не вызвали — тело спит, как невзятая ветка `если`.

Зачем: повтор; верхний уровень как план из глаголов; детали можно сменить, сохранив имя. Плохая функция делает «и фильтр, и запись лога, и отправку на сервер» без нужды — тогда имя врёт.

Вызов — перейти, выполнить, вернуться (с значением или без — урок про return). Стек вызовов уже мелькал в компьютере: каждая незавершённая функция кадр. Рекурсия придёт позже; здесь достаточно «вернуться туда, откуда звали».

Имя — глагол или «существительное от действия»: `count_nonzero`, не `data2`. Один экран тела. Если объясняете функцию через «и ещё», режьте.

```text
ФУНКЦИЯ clip(x, lo, hi):
  если x < lo вернуть lo
  если x > hi вернуть hi
  вернуть x

команда ← clip(сырая, 0, 100)
```

Верх: «ограничили команду». Низ: сравнения. Меняете пороги в одном месте.
