# Циклы

Ветка выбирает путь раз. Цикл возвращает к тем же шагам: **условие или набор** плюс **тело**. Проход — итерация.

«Пока» — пока выражение истинно; тело должно когда-нибудь сделать его ложным, иначе вечность. «Для каждого» — элементы по очереди, конец обычно от длины набора. Счётный: N раз или `i` от 0 до N−1, когда нужен индекс.

Тело меняет состояние (счётчик, следующий байт, сумма); условие смотрит на него. Забыли обновить — вечный цикл. Досрочный выход и «к следующей» — умеренно, иначе граф прыжков; чаще яснее условие.

Вложенность: все пары — порядка N². Сначала правильность, потом «хватит ли одного прохода». Ожидание события на роботе: цикл с таймаутом, не «пока Вселенная».

```text
сумма ← 0
для каждого x в списке:
  сумма ← сумма + x
```

Пока с датчиком: счётчик попыток или время, иначе стенд не отойдёт от «ещё секунду».

## Практика

### Задание 1. Пока vs для каждого

Сумма списка vs «жди кнопку, но не дольше 3 с». Какой цикл и что гарантирует конец?

### Задание 2. Забыли обновить

`пока i < 10` тело печатает i, i не растёт. Что происходит и какой минимальный фикс?

### Задание 3. N²

Для каждого элемента сравнить со всеми. На n=5 сколько сравнений? Когда это ещё терпимо в учебном скрипте?

### Задание 4. Break

Цикл по файлу, нашли первую ошибку — выйти. Когда break яснее флага `found`, когда флаг лучше?

Дальше именованный кусок шагов: **функции**.
