# Операторы

Оператор из операндов делает новое значение или меняет состояние. Унарные: `не ready`, `-x`. Бинарные: `a + b`, `x > y`.

Арифметика: `+ - * /`, остаток, иногда степень. Целое деление может отбросить дробь. Остаток — «каждый десятый», чередование.

Сравнение даёт логическое. Однородное с однородным. Вещественное `==` часто ложь из-за погрешности — порог близости.

Логика: И истинно только если оба; ИЛИ если хотя бы один; НЕ переворачивает. Безопасность робота: «датчик ок И скорость в диапазоне И НЕ стоп».

Присваивание пишет в переменную. `+=` разворачивайте в уме в полное «взять, изменить, записать». Приоритет: арифметика крепче сравнений, сравнения крепче логики, присваивание слабое. Сомневаетесь — скобки. Один символ `+` для чисел сумма, для строк склейка — смотрите типы, не картинку.

```text
ok ← (temp > 0) И (temp < 80)
n ← n + 1
```

`=` в одних языках присвоить, в других сравнить. Не переносите привычку вслепую.

## Практика

### Задание 1. Три равенства

Присвоить, сравнить, «почти равно» для float. Напишите три разных шага и что сломается, если взять не тот.

### Задание 2. Таблица И/ИЛИ

Датчик ок да/нет, стоп да/нет. Когда ехать при «ок И НЕ стоп»? Когда ИЛИ был бы опасен?

### Задание 3. Остаток

Индекс 0…21, каждый третий пишем в лог. Какое условие с остатком? Прогон на 0, 1, 2, 3.

### Задание 4. Приоритет

`не a И b` без скобок. Два разных смысла скобками. Какой нужен для «не (оба)»?

Дальше выбор пути: **ветвление**.
