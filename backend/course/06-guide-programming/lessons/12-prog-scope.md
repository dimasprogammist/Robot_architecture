# Область видимости

Вы завели `скорость` внутри функции, а снаружи её «нет». Это не поломка языка. **Область видимости** — правило, из каких мест имя видно. Локальное имя живёт в функции (часто в блоке) и умирает, когда функция кончилась. Параметр — тоже локальное имя: дырка входа, не глобальная ячейка с тем же словом.

Зачем так. Если бы все имена были общими на всю программу, два автора назвали бы счётчики одинаково и стёрли бы друг другу работу. Локальность — забор. Снаружи функцию вызывают, внутрь не лезут руками к её черновикам.

Глобальные имена видны многим местам. Иногда это настройки «лимит попыток». Часто это ловушка: функция молча читает и пишет общее, тесты врут, параллельные куски дерутся. Правило по умолчанию: данные входят аргументами, выходят возвратом.

Вложенность: внутри цикла имя `элемент` не обязано существовать после цикла — зависит от языка. Не переносите привычку вслепую. Тень: внутреннее `x` закрывает внешнее `x` на время. Читать тяжело. Лучше разные слова.

```text
лимит ← 3                    # снаружи, если так задумали

ФУНКЦИЯ попытка(n):
  осталось ← лимит - n       # читает внешнее — уже спорно
  ВЕРНУТЬ осталось

ФУНКЦИЯ попытка_лучше(n, лимит):
  ВЕРНУТЬ лимит - n
```

Второй вариант можно вызвать с разными лимитами без правки «всей программы».

Область видимости позже встретится в модулях: имя из файла датчиков не то же, что имя из файла экрана, даже если оба `helper`.

## Практика

### Задание 1. Снаружи не видно

Функция посчитала `сумма` внутри и не вернула. Снаружи пишут `напечатать сумма`. Почему исполнитель прав, отказываясь? Как починить замысел?

### Задание 2. Одинаковые слова

Снаружи `скорость ← 5`. Функция с параметром `скорость` делает `скорость ← 0`. Что станет с внешней ячейкой в учебной модели «числа копируют»? Зачем тогда возврат?

### Задание 3. Глобальный лимит

Фильтр читает глобальный `порог`. Два вызова подряд хотят разные пороги. Почему тесты врут? Как аргумент лечит?

### Задание 4. Тень

Внутри функции завели своё `x`, снаружи тоже `x`. Почему отладка «я же менял x» сходит с ума? Как назвать внутреннее честнее?
