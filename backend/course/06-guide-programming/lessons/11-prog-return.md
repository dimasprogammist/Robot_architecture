# Возврат значения

Функция умеет принимать данные. Этого мало, если после работы снаружи ничего нельзя взять в руки. **Возврат** — способ сказать вызывающему: «результат вот этот». В псевдокоде: `ВЕРНУТЬ выражение`. Снаружи: `y ← ограничить(скорость)`.

Печать на экран — другое. Человек увидит число, следующая строка программы его **не получит**, если вы только напечатали. Отладочная печать помогает вам, возврат помогает алгоритму. Путать их — собрать программу, которая «вроде работает в консоли», а встроить в робота нельзя: мотору нужно число, не картинка текста.

Возврат обычно сразу заканчивает тело: дальше строки не выполняются. Несколько точек возврата нормальны, если ветки покрывают случаи: плохой вход — сразу отказ, хороший — ответ. Иногда яснее одна переменная `результат` и один возврат в конце. Выбирайте то, что читается, не «как в учебнике 1998 года».

Если цель — посчитать число, флаг, новую строку, не прячьте ответ в глобальную переменную «на всех». Глобаль потом невозможно тестировать: соседний вызов подменит значение. Процедуры без возврата тоже нужны: сохранить файл, дёрнуть реле. Тогда контракт другой: «сделай эффект», не «дай число».

Ошибки: вернуть особое значение, пару «успех + данные» или позже — исключение. Главное не молчать. Вызывающий должен отличить «скорость 0 потому что стоим» от «датчика нет».

Цепочка естественна: `показать(ограничить(прочитать()))`. Каждый кусок маленький, результат течёт дальше.

```text
ФУНКЦИЯ ограничить(x, низ, верх):
  если x < низ:
    ВЕРНУТЬ низ
  если x > верх:
    ВЕРНУТЬ верх
  ВЕРНУТЬ x

команда ← ограничить(сырая, 0, 100)
```

Верхний уровень читается: «ограничили команду». Внутри — сравнения. Мотору отдают `команда`, а не надеются, что кто-то прочитал печать.

## Практика

### Задание 1. Печать или возврат

Функция считает сумму двух чисел и только печатает её. Почему следующая функция не может использовать эту сумму? Исправьте замысел без кода языка: что должно вернуться?

### Задание 2. Ранний выход

Вход пустой. Почему сразу вернуть «нет данных» яснее, чем огромный `иначе` вокруг всей работы? Нарисуйте две ветки.

### Задание 3. Ноль как ответ и как беда

Температура 0 °C — норма. Датчик молчит — тоже хочется «положить 0». Как возврат должен различить эти случаи? Не обязательно код — контракт.

### Задание 4. Цепочка

Три шага: прочитать список, найти максимум, ограничить его сотней. Где возвраты, где хватит одной процедуры с эффектом? Почему максимум не должен только печататься?

Дальше имена живут не вечно и не везде: **область видимости**.
