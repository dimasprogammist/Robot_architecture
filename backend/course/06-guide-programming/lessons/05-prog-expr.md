# Выражения

Выражение — вопрос «чему равно?»: `3 + 4`, `speed * dt`, `count > 0`, `name + "-v2"`. У результата тип. **Инструкция** — приказ: присвоить, напечатать, крутить цикл. Справа в `x ← 3 + 4` выражение, слева действие. Путаница: ждать значение от конструкции, которая только меняет мир.

Простое выражение — литерал или имя. Составное — операторы и вызовы, внутри наружу, плюс приоритет и скобки. `(a + b) * c` для читателя лучше памяти таблицы. Побочный эффект внутри формулы (`x` меняется в середине) на обучении вреден: сначала посчитать, потом присвоить.

Цепочка `h(g(f(x)))` — тоже выражения. Промежуточные имена — ясность, не слабость. Условие ветки почти всегда хочет логическое; «почти истина» по правилам языка — минное поле.

```text
dt ← 0.1
delta ← speed * dt
едет ← speed > 0
```

Три понятных имени лучше одной непрозрачной строки в отладке.

## Практика

### Задание 1. Выражение или приказ

`напечатать x`, `x + 1`, `x ← x + 1`. Что вычисляется в значение, что только действует? Где можно подставить вместо `y`?

### Задание 2. Скобки

`a + b * c` при a=1, b=2, c=3. Чему равно и как скобками получить другую сумму?

### Задание 3. Побочный эффект

Почему менять счётчик внутри условия `пока` в том же выражении, что и сравнение, опасно? Разнесите на две инструкции.

### Задание 4. Подвыражение

Формула «проехали путь за dt, если скорость положительна». Разбейте на два выражения и одно имя для логического.

Дальше азбука знаков внутри выражений: **операторы**.
