# Переменная

Переменная — **имя**, связанное со **значением** в памяти во время выполнения. `speed`, `count`, `user_name`. Тип значения — следующий урок. Коробка — неполная аналогия: иногда лежит само число, иногда ссылка. Пока модель: по ярлыку программа находит, что сейчас лежит.

Присваивание `x ← 10` или `x = 10`: отныне имя значит это значение. `x ← x + 1` — не уравнение алгебры: справа считают, слева пишут. До первого присваивания чтение часто ошибка. Потом значение живёт, пока не сменят или не умрёт область видимости.

Имена для людей. `tmp2` в десяти местах прячет алгоритм. `battery_percent`, `is_ready` читаются как текст. Константа — параметр, который по смыслу не трогают («лимит попыток = 3»), не путать со счётчиком попыток. Одна переменная — один смысл: флаг и код ошибки в одной ячейке — археология.

```text
count ← 0
count ← count + 1
# count сейчас 1
```

Робот: `is_ready` не должен на следующем шаге внезапно стать числом оборотов.
