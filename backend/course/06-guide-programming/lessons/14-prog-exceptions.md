# Исключения

Возврат «особого числа» путается с настоящим ответом. Код ошибки, который забыли проверить, живёт дальше как будто всё хорошо. **Исключение** — другой канал: «нормальный ход прерван, вот что случилось». Выполнение прыгает к обработчику, если он есть, иначе программа заканчивается с сообщением.

Идея для новичка: вызов вроде «прочитай файл» либо даёт содержимое, либо сообщает, что файла нет — и вы **не можете случайно принять «нет файла» за пустой текст**, если только сами так не решили.

Обработка: «попробовать шаг; если случился такой-то сбой — вот запасной путь». Не оборачивайте всю программу в «поймать вообще всё и промолчать». Молчание хуже падения: робот едет дальше без карты.

Где ловить? Там, где вы знаете, что делать человеку или системе: другой файл, повтор, безопасный стоп. Там, где не знаете, — пусть летит выше, к тому, кто знает. Ловить у самого дна и игнорировать — спрятать болезнь.

Исключения не заменяют проверки входа. Если пустой список запрещён, можно сразу вернуть понятный отказ или бросить исключение — но не делать вид, что среднее из ничего равно нулю.

В Python позже будут свои имена ошибок. Здесь достаточно: нормальный возврат для нормы, исключение для срыва, и не путать с печатью.

```text
ПОПРОБОВАТЬ:
  текст ← прочитать(путь)
ИСКЛЮЧЕНИЕ «нет файла»:
  сказать человеку и остановиться
```

После успешного чтения работа идёт как раньше. Нет файла — не делим и не подаём мотору пустоту.

## Практика

### Задание 1. Ноль или исключение

Функция среднего. Пустой список: вернуть 0, вернуть «пусто», бросить исключение. Для робота на конвейере какой контракт честнее и почему 0 опасен?

### Задание 2. Поймали всё

«Любая ошибка — напечатать ок и дальше». Почему это хуже падения на стенде? Приведите пример скрытой беды.

### Задание 3. Где ловить

Чтение конфига глубоко внутри. Кто должен решить «взять конфиг по умолчанию»: нижняя функция, которая не знает смысла робота, или верх, который знает?

### Задание 4. Не вместо if

Скорость отрицательная — ожидаемый вход. Почему обычная ветка `если` здесь уместнее исключения? Когда наоборот файл «обязан быть»?
