# Ветвление

Без ветки программа одна дорога и не реагирует на вход. Условие — логическое выражение; истина → шаги A, иначе → B. Иначе можно не быть: «если ошибка — стоп», дальше общий путь.

```text
ЕСЛИ условие:
  шаги A
ИНАЧЕ:
  шаги B
```

Несколько порогов — цепочка иначе-если, не десять независимых `если` подряд, которые все могут сработать. Вложенность глубже трёх уровней почти всегда можно сплющить именами (`is_safe`) или ранним выходом.

Порядок проверок важен: сначала дешёвое и частое, опасное — раньше, чем дорогое. Пустая ветка «чтобы было» хуже явного ничего. Сравнивайте однородное; `если speed` в языке, где число «как истина», прячет порог.

Робот: сначала авария, потом «едь». Иначе красивый круиз переедет концевик.

Лапша из вложений — признак, что условие не назвали. Вынесите логическое имя, читайте верх как протокол.

## Практика

### Задание 1. Два порога

Температура: холодно / норма / жарко. Цепочка иначе-если и почему три отдельных `если` опасны.

### Задание 2. Порядок

«Нет связи» и «батарея < 5%». Какое первым и почему для безопасности?

### Задание 3. Имя условия

Вложили пять `если`. Вынесите `can_move`. Что стало читаться на верхнем уровне?

### Задание 4. Нет иначе

Ветка только на ошибку, успех идёт дальше. Когда это яснее, чем пустой `иначе`?

Дальше повтор шагов: **циклы**.
