# Типы значений

Тип — соглашение: что значат биты и какие операции законны. `42` и `"42"` для человека похожи; для программы арифметика и текст — разные миры.

Встречаются почти везде: целые (счётчики, индексы); вещественные (измерения, приближение); логический (истина/ложь, основа веток); строки; пусто («здесь ничего», None/null — детали языка). Составные — список, словарь, запись: тип есть и у «коробки из частей».

Статическая проверка до запуска или динамическая в рантайме — одна идея: операция должна соответствовать природе. Сложить числа нормально. Смешать без правила преобразования — ошибка или сюрприз (`"3" + 1` в разных языках разное).

Целое vs вещественное: деньги и счётчики не любят «почти 2.999». Логический не третье число «типа 2». Пусто — не ноль и не пустая строка, пока вы сами так не определили.

Язык модуля дальше — Python, но урок про мысль, не про синтаксис аннотаций.

```text
n ← 3          # целое
t ← "3"        # текст
ok ← ложь      # логический
```

Сложить `n` и `t` без явного перевода — вопрос к языку, не «очевидно 6».

### Задание 2. Пусто vs ноль

Датчик не ответил vs температура 0. Почему один тип «пусто», другой целое/вещественное? Что сделает ветка `если x = 0` в обоих случаях?

### Задание 3. Вещественное

Два сложения 0.1. Почему «просто деньги float» плохая идея даже без курса численки? Где на роботе float уместен?
