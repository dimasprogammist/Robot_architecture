# Циклы

## Цель

Понять циклы как способ повторять шаги без копирования кода: пока условие истинно, или для каждого элемента набора. После урока вы сможете выбирать вид цикла, гарантировать завершение и отличать логику тела от условия продолжения.

## Что уже пройдено

Ветвление выбирает путь один раз. Цикл многократно возвращает выполнение к одним и тем же шагам. Вместе с переменными это даёт обработку списков, ожидание событий и накопление результатов.

## Объяснение с нуля

Цикл состоит из **условия продолжения** (или набора элементов) и **тела** — шагов, которые повторяются. Каждый проход тела — итерация.

Два больших семейства:

1. **Цикл с условием** («пока» / while): повторять, пока выражение истинно. Нужно, чтобы внутри тело когда-нибудь сделало условие ложным — иначе получится бесконечный цикл.
2. **Цикл по коллекции** («для каждого» / for-each): взять элементы по очереди. Конечность обычно следует из конечности набора.

Есть и счётные циклы: «повторить N раз» или «для i от 0 до N-1». Это удобная форма, когда важны индексы.

Тело цикла часто меняет состояние: увеличивает счётчик, читает следующий байт, накапливает сумму. Условие должно смотреть на это состояние. Классическая ошибка — забыть обновить переменную условия.

Иногда нужен досрочный выход (`break` как идея) или переход к следующей итерации (`continue`). Пользуйтесь ими умеренно: частые прыжки превращают цикл в запутанный граф. Часто яснее уточнить условие или вложить проверку.

Вложенные циклы допустимы (матрица, сравнение всех пар), но стоимость быстро растёт: двойной проход по N элементам — порядка N² шагов. Сначала думайте о правильности, потом о том, нельзя ли обойтись одним проходом.

Цикл «пока питание есть» в контроллере — особый случай: это сервисный режим, а не баг. В учебных задачах обработки данных бесконечность почти всегда ошибка.

## Термины

- **Итерация** — один проход тела цикла.
- **Условие продолжения** — логика «повторять ещё?»
- **Тело цикла** — повторяемые шаги.
- **Бесконечный цикл** — условие никогда не становится ложным (иногда намеренно в сервисах).
- **Инвариант цикла** — утверждение, истинное перед/после каждой итерации.
- **Счётчик / индекс** — переменная, нумерующая шаги или позиции.

## Внутреннее устройство

Цикл — это условный переход назад: выполнили тело → проверили условие → прыгнули к началу или пошли дальше. Процессор снова и снова гоняет один и тот же участок кода с разными данными в регистрах и памяти.

Инвариант помогает доказывать правильность. Для суммы списка инвариант: «`sum` равен сумме уже просмотренных элементов». На старте сумма нулевая и просмотренных нет; в конце просмотрены все — `sum` верен. Даже неформальное удержание инварианта в голове снижает число ошибок.

Изменение коллекции во время обхода — опасная зона: пропуск элементов, выход за границы, сюрпризы итератора. На вводном уровне лучше сначала собрать изменения, потом применить, или явно идти по копии индексов.

Индексы обычно считают с нуля в современных языках: первый элемент — позиция 0, последний — `длина - 1`. Выход за границу — классическая ошибка выполнения.

Связка «цикл + ветвление» — нормальная композиция: для каждого элемента решить, учитывать его или нет.

## Пример

```text
Задача: посчитать число элементов больше порога.

list ← [1, 7, 3, 9, 2]
threshold ← 5
count ← 0

ДЛЯ каждого x в list:
  ЕСЛИ x > threshold:
    count ← count + 1

# эквивалентная идея циклом "пока":
i ← 0
count ← 0
ПОКА i < длина(list):
  x ← list[i]
  ЕСЛИ x > threshold:
    count ← count + 1
  i ← i + 1

Результат: count = 2  (элементы 7 и 9)

# Python-иллюстрация:
count = 0
for x in [1, 7, 3, 9, 2]:
    if x > 5:
        count += 1
```

## Разбор

Вариант «для каждого» скрывает индекс — читать легче, когда индекс не нужен. Вариант «пока» делает индекс явным: видно, что `i` растёт и условие `i < длина` когда-нибудь станет ложным.

Если забыть `i ← i + 1`, цикл станет бесконечным: классическая демонстрация связи условия и обновления. Вложенное ветвление внутри цикла — нормальная композиция: повторяем проверку для каждого элемента.

Инвариант здесь: после k итераций `count` равен числу элементов среди первых k, которые больше порога. Это помогает проверить граничные случаи: пустой список → 0; все меньше порога → 0.

Оба варианта должны давать одинаковый ответ на одних данных — хороший способ самопроверки при переписывании формы цикла.

## Ошибки

- Забыть обновлять переменную условия.
- Выходить за границы массива индексом.
- Менять коллекцию во время обхода без правил.
- Путать «повторить N раз» с «пока условие» и получать лишние/недостающие итерации.
- Писать вложенность «на всякий случай», когда достаточно одного прохода.

## Что запомнить

Цикл повторяет тело по условию или по элементам. Нужно гарантировать прогресс к завершению (или явно держать сервисный цикл). Инвариант помогает думать о правильности. Ветвление внутри цикла — обычная композиция. Индексы требуют аккуратности с границами.

## Задание

Напишите алгоритм поиска первого элемента, равного целевому, с возвратом индекса или сообщения «не найден». Сделайте версии `для каждого` и `пока`. Прогоните на списках, где элемент в начале, в конце и отсутствует.
