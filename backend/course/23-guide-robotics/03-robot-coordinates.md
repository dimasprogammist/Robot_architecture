# Координаты, положение и движение робота

## Цель

Чтобы управлять роботом, недостаточно сказать ему «двигайся туда». Компьютеру нужно описать положение объекта численно.

Для этого используются координаты и системы отсчёта.

После урока вы должны понимать:

* что такое система координат;
* как описывается положение объекта;
* чем положение отличается от ориентации;
* что такое X, Y и Z;
* что такое углы поворота;
* зачем роботу несколько систем координат;
* как описывать движение мобильного робота и манипулятора;
* почему координаты являются основой навигации и кинематики.

---

# Зачем роботу координаты

Представим человека.

Мы можем сказать:

> Машина находится справа от двери.

Человек понимает смысл фразы.

Компьютеру нужна более точная информация.

Например:

```text
X = 4.2 м
Y = 1.7 м
```

Теперь положение можно представить численно.

Если робот находится на плоскости, достаточно двух координат:

```text
X
↑
│
│       ● Робот
│
│
└────────────→ Y
```

Если рассматриваем трёхмерное пространство, появляется третья координата:

```text
        Z
        ↑
        │
        │
        └────→ Y
       /
      /
     X
```

---

# Система координат

Система координат задаёт:

* начало отсчёта;
* направления осей;
* единицы измерения.

Например:

```text
        Y
        ↑
        │
        │
        │
        └────────→ X
       (0,0)
```

Точка:

```text
X = 3
Y = 2
```

находится в координатах:

```text
(3, 2)
```

Для робота это может означать:

```text
3 метра по X
2 метра по Y
```

---

# Начало координат

Точка:

```text
(0, 0)
```

называется началом координат.

В трёхмерном пространстве:

```text
(0, 0, 0)
```

Начало координат выбирается относительно конкретной системы.

Например, на карте склада можно сказать:

```text
левый нижний угол склада = (0, 0)
```

А затем описывать расположение роботов относительно этой точки.

---

# Положение робота

Для простого мобильного робота на плоскости положение можно описать:

```text
x
y
```

Но этого недостаточно.

Представим робота:

```text
      ↑
      │ направление
      │
    ┌─┴─┐
    │ R │
    └───┘
```

Он находится в одной и той же точке, но может смотреть:

```text
вверх
```

или:

```text
вправо
```

или:

```text
вниз
```

Поэтому нам нужна ещё ориентация.

---

# Положение и ориентация

Для мобильного робота на плоскости часто используется три параметра:

```text
x
y
θ
```

где:

* `x` — положение по одной оси;
* `y` — положение по другой оси;
* `θ` — угол ориентации.

Например:

```text
x = 5.0 м
y = 2.0 м
θ = 90°
```

Это означает:

```text
робот находится в точке (5, 2)
и ориентирован под углом 90°.
```

Такое описание называется **позой робота**.

---

# Поза

В робототехнике часто используется термин **pose** — поза или положение с ориентацией.

Для двумерного робота:

```text
Pose = (x, y, θ)
```

Например:

```text
Pose = (10, 4, 180°)
```

можно представить так:

```text
10 м по X
4 м по Y
ориентация 180°
```

Для трёхмерного объекта положение уже включает:

```text
X
Y
Z
```

а ориентация — три угловых параметра.

Упрощённо:

```text
Position:
(X, Y, Z)

Orientation:
(угол вокруг X,
 угол вокруг Y,
 угол вокруг Z)
```

---

# Почему появляется Z

На плоском складе робот может двигаться:

```text
X
Y
```

Но для дрона этого недостаточно.

Дрон может находиться:

```text
X = 10 м
Y = 5 м
Z = 3 м
```

где:

```text
Z = высота
```

Получается:

```text
             Z
             ↑
             │     ● дрон
             │    /
             │   /
             │  /
             └────────→ Y
            /
           /
          X
```

Поэтому летающие роботы работают в полноценном трёхмерном пространстве.

---

# Ориентация в пространстве

Положение отвечает на вопрос:

> Где находится объект?

Ориентация:

> Куда он повернут?

Например, камера может находиться в точке:

```text
(2, 3, 1)
```

но быть направлена:

```text
вперёд
```

или:

```text
влево
```

или:

```text
вниз
```

Это разные состояния при одинаковом положении.

---

# Углы

Для описания ориентации используют углы.

Часто встречаются названия:

```text
Roll
Pitch
Yaw
```

Упрощённо:

```text
Roll  — вращение вокруг продольной оси
Pitch — наклон вперёд/назад
Yaw   — поворот влево/вправо
```

Для самолёта или дрона это особенно важно.

```text
        Pitch
          ↕
          
Roll  ←  ●  →  Roll

          ↻
         Yaw
```

Например:

```text
Yaw = 90°
```

может означать поворот вокруг вертикальной оси на 90°.

---

# Системы координат у робота

На практике у робота редко бывает только одна система координат.

Например, есть:

```text
Мировая система
       ↓
система робота
       ↓
система камеры
       ↓
система датчика
```

Почему?

Потому что каждый компонент имеет своё положение.

Например, камера установлена:

```text
на 20 см выше центра робота
```

и смотрит немного вниз.

Для робота это означает, что координаты камеры отличаются от координат корпуса.

---

# Мировая система координат

Представим склад.

```text
                 Y
                 ↑
                 │
        ┌────────┼───────┐
        │        │       │
        │        │   ● R │
        │        │       │
        └────────┴───────┘
                 └──────→ X
```

Можно принять:

```text
(0,0)
```

за угол помещения.

Тогда все роботы могут описывать своё положение относительно этой системы.

Например:

```text
Robot A:
(2, 5)

Robot B:
(8, 3)
```

---

# Система координат робота

Сам робот имеет собственную систему координат.

Обычно её начало находится примерно в центре платформы.

```text
        Y
        ↑
        │
    ┌───┼───┐
    │   ●   │
    └───────┘
        └────→ X
```

Теперь можно сказать:

```text
датчик находится:
X = 0.2 м
Y = 0.1 м
```

относительно центра робота.

---

# Зачем преобразовывать координаты

Представим, что камера обнаружила объект.

Камера сообщает:

```text
объект находится
на 1 м впереди
и на 0.3 м левее
```

Это координаты относительно камеры.

Но системе навигации нужно знать:

> Где этот объект находится относительно мира?

Для этого требуется преобразование координат.

Концептуально:

```text
координаты камеры
       ↓
преобразование
       ↓
координаты робота
       ↓
преобразование
       ↓
мировые координаты
```

Именно поэтому системы координат являются фундаментальной частью робототехники.

---

# Движение по координатам

Допустим, робот находится:

```text
(2, 3)
```

и должен попасть в:

```text
(7, 3)
```

Тогда ему нужно переместиться:

```text
ΔX = 7 - 2 = 5
ΔY = 3 - 3 = 0
```

То есть:

```text
5 метров по X
```

Если цель:

```text
(7, 6)
```

то:

```text
ΔX = 5
ΔY = 3
```

---

# Расстояние между точками

Для двух точек:

```text
A = (x₁, y₁)
B = (x₂, y₂)
```

расстояние можно найти по теореме Пифагора:

```text
d = √((x₂ - x₁)² + (y₂ - y₁)²)
```

Например:

```text
A = (1, 1)
B = (4, 5)
```

Тогда:

```text
Δx = 3
Δy = 4
```

и:

```text
d = √(3² + 4²)
  = √25
  = 5
```

То есть между точками 5 единиц расстояния.

Это простая математика, но она постоянно используется в робототехнике.

---

# Направление к цели

Одного расстояния недостаточно.

Роботу нужно знать, **куда двигаться**.

Для этого можно определить направление от текущей точки к цели.

Например:

```text
Robot
  ●──────────────→
                 ● Goal
```

Если робот уже ориентирован в сторону цели, задача простая.

Если нет:

```text
      Goal
        ●
       /
      /
     /
    ● Robot
      ↑
      │ текущее направление
```

сначала нужно изменить ориентацию, а затем двигаться.

---

# Скорость

Положение показывает:

```text
где робот
```

Скорость показывает:

```text
как быстро он движется
```

Например:

```text
v = 1 м/с
```

означает, что за одну секунду робот проходит примерно один метр, если скорость постоянна.

Для мобильного робота можно отдельно рассматривать:

```text
линейную скорость
```

и:

```text
угловую скорость
```

Линейная:

```text
м/с
```

Угловая:

```text
рад/с
```

---

# Поворот робота

Робот может одновременно:

```text
двигаться вперёд
```

и:

```text
поворачиваться
```

Для этого его состояние может включать:

```text
x
y
θ
v
ω
```

где:

* `x`, `y` — положение;
* `θ` — ориентация;
* `v` — линейная скорость;
* `ω` — угловая скорость.

Такой набор параметров уже позволяет описывать достаточно много ситуаций.

---

# Координаты манипулятора

Для манипулятора задача становится интереснее.

Представим руку:

```text
Основание
   ●
   │
   └────●
        │
        └────●
             │
             └── Захват
```

Нам нужно узнать:

> Где находится захват?

При этом мы знаем углы суставов.

Например:

```text
Сустав 1 = 30°
Сустав 2 = 45°
Сустав 3 = 10°
```

По этим значениям можно вычислить положение рабочего органа.

Это называется **прямой кинематикой**.

---

# Обратная задача

Теперь наоборот.

Мы хотим:

```text
Захват → точка (X, Y, Z)
```

и спрашиваем:

> Какие углы суставов нужны?

Это уже **обратная кинематика**.

Упрощённо:

```text
Углы суставов
      ↓
Прямая кинематика
      ↓
Положение захвата
```

и наоборот:

```text
Желаемое положение
      ↓
Обратная кинематика
      ↓
Углы суставов
```

Эту тему мы подробно разберём позже.

---

# Координаты и навигация

Для мобильного робота координаты являются основой навигации.

Например:

```text
Старт:
(1, 1)

Цель:
(8, 5)
```

Навигационная система может построить маршрут:

```text
(1,1)
  ↓
(3,1)
  ↓
(3,4)
  ↓
(8,4)
  ↓
(8,5)
```

Робот должен последовательно двигаться между этими точками.

Такие промежуточные точки часто называют **waypoints**.

---

# Почему координаты не идеальны

На практике робот редко знает своё положение абсолютно точно.

Например, энкодеры могут показать:

```text
робот проехал 5.0 м
```

Но реальные 5 метров могут оказаться:

```text
4.8 м
```

или:

```text
5.2 м
```

Причины:

* проскальзывание колёс;
* неровность поверхности;
* ошибки датчиков;
* неточность измерений;
* механический люфт;
* внешние воздействия.

Поэтому робототехника работает не только с координатами, но и с **оценкой состояния**.

---

# Координаты в реальной системе

Рассмотрим робота на складе.

```text
             Y
             ↑
             │
       ┌─────┼───────────┐
       │     │           │
       │     │     ● R   │
       │     │    ↗      │
       │     │           │
       └─────┴───────────┘
             └──────────→ X
```

Робот может иметь:

```text
X = 12.4 м
Y = 5.8 м
Yaw = 35°
```

Навигационная система может сказать:

```text
Цель:
X = 18.0 м
Y = 8.0 м
```

Контроллер движения получает задачу приблизиться к этой точке.

Дальше уже используются:

* кинематика;
* скорость;
* регуляторы;
* датчики;
* планирование движения.

---

# Главное различие

Важно не путать:

### Положение

```text
Где находится объект?
```

### Ориентация

```text
Куда он повернут?
```

### Скорость

```text
Как быстро он движется?
```

### Ускорение

```text
Как изменяется скорость?
```

Например:

```text
Robot:

Position:
X = 10 м
Y = 4 м

Orientation:
Yaw = 90°

Velocity:
1 м/с
```

Это уже достаточно подробное описание состояния мобильного робота.

# Итог

Координаты позволяют роботу описывать пространство численно.

Для простой плоской системы достаточно:

```text
X
Y
```

Для мобильного робота добавляется ориентация:

```text
X
Y
θ
```

Для трёхмерной системы:

```text
X
Y
Z
```

и параметры ориентации.

На основе координат строятся:

* навигация;
* кинематика;
* планирование движения;
* управление манипуляторами;
* работа камер и датчиков;
* оценка положения робота.

Поэтому координатная система — это один из фундаментальных языков, на котором разные части робототехнической системы описывают пространство и движение.
