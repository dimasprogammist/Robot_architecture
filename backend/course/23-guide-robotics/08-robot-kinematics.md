# Кинематика робота

## Цель

Кинематика позволяет описывать связь между движением отдельных частей робота и положением его рабочего органа или корпуса.

Она особенно важна для манипуляторов, но используется и в мобильной робототехнике.

После урока вы должны понимать:

* что такое кинематика;
* что такое звено и сустав;
* что такое степень свободы;
* что такое прямая кинематика;
* что такое обратная кинематика;
* почему у одной точки может быть несколько вариантов достижения;
* как координаты связаны с суставами робота;
* почему кинематика является связующим звеном между механикой и управлением.

---

# Что такое кинематика

Кинематика изучает движение без подробного рассмотрения причин этого движения.

В робототехнике нас часто интересует вопрос:

> Где находится рабочий орган робота?

Например:

```text
        Захват
           ●
          /
         /
        ●
       /
      ●
      │
   основание
```

Мы знаем углы суставов и длины звеньев.

Нужно определить:

```text
X
Y
Z
```

координаты захвата.

Это задача кинематики.

---

# Механизм робота

Манипулятор обычно состоит из:

```text
основание
   ↓
сустав
   ↓
звено
   ↓
сустав
   ↓
звено
   ↓
рабочий орган
```

### Звено

Жёсткая часть механизма между суставами.

### Сустав

Механическое соединение, которое позволяет выполнять определённое движение.

Например:

```text
вращательный сустав
```

позволяет вращаться вокруг оси.

---

# Простой двухзвенный манипулятор

Рассмотрим механизм:

```text
        ● конец
       /
      / L2
     ●
    /
   / L1
  ●
основание
```

Пусть:

```text
L1 = длина первого звена
L2 = длина второго звена
```

и:

```text
θ1 = угол первого сустава
θ2 = угол второго сустава
```

Нужно найти положение конца.

---

# Прямая кинематика

Прямая кинематика отвечает:

> Если известны углы суставов, где окажется рабочий орган?

Упрощённо:

```text
Углы суставов
      ↓
Прямая кинематика
      ↓
Координаты конца
```

Для плоского двухзвенного манипулятора:

```text
x = L1 cos(θ1) + L2 cos(θ1 + θ2)

y = L1 sin(θ1) + L2 sin(θ1 + θ2)
```

Эти формулы позволяют вычислить положение рабочего органа.

---

# Пример

Пусть:

```text
L1 = 1 м
L2 = 1 м

θ1 = 0°
θ2 = 0°
```

Оба звена направлены вправо:

```text
●──────●──────●
```

Получаем:

```text
x = 2
y = 0
```

Рабочий орган находится:

```text
(2, 0)
```

---

# Другой пример

Теперь:

```text
θ1 = 90°
θ2 = 0°
```

Механизм направлен вверх:

```text
      ●
      │
      ●
      │
      ●
```

Получаем примерно:

```text
x = 0
y = 2
```

---

# Если второй сустав повернут

Пусть:

```text
θ1 = 0°
θ2 = 90°
```

Тогда первое звено идёт вправо, а второе поворачивается относительно него.

```text
      ●
      │
      │
      ●──────●
     база
```

Положение зависит от того, как именно определены углы суставов.

Это показывает важность единого соглашения о системах координат.

---

# Обратная кинематика

Теперь поставим задачу наоборот.

Мы хотим:

```text
Захват должен оказаться здесь:

          ●
         /
        /
       /
      ●
```

Но нам неизвестны:

```text
θ1
θ2
```

Нужно найти их.

Это задача **обратной кинематики**.

```text
Желаемая точка
      ↓
Обратная кинематика
      ↓
Углы суставов
```

---

# Почему обратная кинематика сложнее

Прямая кинематика:

```text
углы → координаты
```

обычно вычисляется относительно просто.

Обратная:

```text
координаты → углы
```

может иметь:

* несколько решений;
* одно решение;
* отсутствие решения.

---

# Несколько решений

Представим руку, которая должна достать до точки.

Она может находиться:

```text
локоть сверху
```

или:

```text
локоть снизу
```

Условно:

```text
   ●
  / \
 ●   ●
```

Оба варианта могут привести к одному положению захвата.

Получается:

```text
одна точка
↓
несколько конфигураций
```

---

# Недостижимая точка

У манипулятора есть физический рабочий диапазон.

Если:

```text
L1 = 1 м
L2 = 1 м
```

максимальное расстояние от основания:

```text
2 м
```

Точка:

```text
3 м
```

недостижима.

Программа не может решить эту задачу только математикой.

Механика ограничивает пространство.

---

# Рабочее пространство

Область, в которую робот может достать рабочим органом, называется рабочим пространством.

Для простого двухзвенного манипулятора оно примерно напоминает область между окружностями:

```text
      ┌─────────┐
    /             \
   /   рабочая     \
  |     область     |
   \               /
    \─────────────/
```

Точная форма зависит от:

* длины звеньев;
* диапазонов суставов;
* конструкции;
* ограничителей.

---

# Степени свободы

Каждый независимый тип движения добавляет степень свободы.

Например:

```text
1 сустав
```

может вращаться:

```text
↻
```

Это одна степень свободы.

Два независимых вращательных сустава:

```text
↻ + ↻
```

дают две степени свободы.

---

# Робот с шестью степенями свободы

Промышленный манипулятор часто имеет шесть степеней свободы.

Они позволяют управлять:

```text
X
Y
Z
```

и:

```text
ориентацией
```

по трём осям.

Условно:

```text
3 степени → положение

3 степени → ориентация
```

В результате рабочий орган можно расположить в трёхмерном пространстве и повернуть нужным образом.

---

# Избыточность

Иногда степеней свободы больше, чем минимально необходимо.

Например:

```text
цель имеет 6 параметров
```

а робот имеет:

```text
7 степеней свободы
```

Тогда существуют дополнительные варианты конфигурации.

Это может быть полезно для:

* обхода препятствий;
* удобной конфигурации;
* уменьшения нагрузки;
* ограничения движения суставов.

---

# Кинематическая цепь

Манипулятор можно представить как цепочку:

```text
Основание
   ↓
Joint 1
   ↓
Link 1
   ↓
Joint 2
   ↓
Link 2
   ↓
Joint 3
   ↓
Link 3
   ↓
End Effector
```

Каждый сустав меняет положение следующего звена.

В результате изменение одного угла может изменить положение всего рабочего органа.

---

# Рабочий орган

Конечная часть робота называется **end effector**.

Это может быть:

* захват;
* присоска;
* сварочная головка;
* сверло;
* камера;
* инструмент;
* измерительный датчик.

Кинематически нас часто интересует именно положение этой точки или инструмента.

---

# Простая программа прямой кинематики

Для двухзвенного манипулятора можно написать:

```python
import math


L1 = 1.0
L2 = 1.0

theta1 = math.radians(30)
theta2 = math.radians(45)

x = (
    L1 * math.cos(theta1)
    + L2 * math.cos(theta1 + theta2)
)

y = (
    L1 * math.sin(theta1)
    + L2 * math.sin(theta1 + theta2)
)

print("X:", x)
print("Y:", y)
```

Программа получает:

```text
длины звеньев
+
углы суставов
```

и вычисляет:

```text
X
Y
```

рабочего органа.

---

# Кинематика мобильного робота

Кинематика используется не только в манипуляторах.

Рассмотрим двухколёсный робот.

```text
        движение
           ↑
           │
       ┌───┴───┐
       │       │
       └───────┘
         ○   ○
```

Если левое и правое колёса вращаются с одинаковой скоростью:

```text
vL = vR
```

робот движется прямо.

Если:

```text
vL ≠ vR
```

он поворачивает.

То есть скорость отдельных колёс определяет движение корпуса.

Это тоже кинематическая задача.

---

# Почему кинематика важна для программирования

Представим команду:

```text
Переместить захват в точку:

X = 300 мм
Y = 200 мм
Z = 150 мм
```

Контроллеру недостаточно знать только эту точку.

Ему нужно определить:

```text
какие углы суставов
```

а затем:

```text
какие команды отправить приводам
```

Получается цепочка:

```text
Координаты цели
      ↓
Обратная кинематика
      ↓
Углы суставов
      ↓
Контроллеры приводов
      ↓
Двигатели
      ↓
Механика
```

---

# Кинематика и управление

Кинематика отвечает на вопрос:

```text
какое движение должно быть?
```

А регулятор отвечает:

```text
как физически заставить механизм выполнить это движение?
```

Например:

```text
Кинематика:
сустав должен быть 45°

PID:
как управлять мотором,
чтобы сустав достиг 45°
```

Это разные уровни системы.

---

# Ограничения суставов

Реальный сустав редко может вращаться бесконечно.

Например:

```text
-90° ≤ θ ≤ +90°
```

Если алгоритм потребовал:

```text
θ = 150°
```

механика не сможет выполнить команду.

Поэтому кинематическая система должна учитывать:

* пределы углов;
* максимальную скорость;
* максимальное ускорение;
* механические ограничения.

---

# Сингулярность

У некоторых конфигураций робота возникают особые положения, в которых управление становится проблемным.

Например, несколько звеньев могут выстроиться почти в одну линию:

```text
●────●────●
```

В такой конфигурации некоторые направления движения рабочего органа становятся трудноуправляемыми.

Это называется **сингулярностью**.

На начальном уровне важно запомнить только идею:

> Некоторые положения робота математически и физически неудобны для управления.

---

# Кинематическая модель

В программном обеспечении робота можно иметь математическое описание:

```text
Joint 1
  длина = 0.5 м

Joint 2
  длина = 0.4 м

Joint 3
  длина = 0.2 м
```

Затем программа использует эту модель для вычислений.

```text
Модель
  ↓
Кинематические расчёты
  ↓
Положение / траектория
```

Такой подход позволяет сначала вычислить движение математически, а затем передать его реальному роботу.

# Итог

Кинематика связывает:

```text
суставы
    ↓
звенья
    ↓
положение рабочего органа
```

Главные понятия:

```text
Звено
Сустав
Степень свободы
Прямая кинематика
Обратная кинематика
Рабочее пространство
Кинематическая цепь
```

Основные задачи:

```text
углы → положение
```

и:

```text
положение → углы
```

Кинематика особенно важна для манипуляторов, но аналогичные идеи используются и в мобильных роботах.

Следующий шаг — подробнее рассмотреть один из самых распространённых вариантов мобильной робототехники: **дифференциальный привод**.
