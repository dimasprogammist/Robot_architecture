# Дифференциальный привод и мобильные роботы

## Цель

Двухколёсная мобильная платформа — одна из самых простых и одновременно самых важных конструкций в робототехнике.

Она позволяет понять связь между:

* скоростью колёс;
* скоростью робота;
* поворотом;
* радиусом траектории;
* энкодерами;
* кинематикой;
* управлением.

После урока вы должны понимать:

* как устроен дифференциальный привод;
* почему два колеса могут управлять направлением движения;
* как робот едет прямо;
* как робот поворачивает;
* как он разворачивается на месте;
* что такое линейная и угловая скорость;
* как скорость колёс связана с движением робота.

---

# Что такое дифференциальный привод

Рассмотрим простейшего робота:

```text
        перед

      ┌─────────┐
      │         │
      └─────────┘
        ○     ○
       левое правое
       колесо колесо
```

У каждого ведущего колеса свой двигатель.

```text
Левый мотор  → левое колесо
Правый мотор → правое колесо
```

Дополнительно может использоваться:

```text
маленькое свободное колесо
```

которое не управляет движением, а только поддерживает корпус.

---

# Почему два мотора позволяют поворачивать

Пусть оба колеса вращаются одинаково:

```text
vL = 1 м/с
vR = 1 м/с
```

Тогда робот движется прямо.

```text
      ↑
      │
      │
    ┌─┴─┐
    │   │
    └───┘
```

Теперь:

```text
vL = 0.5 м/с
vR = 1.0 м/с
```

Правое колесо движется быстрее.

Робот начинает поворачивать влево.

```text
        ↖
       /
      /
    ┌─┐
    └─┘
```

То есть направление движения определяется разницей скоростей колёс.

---

# Движение прямо

Для движения прямо:

```text
vL = vR
```

Например:

```text
vL = 0.8 м/с
vR = 0.8 м/с
```

Робот движется прямо.

Но на практике одинаковая команда моторам не всегда даёт одинаковую скорость.

Например:

```text
левое колесо = 0.78 м/с
правое колесо = 0.83 м/с
```

Тогда робот постепенно начнёт отклоняться.

Именно здесь становятся важны энкодеры и обратная связь.

---

# Поворот

Если:

```text
vL ≠ vR
```

робот движется по дуге.

Например:

```text
vL = 0.5
vR = 1.0
```

Правое колесо проходит большее расстояние за то же время.

```text
        правое колесо
              →
             /
            /
           /
      робот
         ↖
```

Траектория центра робота становится дугой.

---

# Поворот на месте

Очень интересный режим:

```text
vL = -1
vR = +1
```

Одно колесо вращается назад, другое вперёд.

Тогда робот может вращаться практически вокруг собственного центра.

```text
       ↺
     ┌───┐
     │ R │
     └───┘
```

Это одно из главных преимуществ дифференциального привода.

Робот может разворачиваться в очень ограниченном пространстве.

---

# Геометрия робота

Обозначим расстояние между центрами колёс:

```text
L
```

Например:

```text
L = 0.4 м
```

Пусть скорости:

```text
vL
vR
```

Тогда движение робота можно описывать математически.

Средняя линейная скорость:

```text
v = (vR + vL) / 2
```

Угловая скорость:

```text
ω = (vR - vL) / L
```

Эти две формулы очень полезны для понимания дифференциального привода.

---

# Пример

Пусть:

```text
vL = 1 м/с
vR = 1 м/с
L = 0.5 м
```

Тогда:

```text
v = (1 + 1) / 2
  = 1 м/с
```

и:

```text
ω = (1 - 1) / 0.5
  = 0
```

То есть:

```text
скорость = 1 м/с
поворот = 0
```

Робот едет прямо.

---

# Пример поворота

Пусть:

```text
vL = 0.5 м/с
vR = 1.0 м/с
L = 0.5 м
```

Тогда:

```text
v = (1.0 + 0.5) / 2
  = 0.75 м/с
```

Угловая скорость:

```text
ω = (1.0 - 0.5) / 0.5
  = 1 рад/с
```

Робот одновременно:

```text
движется вперёд
```

и:

```text
поворачивает.
```

---

# Радиус поворота

При движении по дуге полезно знать радиус.

Упрощённо:

```text
R = v / ω
```

Если:

```text
v = 0.75 м/с
ω = 1 рад/с
```

получаем:

```text
R = 0.75 м
```

То есть центр робота движется по окружности радиусом примерно 0.75 м.

---

# Мгновенный центр вращения

При разных скоростях колёс можно представить точку, вокруг которой в данный момент вращается робот.

Она называется мгновенным центром вращения.

Условно:

```text
             ●
            /
           /
          /
         ●
      робот
```

Если колёса вращаются с разными скоростями, геометрия движения определяется их разницей.

Это позволяет математически описывать траекторию мобильного робота.

---

# Скорость колёс и скорость робота

Очень важно различать:

```text
скорость левого колеса
```

```text
скорость правого колеса
```

и:

```text
скорость корпуса робота
```

Они связаны, но не одинаковы.

Например:

```text
vL = 0.8 м/с
vR = 1.0 м/с
```

Тогда робот имеет собственную линейную и угловую скорость.

---

# Связь с энкодерами

На практике мы часто управляем не скоростью непосредственно, а двигателями.

Энкодеры измеряют вращение:

```text
колесо
  ↓
энкодер
  ↓
импульсы
  ↓
скорость колеса
```

Контроллер может поддерживать:

```text
vL = заданное
vR = заданное
```

с помощью PID-регуляторов.

Получается:

```text
Навигация
    ↓
нужная скорость робота
    ↓
скорости левого/правого колеса
    ↓
PID
    ↓
двигатели
```

---

# Почему нельзя просто подавать одинаковый PWM

Допустим:

```text
PWM Left  = 50%
PWM Right = 50%
```

Кажется, что робот должен ехать прямо.

Но реальные моторы могут различаться.

Например:

```text
Left  → 700 RPM
Right → 750 RPM
```

Тогда робот начнёт поворачивать.

Поэтому точные мобильные роботы используют обратную связь.

---

# Дифференциальный привод и одометрия

Если мы знаем:

```text
сколько повернулось левое колесо
```

и:

```text
сколько повернулось правое колесо
```

можно оценивать движение робота.

Например:

```text
оба колеса прошли одинаковое расстояние
```

→ робот двигался примерно прямо.

Если правое колесо прошло больше:

```text
правое > левое
```

→ робот повернул.

На основе этого можно оценивать:

```text
X
Y
θ
```

робота.

Это называется **одометрией**.

---

# Пример одометрии

Пусть:

```text
левое колесо:
ΔsL = 1.0 м

правое:
ΔsR = 1.0 м
```

Тогда:

```text
Δs = 1.0 м
```

и ориентация практически не меняется.

Если:

```text
ΔsL = 0.8 м
ΔsR = 1.0 м
```

робот повернулся.

Из разницы пройденных расстояний можно оценить изменение угла:

```text
Δθ ≈ (ΔsR - ΔsL) / L
```

где `L` — расстояние между колёсами.

---

# Проблема проскальзывания

Одометрия имеет серьёзное ограничение.

Представим:

```text
колесо вращается
```

но робот почти не движется.

Например:

```text
колесо проскальзывает на льду.
```

Энкодер видит:

```text
движение
```

но реального перемещения почти нет.

Получается ошибка:

```text
оценка:
+2 м

реальность:
+1.5 м
```

Такая ошибка постепенно накапливается.

Поэтому одометрию часто объединяют с другими датчиками.

---

# Манёвренность

Дифференциальная платформа может быть очень манёвренной.

Она способна:

```text
ехать вперёд
ехать назад
поворачивать
разворачиваться на месте
```

Но есть ограничения.

Например, она не может непосредственно двигаться боком:

```text
←
```

как платформа с omnidirectional-колёсами.

Это определяется кинематикой шасси.

---

# Сравнение шасси

### Дифференциальное

```text
○     ○
```

Плюсы:

* простота;
* дешёвая механика;
* хорошая манёвренность;
* простой контроль.

Минусы:

* не может ехать боком;
* требует контроля двух колёс.

### Ackermann

Похоже на автомобиль:

```text
↙       ↘
○       ○
```

Плюсы:

* хорошо движется на высокой скорости;
* естественная автомобильная кинематика.

Минусы:

* больше радиус поворота;
* сложнее развернуться на месте.

### Mecanum

Позволяет двигаться:

```text
← → ↑ ↓
```

Плюсы:

* высокая манёвренность.

Минусы:

* сложнее управление;
* более требовательная механика;
* хуже работает на некоторых поверхностях.

---

# Управление траекторией

Представим:

```text
Старт
 ●
  \
   \
    \
     ● Цель
```

Навигационная система определяет:

```text
куда двигаться
```

Но дифференциальному роботу нужно преобразовать это в:

```text
скорость левого колеса
скорость правого колеса
```

Например:

```text
нужно повернуть влево

Left  = 0.4 м/с
Right = 0.8 м/с
```

Если нужно повернуть сильнее:

```text
Left  = 0.1
Right = 0.8
```

Если нужно развернуться:

```text
Left  = -0.5
Right = 0.5
```

Таким образом, более высокий уровень управления задаёт движение, а кинематический слой переводит его в команды колёсам.

---

# Практическая архитектура

Для небольшого автономного робота можно построить такую структуру:

```text
              Навигация
                  ↓
           желаемое движение
                  ↓
         Контроллер траектории
                  ↓
       ┌──────────┴──────────┐
       ↓                     ↓
  Target Left            Target Right
       ↓                     ↓
      PID                   PID
       ↓                     ↓
   Мотор L               Мотор R
       ↓                     ↓
  Энкодер L              Энкодер R
       └──────────┬──────────┘
                  ↓
               Оценка
              движения
```

Это уже достаточно близко к архитектуре реального робота.

# Итог

Дифференциальный привод строится вокруг простой идеи:

```text
левое колесо + правое колесо
```

Разница их скоростей определяет поворот.

Основные случаи:

```text
vL = vR
→ прямо

vL < vR
→ поворот в одну сторону

vL > vR
→ поворот в другую сторону

vL = -vR
→ вращение на месте
```

Эта схема проста, но на ней можно изучить практически всю базовую мобильную робототехнику:

```text
механика
↓
кинематика
↓
энкодеры
↓
одометрия
↓
PID
↓
управление траекторией
```

Следующая задача — научиться оценивать положение мобильного робота в пространстве и понимать, почему одной одометрии обычно недостаточно.
