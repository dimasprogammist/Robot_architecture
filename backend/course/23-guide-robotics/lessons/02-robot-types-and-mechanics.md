# Какие бывают роботы и как устроена их механика

## Цель

Роботы могут выглядеть совершенно по-разному. Одни ездят на двух колёсах, другие передвигаются на гусеницах, третьи летают, четвёртые ходят на ногах, а некоторые вообще не перемещаются и работают из одного фиксированного положения.

После урока вы должны понимать:

* какие основные типы роботов существуют;
* чем мобильный робот отличается от манипулятора;
* какие бывают шасси;
* какие бывают механические передачи;
* зачем роботам редукторы;
* чем отличаются колёсные, гусеничные и шагающие конструкции;
* как устроена механика летающих роботов;
* что такое степень свободы;
* почему механика определяет возможности робота.

---

# Роботы бывают очень разными

Прежде чем изучать управление роботом, полезно понять, **какими вообще бывают сами роботы**.

Условно их можно разделить по способу взаимодействия с окружающим пространством.

```text
РОБОТЫ
│
├── Мобильные
│   ├── Колёсные
│   ├── Гусеничные
│   └── Шагающие
│
├── Летающие
│   ├── Мультикоптеры
│   ├── Самолётные
│   └── Гибридные
│
├── Манипуляторы
│   ├── Промышленные
│   ├── Коллаборативные
│   └── Специализированные
│
├── Гуманоидные
│
└── Стационарные
    ├── Портальные
    ├── Рельсовые
    └── Специализированные
```

Это не строгая научная классификация. Один робот может одновременно относиться к нескольким категориям.

Например, мобильная роботизированная платформа может иметь манипулятор:

```text
      Манипулятор
          │
          ↓
   ┌─────────────┐
   │   Платформа │
   └─────────────┘
       ○     ○
```

То есть она одновременно является мобильным роботом и роботом-манипулятором.

---

# Мобильные роботы

Мобильный робот способен перемещаться относительно окружающего мира.

Самый простой вариант — колёсный робот.

```text
        корпус
   ┌──────────────┐
   │              │
   └──────────────┘
      ○        ○
```

Колёсная схема проста, экономична и позволяет эффективно двигаться по относительно ровной поверхности.

Поэтому колёсные роботы встречаются очень часто:

* AGV;
* AMR;
* роботы-пылесосы;
* мобильные платформы;
* складские роботы;
* небольшие учебные роботы;
* автономные тележки.

---

# Двухколёсное шасси

Одна из самых простых схем — два ведущих колеса.

```text
      Движение →
    
        ┌───────┐
        │       │
        └───────┘
         ○     ○
```

Каждое колесо имеет собственный привод.

Например:

```text
Левый мотор  → левое колесо
Правый мотор → правое колесо
```

Если оба колеса вращаются с одинаковой скоростью:

```text
L = 100
R = 100
```

робот движется прямо.

Если:

```text
L = 50
R = 100
```

робот начинает поворачивать.

Если:

```text
L = -100
R = 100
```

робот может вращаться почти на месте.

Такая схема называется **дифференциальным приводом**.

Подробнее её мы разберём в отдельном уроке.

---

# Четырёхколёсное шасси

Можно использовать четыре колеса.

```text
    ○────────○
    │        │
    │ корпус │
    │        │
    ○────────○
```

Но здесь возникает важный вопрос:

> Как именно робот будет поворачивать?

Один вариант — использовать рулевой механизм.

```text
передние колёса
     ↙    ↘
    ○      ○
       │
      корпус
       │
    ○      ○
```

Это напоминает автомобиль.

Другой вариант — независимо управлять колёсами.

Тогда можно получить более сложную кинематику.

---

# Шасси с omnidirectional-колёсами

Некоторые роботы должны двигаться не только вперёд и назад, но и боком.

Для этого применяют специальные колёса.

Например, **Mecanum wheel** имеет ролики под углом.

Условно:

```text
     ╱╱╱
    ╱╱╱
   ╱╱╱
```

За счёт комбинации вращения нескольких колёс платформа может:

```text
вперёд
назад
влево
вправо
по диагонали
вращаться
```

Такие платформы полезны там, где пространство ограничено и требуется высокая манёвренность.

Однако механика становится сложнее, а требования к поверхности и управлению возрастают.

---

# Гусеничные роботы

Вместо колёс можно использовать гусеницы.

```text
   ╔══════════╗
   ║  корпус  ║
   ╚══════════╝
    ██████████
```

Гусеница распределяет нагрузку по большей площади.

Это полезно на:

* грунте;
* песке;
* неровной поверхности;
* строительных площадках.

Но гусеничный привод имеет свои особенности.

При повороте одна гусеница может двигаться быстрее другой:

```text
левая:   50
правая: 100
```

или вообще вращаться в обратную сторону:

```text
левая:  -100
правая: +100
```

Так робот может разворачиваться на месте.

---

# Шагающие роботы

Вместо колёс робот может использовать ноги.

```text
        корпус
      ┌────────┐
      └────────┘
       │ │ │ │
       │ │ │ │
      /  / \  \
```

Механика становится значительно сложнее.

Каждая нога может иметь несколько суставов.

Например:

```text
Таз
 ↓
Бедро
 ↓
Колено
 ↓
Голень
 ↓
Стопа
```

Каждый сустав требует отдельного привода или механизма.

Поэтому четырёхногий или гуманоидный робот может иметь десятки степеней свободы.

Главное преимущество ног — возможность преодолевать препятствия и двигаться там, где колёсам трудно.

Но управление становится намного сложнее.

---

# Летающие роботы

Летающий робот уже не может опираться на поверхность.

Поэтому ему необходимо постоянно создавать силу, компенсирующую действие силы тяжести.

Самый известный пример — квадрокоптер.

```text
       ○
       │
       │
 ○─────┼─────○
       │
       │
       ○
```

Четыре винта создают тягу.

Если суммарная тяга направлена вверх и равна весу аппарата:

```text
Тяга ≈ Вес
```

аппарат может удерживаться на высоте.

Если тяга становится больше:

```text
Тяга > Вес
```

он поднимается.

Если меньше:

```text
Тяга < Вес
```

он снижается.

---

# Как квадрокоптер поворачивает

Квадрокоптер не использует обычный автомобильный руль.

Он изменяет скорость вращения отдельных винтов.

Например:

```text
увеличить скорость задних моторов
уменьшить скорость передних
```

можно создать наклон.

После наклона часть тяги начинает действовать горизонтально.

```text
       ↑ тяга
      /
     /
    /  → движение
```

Таким образом:

```text
вращение винтов
      ↓
изменение тяги
      ↓
изменение ориентации
      ↓
движение
```

Механика летающего робота сильно отличается от механики наземного.

---

# Самолётные и гибридные роботы

Другой вариант — роботизированный летательный аппарат самолётного типа.

У него есть:

* крыло;
* фюзеляж;
* двигатель;
* рулевые поверхности.

Самолёт эффективнее при длительном горизонтальном полёте, но обычно не может так свободно зависать на месте, как мультикоптер.

Существуют и гибридные конструкции.

Например:

```text
вертикальный взлёт
       ↓
горизонтальный полёт
```

Механика и управление такого аппарата значительно сложнее.

---

# Манипуляторы

Манипулятор — робот, основная задача которого заключается в перемещении рабочего органа.

Например:

```text
       Захват
          ↓
        ┌───┐
        └───┘
          │
        ──●──
          │
          ●
          │
        ──●──
          │
       основание
```

У него есть:

* основание;
* звенья;
* суставы;
* приводы;
* рабочий орган.

Манипулятор может:

* брать детали;
* перемещать детали;
* сваривать;
* красить;
* закручивать;
* устанавливать компоненты;
* выполнять сборочные операции.

---

# Степени свободы

Очень важное понятие — **степень свободы**.

Простыми словами:

> Степень свободы — независимое направление движения системы.

Например, дверь может вращаться вокруг одной оси.

У неё одна основная степень свободы:

```text
       ↑
       │ ось
       │
┌──────●
│     /
│   /
│ /
```

Простой манипулятор может иметь несколько суставов:

```text
●───●───●───●
```

Каждый сустав добавляет возможность изменить положение следующего звена.

Чем больше степеней свободы, тем больше вариантов движения.

Но одновременно:

* сложнее механика;
* больше приводов;
* больше датчиков;
* сложнее управление;
* сложнее программирование.

---

# Гуманоидные роботы

Гуманоидный робот пытается воспроизводить форму и движения человека.

Типичная структура:

```text
        голова
          ●
          │
      ┌───┴───┐
      │ корпус│
      └───┬───┘
        /   \
       /     \
     рука     рука
       │       │
       │       │
      нога    нога
```

У него могут быть:

* шея;
* плечи;
* локти;
* кисти;
* таз;
* колени;
* голеностоп.

Главная сложность заключается в большом количестве степеней свободы и необходимости сохранять равновесие.

---

# Стационарные роботы

Не каждый робот должен ездить или летать.

Промышленный манипулятор может быть закреплён на основании:

```text
        робот
          │
          ↓
       ┌─────┐
       │     │
═══════╧═════╧═══════
       основание
```

Он работает в определённой рабочей зоне.

Другой пример — портальная система.

```text
┌──────────────────────┐
│                      │
│        ┌───┐         │
│        │   │         │
│        └─┬─┘         │
│          ↓           │
└──────────────────────┘
```

Рабочий орган может перемещаться по направляющим.

Такие системы удобны, когда требуется:

* высокая жёсткость;
* точность;
* повторяемость;
* большая рабочая зона.

---

# Механические передачи

Теперь перейдём к одной из важнейших тем.

Двигатель редко подключается к механизму напрямую.

Причина проста.

Двигатель может вращаться быстро, но создавать недостаточный момент.

Например:

```text
Двигатель:

3000 об/мин
0.5 Н·м
```

А колесу может потребоваться:

```text
300 об/мин
5 Н·м
```

Тогда нужна передача.

---

# Зубчатая передача

Самый очевидный вариант — шестерни.

```text
     ⚙
      ⚙
```

Если маленькая шестерня вращает большую:

```text
маленькая → большая
```

скорость уменьшается, а момент увеличивается.

Это и есть один из принципов редуктора.

Передаточное отношение можно представить упрощённо:

```text
i = n_вход / n_выход
```

Например:

```text
n_вход  = 3000 об/мин
n_выход = 300 об/мин

i = 3000 / 300
i = 10
```

То есть передаточное отношение примерно 10:1.

---

# Ременная передача

Вместо зубчатых колёс можно использовать шкивы и ремень.

```text
    O========O
```

Ременные передачи используются, когда нужно передать вращение между валами на некотором расстоянии.

Преимущества:

* простая конструкция;
* относительно тихая работа;
* возможность разместить валы на расстоянии.

Недостаток — обычный ремень может проскальзывать.

Для точных механизмов используют зубчатые ремни.

---

# Цепная передача

Похожий принцип используется в цепной передаче.

```text
    ⚙========⚙
```

Цепь соединяет две звёздочки.

Такая схема распространена в:

* велосипедах;
* транспортных механизмах;
* роботизированных платформах;
* приводах конвейеров.

Цепная передача хорошо передаёт большие нагрузки, но требует обслуживания.

---

# Винтовая передача

Вращательное движение можно преобразовать в линейное.

Например:

```text
      вращение
          ↻
     ───────────
          │
          ↓
        линейное
        движение
```

Так работают различные винтовые механизмы.

Они используются в:

* линейных приводах;
* станках;
* координатных системах;
* роботизированных механизмах.

---

# Червячная передача

Червячная передача состоит из червяка и колеса.

Упрощённо:

```text
────────────
   ⚙
```

Она позволяет получить большое передаточное отношение в компактной конструкции.

Часто используется там, где важны:

* большое уменьшение скорости;
* увеличение момента;
* компактность;
* определённые свойства удержания нагрузки.

Однако у неё могут быть заметные потери энергии из-за трения.

---

# Редуктор

Редуктор — механизм, который изменяет скорость и момент вращения.

Он может состоять из нескольких ступеней.

```text
Двигатель
    ↓
Шестерни
    ↓
Шестерни
    ↓
Выходной вал
```

Например:

```text
3000 об/мин
     ↓
1000 об/мин
     ↓
300 об/мин
     ↓
100 об/мин
```

Чем сильнее уменьшается скорость, тем выше обычно становится доступный выходной момент, хотя реальная передача имеет потери.

---

# Почему нельзя просто поставить мощный двигатель

Это распространённая ошибка.

Можно подумать:

> Если нужен большой момент, поставим двигатель мощнее.

Но мощный двигатель может быть:

* тяжелее;
* дороже;
* больше;
* требовать больше тока;
* сильнее нагружать конструкцию;
* сложнее охлаждаться.

Редуктор позволяет использовать двигатель с подходящими характеристиками и преобразовать его скорость и момент под задачу.

Поэтому сочетание:

```text
Двигатель + редуктор
```

в робототехнике встречается очень часто.

---

# Дифференциал

В некоторых роботах требуется передавать мощность двум колёсам так, чтобы они могли вращаться с разными скоростями.

Например, автомобиль при повороте:

```text
внешнее колесо
      ↓
движется быстрее

внутреннее колесо
      ↓
движется медленнее
```

Для этого используется дифференциал.

Без него колёсам пришлось бы проскальзывать относительно поверхности или возникали бы дополнительные механические нагрузки.

---

# Подшипники и валы

Механизм не может нормально работать только из одних шестерён.

Нужны валы:

```text
двигатель → вал → шестерня
```

И подшипники:

```text
┌─────────────┐
│  подшипник  │
│      ●      │
└─────────────┘
```

Подшипник позволяет валу вращаться с меньшим трением и удерживает его в нужном положении.

В серьёзной механике выбор подшипников, валов и креплений имеет такое же значение, как выбор двигателя.

---

# Как механика определяет возможности робота

Рассмотрим два робота.

### Робот A

```text
2 колеса
2 двигателя
низкий корпус
```

Он хорошо подходит для:

* движения по ровному полу;
* простых экспериментов;
* перевозки небольших грузов.

### Робот B

```text
4 ноги
12 суставов
12 приводов
IMU
энкодеры
```

Он может двигаться по более сложной поверхности.

Но его механика значительно сложнее.

Это приводит к важному принципу:

> **Нельзя сначала придумать программу робота, а потом полностью игнорировать механику.**

Архитектура робота должна учитывать физическую конструкцию с самого начала.

---

# Один и тот же привод — разные роботы

Допустим, у нас есть один двигатель.

Его можно подключить к:

```text
двигателю → колесу
```

Получится мобильная платформа.

Или:

```text
двигатель → сустав
```

Получится звено манипулятора.

Или:

```text
двигатель → винт
```

Получится часть летающего аппарата.

Сам двигатель может быть одинаковым.

Но механика вокруг него полностью меняет поведение системы.

---

# Как выбирать механическую схему

При проектировании робота нужно сначала определить задачу.

Например:

> Робот должен перевозить груз по складу.

Тогда важны:

* грузоподъёмность;
* скорость;
* радиус поворота;
* размер;
* запас энергии;
* состояние пола.

Для ровного пола может подойти колёсное шасси.

Если поверхность плохая:

```text
колёса → возможно гусеницы
```

Если робот должен преодолевать большие препятствия:

```text
гусеницы → возможно ноги
```

Если робот вообще не должен перемещаться:

```text
мобильная платформа не нужна
```

Таким образом, механическая конструкция выбирается **из задачи**, а не наоборот.

# Итог

Робототехника включает множество совершенно разных механических систем.

Робот может:

* ездить;
* летать;
* ходить;
* манипулировать объектами;
* перемещаться по рельсам;
* работать стационарно.

Для движения и работы используются:

```text
колёса
гусеницы
ноги
суставы
валы
шестерни
ремни
цепи
винтовые механизмы
редукторы
```

Главная мысль урока:

> **Механика определяет физические возможности робота, а программное обеспечение управляет этими возможностями.**

Поэтому прежде чем писать алгоритм управления, нужно понимать, **какой физический механизм этот алгоритм вообще должен приводить в движение**.
