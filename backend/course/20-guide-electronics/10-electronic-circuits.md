# Как собрать всё вместе: простые электронные схемы

## Цель

До этого мы рассматривали отдельные компоненты. Теперь соберём их в общую картину.

После урока вы должны уметь:

* читать простую электрическую схему;
* определять источник питания;
* находить управляющую и силовую части;
* понимать роль резистора;
* понимать роль конденсатора;
* использовать диод для защиты;
* использовать транзистор как ключ;
* понимать назначение реле;
* связывать датчик, контроллер и исполнительное устройство;
* видеть общую структуру электронной системы.

---

## Электронная схема как система

Отдельный компонент редко решает всю задачу.

Например, чтобы включить двигатель по сигналу датчика, может понадобиться:

```text
датчик
  ↓
контроллер
  ↓
транзистор
  ↓
двигатель
```

Но если смотреть подробнее, появляются дополнительные элементы:

```text
датчик
  ↓
контроллер
  ↓
управляющий резистор
  ↓
MOSFET
  ↓
защитный диод
  ↓
двигатель
```

А также:

```text
источник питания
  ↓
конденсаторы
  ↓
система
```

Каждый компонент выполняет свою функцию.

---

## Простейшая цепь

Начнём с самого простого:

```text
+V
 │
[R]
 │
LED
 │
GND
```

Здесь:

* источник создаёт напряжение;
* резистор ограничивает ток;
* LED преобразует электрическую энергию в свет;
* GND замыкает цепь.

Если убрать резистор, ток может стать слишком большим и светодиод может выйти из строя.

---

## Светодиод и резистор

Для приблизительного расчёта резистора можно использовать:

```text
R = (Vsource - VLED) / I
```

Например:

```text
Vsource = 12 V
VLED = 2 V
I = 0.01 A
```

Тогда:

```text
R = (12 - 2) / 0.01
R = 1000 Ω
```

Получаем:

```text
R = 1 kΩ
```

После этого необходимо также проверить мощность резистора:

```text
P = I²R
```

---

## Конденсатор возле питания

В цифровой схеме часто устанавливают конденсатор возле микросхемы:

```text
+V ────────┬──── микросхема
           │
          [C]
           │
GND ───────┴────
```

Он помогает сглаживать быстрые изменения напряжения и локально компенсировать кратковременные изменения потребления.

Поэтому возле микросхем часто можно увидеть небольшие керамические конденсаторы.

---

## Транзисторный ключ

Теперь подключим нагрузку.

```text
        +V
         │
       LOAD
         │
         D
      MOSFET
         S
         │
        GND

GPIO ─── Gate
```

GPIO не питает нагрузку.

Он только управляет MOSFET.

Силовой ток проходит через отдельный источник питания.

---

## Добавляем защиту

Если нагрузка индуктивная:

```text
реле
соленоид
двигатель
```

необходимо учитывать выбросы напряжения.

Для подходящих DC-нагрузок можно использовать защитный диод.

```text
       +V
        │
      LOAD
        │
        +────|<|────+
        │   диод    │
        │           │
        └── MOSFET ─┘
```

Конкретная схема зависит от типа нагрузки.

---

## Реле

Иногда нужно полностью разделить управляющую и силовую цепи.

Тогда используют реле:

```text
контроллер
    │
    ▼
катушка реле
    │
    ▼
контакт
    │
    ▼
нагрузка
```

Например:

```text
PLC 24 V
   │
   ▼
реле
   │
   ▼
24 V лампа
```

или при подходящем реле:

```text
PLC
 │
 ▼
реле
 │
 ▼
другая электрическая цепь
```

## Датчик → контроллер → нагрузка

Теперь соберём полноценную систему.

```text
┌──────────┐
│  Датчик  │
└────┬─────┘
     │
     ▼
┌──────────┐
│   PLC    │
└────┬─────┘
     │
     ▼
┌──────────┐
│ Драйвер  │
└────┬─────┘
     │
     ▼
┌──────────┐
│ Нагрузка │
└──────────┘
```

Например:

```text
датчик уровня
      ↓
PLC
      ↓
MOSFET / реле
      ↓
клапан
```

Если уровень становится слишком низким:

```text
датчик → PLC → выход → клапан
```

PLC включает клапан.

---

## Система управления двигателем

Для двигателя структура может быть такой:

```text
датчик
  ↓
PLC
  ↓
выход
  ↓
контактор / драйвер / ПЧ
  ↓
двигатель
```

Если нужен контроль скорости:

```text
PLC
 ↓
частотный преобразователь
 ↓
двигатель
```

Если нужен простой запуск небольшого DC-мотора:

```text
контроллер
 ↓
MOSFET / драйвер
 ↓
DC-мотор
```

---

## Как читать схему

При чтении схемы удобно двигаться от источника энергии.

Сначала найдите:

```text
источник питания
```

Затем определите:

```text
GND
```

После этого ищите путь тока:

```text
+V → компонент → компонент → GND
```

Для управляющих цепей ищите:

```text
сигнал → обработка → выход
```

Например:

```text
+24 V
  │
датчик
  │
PLC
  │
выход
  │
реле
  │
клапан
  │
0 V
```

## Управляющая и силовая части

Практически любую систему автоматизации удобно мысленно разделить на две части.

### Управление

```text
датчики
↓
PLC
↓
программа
↓
выходы
```

### Силовая часть

```text
источник
↓
коммутация
↓
исполнительный механизм
```

Связь между ними:

```text
PLC → транзистор
PLC → реле
PLC → контактор
PLC → драйвер
PLC → частотный преобразователь
```

## Где находятся изученные компоненты

Теперь можно связать всё в одну картину.

### Резистор

Используется для:

* ограничения тока;
* задания режимов;
* делителей напряжения;
* подтяжки сигналов.

### Конденсатор

Используется для:

* фильтрации;
* сглаживания;
* развязки питания;
* хранения небольшого количества энергии.

### Катушка

Используется для:

* создания магнитного поля;
* электромагнитов;
* реле;
* фильтров;
* трансформаторов.

### Диод

Используется для:

* выпрямления;
* защиты;
* стабилизации;
* световой индикации.

### Транзистор

Используется для:

* переключения;
* усиления;
* управления нагрузками.

### Реле

Используется для:

* коммутации;
* развязки;
* управления другой электрической цепью.

---

## Пример автоматизации

Рассмотрим простой конвейер.

Есть:

* датчик объекта;
* PLC;
* двигатель;
* контактор.

Логика:

```text
объект обнаружен
       ↓
датчик
       ↓
PLC
       ↓
программа
       ↓
выход PLC
       ↓
контактор
       ↓
двигатель
```

PLC не передаёт мощность двигателя через свой выход.

Он только даёт команду устройству, которое управляет силовой цепью.

---

## Полная картина

В результате получается:

```text
┌────────────┐
│   Датчики  │
└─────┬──────┘
      │
      ▼
┌────────────┐
│     PLC    │
└─────┬──────┘
      │
      ▼
┌────────────┐
│ Драйвер    │
│ / реле     │
│ / контактор│
└─────┬──────┘
      │
      ▼
┌────────────┐
│ Исполнитель│
│ный механизм│
└────────────┘
```

Именно эту архитектуру нужно постоянно держать в голове при изучении автоматизации.

---

## Практика

1. Нарисуйте схему светодиода с резистором.
2. Добавьте конденсатор на питание.
3. Нарисуйте MOSFET, управляющий реле.
4. Добавьте защитный диод.
5. Нарисуйте систему `датчик → PLC → клапан`.
6. Нарисуйте систему `датчик → PLC → контактор → двигатель`.
7. Для каждой схемы подпишите источник питания.
8. Отдельно обозначьте управляющую и силовую части.
9. Для каждой нагрузки объясните, зачем нужен промежуточный элемент управления.
