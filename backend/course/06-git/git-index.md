# Индекс (staging)

## Цель

Понять индекс как подготовленный набор того, что войдёт в следующий commit.

## Что уже пройдено

Рабочее дерево — черновик на диске. Индекс — черновик следующего снимка.

## Объяснение с нуля

**Индекс** — структура в `.git`, описывающая, каким будет следующий снимок при коммите сейчас. Это не облако и не полная копия проекта в отдельной папке, а список путей и хешей blob.

Зачем слой? Чтобы в один коммит взять два файла из пяти изменённых. `git add` обновляет индекс: читает байты с диска, при необходимости пишет blob, прописывает путь.

Три стадии файла: изменён только на диске; учтён в индексе; зафиксирован в коммите, на который указывает ветка.

## Термины

- **Индекс / staging** — подготовленное дерево следующего коммита.
- **Staged** — учтено в индексе.
- **Unstaged** — на диске новее, чем в индексе.
- **`git add`** — обновить индекс содержимым пути.

## Внутреннее устройство

При коммите Git оформляет tree из индекса, создаёт commit, двигает ветку.

```text
диск:  a.py(v3), b.py(v2)
индекс: a.py(v3), b.py(v1)
HEAD:   a.py(v2), b.py(v1)
# следующий commit возьмёт индекс: a=v3, b=v1
```

## Пример

```bash
echo one > a.txt
echo two > b.txt
git add a.txt
git status
```

Первый снимок может рассказать только про `a.txt`.

## Разбор

Индекс — не «очередь на GitHub». Это локальная сборка снимка. Десять коммитов можно сделать без сети.

## Ошибки

- Всегда `git add .` не глядя (секреты, мусор).
- Путать «сохранил файл» и «добавил в индекс».
- Думать, что индекс хранит только diff, а не целевое содержимое.

## Что запомнить

Коммит фотографирует индекс, не «всю грязь в папке». `git add` выбирает байты для следующего tree.

## Задание

Измените два файла, добавьте в индекс один. Опишите словами дерево будущего коммита.

## Ещё раз тем же смыслом

Git не угадывает намерение: он двигает указатели и создаёт объекты по правилам. Рисуйте стрелки «ветка → commit → tree → blob». Контрпример («а если push после rebase?») проявляет цену переписывания хешей. Перескажите урок за две минуты без списка флагов — только снимки и refs. Свой учебный репозиторий ценнее чужого длинного учебника. Сначала модель, потом команда.
