# Удалённый репозиторий

## Цель

Понять remote как именованный адрес другой копии той же объектной модели.

## Что уже пройдено

Локальные снимки и ветки ясны. Пора обмениваться между компьютерами.

## Объяснение с нуля

**Удалённый репозиторий** — другая база объектов с собственными refs. Часто лежит на сервере, но это может быть и путь на диске. Git не «отправляет файлы в облако» абстрактно: он договаривается, каких объектов не хватает, и передаёт недостающие, плюс обновляет ссылки.

Локально remote — короткое имя (часто `origin`) → URL. Само имя не священно. Обмен — fetch/push; они про объекты и указатели, не про «синхронизацию папки как у Dropbox».

## Термины

- **Remote** — имя → URL другой копии.
- **Remote-tracking branch** — локальный ref вроде `origin/main`, память о том, где была чужая ветка после последнего обмена.
- **Обмен объектами** — досылка недостающих blob/tree/commit.

## Внутреннее устройство

```text
локально: objects + refs/heads/main
remote:   objects + refs/heads/main
после fetch: refs/remotes/origin/main ≈ снимок указателя remote
```

`origin/main` — не ваша ветка для коммитов; это закладка.

## Пример

```bash
git remote -v
git remote add origin <url>
```

## Разбор

Удалённый репозиторий не отменяет локальную полную историю: у вас уже есть объекты. Сеть нужна, чтобы разделить недостающее и обновить указатели.

## Ошибки

- Думать, что без remote нет Git.
- Коммитить «в origin» как в рабочую ветку.
- Путать URL и имя remote.

## Что запомнить

Remote — адрес другой копии той же модели снимков. Tracking-refs — локальная память о чужих указателях.

## Задание

Добавьте remote (хотя бы тестовый URL) и посмотрите `git remote -v`. Запишите, чем имя отличается от URL.

## Связь со следующим уроком

Следующий урок — соглашение об имени origin.

## Ещё раз тем же смыслом

Git не угадывает намерение: он двигает указатели и создаёт объекты по правилам. Рисуйте стрелки «ветка → commit → tree → blob». Контрпример («а если push после rebase?») проявляет цену переписывания хешей. Перескажите урок за две минуты без списка флагов — только снимки и refs. Свой учебный репозиторий ценнее чужого длинного учебника. Сначала модель, потом команда.
