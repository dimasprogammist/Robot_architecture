# Шлюз по умолчанию

Подсеть объяснила, кто рядом. Все остальные назначения хост не тащит «наугад в кабель»: он отдаёт пакет **шлюзу по умолчанию** — маршрутизатору на границе этой сети. В таблице это `default` или `0.0.0.0/0` (в IPv6 — `::/0`) через адрес шлюза, который сам лежит в вашей подсети.

Без default route жива только LAN: ping соседу есть, сайт — нет. Этот симптом легко списать на DNS. Сначала смотрят, есть ли строка default в `ip route`.

Шлюз должен быть **on-link**. Адрес `192.168.1.1` при вашей сети `192.168.2.0/24` — классическая кривая ручная настройка: ARP до шлюза не к кому слать.

На домашней границе тот же ящик делает NAT и фильтр. В офисе за шлюзом может быть целая фабрика маршрутов. Хосту всё равно: ему нужен next hop и его MAC.

```text
dst = 8.8.8.8  (не LAN)
→ next hop = 192.168.1.1
→ кадр: MAC шлюза, внутри IP dst всё ещё 8.8.8.8
```

Конечный адрес в пакете не подменяют на адрес шлюза (NAT — отдельная история на границе, и она про публичный выход, не про «забыть 8.8.8.8»).

Два default сразу — Ethernet плюс Wi‑Fi, или VPN. Побеждает **метрика** (меньше — предпочтительнее) или более узкие маршруты VPN. Кривой VPN-профиль подменяет default и «интернет пропадает», хотя LAN жива.

Шлюз и DNS-сервер дома часто совпадают численно — оба на роутере. Роли разные: один — куда класть пакет, другой — куда спрашивать имя. Сломанный DNS при живом шлюзе: `ping 8.8.8.8` есть, `ping example.com` нет.

```bash
ip route
ip neigh
```

Пинганите шлюз, если ICMP не режут. В `ip neigh` должен появиться его MAC. Нет MAC и нет default — разные поломки.

Резерв шлюза (VRRP и родственники) — когда LAN не должна умирать вместе с одним железным ящиком. На домашнем роутере этого обычно нет: умер ящик — умер выход.

## Практика

### Задание 1. Найти выход

Найдите default gateway. Лежит ли он в вашей подсети? Есть ли его MAC в `ip neigh` после одного ping?

### Задание 2. Два симптома

A: сосед в LAN пингуется, `ip route` без default. B: default есть, имя сайта не резолвится, цифровой IP пингуется. Что чинить в A и в B?

### Задание 3. Чужая подсеть

Хост `10.1.1.10/24`, шлюз прописали `10.1.2.1`. Почему кадр до шлюза не соберётся? Как исправить, не трогая «интернет»?

### Задание 4. VPN

Зачем VPN иногда меняет default? Какой побочный эффект для доступа к принтеру в LAN, если все маршруты уехали в туннель?
