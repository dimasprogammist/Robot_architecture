# Геометрия изображения и перспектива

## Цель

Понять, как реальные размеры и положения объектов превращаются в координаты изображения и почему пиксель нельзя автоматически считать миллиметром.

После урока вы должны понимать:

* что такое система координат изображения;
* как связаны пиксели и физические координаты;
* почему возникает перспектива;
* что такое масштаб изображения;
* почему один и тот же объект может иметь разный размер в пикселях;
* зачем нужны преобразования координат;
* когда необходимо учитывать калибровку.

## Координаты изображения

Компьютерное изображение состоит из пикселей.

Каждый пиксель имеет координату.

Упрощённо:

```text
(0,0)
  ┌─────────────────────────→ X
  │
  │
  │       объект
  │       █████
  │       █████
  │
  ↓
  Y
```

Обычно начало координат находится в левом верхнем углу.

Например:

```text
X = 320
Y = 180
```

означает положение некоторой точки изображения.

Но это ещё не означает:

```text
320 мм
180 мм
```

Координаты изображения измеряются в пикселях.

## Пиксель и физический размер

Чтобы перейти от пикселей к миллиметрам, нужно знать масштаб.

Допустим:

```text
100 мм = 1000 px
```

Тогда:

```text
1 px = 0.1 мм
```

Если объект занимает:

```text
350 px
```

его физический размер при таком масштабе будет:

```text
350 × 0.1 = 35 мм
```

Но это работает только при определённых условиях.

## Когда простой масштаб работает

Простейшее преобразование возможно, если:

* объект находится примерно в одной плоскости;
* камера установлена стабильно;
* перспектива мала или компенсирована;
* масштаб известен;
* рабочая область ограничена.

Например, камера смотрит почти перпендикулярно на плоскую деталь.

Тогда:

```text
pixel → millimeter
```

может быть достаточно простым преобразованием.

## Перспектива

Если камера смотрит на объект под углом, возникает перспектива.

Представим дорогу:

```text
камера
   \
    \
     \________________
      \              /
       \            /
        \__________/
```

Параллельные линии визуально сходятся.

В машинном зрении это означает, что объекты на разном расстоянии от камеры могут иметь разный масштаб.

## Пример

Две одинаковые детали:

```text
ближе к камере:

████████

дальше:

████
```

Физически они одинакового размера.

Но в изображении одна занимает больше пикселей.

Поэтому нельзя просто измерить объект в пикселях и всегда получить его физический размер.

## Почему это важно

Допустим, нужно проверить диаметр отверстия:

```text
25.00 ± 0.10 мм
```

Если объект немного перемещается по глубине, его изображение может изменить размер.

Получится:

```text
кадр 1 → 250 px
кадр 2 → 247 px
кадр 3 → 253 px
```

Алгоритм может решить, что размер детали изменился.

Хотя на самом деле изменилась только геометрия съёмки.

## Ортогональная установка

Один из способов уменьшить проблемы — расположить камеру перпендикулярно плоскости объекта.

Например:

```text
       камера
         │
         │
         │
         ▼
   ┌──────────────┐
   │    объект    │
   └──────────────┘
```

Так геометрия изображения становится проще.

Но это не означает, что перспектива полностью исчезает.

## Поле зрения и масштаб

Пусть камера видит:

```text
FOV = 400 мм
```

по горизонтали.

Если ширина изображения:

```text
2000 px
```

то приблизительный масштаб:

```text
400 / 2000 = 0.2 мм/px
```

Если объект занимает:

```text
500 px
```

получаем:

```text
500 × 0.2 = 100 мм
```

Это простой пример.

В реальной системе масштаб может зависеть от положения точки в кадре.

## Нелинейность

При перспективе зависимость между координатами изображения и реальными координатами может быть нелинейной.

То есть нельзя всегда использовать:

```text
X_mm = X_px × constant
```

для всей области изображения.

В центре ошибка может быть небольшой, а ближе к краям — заметной.

## Искажения объектива

Кроме перспективы, объектив может вносить собственные искажения.

Например:

```text
прямая линия

│              │
│              │
│              │
```

может стать:

```text
)              (
)              (
)              (
```

Поэтому точные измерения требуют учитывать не только перспективу, но и характеристики оптики.

## Калибровочная сетка

Для изучения геометрии удобно использовать шахматную доску:

```text
┌─┬─┬─┬─┬─┐
│█│ │█│ │█│
├─┼─┼─┼─┼─┤
│ │█│ │█│ │
├─┼─┼─┼─┼─┤
│█│ │█│ │█│
└─┴─┴─┴─┴─┘
```

Известно, что размеры клеток, например:

```text
10 × 10 мм
```

По изображению можно определить, как известные физические точки отображаются в пикселях.

Эта информация используется при калибровке.

## Преобразование координат

Пусть известна точка:

```text
изображение:
(450, 320)
```

а после калибровки она соответствует:

```text
физическая система:
(120.5 мм, 85.2 мм)
```

Тогда появляется преобразование:

```text
pixel coordinates
        ↓
calibration
        ↓
physical coordinates
```

Это особенно важно для робототехники.

## Координаты робота

Предположим, камера обнаружила:

```text
X_image = 800 px
Y_image = 420 px
```

Роботу нельзя просто передать:

```text
X = 800
Y = 420
```

Робот может работать в миллиметрах:

```text
X = 435.2 мм
Y = 218.7 мм
```

Кроме того, системы координат могут иметь разное начало и направление осей.

Поэтому требуется преобразование.

## Система координат камеры

Удобно ввести отдельную систему координат:

```text
камера
  │
  ├── X
  ├── Y
  └── Z
```

Затем связать её с системой координат объекта или робота.

Например:

```text
камера
   ↓
система координат камеры
   ↓
калибровочное преобразование
   ↓
система координат робота
```

## Перспективное преобразование

В компьютерном зрении существует преобразование, которое позволяет связать плоскую область изображения с другой плоской областью.

Оно часто используется, когда нужно исправить перспективу.

Например, изображение документа под углом:

```text
    ┌─────────
   /
  /
 /
```

можно преобразовать в:

```text
┌──────────────┐
│              │
│   документ   │
│              │
└──────────────┘
```

Такое преобразование называется перспективным.

## Практический пример

Допустим, камера смотрит на прямоугольную рабочую область.

Из-за установки под углом она выглядит:

```text
      ┌───────────
     /
    /
   └────────────
```

Нас интересует только эта область.

Можно найти четыре её угла:

```text
P1
      ┌─────────── P2
     /
    /
P4 └──────────── P3
```

и преобразовать её в прямоугольник:

```text
P1 ┌──────────── P2
   │              │
   │ рабочая зона │
   │              │
P4 └──────────── P3
```

После этого многие измерения становятся проще.

## Гомография

Для плоских объектов часто используется математическое преобразование, называемое **гомографией**.

На практике его можно применять через OpenCV.

Например:

```python
import cv2
import numpy as np

matrix = cv2.getPerspectiveTransform(
    source_points,
    destination_points
)

warped = cv2.warpPerspective(
    image,
    matrix,
    (width, height)
)
```

Здесь исходные точки связываются с целевыми.

Подробная математика преобразования будет нужна позже при более глубоком изучении компьютерного зрения.

Сейчас важно понимать принцип:

```text
исходная геометрия
        ↓
известное преобразование
        ↓
исправленная геометрия
```

## Когда перспектива является проблемой

Перспектива особенно важна при:

* измерении размеров;
* определении координат;
* работе с роботами;
* анализе плоских деталей;
* контроле положения;
* сравнении объектов.

Если задача только в классификации:

```text
деталь A
или
деталь B
```

перспектива может быть менее критичной.

## Когда простого масштаба достаточно

Не всегда нужна сложная калибровка.

Если:

* объект находится в одной плоскости;
* камера неподвижна;
* область небольшая;
* точность невысокая;

может быть достаточно:

```text
px → mm
```

по известному эталонному объекту.

Важно не усложнять систему без необходимости.

## Главное

Изображение представляет физический мир через координаты пикселей.

Чтобы получить реальные размеры и координаты, необходимо учитывать:

* масштаб;
* перспективу;
* положение камеры;
* геометрию объектива;
* калибровку.

Полезная схема:

```text
реальный объект
      ↓
оптическая система
      ↓
изображение
      ↓
координаты пикселей
      ↓
калибровка / преобразование
      ↓
физические координаты
```

Это особенно важно для измерительных систем и робототехники, где информация из изображения должна превратиться в реальные миллиметры и координаты движения.
