# Калибровка камеры

## Цель

Понять, зачем нужна калибровка камеры и как она позволяет связать координаты изображения с геометрией реального мира.

После урока вы должны понимать:

* что такое калибровка камеры;
* зачем определяют внутренние параметры камеры;
* что такое дисторсия;
* зачем используют шахматную доску;
* чем калибровка отличается от простого определения масштаба;
* как калибровка применяется в измерениях и робототехнике.

## Зачем нужна калибровка

Камера создаёт изображение реального мира, но изображение не является идеальной копией пространства.

На него влияют:

* положение камеры;
* фокусное расстояние;
* размер сенсора;
* положение главной точки;
* искажения объектива;
* перспектива.

Поэтому если нужно получить точные геометрические данные, необходимо знать характеристики камеры и оптической системы.

Этот процесс называется **калибровкой**.

## Что мы хотим получить

Упрощённо можно представить задачу так:

```text
реальный мир
    ↓
камера
    ↓
пиксели
```

При калибровке мы хотим лучше понять преобразование:

```text
реальный мир
      ↕
   камера
      ↕
 изображение
```

Это позволяет:

* исправлять искажения;
* оценивать геометрию;
* измерять объекты;
* определять положение;
* работать с роботами.

## Внутренние параметры камеры

К внутренним параметрам относятся характеристики самой камеры и её оптической системы.

Упрощённо матрицу параметров можно представить так:

```text
┌ fx   0   cx ┐
│  0  fy   cy │
└  0   0    1 ┘
```

Здесь:

```text
fx, fy
```

связаны с масштабом изображения по осям.

```text
cx, cy
```

описывают положение главной точки изображения.

Для практической работы не обязательно вручную рассчитывать эти значения.

Библиотеки компьютерного зрения могут определить их по набору калибровочных изображений.

## Искажения объектива

Реальный объектив может искривлять изображение.

Например, прямые линии:

```text
│             │
│             │
│             │
```

могут выглядеть примерно так:

```text
)             (
)             (
)             (
```

Такое искажение называют дисторсией.

Для измерений оно может быть критичным.

## Почему искажения мешают

Представим, что на плоской поверхности находится сетка:

```text
┌─┬─┬─┬─┬─┐
├─┼─┼─┼─┼─┤
├─┼─┼─┼─┼─┤
└─┴─┴─┴─┴─┘
```

Из-за оптики изображение может выглядеть:

```text
╭──────────╮
│╲┬╲┬╲┬╲┬╲│
│ ├ ├ ├ ├ │
│╱┴╱┴╱┴╱┴╱│
╰──────────╯
```

Размеры ячеек будут отличаться по изображению.

Если выполнять измерения непосредственно по пикселям, результат может иметь ошибку.

## Калибровочная мишень

Для калибровки используют объект с известной геометрией.

Один из распространённых вариантов — шахматная доска.

Например:

```text
┌─┬─┬─┬─┬─┬─┐
│█│ │█│ │█│ │
├─┼─┼─┼─┼─┼─┤
│ │█│ │█│ │█│
├─┼─┼─┼─┼─┼─┤
│█│ │█│ │█│ │
├─┼─┼─┼─┼─┼─┤
│ │█│ │█│ │█│
└─┴─┴─┴─┴─┴─┘
```

Известны:

* количество углов;
* расстояние между углами;
* физический размер клетки.

Камера делает несколько снимков этой мишени.

## Почему нужно несколько изображений

Одного кадра обычно недостаточно для хорошей калибровки.

Мишень помещают в разные положения:

```text
кадр 1 → центр
кадр 2 → левый верхний угол
кадр 3 → правый верхний угол
кадр 4 → левый нижний
кадр 5 → правый нижний
```

Также можно изменять наклон мишени.

Это помогает алгоритму увидеть геометрию изображения в разных областях.

## Поиск углов

OpenCV умеет находить характерные точки шахматной доски.

Например:

```python
import cv2

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

found, corners = cv2.findChessboardCorners(
    gray,
    (9, 6)
)
```

Если углы найдены:

```text
found = True
```

получаем координаты характерных точек.

## Реальные координаты

Допустим, клетка имеет размер:

```text
20 мм
```

Тогда можно построить реальные координаты:

```text
(0, 0)
(20, 0)
(40, 0)
(60, 0)
...
```

В изображении эти же точки могут иметь координаты:

```text
(125, 83)
(162, 84)
(199, 86)
(236, 88)
...
```

Калибровка ищет параметры, которые связывают эти два набора данных.

## Исправление дисторсии

После получения параметров камеры можно исправить искажения.

В OpenCV для этого используются соответствующие функции.

Упрощённо:

```python
camera_matrix, distortion = ...
```

затем:

```python
corrected = cv2.undistort(
    image,
    camera_matrix,
    distortion
)
```

Получаем изображение, в котором геометрические искажения уменьшены.

## Калибровка не делает камеру идеальной

Важно понимать:

> калибровка не превращает плохую оптическую систему в идеальную.

Она позволяет математически описать и компенсировать известные геометрические эффекты.

Если:

* камера вибрирует;
* объектив плохо сфокусирован;
* освещение нестабильно;
* объект перемещается;

калибровка сама по себе это не исправит.

## Калибровка и измерения

Предположим, нужно измерить ширину детали.

Без калибровки:

```text
ширина = 430 px
```

После учёта геометрии можно получить:

```text
ширина = 52.37 мм
```

Но для точного измерения нужно учитывать ещё:

* точность камеры;
* объектив;
* освещение;
* положение детали;
* разрешение;
* алгоритм поиска границ.

Калибровка — только один элемент измерительной системы.

## Калибровка и перспектива

Есть два разных вопроса.

### Искажения объектива

Например:

```text
прямая линия → искривлённая
```

Это связано с оптической дисторсией.

### Перспектива

Например:

```text
одинаковые объекты на разном расстоянии
→ разные размеры в изображении
```

Это связано с геометрией проекции.

В реальной системе могут потребоваться оба типа коррекции.

## Плоская калибровка

Если объект находится в одной плоскости, часто можно построить преобразование:

```text
плоскость изображения
        ↓
плоскость объекта
```

Например:

```text
пиксели
  ↓
гомография
  ↓
миллиметры
```

Это удобно для:

* конвейеров;
* столов роботов;
* плоских деталей;
* координатных систем;
* измерений на одной рабочей поверхности.

## Калибровка камеры для робота

Рассмотрим систему:

```text
        камера
          │
          ▼
      изображение
          │
          ▼
    координаты объекта
          │
          ▼
       робот
```

Камера может найти объект в пикселях:

```text
(640, 420)
```

Но робот должен получить положение в своей системе координат:

```text
X = 520 мм
Y = 180 мм
```

Между ними необходимо установить связь.

Это является частью более общей задачи калибровки vision-системы.

## Важное различие

Есть несколько разных видов калибровки.

### Калибровка камеры

Определяет характеристики камеры и объектива.

### Калибровка изображения

Позволяет преобразовать изображение и исправить геометрические искажения.

### Калибровка масштаба

Связывает пиксели с физическими единицами:

```text
px → mm
```

### Калибровка камеры относительно робота

Связывает систему координат камеры с системой координат робота.

Эти задачи связаны, но не являются одним и тем же.

## Пример

Допустим, камера смотрит на рабочий стол робота.

На столе находится деталь.

Камера определяет:

```text
центр детали:
X = 730 px
Y = 420 px
```

После геометрического преобразования:

```text
X = 315 мм
Y = 210 мм
```

Затем выполняется преобразование в систему координат робота:

```text
X_robot = 520 мм
Y_robot = 145 мм
```

И робот получает координаты для движения.

## Что влияет на качество калибровки

Важно:

* использовать качественную калибровочную мишень;
* правильно определить её размеры;
* получить изображения с разных положений;
* заполнить мишенью значительную часть кадра;
* избегать размытия;
* правильно сфокусировать камеру;
* обеспечить стабильное освещение.

Если исходные изображения плохие, результат калибровки тоже будет плохим.

## Когда калибровка особенно важна

Она особенно необходима для:

* точных измерений;
* роботизированного захвата;
* определения координат;
* метрологических задач;
* работы с несколькими камерами;
* исправления заметной дисторсии.

Если задача простая:

```text
есть объект / нет объекта
```

полная геометрическая калибровка может вообще не потребоваться.

## Главное

Калибровка позволяет установить математическую связь между камерой и геометрией реального мира.

Упрощённая схема:

```text
калибровочная мишень
        ↓
несколько изображений
        ↓
поиск известных точек
        ↓
расчёт параметров камеры
        ↓
исправление искажений
        ↓
геометрически корректное изображение
```

Важно различать:

```text
калибровка камеры
≠
просто масштабирование
≠
просто исправление перспективы
```

В сложной системе эти операции могут использоваться вместе.

Для машинного зрения калибровка особенно важна тогда, когда от изображения требуется не просто определить наличие объекта, а получить **точные геометрические данные**.
