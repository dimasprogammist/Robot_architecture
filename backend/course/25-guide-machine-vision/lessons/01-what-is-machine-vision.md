# Что такое машинное зрение и чем оно отличается от компьютерного зрения

## Цель

Разобраться, что такое машинное зрение, из каких задач оно состоит и чем промышленная система технического зрения отличается от обычного компьютерного зрения.

После урока вы должны понимать:

* что называют машинным зрением;
* чем машинное зрение отличается от компьютерного зрения;
* из каких основных частей состоит система технического зрения;
* почему камера сама по себе ещё не является системой машинного зрения;
* какие задачи решают системы технического зрения на производстве;
* как результат анализа изображения превращается в управляющее решение.

## От компьютерного зрения к машинному зрению

В предыдущем разделе мы рассматривали **компьютерное зрение** — область, в которой компьютер получает изображения и пытается извлечь из них полезную информацию.

Например, программа может:

* найти объект на фотографии;
* определить его класс;
* обнаружить человека;
* посчитать количество объектов;
* найти контуры;
* отслеживать объект на видео;
* определить положение объекта.

Все эти задачи относятся к компьютерному зрению.

**Машинное зрение** использует те же базовые методы обработки изображений, но рассматривает их как часть законченной технической системы.

Например, на конвейере необходимо проверить, установлен ли болт в корпусе детали.

Недостаточно просто получить фотографию.

Нужно:

1. подать деталь в зону контроля;
2. расположить её относительно камеры;
3. обеспечить одинаковое освещение;
4. сделать снимок;
5. обработать изображение;
6. определить, присутствует ли болт;
7. принять решение `OK` или `NOK`;
8. передать результат контроллеру;
9. при необходимости остановить конвейер или удалить бракованную деталь.

Именно такой законченный процесс и является типичной задачей машинного зрения.

## Главное различие

Упрощённо различие можно представить так:

**Компьютерное зрение** отвечает на вопрос:

> Что можно узнать из изображения?

**Машинное зрение** дополнительно отвечает:

> Как организовать получение изображения и использовать результат в реальном техническом процессе?

Поэтому машинное зрение включает не только алгоритмы.

В систему могут входить:

* камера;
* объектив;
* освещение;
* контроллер;
* компьютер или промышленный vision-контроллер;
* датчики;
* механика;
* средства связи;
* программное обеспечение;
* система управления оборудованием.

## Пример с производственной линией

Представим конвейер с коробками.

На каждой коробке должна находиться этикетка.

Камера устанавливается над конвейером.

Когда датчик обнаруживает коробку, система делает снимок.

Программа определяет:

* есть ли этикетка;
* находится ли она примерно в правильном месте;
* соответствует ли её размер заданному;
* возможно ли прочитать код.

После этого система выдаёт результат:

```text
Коробка №125
Этикетка: обнаружена
Положение: OK
Размер: OK
Код: прочитан
Результат: OK
```

Если этикетки нет:

```text
Коробка №126
Этикетка: отсутствует
Результат: NOK
```

Дальше результат может поступить в ПЛК:

```text
Vision_OK = TRUE
Vision_NOK = FALSE
```

или:

```text
Vision_OK = FALSE
Vision_NOK = TRUE
```

ПЛК уже может управлять исполнительным механизмом.

Например:

```text
камера → анализ → NOK → ПЛК → цилиндр → удаление коробки
```

Таким образом, машинное зрение становится частью системы автоматизации.

## Типичная архитектура

Упрощённая система выглядит следующим образом:

```text
                 ┌──────────────┐
                 │    Объект    │
                 └──────┬───────┘
                        │
                        ▼
                 ┌──────────────┐
                 │  Освещение   │
                 └──────┬───────┘
                        │
                        ▼
                 ┌──────────────┐
                 │    Камера    │
                 └──────┬───────┘
                        │
                        ▼
                 ┌──────────────┐
                 │ Обработка    │
                 │ изображения  │
                 └──────┬───────┘
                        │
                        ▼
                 ┌──────────────┐
                 │   Решение    │
                 │   OK / NOK   │
                 └──────┬───────┘
                        │
                        ▼
                 ┌──────────────┐
                 │ ПЛК / робот  │
                 └──────────────┘
```

Каждый блок выполняет свою функцию.

Если один из них работает плохо, вся система может работать нестабильно.

## Камера — это только один элемент

Одна из самых важных идей машинного зрения заключается в том, что качество результата определяется не только алгоритмом.

Допустим, алгоритм прекрасно умеет находить трещины на поверхности металлической детали.

Но камера получает изображение:

* с бликами;
* с сильными тенями;
* с изменяющейся экспозицией;
* с недостаточным разрешением.

В результате хороший алгоритм может не справиться.

Поэтому в машинном зрении часто действует принцип:

> Сначала нужно получить стабильное изображение, а уже потом применять сложные алгоритмы.

Это одна из главных причин, почему в техническом зрении так важны камера, объектив и освещение.

## Какие задачи решает машинное зрение

На практике можно встретить множество задач.

### Контроль наличия

Проверить, присутствует ли объект:

```text
болт есть → OK
болта нет → NOK
```

### Контроль правильности сборки

Например, проверить, правильно ли установлены несколько компонентов.

```text
Компонент A → есть
Компонент B → есть
Компонент C → есть
```

Если хотя бы одного нет, изделие бракуется.

### Контроль размеров

Например:

```text
диаметр = 24.97 мм
допуск = 25.00 ± 0.10 мм
```

Результат:

```text
OK
```

### Поиск дефектов

Система может искать:

* царапины;
* трещины;
* сколы;
* пятна;
* отверстия;
* загрязнения;
* деформации.

### Чтение информации

Например:

* штрихкоды;
* QR-коды;
* символы;
* маркировку;
* серийные номера.

### Определение положения

Система может определить координаты детали:

```text
X = 124 px
Y = 87 px
Angle = 12°
```

Эта информация может использоваться роботом.

## Машинное зрение и робототехника

В робототехнике машинное зрение часто используется как источник информации о внешнем мире.

Например, робот должен взять деталь с конвейера.

Камера определяет:

```text
X = 540 мм
Y = 230 мм
Angle = 18°
```

Эти данные передаются роботу.

Робот рассчитывает движение и захватывает деталь.

Получается цепочка:

```text
камера
   ↓
изображение
   ↓
обработка
   ↓
положение объекта
   ↓
координаты
   ↓
робот
   ↓
захват
```

Здесь система зрения не управляет двигателями непосредственно.

Она сообщает роботу информацию, на основании которой робот выполняет движение.

## Online и offline обработка

В техническом зрении часто важно время обработки.

Если камера получает:

```text
30 кадров/с
```

то новый кадр появляется примерно каждые:

```text
33 мс
```

Если обработка одного кадра занимает несколько секунд, система не сможет работать в реальном времени.

Поэтому учитывают:

* время экспозиции;
* скорость передачи изображения;
* время обработки;
* задержку связи;
* время принятия решения;
* время реакции оборудования.

Для производственной системы важна не только правильность решения, но и его своевременность.

## Почему промышленная система сложнее программы на компьютере

Допустим, вы написали программу:

```python
image = camera.read()
result = detect_object(image)
print(result)
```

Для эксперимента этого может быть достаточно.

Но на производстве возникают дополнительные вопросы:

* Что будет, если камера отключится?
* Что будет, если объект не попал в кадр?
* Что будет, если освещение изменилось?
* Что будет, если ПЛК не получил результат?
* Что будет при потере сети?
* Как система поймёт, что результат относится именно к этой детали?
* Что делать при повторном запуске?
* Как определить неисправность камеры?
* Как оператор узнает причину брака?

Поэтому машинное зрение — это инженерная система, а не только программа обработки изображения.

## Контроль и измерение

Важно различать две большие категории задач.

### Контроль

Система отвечает:

```text
правильно / неправильно
есть / нет
OK / NOK
```

Например:

> Есть ли крышка на корпусе?

### Измерение

Система пытается определить численное значение:

```text
ширина = 31.42 мм
```

Например:

> Каков диаметр отверстия?

Измерительные задачи обычно предъявляют более высокие требования к стабильности системы.

Нужно учитывать:

* геометрию камеры;
* объектив;
* перспективу;
* калибровку;
* разрешение;
* положение объекта;
* освещение.

## Главное

Машинное зрение — это не просто камера и не просто алгоритм обработки изображения.

Это законченная система, которая:

1. получает изображение;
2. обеспечивает его стабильность;
3. анализирует изображение;
4. извлекает необходимую информацию;
5. принимает решение;
6. передаёт результат в технологический процесс.

Компьютерное зрение даёт математические и программные инструменты работы с изображениями.

Машинное зрение превращает эти инструменты в работающую техническую систему.
