# Контроль размеров и геометрии

## Цель

Понять, как машинное зрение используется для контроля геометрии деталей и почему измерение размера — это только часть полноценной системы контроля.

После урока вы должны понимать:

* какие геометрические параметры можно контролировать;
* чем измерение отличается от контроля;
* как задаются допуски;
* как проверять несколько размеров одновременно;
* что такое базовые элементы детали;
* почему положение детали нужно учитывать;
* как строится промышленная проверка геометрии.

## Измерение и контроль

В предыдущем уроке мы рассматривали получение физических размеров из изображения.

Теперь сделаем следующий шаг.

Допустим, система измерила:

```text
ширина = 49.96 мм
```

Само по себе это просто число.

Для контроля нужно знать требования:

```text
номинал = 50.00 мм
допуск = ±0.10 мм
```

Допустимый диапазон:

```text
49.90 ... 50.10 мм
```

Следовательно:

```text
49.96 → OK
```

Получается цепочка:

```text
изображение
    ↓
измерение
    ↓
сравнение с требованиями
    ↓
OK / NOK
```

## Какие параметры можно контролировать

Система машинного зрения может проверять:

* ширину;
* высоту;
* длину;
* диаметр;
* радиус;
* расстояние между отверстиями;
* положение отверстий;
* углы;
* расстояния между элементами;
* площадь;
* соотношение размеров;
* положение относительно базовой точки;
* наличие симметрии;
* форму.

Например, для детали:

```text
┌──────────────────────┐
│       ○       ○      │
│                      │
│    ┌────────────┐    │
│    │            │    │
│    └────────────┘    │
└──────────────────────┘
```

можно проверить:

```text
ширина детали
высота детали
диаметр отверстий
расстояние между отверстиями
положение отверстий
размер внутреннего прямоугольника
```

## Номинал и допуск

Для каждого параметра можно задать:

```text
номинал
минимум
максимум
```

Например:

```text
Width:
Nominal = 50.00
Min     = 49.90
Max     = 50.10
```

Или:

```text
Hole diameter:
Nominal = 12.00
Tolerance = ±0.05
```

Тогда:

```text
11.95 ... 12.05 мм
```

является допустимым диапазоном.

## Несколько параметров

Реальная система редко проверяет только один размер.

Например:

```text
Width       = 50.03 мм
Height      = 24.97 мм
Hole_1      = 12.01 мм
Hole_2      = 12.00 мм
Hole_dist   = 75.04 мм
Angle       = 0.6°
```

Каждый параметр проверяется отдельно.

Результаты:

```text
Width       → OK
Height      → OK
Hole_1      → OK
Hole_2      → OK
Hole_dist   → OK
Angle       → OK
```

Общий результат:

```text
PART = OK
```

Если хотя бы один обязательный параметр не прошёл контроль:

```text
PART = NOK
```

## Геометрические элементы

Чтобы измерять деталь, нужно сначала найти её геометрические элементы.

Например:

```text
точка
линия
окружность
контур
прямоугольник
```

Из них можно строить измерения.

Например:

```text
●────────────●
P1           P2
```

можно получить расстояние:

```text
distance(P1, P2)
```

Две линии:

```text
────────────
      ╲
       ╲
        ╲
```

позволяют определить угол.

Окружность:

```text
   ███
 ██   ██
██     ██
 ██   ██
   ███
```

позволяет измерить диаметр.

## Базы

При контроле детали часто важно не просто измерить абсолютные координаты.

Нужно определить положение относительно определённой базы.

Например:

```text
┌────────────────────────┐
│                        │
│   ○              ○     │
│                        │
└────────────────────────┘
↑
база A
```

Сначала система находит базовую грань.

Затем измеряет положение отверстий относительно неё.

Это значительно полезнее, чем просто измерять координаты относительно изображения.

## Почему база важна

Представим, что деталь немного сместилась:

```text
кадр 1:

┌─────────────┐
│     ○       │
└─────────────┘

кадр 2:

       ┌─────────────┐
       │     ○       │
       └─────────────┘
```

Абсолютная координата отверстия изменилась.

Но расстояние:

```text
от края детали до отверстия
```

может остаться тем же.

Поэтому промышленный контроль часто строится относительно геометрии самой детали.

## Относительные измерения

Вместо:

```text
X_hole = 350 px
```

можно использовать:

```text
distance(edge, hole) = 25.03 мм
```

Это делает контроль устойчивее к перемещению детали в кадре.

## Контроль положения отверстия

Например:

```text
┌─────────────────────┐
│                     │
│       ○             │
│                     │
└─────────────────────┘
```

Номинальное положение:

```text
X = 40.00 мм
Y = 20.00 мм
```

Допуск:

```text
±0.10 мм
```

Система измеряет:

```text
X = 40.04
Y = 19.96
```

Обе координаты находятся в допустимом диапазоне.

Результат:

```text
OK
```

## Позиционный допуск

Иногда нужно проверять не каждую координату отдельно, а расстояние от измеренной точки до номинального положения.

Например:

```text
номинал ●
         \
          \
           ● измерение
```

Можно рассчитать отклонение:

```text
d = √(dx² + dy²)
```

и сравнить:

```text
d ≤ tolerance
```

Это более естественный способ контроля положения точки.

## Контроль угла

Допустим, элемент должен находиться под углом:

```text
90.0°
```

Допуск:

```text
±0.5°
```

Получаем:

```text
89.5 ... 90.5°
```

Измерено:

```text
90.2°
```

Результат:

```text
OK
```

## Контроль параллельности

Можно определить две линии:

```text
──────────────
──────────────
```

и сравнить их направления.

Если углы:

```text
Angle1 = 2.1°
Angle2 = 2.4°
```

разница:

```text
0.3°
```

Если допустимо:

```text
≤ 0.5°
```

то условие выполнено.

## Контроль концентричности

Например, деталь содержит два отверстия:

```text
   ┌───────────┐
   │    ○      │
   │   ○       │
   └───────────┘
```

Можно определить центры окружностей и расстояние между ними.

Это позволяет контролировать:

* смещение;
* соосность;
* положение относительно других элементов.

## Профиль детали

Иногда не требуется проверять отдельные размеры.

Нужно проверить саму форму.

Например:

```text
эталон:

    ┌───────┐
   /         \
  /           \
  └───────────┘
```

и реальная деталь:

```text
    ┌───────┐
   /         \
  /           \
  └───────┘
```

Можно сравнивать контур с эталонным профилем.

## Проверка по зонам

Можно разделить изображение на области:

```text
┌───────────────┐
│ A             │
│               │
├───────┬───────┤
│ B     │ C     │
│       │       │
└───────┴───────┘
```

В каждой зоне выполняется отдельная проверка.

Например:

```text
Zone A → внешний контур
Zone B → отверстие
Zone C → наличие компонента
```

Так проще строить алгоритм.

## Допуски и реальная погрешность

Очень важно не задавать допуск меньше реальной погрешности системы.

Предположим:

```text
реальная погрешность системы ≈ ±0.15 мм
```

а технологический допуск:

```text
±0.05 мм
```

Тогда система может быть физически неспособна надёжно различать допустимые и недопустимые детали.

Проблема не в программе.

Проблема в измерительной системе.

Нужно анализировать:

* камеру;
* объектив;
* освещение;
* механику;
* калибровку;
* алгоритм.

## Повторяемость

Допустим, одна и та же деталь измеряется десять раз:

```text
50.01
50.02
50.01
50.03
50.02
50.01
...
```

Разброс небольшой.

Это хорошая повторяемость.

Если:

```text
49.8
50.2
49.9
50.3
49.7
```

система нестабильна.

Для промышленного контроля повторяемость особенно важна.

## Эталонная деталь

После создания системы полезно иметь эталонную деталь.

Например:

```text
REFERENCE PART
```

Для неё известны размеры.

При запуске системы можно проверить:

```text
эталон
 ↓
камера
 ↓
измерения
 ↓
сравнение с ожидаемыми значениями
```

Если результат сильно отличается, система может потребовать проверки.

## Полный цикл контроля

Типичный процесс:

```text
1. объект появляется
        ↓
2. trigger
        ↓
3. камера делает снимок
        ↓
4. поиск детали
        ↓
5. построение системы координат
        ↓
6. поиск геометрических элементов
        ↓
7. измерения
        ↓
8. сравнение с допусками
        ↓
9. OK / NOK
        ↓
10. передача результата
```

## Передача результата в производство

Результат может передаваться в ПЛК:

```text
PartReady = TRUE
PartOK = TRUE
PartNOK = FALSE
```

Также можно передать измерения:

```text
Width = 50.03
Height = 25.01
HoleDiameter = 12.00
```

ПЛК уже принимает решение, что делать с деталью.

Например:

```text
OK
→ пропустить

NOK
→ включить отбраковку
```

## Сохранение измерений

Для анализа производства полезно сохранять результаты:

```text
time
part_id
width
height
hole_diameter
result
```

Например:

```text
2026-10-02 10:15:03
PART_10231
50.03
24.98
12.01
OK
```

По накопленным данным можно увидеть постепенное изменение размеров детали.

## Тренд

Допустим, измерение диаметра за смену:

```text
12.00
12.01
12.01
12.02
12.03
12.04
12.05
12.06
```

Все значения ещё могут находиться в допуске.

Но появляется тренд.

Это может означать изменение технологического процесса.

Таким образом машинное зрение может использоваться не только для отбраковки, но и для мониторинга процесса.

## Главное

Контроль геометрии — это не просто получение одного числа.

Полная задача выглядит так:

```text
найти деталь
    ↓
определить базу
    ↓
найти геометрические элементы
    ↓
измерить
    ↓
перевести в физические единицы
    ↓
учесть допуски
    ↓
получить OK / NOK
```

Для хорошей системы особенно важны:

* стабильная механика;
* стабильное изображение;
* правильная калибровка;
* корректно выбранные базы;
* подходящие алгоритмы;
* реалистичные допуски.

Машинное зрение в таком случае становится частью системы контроля качества производства.
