# Измерения по изображению

## Цель

Понять, как система машинного зрения может измерять реальные размеры объектов по цифровому изображению.

После урока вы должны понимать:

* что именно можно измерять на изображении;
* чем измерение в пикселях отличается от измерения в миллиметрах;
* как определяется масштаб;
* почему положение объекта влияет на измерение;
* какие алгоритмы применяются для поиска границ;
* как формируются допуски;
* почему точность измерения зависит от всей системы.

## Что такое измерение в машинном зрении

Одна из распространённых задач машинного зрения — определить физический размер объекта.

Например:

```text
ширина детали = 48.25 мм
```

или:

```text
диаметр отверстия = 12.03 мм
```

или:

```text
расстояние между отверстиями = 75.10 мм
```

Но камера непосредственно измеряет не миллиметры.

Она видит пиксели.

Поэтому задача состоит из нескольких этапов:

```text
изображение
    ↓
поиск объекта
    ↓
поиск геометрических признаков
    ↓
измерение в пикселях
    ↓
геометрическое преобразование
    ↓
размер в миллиметрах
```

## Измерение в пикселях

Предположим, мы нашли прямоугольник:

```text
┌───────────────┐
│               │
│               │
└───────────────┘
```

Его ширина:

```text
500 px
```

Это уже измерение.

Но физический размер неизвестен.

Чтобы получить миллиметры, нужен масштаб.

## Простой масштаб

Допустим, известный эталон имеет размер:

```text
100 мм
```

и занимает:

```text
1000 px
```

Тогда:

```text
100 мм / 1000 px = 0.1 мм/px
```

Если другой объект имеет ширину:

```text
530 px
```

то:

```text
530 × 0.1 = 53 мм
```

Получаем:

```text
ширина = 53 мм
```

## Почему это только приближение

Такой расчёт предполагает, что масштаб одинаковый во всей интересующей области.

Это может быть достаточно, если:

* объект плоский;
* камера установлена перпендикулярно;
* поле зрения небольшое;
* перспектива мала;
* объектив хорошо скорректирован.

Для более точных измерений нужна полноценная геометрическая калибровка.

## Поиск границы объекта

Перед измерением нужно понять, где заканчивается объект.

Например:

```text
фон:

........................

объект:

......██████████.........
......██████████.........
```

Алгоритм должен определить границу:

```text
██████████
↑        ↑
X1       X2
```

Тогда ширина:

```text
X2 - X1
```

## Пороговая обработка

Если объект хорошо отличается от фона по яркости, можно использовать бинаризацию.

Например:

```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

_, binary = cv2.threshold(
    gray,
    120,
    255,
    cv2.THRESH_BINARY
)
```

Получаем изображение:

```text
чёрный фон
████████████
белый объект
░░░░░░░░░░░░
```

Затем можно найти контур объекта.

## Контуры

OpenCV позволяет найти контуры:

```python
contours, _ = cv2.findContours(
    binary,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
```

Для каждого контура можно получить ограничивающий прямоугольник:

```python
x, y, w, h = cv2.boundingRect(contour)
```

Здесь:

```text
x → координата X
y → координата Y
w → ширина
h → высота
```

Например:

```text
x = 100
y = 50
w = 500
h = 300
```

Значит:

```text
ширина = 500 px
высота = 300 px
```

## Прямоугольник не всегда подходит

Ограничивающий прямоугольник:

```text
┌──────────────┐
│   ╱────╲     │
│  │ объект│   │
│   ╲────╱     │
└──────────────┘
```

может содержать много пустого пространства.

Для круглого объекта полезнее определить окружность.

## Измерение диаметра

Если на изображении найден круг:

```text
      ███
   ██     ██
  █         █
   ██     ██
      ███
```

можно оценить его центр и радиус.

Если радиус:

```text
r = 120 px
```

то диаметр:

```text
D = 2r = 240 px
```

После преобразования масштаба:

```text
D = 24.0 мм
```

## Измерение расстояния

Допустим, нужно измерить расстояние между двумя точками:

```text
P1 ●────────────● P2
```

Если:

```text
P1 = (100, 200)
P2 = (500, 200)
```

расстояние по горизонтали:

```text
500 - 100 = 400 px
```

Если:

```text
0.1 мм/px
```

получаем:

```text
400 × 0.1 = 40 мм
```

## Расстояние между произвольными точками

Если точки имеют координаты:

```text
P1 = (x1, y1)
P2 = (x2, y2)
```

евклидово расстояние:

```text
d = √((x2 - x1)² + (y2 - y1)²)
```

Например:

```text
P1 = (100, 100)
P2 = (400, 500)
```

тогда:

```text
dx = 300
dy = 400
```

и:

```text
d = √(300² + 400²)
  = 500 px
```

После преобразования масштаба можно получить физический размер.

## Углы

Машинное зрение может измерять не только расстояния, но и углы.

Например, деталь повернута:

```text
        /
       /
──────/──────
```

Алгоритм может определить:

```text
Angle = 17.5°
```

Это полезно для:

* ориентации деталей;
* роботизированного захвата;
* контроля сборки;
* определения положения компонентов.

## Допуски

Само измерение ещё не является решением.

Предположим:

```text
номинал = 50.00 мм
допуск = ±0.10 мм
```

Допустимый диапазон:

```text
49.90 ... 50.10 мм
```

Если измерено:

```text
50.04 мм
```

то:

```text
OK
```

Если:

```text
50.18 мм
```

то:

```text
NOK
```

Таким образом:

```text
измерение
   ↓
сравнение с допуском
   ↓
OK / NOK
```

## Измерение нескольких параметров

Реальная деталь может проверяться сразу по нескольким параметрам:

```text
ширина = 50.03 мм
высота = 24.98 мм
диаметр = 12.01 мм
угол = 0.8°
```

Каждый параметр имеет свой допуск.

Например:

```text
Width:  50.00 ± 0.10
Height: 25.00 ± 0.10
Hole:   12.00 ± 0.05
Angle:   0.0 ± 1.0°
```

Итог:

```text
Width  → OK
Height → OK
Hole   → OK
Angle  → OK

RESULT → OK
```

## Точность и разрешение

Важно различать:

```text
разрешение
```

и:

```text
точность измерения
```

Если один пиксель соответствует:

```text
0.1 мм
```

это не означает автоматически, что система измеряет с точностью:

```text
±0.1 мм
```

На точность влияют:

* оптика;
* качество изображения;
* освещение;
* шум;
* алгоритм поиска границы;
* калибровка;
* стабильность объекта;
* положение камеры.

## Субпиксельные методы

Граница объекта не обязательно должна определяться только с точностью до целого пикселя.

Некоторые алгоритмы могут оценивать положение границы с субпиксельной точностью.

Например:

```text
граница ≈ 120.37 px
```

а не только:

```text
120 px
```

Это позволяет повысить точность геометрического анализа.

Но субпиксельный алгоритм не отменяет физические ограничения системы.

Если изображение плохое, математическая обработка не создаст отсутствующую информацию.

## Повторяемость

Для промышленного измерения важно не только попасть близко к истинному размеру.

Нужно, чтобы повторные измерения были похожими.

Например:

```text
измерение 1 → 50.02 мм
измерение 2 → 50.03 мм
измерение 3 → 50.02 мм
```

Это хорошая повторяемость.

Если:

```text
50.02
49.71
50.31
49.85
50.20
```

система нестабильна.

## Эталон

Для проверки измерительной системы используют эталонный объект с известным размером.

Например:

```text
эталон = 50.00 мм
```

Камера измеряет:

```text
50.01
50.00
50.02
50.01
```

Можно оценить стабильность системы.

Если результат:

```text
50.30
```

при ожидаемом:

```text
50.00
```

необходимо искать причину:

* калибровка;
* оптика;
* масштаб;
* положение объекта;
* алгоритм.

## Практический пример

Предположим, камера проверяет ширину металлической детали.

Этапы:

```text
1. trigger
      ↓
2. снимок
      ↓
3. grayscale
      ↓
4. фильтрация
      ↓
5. threshold
      ↓
6. contour
      ↓
7. bounding box
      ↓
8. ширина в px
      ↓
9. преобразование px → mm
      ↓
10. сравнение с допуском
      ↓
11. OK / NOK
```

Например:

```text
ширина = 502 px
масштаб = 0.1 мм/px
```

Получаем:

```text
50.2 мм
```

Если допуск:

```text
50.0 ± 0.3 мм
```

то:

```text
49.7 ... 50.3
```

и результат:

```text
OK
```

## Что происходит после измерения

Результат может передаваться в систему управления:

```text
Vision:
Width = 50.2
Result = OK
```

ПЛК получает:

```text
Vision_OK = TRUE
```

Если:

```text
Width = 50.7
```

получаем:

```text
Vision_NOK = TRUE
```

и ПЛК может удалить деталь.

## Измерение и контроль

Важно различать:

```text
измерить
```

и:

```text
контролировать
```

Измерение:

```text
ширина = 50.04 мм
```

Контроль:

```text
50.04 входит в допуск?
→ Да
→ OK
```

То есть измерение является промежуточным этапом принятия решения.

## Главное

Измерительная система машинного зрения обычно работает по цепочке:

```text
изображение
 ↓
поиск геометрических признаков
 ↓
измерение в пикселях
 ↓
калибровка
 ↓
размер в физических единицах
 ↓
сравнение с допуском
 ↓
OK / NOK
```

Для качественного измерения недостаточно высокой разрешающей способности камеры.

Необходимо обеспечить стабильную всю систему:

```text
камера
+
объектив
+
освещение
+
механика
+
калибровка
+
алгоритм
```

Именно поэтому машинное зрение является инженерной системой, а не просто программой обработки фотографий.
