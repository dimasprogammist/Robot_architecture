# Объективы и фокусное расстояние

## Цель

Разобраться, зачем системе машинного зрения нужен объектив и как его характеристики влияют на изображение.

После урока вы должны понимать:

* что делает объектив;
* что такое фокусное расстояние;
* что такое поле зрения;
* как рабочее расстояние связано с объективом;
* почему один объектив не подходит для всех задач;
* что такое глубина резкости;
* откуда появляются оптические искажения.

## Зачем нужен объектив

Камера должна получить свет от объекта на своей матрице.

Но матрица сама по себе не может просто «посмотреть» на объект.

Объектив собирает свет и формирует изображение на сенсоре.

Упрощённо:

```text
объект
   \
    \ свет
     \
   [ ОБЪЕКТИВ ]
          \
           \
         [МАТРИЦА]
```

Таким образом:

> объектив определяет, каким образом окружающая сцена проецируется на матрицу камеры.

Поэтому объектив является одним из ключевых элементов системы машинного зрения.

## Фокусное расстояние

Одной из главных характеристик объектива является **фокусное расстояние**.

Оно обычно указывается в миллиметрах:

```text
8 мм
12 мм
16 мм
25 мм
35 мм
50 мм
75 мм
```

Упрощённо можно сказать:

* маленькое фокусное расстояние → широкий угол обзора;
* большое фокусное расстояние → более узкий угол обзора.

Например:

```text
8 мм
```

может дать широкий обзор.

А:

```text
50 мм
```

позволяет получить более узкое поле зрения при той же геометрии установки.

## Поле зрения

**Field of View (FOV)** — область пространства, которую видит камера.

Например:

```text
┌────────────────────────────┐
│                            │
│       поле зрения          │
│                            │
└────────────────────────────┘
```

Если ширина поля зрения составляет:

```text
300 мм
```

то камера должна охватывать область шириной 300 мм.

Для задачи контроля это очень важный параметр.

## Связь между FOV и разрешением

Предположим:

```text
ширина FOV = 200 мм
ширина изображения = 2000 px
```

Тогда масштаб:

```text
200 мм / 2000 px = 0.1 мм/px
```

То есть примерно:

```text
1 px ≈ 0.1 мм
```

Если изменить объектив так, чтобы поле зрения стало:

```text
400 мм
```

при той же матрице:

```text
400 мм / 2000 px = 0.2 мм/px
```

Детали будут представлены меньшим количеством пикселей.

Поэтому выбор объектива непосредственно влияет на возможность измерять и обнаруживать мелкие детали.

## Почему нельзя просто увеличить разрешение камеры

Допустим, требуется видеть маленький дефект.

Можно подумать:

> Поставим камеру с огромным количеством мегапикселей.

Но если объектив даёт слишком большое поле зрения, объект всё равно может занимать относительно небольшую часть кадра.

Например:

```text
весь кадр = 1000 мм
деталь = 50 мм
```

Большая часть пикселей приходится не на деталь.

Иногда гораздо эффективнее:

* уменьшить поле зрения;
* правильно выбрать фокусное расстояние;
* расположить камеру;
* подобрать подходящий сенсор.

## Рабочее расстояние

**Working Distance (WD)** — расстояние между объективом и объектом или заданной плоскостью контроля.

Например:

```text
камера
  │
  │
  │ 500 мм
  │
  ▼
объект
```

Рабочее расстояние важно по нескольким причинам.

Камера может физически не иметь возможности приблизиться к объекту.

Например, между камерой и объектом находятся:

* защитный кожух;
* механизмы;
* робот;
* конвейер;
* ограждение.

Поэтому объектив должен обеспечивать нужное поле зрения на доступном рабочем расстоянии.

## Фокусировка

Чтобы изображение было резким, система должна правильно сфокусировать объектив.

Если объект находится вне подходящей зоны фокусировки, детали становятся размытыми.

Например:

```text
резко:
████████████

размыто:
░▒▓████▓▒░
```

Для измерительной задачи даже небольшое размытие может ухудшить результат.

## Глубина резкости

**Глубина резкости** — диапазон расстояний, в котором объекты остаются достаточно резкими.

Например:

```text
камера
  │
  ├── резкая зона ───────┐
  │                      │
  │                      │
  ▼                      ▼
        объект
```

Если все детали находятся примерно в одной плоскости, задача обычно проще.

Если объект имеет большую глубину:

```text
ближняя часть
       \
        \
         дальняя часть
```

может оказаться, что одна часть изображения резкая, а другая уже заметно размыта.

## Почему глубина резкости важна в производстве

Представим, что нужно проверять детали разной высоты.

Одна деталь находится:

```text
100 мм
```

от объектива.

Другая:

```text
120 мм
```

Если глубина резкости мала, одна деталь может быть резкой, а другая — нет.

Это может привести к нестабильности алгоритма.

Поэтому в машинном зрении часто специально проектируют оптическую систему так, чтобы рабочая область попадала в подходящую глубину резкости.

## Искажения

Реальный объектив не является идеальной математической линзой.

Он может создавать геометрические искажения.

Например, прямые линии возле края изображения могут выглядеть искривлёнными.

Один из известных типов искажений — **barrel distortion**, или бочкообразное искажение.

Условно:

```text
идеально:

│          │
│          │
│          │

искажено:

(          )
(          )
(          )
```

Другой тип — подушкообразное искажение.

Для обычной фотографии это может быть почти незаметно.

Для точного измерения оно становится существенным.

## Перспектива

Даже идеальный объектив не отменяет перспективу.

Предметы, находящиеся ближе к камере, могут выглядеть крупнее.

Например:

```text
камера
   \
    \       большой объект
     \     █████
      \
       \  маленький объект
        \ ██
```

Если измерять размеры непосредственно в пикселях, результат может зависеть от положения объекта.

Поэтому измерительные системы часто используют:

* фиксированное положение;
* перпендикулярную установку;
* калибровку;
* телецентрические объективы.

## Телецентрические объективы

Для точных измерений существуют специальные **телецентрические объективы**.

Они позволяют существенно уменьшить влияние перспективы в рабочей области.

Упрощённо обычный объектив:

```text
ближе → объект выглядит больше
дальше → объект выглядит меньше
```

Телецентрическая оптика позволяет получить более стабильное геометрическое представление объекта.

Такие объективы применяются, когда важна точность измерений.

Например:

* диаметр детали;
* расстояние между отверстиями;
* ширина компонента;
* геометрические допуски.

## Светосила

Объектив характеризуется также максимальной относительной апертурой.

Это влияет на количество света, которое может попасть на матрицу.

В промышленной системе это важно, потому что короткая экспозиция требует достаточного количества света.

Но больше света не всегда означает лучшее изображение.

Нужно обеспечить управляемое и стабильное освещение.

## Фиксированный и переменный фокус

Объективы могут иметь фиксированное или регулируемое фокусное расстояние.

Например:

```text
25 мм
```

— фиксированный вариант.

Другие объективы позволяют менять фокусное расстояние.

Для промышленной системы часто предпочитают стабильную конфигурацию, потому что после настройки параметры должны сохраняться.

## Как выбирать объектив

Сначала определяют:

```text
размер объекта
+
рабочее расстояние
+
размер сенсора
+
требуемое поле зрения
+
необходимое разрешение
```

После этого выбирают объектив.

Нельзя правильно выбрать объектив, не зная хотя бы приблизительных параметров задачи.

## Пример

Допустим:

```text
ширина контролируемой зоны = 300 мм
рабочее расстояние = 500 мм
```

Камера должна видеть всю зону.

При этом нужно обнаружить:

```text
дефект ≈ 0.5 мм
```

Если выбрать слишком широкий угол:

```text
FOV = 800 мм
```

то 300-миллиметровая деталь займёт небольшую часть изображения.

Если выбрать слишком узкое поле:

```text
FOV = 100 мм
```

часть объекта вообще не попадёт в кадр.

Нужен компромисс, рассчитанный под конкретную матрицу камеры.

## Объектив и камера выбираются вместе

Очень важно:

> Нельзя выбирать объектив отдельно от камеры.

Нужно учитывать:

* размер сенсора;
* разрешение;
* рабочее расстояние;
* FOV;
* требования к резкости;
* глубину резкости;
* искажения;
* освещение.

Например, объектив может быть хорошим сам по себе, но не подходить для размера сенсора конкретной камеры.

## Главное

Объектив определяет, как физический мир превращается в изображение.

Ключевые параметры:

* фокусное расстояние;
* поле зрения;
* рабочее расстояние;
* глубина резкости;
* светосила;
* оптические искажения.

Для машинного зрения объектив особенно важен, потому что от него напрямую зависит:

```text
что попадёт в кадр
↓
какого размера будет объект
↓
сколько пикселей будет приходиться на деталь
↓
насколько точно её можно анализировать
```

Поэтому камера и объектив должны проектироваться как единая оптическая система.
