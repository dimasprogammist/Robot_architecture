# Камеры: типы, матрицы, разрешение и FPS

## Цель

Понять, как устроены камеры для машинного зрения и какие характеристики действительно важны при выборе камеры.

После урока вы должны понимать:

* что такое матрица камеры;
* чем отличаются разрешение и размер изображения;
* что такое FPS;
* чем глобальный затвор отличается от построчного;
* чем монохромная камера отличается от цветной;
* почему высокая разрешающая способность не всегда означает лучший результат;
* какие параметры камеры важны для промышленной задачи.

## Камера в системе машинного зрения

Камера превращает свет, пришедший от объекта через объектив, в цифровое изображение.

Упрощённо процесс выглядит так:

```text
объект
   ↓
отражённый свет
   ↓
объектив
   ↓
матрица
   ↓
электрический сигнал
   ↓
цифровые данные
   ↓
изображение
```

Камера является связующим звеном между физическим миром и программой.

Программа работает уже не с реальным объектом, а с его цифровым представлением.

## Матрица камеры

Внутри камеры находится светочувствительная матрица.

Она состоит из большого количества элементов — пикселей.

Например:

```text
1920 × 1080
```

означает:

```text
1920 пикселей по горизонтали
1080 пикселей по вертикали
```

Общее количество пикселей:

```text
1920 × 1080 = 2 073 600
```

то есть примерно 2 мегапикселя.

## Что такое пиксель

Пиксель — это минимальный элемент цифрового изображения.

Например, простое изображение может выглядеть как:

```text
0   0   0   255 255
0   0   0   255 255
0   0   0   255 255
```

В чёрно-белом представлении значения могут обозначать яркость.

Условно:

```text
0   → чёрный
255 → белый
```

В реальной камере принцип зависит от типа сенсора и режима работы, но для понимания цифрового изображения такой пример подходит.

## Разрешение

Разрешение определяет, сколько пикселей содержит изображение.

Например:

```text
1280 × 1024
1920 × 1080
2448 × 2048
4096 × 3000
```

Большее разрешение позволяет различать более мелкие детали.

Но есть важный момент.

Если объект занимает небольшую часть кадра, увеличение разрешения не всегда решает проблему.

Например:

```text
┌──────────────────────────────┐
│                              │
│             ▪                │
│                              │
└──────────────────────────────┘
```

Если объект занимает всего несколько пикселей, даже очень хороший алгоритм не сможет получить из него много информации.

Поэтому важно не просто количество мегапикселей, а то, сколько пикселей приходится на интересующую деталь.

## Пиксели на объект

Допустим, поле зрения камеры по ширине:

```text
200 мм
```

а разрешение:

```text
2000 px
```

Тогда приблизительно:

```text
200 мм / 2000 px = 0.1 мм/px
```

Получается, один пиксель соответствует примерно:

```text
0.1 мм
```

Если нужно обнаружить дефект размером 0.5 мм, он теоретически займёт около:

```text
0.5 / 0.1 = 5 px
```

Это уже значительно полезнее для анализа.

На практике требования зависят от конкретной задачи, контраста, шума и алгоритма.

## Размер сенсора

Важно различать:

* разрешение;
* физический размер матрицы.

Например, две камеры могут иметь одинаковое разрешение:

```text
1920 × 1080
```

но разные физические размеры сенсора.

Это влияет на:

* поле зрения;
* требования к объективу;
* глубину резкости;
* шум;
* светочувствительность;
* оптическую систему.

Поэтому выбирать камеру только по числу мегапикселей неправильно.

## FPS

FPS — frames per second, количество кадров в секунду.

Например:

```text
30 FPS
```

означает:

```text
30 кадров за секунду
```

При:

```text
60 FPS
```

камера может выдавать до 60 кадров в секунду.

Это важно для движущихся объектов.

## Движение объекта

Предположим, объект движется со скоростью:

```text
1000 мм/с
```

За:

```text
1 мс
```

он переместится примерно на:

```text
1 мм
```

Если камера делает снимок с длинной выдержкой, изображение может смазаться.

Поэтому для движущихся объектов важны не только FPS, но и:

* время экспозиции;
* освещение;
* усиление;
* скорость движения;
* способ запуска камеры.

## Экспозиция

Экспозиция определяет, сколько времени матрица получает свет.

Например:

```text
1/1000 с
```

означает очень короткое время экспозиции.

Короткая экспозиция помогает уменьшить смазывание движения.

Но для неё требуется достаточное количество света.

Поэтому снова появляется связь:

```text
камера ↔ объектив ↔ освещение
```

Нельзя рассматривать эти элементы полностью независимо.

## Global shutter и rolling shutter

Это одна из важных характеристик камеры для движущихся объектов.

### Rolling shutter

При построчном считывании разные строки матрицы считываются в разные моменты времени.

Упрощённо:

```text
строка 1 → момент t1
строка 2 → момент t2
строка 3 → момент t3
строка 4 → момент t4
```

Если объект движется, его положение успевает измениться между считыванием разных строк.

В результате геометрия объекта может исказиться.

Например, вертикальный объект может выглядеть наклонённым.

### Global shutter

При глобальном затворе изображение захватывается синхронно для всего кадра.

Упрощённо:

```text
все пиксели
     ↓
один момент экспозиции
```

Для промышленного зрения и быстрых движущихся объектов это часто очень полезно.

## Монохромные камеры

Монохромная камера работает с яркостью без цветовой информации.

Условно:

```text
чёрный
темно-серый
серый
светло-серый
белый
```

Преимущества могут включать:

* высокую чувствительность;
* хорошую работу с контрастом;
* отсутствие необходимости анализировать цвет.

Если задача заключается, например, в измерении геометрии металлической детали, цвет может вообще не требоваться.

## Цветные камеры

Цветная камера сохраняет информацию о цвете.

Она нужна, если цвет является важным признаком.

Например:

```text
красная деталь → класс A
синяя деталь → класс B
```

Или:

```text
зелёная маркировка → OK
красная маркировка → NOK
```

Но цветная камера не является автоматически лучшим выбором.

Если цвет не используется в задаче, монохромная камера может быть вполне подходящей.

## Камеры высокого разрешения

Высокое разрешение полезно, когда необходимо видеть мелкие детали.

Например:

```text
деталь = 300 мм
дефект = 0.2 мм
```

Но рост разрешения увеличивает:

* объём данных;
* требования к интерфейсу;
* нагрузку на компьютер;
* время обработки;
* требования к хранению изображений.

Например, передавать тысячи кадров большого разрешения в секунду может быть технически сложно.

Поэтому камера выбирается не по принципу:

> чем больше разрешение, тем лучше.

Правильнее:

> какое разрешение необходимо именно для этой задачи?

## Интерфейс

Камера должна передавать данные вычислительной системе.

Встречаются разные интерфейсы.

Например:

```text
USB
GigE
USB3 Vision
GigE Vision
Camera Link
CoaXPress
```

При выборе учитывают:

* скорость передачи;
* длину линии;
* надёжность;
* синхронизацию;
* совместимость;
* стоимость.

Для промышленной системы особенно важно, чтобы вся цепочка работала стабильно.

## Частота кадров и производительность системы

Предположим:

```text
камера = 60 FPS
```

Но алгоритм способен обрабатывать только:

```text
15 FPS
```

Тогда система не сможет полноценно обрабатывать каждый кадр.

Поэтому производительность определяется всей цепочкой:

```text
камера
 ↓
передача
 ↓
память
 ↓
обработка
 ↓
решение
```

Иногда лучше использовать камеру с меньшим FPS, но обеспечить гарантированную обработку каждого необходимого кадра.

## Как выбирать камеру

Для выбора камеры сначала нужно определить задачу.

Полезно задать вопросы:

1. Какой объект нужно видеть?
2. Какой размер объекта?
3. Какое поле зрения необходимо?
4. Какой минимальный дефект нужно обнаружить?
5. Объект движется или стоит?
6. Насколько быстро он движется?
7. Нужен ли цвет?
8. Какое освещение используется?
9. Нужно ли аппаратное срабатывание?
10. Сколько кадров в секунду необходимо?
11. Какой интерфейс доступен?
12. Где будет установлена камера?

Только после этого имеет смысл выбирать конкретную модель.

## Пример

Допустим, нужно контролировать металлические детали на конвейере.

Условия:

```text
ширина зоны = 300 мм
скорость конвейера = 1 м/с
минимальный дефект = 0.5 мм
цвет не важен
```

Можно рассматривать:

* монохромную камеру;
* достаточное разрешение;
* короткую экспозицию;
* подходящее освещение;
* глобальный затвор;
* аппаратный trigger.

Но окончательный выбор требует расчёта всей оптической системы.

## Камера не существует отдельно

Очень важно привыкнуть мыслить не отдельными характеристиками, а системой:

```text
задача
 ↓
поле зрения
 ↓
объектив
 ↓
размер матрицы
 ↓
разрешение
 ↓
экспозиция
 ↓
освещение
 ↓
FPS
 ↓
интерфейс
 ↓
обработка
```

Изменение одного параметра может повлиять на остальные.

Например, уменьшение времени экспозиции требует больше света.

Большее разрешение увеличивает поток данных.

Более высокая скорость объекта требует лучшей синхронизации и меньшего времени экспозиции.

## Главное

При выборе камеры важны не только мегапиксели.

Нужно учитывать:

* разрешение;
* размер сенсора;
* размер пикселя;
* FPS;
* экспозицию;
* тип затвора;
* цвет или монохром;
* интерфейс;
* trigger;
* требования конкретной задачи.

Главный принцип:

> Камера выбирается не сама по себе, а под всю систему машинного зрения.
