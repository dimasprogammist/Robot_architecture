# Базовая обработка изображений

## Цель урока

После этого урока вы должны понимать:

* зачем изображения предварительно обрабатывают;
* что такое изменение размера;
* что такое область интереса (ROI);
* как изменяются яркость и контраст;
* что такое шум;
* зачем нужны фильтры и размытие;
* чем отличаются Gaussian Blur и медианный фильтр;
* что такое пороговая обработка;
* как несколько операций объединяются в последовательность обработки.

## Зачем обрабатывать изображение

Изображение с камеры редко идеально подходит для анализа сразу после получения.

На нём могут присутствовать:

* шум;
* слишком мелкие детали;
* ненужные области;
* неравномерное освещение;
* слабый контраст;
* случайные точки;
* слишком большое разрешение.

Поэтому перед основным алгоритмом изображение часто предварительно обрабатывают.

Общая схема:

```text
Изображение с камеры
        ↓
Предварительная обработка
        ↓
Основной алгоритм
        ↓
Результат
```

Важно понимать:

> предварительная обработка нужна не для того, чтобы изображение выглядело красивее, а для того, чтобы следующему алгоритму было проще работать с данными.

## Изменение размера

Иногда изображение слишком большое.

Например, камера выдаёт:

```text
3840 × 2160
```

а для конкретной задачи достаточно:

```text
1280 × 720
```

Тогда изображение можно уменьшить.

Это позволяет:

* уменьшить количество обрабатываемых пикселей;
* снизить нагрузку на процессор;
* ускорить алгоритмы;
* уменьшить потребление памяти.

Например:

```text
3840 × 2160
      ↓
1280 × 720
      ↓
анализ
```

Однако чрезмерное уменьшение может уничтожить важные детали.

Поэтому размер изображения выбирают исходя из задачи.

## Обрезка изображения

Часто на изображении присутствует большое количество ненужной информации.

Например:

```text
+--------------------------------------+
|                                      |
|                                      |
|       +--------------------+         |
|       |                    |         |
|       |    рабочая зона    |         |
|       |                    |         |
|       +--------------------+         |
|                                      |
+--------------------------------------+
```

Если объект всегда находится в определённой части изображения, можно работать только с этой областью.

Такая область называется **ROI — Region of Interest**, то есть область интереса.

Например:

```text
Полное изображение
        ↓
       ROI
        ↓
Основной алгоритм
```

Это одновременно:

* уменьшает количество данных;
* ускоряет обработку;
* иногда повышает устойчивость алгоритма.

## Изменение яркости

Яркость определяет, насколько светлым или тёмным выглядит изображение.

Можно увеличить яркость:

```text
тёмное изображение
        ↓
увеличение яркости
        ↓
более светлое изображение
```

Или уменьшить её:

```text
светлое изображение
        ↓
уменьшение яркости
        ↓
более тёмное изображение
```

В простейшем случае к значениям пикселей добавляется или вычитается некоторое число.

Например:

```text
новое значение = старое значение + 30
```

При этом значения не должны выходить за допустимый диапазон.

## Контраст

Контраст показывает, насколько сильно отличаются светлые и тёмные области.

Если контраст низкий:

```text
тёмное
████████████
████████████
████████████
```

отличия между областями небольшие.

При большем контрасте:

```text
тёмное  ███
среднее █████████
светлое ███████████████
```

объекты могут стать заметнее.

Но слишком сильное изменение контраста также может ухудшить изображение и уничтожить детали.

## Что такое шум

**Шум** — это нежелательные случайные изменения значений пикселей.

Например, вместо ожидаемого значения:

```text
100
```

камера может получить:

```text
97
103
91
108
```

Шум может появляться из-за:

* особенностей матрицы;
* слабого освещения;
* электронных помех;
* высокой чувствительности;
* особенностей передачи данных.

На изображении шум может выглядеть как случайные точки или мелкие изменения яркости.

Упрощённо:

```text
Полезное изображение + шум
            ↓
      Фильтрация
            ↓
      Более чистое изображение
```

## Фильтрация

Фильтр изменяет значение пикселя на основе его самого и/или соседних пикселей.

Например:

```text
соседи → [10, 12, 11]
          [13, 100, 12]
          [11, 13, 10]
```

Центральный пиксель `100` сильно отличается от соседей.

Фильтр может определить, что это, вероятно, шум, и заменить значение на более подходящее.

Фильтры являются фундаментальным инструментом обработки изображений.

## Размытие

Размытие используется для уменьшения мелких деталей и шума.

Идея проста:

```text
резкие изменения
       ↓
усреднение соседних пикселей
       ↓
более плавное изображение
```

Например:

```text
до:

0 0 0
0 255 0
0 0 0

после размытия:

20 30 20
30 50 30
20 30 20
```

Точные значения зависят от используемого алгоритма и параметров.

## Gaussian Blur

Один из распространённых фильтров — гауссово размытие.

В OpenCV оно доступно через:

```python
blurred = cv2.GaussianBlur(image, (5, 5), 0)
```

Здесь:

```text
(5, 5)
```

определяет размер ядра фильтра.

Чем сильнее размытие, тем больше мелких деталей может исчезнуть.

Gaussian Blur часто используется перед:

* поиском границ;
* выделением объектов;
* пороговой обработкой;
* анализом контуров.

## Медианный фильтр

Другой популярный вариант — медианный фильтр.

Он особенно полезен против некоторых видов импульсного шума.

Например:

```python
filtered = cv2.medianBlur(image, 5)
```

Вместо обычного усреднения используется медианное значение соседних пикселей.

Это позволяет убрать отдельные выбросы, сохраняя при этом некоторые границы лучше, чем простое размытие.

## Пороговая обработка

Пороговая обработка позволяет превратить изображение в более простую форму.

Например, есть изображение в оттенках серого:

```text
20   30   40   220
25   35   45   230
15   20   50   210
```

Можно выбрать порог:

```text
100
```

И определить:

```text
если pixel > 100:
    255
иначе:
    0
```

Получится:

```text
0   0   0   255
0   0   0   255
0   0   0   255
```

Такое изображение называется бинарным.

Обычно используются два значения:

```text
0   → фон
255 → объект
```

## Зачем нужна бинаризация

Пороговая обработка может значительно упростить дальнейший анализ.

Вместо:

```text
256 возможных значений яркости
```

мы получаем:

```text
0 или 255
```

После этого можно искать:

* области;
* контуры;
* объекты;
* их размеры;
* положение.

Например:

```text
Изображение
     ↓
Grayscale
     ↓
Threshold
     ↓
Бинарная маска
     ↓
Поиск объекта
```

## Пример практического конвейера

Представим, что камера смотрит на конвейер, а нам нужно найти тёмную деталь на светлом фоне.

Можно построить такой процесс:

```text
Камера
  ↓
Исходное изображение
  ↓
Изменение размера
  ↓
Grayscale
  ↓
Gaussian Blur
  ↓
Threshold
  ↓
Бинарная маска
  ↓
Поиск объекта
```

Каждый шаг решает свою задачу.

### Шаг 1. Изменение размера

Уменьшаем изображение, если исходное разрешение слишком большое.

### Шаг 2. Grayscale

Удаляем информацию о цвете, если она нам не нужна.

### Шаг 3. Gaussian Blur

Уменьшаем мелкий шум.

### Шаг 4. Threshold

Разделяем объект и фон.

### Шаг 5. Поиск объекта

Используем полученную маску для дальнейшего анализа.

## Почему нельзя просто применить много фильтров

На первый взгляд может показаться:

> чем больше обработки, тем лучше результат.

На практике это не так.

Каждая операция изменяет исходные данные.

Например:

```text
Исходное изображение
        ↓
сильное размытие
        ↓
границы стали менее чёткими
```

Или:

```text
Исходное изображение
        ↓
слишком сильный контраст
        ↓
часть деталей потеряна
```

Поэтому обработка должна быть направлена на конкретную задачу.

Хороший конвейер обработки — это не набор случайных фильтров.

Это последовательность операций, каждая из которых помогает следующему этапу.

## Практический принцип

Полезно задавать вопрос:

> Какую проблему решает эта операция?

Например:

```text
Resize
→ слишком большое изображение

ROI
→ слишком много ненужной области

Blur
→ шум

Grayscale
→ цвет не нужен

Threshold
→ нужно разделить объект и фон
```

Если операция не решает конкретную проблему, возможно, она вообще не нужна.

## Главное

Запомните:

* предварительная обработка подготавливает изображение к дальнейшему анализу;
* изменение размера уменьшает количество данных;
* ROI позволяет работать только с нужной областью;
* яркость и контраст влияют на видимость объектов;
* шум может мешать алгоритмам;
* фильтры помогают уменьшить шум и изменить структуру изображения;
* Gaussian Blur используется для сглаживания;
* медианный фильтр хорошо подходит для некоторых видов импульсного шума;
* пороговая обработка превращает изображение в бинарную маску;
* обработку нужно выбирать исходя из задачи.
