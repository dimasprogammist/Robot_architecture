# Основы нейросетевого компьютерного зрения

## Цель урока

После этого урока вы должны понимать:

* зачем нейронные сети применяются в компьютерном зрении;
* чем нейросетевой подход отличается от ручных правил;
* что происходит с изображением внутри модели;
* что такое обучение модели;
* что такое датасет;
* чем обучение отличается от использования готовой модели;
* почему качество данных так важно;
* где нейросетевое зрение применяется в робототехнике.

## От ручных правил к обучаемым моделям

В классическом компьютерном зрении программист часто сам строит алгоритм:

```text
Изображение
   ↓
Grayscale
   ↓
Blur
   ↓
Threshold
   ↓
Контуры
   ↓
Фильтрация
   ↓
Объект
```

Такой подход отлично работает для некоторых задач.

Но представим сложную сцену:

```text
разные объекты
разные ракурсы
тени
разное освещение
сложный фон
перекрытия
```

Создать набор ручных правил становится трудно.

Нейронная сеть позволяет часть этой работы передать обучению.

## Главная идея

Вместо:

```text
человек вручную задаёт признаки
```

используется:

```text
данные
  ↓
обучение
  ↓
модель сама формирует полезные представления
```

Упрощённо:

```text
Изображения
    ↓
Нейронная сеть
    ↓
Изученные признаки
    ↓
Результат
```

## Что такое нейронная сеть

Нейронная сеть состоит из множества вычислительных элементов, соединённых между собой.

Упрощённая схема:

```text
Вход
 ↓
Слой
 ↓
Слой
 ↓
Слой
 ↓
Выход
```

Каждый слой преобразует данные.

Для изображения это можно представить:

```text
пиксели
  ↓
простые признаки
  ↓
более сложные признаки
  ↓
структуры объекта
  ↓
результат
```

## Изображение как вход

Допустим, есть изображение:

```text
224 × 224 × 3
```

Это означает:

```text
224 пикселя по высоте
224 пикселя по ширине
3 цветовых канала
```

Нейронная сеть получает эти числовые данные как вход.

Упрощённо:

```text
RGB
 ↓
числа
 ↓
тензор
 ↓
нейронная сеть
```

## Что такое тензор

В контексте машинного обучения изображение часто представляется как многомерный массив — **тензор**.

Например:

```text
height × width × channels
```

или:

```text
batch × height × width × channels
```

Точная организация зависит от используемого фреймворка и модели.

Главная идея:

> нейронная сеть работает не с «картинкой как картинкой», а с числовым представлением изображения.

## Признаки внутри сети

В предыдущем уроке мы говорили о классических признаках.

В нейросетевом подходе признаки могут формироваться самой моделью.

Упрощённо:

```text
Изображение
    ↓
[слой]
    ↓
границы
    ↓
[слой]
    ↓
текстуры
    ↓
[слой]
    ↓
части объекта
    ↓
[слой]
    ↓
целый объект
```

Это не следует воспринимать как строгую схему каждого слоя современной модели.

Это удобная концептуальная модель для понимания того, как постепенно формируются более сложные представления.

## CNN

Для компьютерного зрения долгое время особенно важными были **свёрточные нейронные сети (CNN)**.

Свёрточный слой использует небольшие области изображения.

Например:

```text
+---+---+---+
|   |   |   |
+---+---+---+
|   | X |   |
+---+---+---+
|   |   |   |
+---+---+---+
```

Небольшое ядро перемещается по изображению и вычисляет преобразования.

Это позволяет обнаруживать локальные структуры.

## Почему локальные структуры важны

Изображение состоит из взаимосвязанных областей.

Например:

```text
граница
```

может быть частью:

```text
угла
```

углы могут формировать:

```text
геометрическую форму
```

а формы могут быть частью:

```text
объекта
```

Свёрточные сети хорошо подходят для такой иерархии представлений.

## Обучение модели

Нейронная сеть не знает заранее, что является правильным результатом.

Ей нужно показать примеры.

Например:

```text
изображение 1 → кошка
изображение 2 → кошка
изображение 3 → собака
изображение 4 → собака
```

Во время обучения модель делает предсказание:

```text
модель → собака
правильный ответ → кошка
```

После этого вычисляется ошибка.

Модель изменяет свои параметры так, чтобы в дальнейшем получать более подходящий результат.

## Параметры модели

Нейронная сеть содержит большое количество параметров.

Во время обучения они изменяются.

Упрощённо:

```text
параметры
   ↓
предсказание
   ↓
ошибка
   ↓
изменение параметров
   ↓
новое предсказание
```

Этот процесс повторяется много раз.

## Loss

Для оценки ошибки используется функция потерь — **loss function**.

Упрощённо:

```text
правильный ответ
      ↓
сравнение
      ↑
предсказание
      ↓
loss
```

Чем сильнее предсказание отличается от ожидаемого результата, тем больше может быть значение ошибки.

Конкретная функция зависит от задачи.

## Обратное распространение ошибки

Для изменения параметров используется **backpropagation**.

Упрощённо:

```text
Вход
 ↓
модель
 ↓
предсказание
 ↓
loss
 ↓
градиенты
 ↓
изменение параметров
```

Так сеть постепенно адаптируется к обучающим данным.

## Dataset

Для обучения нужна выборка данных.

Например:

```text
dataset/
├── train/
├── validation/
└── test/
```

Внутри могут находиться изображения и соответствующая разметка.

Качество датасета имеет огромное значение.

Если данные плохие:

```text
неправильные метки
размытые изображения
слишком мало примеров
однообразные условия
```

модель тоже может работать плохо.

## Переобучение

Представим, что модель практически запомнила обучающие изображения.

На тренировочных данных:

```text
очень хороший результат
```

Но на новых:

```text
плохой результат
```

Это называется **переобучением (overfitting)**.

Модель научилась хорошо работать с конкретными примерами, но плохо обобщает знания.

## Обобщение

Хорошая модель должна уметь работать с новыми данными.

Например, если во время обучения были:

```text
детали A
```

при разных:

```text
углах
освещении
положениях
```

модель должна иметь возможность распознавать новые детали A в похожих условиях.

Это называется способностью к обобщению.

## Аугментация

Для повышения разнообразия данных применяют аугментацию:

```text
поворот
масштабирование
сдвиг
изменение яркости
отражение
шум
```

Например:

```text
исходная фотография
       ↓
+ небольшой поворот
+ изменение яркости
+ небольшой сдвиг
       ↓
новые варианты
```

Это помогает модели увидеть больше вариантов одного и того же объекта.

## Классификация, детекция и сегментация

Нейронные сети могут решать разные задачи.

### Классификация

```text
Изображение
    ↓
Класс
```

### Детекция

```text
Изображение
    ↓
Объекты + bounding boxes + классы
```

### Сегментация

```text
Изображение
    ↓
маска объектов
```

Таким образом:

```text
одна область
↓
класс

несколько объектов
↓
классы + координаты

точная область объекта
↓
маска
```

## Готовая модель и обучение с нуля

Не всегда нужно обучать сеть полностью с нуля.

Можно использовать **готовую предварительно обученную модель**.

Например:

```text
готовая модель
      ↓
дополнительное обучение
      ↓
задача проекта
```

Это называется transfer learning.

Например, модель уже научилась выделять общие визуальные признаки.

Затем её можно адаптировать под собственные классы.

## Почему это полезно

Обучение большой модели с нуля может потребовать:

```text
много данных
много времени
мощное оборудование
```

Предобученная модель позволяет использовать уже полученные представления и адаптировать их под конкретную задачу.

## Компьютерное зрение на роботе

Представим робота:

```text
Камера
  ↓
Изображение
  ↓
Нейронная сеть
  ↓
Объект
  ↓
Координаты / класс
  ↓
Логика робота
  ↓
Действие
```

Например:

```text
камера увидела деталь
        ↓
модель определила класс
        ↓
система вычислила положение
        ↓
манипулятор получил координаты
        ↓
робот захватил деталь
```

Здесь нейронная сеть является только одной частью всей системы.

## Почему нейросеть не заменяет всю систему

Важно не воспринимать нейросеть как магический блок:

```text
камера → нейросеть → готовый робот
```

Реальная система включает:

```text
камера
освещение
оптику
предобработку
нейросеть
геометрию
логику
управление
диагностику
безопасность
```

Каждая часть решает свою задачу.

## Главное

Запомните:

* нейросети позволяют автоматически изучать признаки изображений;
* изображение передаётся модели как числовые данные;
* CNN являются важным классом моделей для компьютерного зрения;
* обучение заключается в настройке параметров модели по примерам;
* loss показывает ошибку модели;
* backpropagation используется для вычисления направлений изменения параметров;
* качество датасета напрямую влияет на качество модели;
* переобучение возникает, когда модель плохо обобщает новые данные;
* аугментация увеличивает разнообразие обучающих примеров;
* нейронные сети могут решать задачи классификации, детекции и сегментации;
* готовые модели можно адаптировать под собственные задачи.
