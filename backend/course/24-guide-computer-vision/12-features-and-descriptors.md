# Основы признаков и дескрипторов

## Цель урока

После этого урока вы должны понимать:

* что такое признак изображения;
* зачем выделять признаки;
* чем признак отличается от пикселя;
* что такое ключевая точка;
* что такое дескриптор;
* зачем сравнивать признаки между изображениями;
* где признаки используются в компьютерном зрении.

## От пикселей к признакам

Изображение можно представить как огромный массив чисел:

```text
пиксели
↓
числа
↓
матрица
```

Но иногда работать со всеми пикселями напрямую неудобно.

Например, нужно определить:

> похож ли этот фрагмент изображения на фрагмент другого изображения?

Можно сравнивать каждый пиксель.

Но такой подход плохо работает, если объект:

* повернут;
* немного изменил масштаб;
* находится в другом месте;
* освещён немного иначе.

Поэтому используются **признаки**.

## Что такое признак

**Признак (feature)** — характеристика изображения или объекта, которая содержит полезную для задачи информацию.

Например:

```text
граница
угол
характерная точка
текстура
форма
цвет
```

Можно представить:

```text
Изображение
    ↓
Поиск характерных элементов
    ↓
Признаки
    ↓
Описание объекта
```

## Ключевые точки

Один из распространённых вариантов признаков — **ключевые точки (keypoints)**.

Это точки изображения, которые имеют характерные локальные особенности.

Например:

```text
      |
   ---+---
      |
```

Такой угол может быть хорошей ключевой точкой, потому что его структура отличается от соседних областей.

На ровной одноцветной поверхности найти уникальную точку сложнее.

## Почему углы полезны

Представим:

```text
----------------
        |
        |
        |
```

В месте пересечения двух границ происходит заметное изменение структуры.

Такие точки могут быть устойчивыми признаками объекта.

Например:

```text
+---------+
|         |
|    +    |
|         |
+---------+
```

Углы прямоугольника могут использоваться как характерные точки.

## Harris Corner Detector

Один из классических алгоритмов поиска углов — Harris Corner Detector.

В OpenCV:

```python
corners = cv2.cornerHarris(
    gray,
    2,
    3,
    0.04
)
```

Идея алгоритма:

```text
плоская область
→ мало изменений

граница
→ сильное изменение в одном направлении

угол
→ сильное изменение в нескольких направлениях
```

Поэтому углы могут быть хорошими признаками.

## Признак должен быть полезным

Хороший признак желательно:

* легко находить;
* отличать от других;
* сохранять при небольших изменениях изображения;
* быть достаточно устойчивым к шуму;
* быть полезным для конкретной задачи.

Например, отдельный пиксель обычно является слабым признаком.

А характерный угол объекта может быть намного полезнее.

## Что такое дескриптор

Ключевая точка говорит:

```text
где находится интересное место
```

Но этого недостаточно.

Нужно ещё описать:

> как выглядит область вокруг этой точки?

Для этого используется **дескриптор (descriptor)**.

Упрощённо:

```text
Keypoint
    ↓
Область вокруг точки
    ↓
Описание
    ↓
Descriptor
```

Дескриптор обычно представлен набором чисел.

## Зачем нужен дескриптор

Допустим, у нас есть фотография детали:

```text
Изображение A
```

и другое изображение:

```text
Изображение B
```

Мы хотим понять, есть ли на втором изображении та же деталь.

Можно:

```text
найти keypoints
      ↓
получить descriptors
      ↓
сравнить descriptors
      ↓
найти совпадения
```

## SIFT

Один из известных алгоритмов — **SIFT (Scale-Invariant Feature Transform)**.

В OpenCV можно использовать:

```python
sift = cv2.SIFT_create()

keypoints, descriptors = sift.detectAndCompute(
    gray,
    None
)
```

Здесь:

```text
keypoints
```

содержат найденные ключевые точки.

А:

```text
descriptors
```

содержат их описания.

## Получение признаков

Пример:

```python
import cv2

image = cv2.imread("image.jpg")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

sift = cv2.SIFT_create()

keypoints, descriptors = sift.detectAndCompute(
    gray,
    None
)

print("Keypoints:", len(keypoints))
```

Можно визуализировать точки:

```python
result = cv2.drawKeypoints(
    image,
    keypoints,
    None
)

cv2.imshow(
    "Features",
    result
)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

## ORB

Для многих практических задач полезен ORB.

```python
orb = cv2.ORB_create()

keypoints, descriptors = orb.detectAndCompute(
    gray,
    None
)
```

ORB обычно используется как более лёгкий вариант для задач, где важна скорость.

## Сравнение признаков

После получения дескрипторов можно сравнивать их.

Для этого используются сопоставители признаков.

Например:

```python
matcher = cv2.BFMatcher(
    cv2.NORM_HAMMING
)
```

После этого можно искать совпадения:

```python
matches = matcher.match(
    descriptors1,
    descriptors2
)
```

Получаем список соответствий.

## Что означает совпадение

Если два дескриптора похожи, можно предположить:

```text
точка A изображения 1
        ↕
точка B изображения 2
```

относятся к похожей области изображения.

Если таких совпадений много и они согласованы геометрически, можно получить более сильное основание считать, что изображения содержат один и тот же объект или часть объекта.

## Пример идеи сопоставления

Допустим:

```text
Изображение 1:

+------------+
|            |
|    ###     |
|   #####    |
|    ###     |
|            |
+------------+
```

и:

```text
Изображение 2:

+------------+
|       ###  |
|      ##### |
|       ###  |
|            |
+------------+
```

Пиксели находятся в разных местах.

Но характерная структура объекта похожа.

Признаки позволяют найти соответствия независимо от абсолютной позиции объекта.

## Признаки и масштаб

Некоторые алгоритмы стараются сохранять устойчивость к изменению масштаба.

Например:

```text
маленький объект
      ↓
большой объект
```

его локальная структура всё ещё может быть распознана.

Именно поэтому признаки полезнее простого сравнения пикселей во многих задачах.

## Признаки и поворот

Аналогично:

```text
объект
  ↓
поворот
  ↓
объект под другим углом
```

Некоторые методы позволяют находить соответствия даже при изменении ориентации.

## Где используются признаки

Признаки применяются в задачах:

* сопоставления изображений;
* поиска похожих областей;
* распознавания объектов;
* построения панорам;
* оценки движения камеры;
* визуальной одометрии;
* робототехники;
* восстановления геометрических отношений между изображениями.

## Пример в робототехнике

Робот получает два изображения:

```text
Кадр 1
   ↓
Признаки

Кадр 2
   ↓
Признаки
```

После сопоставления:

```text
точки кадра 1
       ↕
точки кадра 2
```

можно оценивать, как изменилась камера между кадрами.

Это является одной из основ более сложных систем визуальной навигации.

## Ограничения

Признаки не являются универсальным решением.

Проблемы могут возникать при:

```text
сильном изменении освещения
сильном размытии
очень маленьком объекте
полностью однородной поверхности
сильной окклюзии
```

Например:

```text
белая стена
```

может практически не содержать характерных точек.

## Признаки и нейросети

Классические методы выделяют признаки специальными алгоритмами.

В нейросетевом компьютерном зрении признаки часто извлекаются самой нейронной сетью.

Упрощённо:

```text
Изображение
    ↓
Нейронная сеть
    ↓
Внутренние признаки
    ↓
Результат
```

На ранних слоях могут появляться представления простых структур:

```text
границы
текстуры
простые формы
```

На более глубоких:

```text
части объектов
сложные структуры
объекты
```

Это одна из важных идей современного компьютерного зрения.

## Главное

Запомните:

* признак — полезная характеристика изображения;
* ключевая точка показывает характерное место;
* дескриптор описывает область вокруг признака;
* признаки можно сопоставлять между изображениями;
* SIFT и ORB — примеры классических методов;
* признаки помогают работать с изменением положения и, в некоторых случаях, масштаба и поворота;
* классические признаки используются в сопоставлении изображений и робототехнике;
* современные нейросети тоже извлекают признаки, но делают это обучаемым способом.

В следующем уроке рассмотрим **классификацию изображений — задачу определения того, к какому классу относится целое изображение**.
