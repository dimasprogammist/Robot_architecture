# Поиск и выделение объектов

## Цель урока

После этого урока вы должны понимать:

* что означает поиск объекта на изображении;
* как связаны сегментация, контуры и поиск объектов;
* как фильтровать найденные области;
* как получать координаты объекта;
* как находить центр объекта;
* как определять его размеры;
* как использовать ограничивающий прямоугольник;
* как отделять реальные объекты от шума.

## От изображения к объекту

В предыдущих уроках мы рассматривали отдельные этапы:

```text
Изображение
    ↓
Обработка
    ↓
Сегментация
    ↓
Маска
    ↓
Контуры
```

Теперь объединим их.

Наша цель:

> получить не просто изображение, а список найденных объектов с их характеристиками.

Например:

```text
Объект 1:
    x = 120
    y = 80
    width = 150
    height = 100
    area = 12000

Объект 2:
    x = 450
    y = 200
    width = 90
    height = 70
    area = 6200
```

Такую информацию уже можно передавать дальше в программу управления.

## Простейший объект

Представим изображение:

```text
+--------------------------+
|                          |
|      ##########          |
|     ############         |
|     ############         |
|      ##########          |
|                          |
+--------------------------+
```

После сегментации получаем маску:

```text
+--------------------------+
|                          |
|      1111111111          |
|     111111111111         |
|     111111111111         |
|      1111111111          |
|                          |
+--------------------------+
```

После поиска контура программа получает границу объекта.

Теперь можно вычислить:

```text
площадь
периметр
центр
размер
координаты
```

## Ограничивающий прямоугольник

Один из самых удобных способов представить объект — прямоугольник.

Для контура:

```python
x, y, w, h = cv2.boundingRect(contour)
```

получаем:

```text
x → левый край
y → верхний край
w → ширина
h → высота
```

Например:

```text
x = 100
y = 50
w = 200
h = 120
```

Можно представить объект:

```text
(100,50)
    +-------------------+
    |                   |
    |      объект       |
    |                   |
    +-------------------+
                      (300,170)
```

Такой прямоугольник называется **bounding box**.

## Почему bounding box полезен

Прямоугольник значительно проще хранить и передавать, чем тысячи координат контура.

Вместо:

```text
(x1, y1)
(x2, y2)
(x3, y3)
...
(x500, y500)
```

можно сохранить:

```text
x
y
width
height
```

Например:

```text
100, 50, 200, 120
```

Этого уже достаточно для многих задач.

## Центр объекта

Если нас интересует положение объекта, часто нужен его центр.

Простейший вариант — центр bounding box:

```python
center_x = x + w // 2
center_y = y + h // 2
```

Получаем:

```text
(center_x, center_y)
```

Другой вариант — использовать моменты контура:

```python
M = cv2.moments(contour)

if M["m00"] != 0:
    cx = int(M["m10"] / M["m00"])
    cy = int(M["m01"] / M["m00"])
```

Центр по моментам может лучше отражать геометрический центр области.

## Фильтрация по площади

После сегментации часто остаётся шум.

Например:

```text
объект
+
маленькие точки
+
мелкие области
```

Если просто получить все контуры, программа может считать каждую точку отдельным объектом.

Поэтому используется фильтрация.

Например:

```python
for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    # Здесь находится достаточно крупный объект
```

Теперь маленькие области игнорируются.

## Фильтрация по размеру

Можно использовать не только площадь.

Например:

```python
x, y, w, h = cv2.boundingRect(contour)

if w < 20 or h < 20:
    continue
```

Так можно отбрасывать слишком маленькие объекты.

Можно также задавать допустимый диапазон:

```python
if not 50 <= w <= 300:
    continue

if not 30 <= h <= 200:
    continue
```

Это особенно полезно, когда известно, примерно какого размера должен быть объект.

## Соотношение сторон

Можно вычислить отношение ширины к высоте:

```python
aspect_ratio = w / h
```

Например:

```text
w = 200
h = 100

aspect_ratio = 2.0
```

Это позволяет отличать вытянутые объекты от почти квадратных.

Например:

```text
aspect_ratio ≈ 1
```

может соответствовать объекту примерно квадратной формы.

А:

```text
aspect_ratio ≈ 3
```

указывает на сильно вытянутую область.

Это не универсальный классификатор, но для простых задач может быть очень полезно.

## Фильтрация по положению

Иногда область интереса находится только в определённой части изображения.

Например:

```text
+--------------------------------+
|                                |
|                                |
|       Рабочая область          |
|       +----------------+       |
|       |                |       |
|       |     объект     |       |
|       |                |       |
|       +----------------+       |
|                                |
+--------------------------------+
```

Если контур находится вне рабочей области, его можно игнорировать.

Это уменьшает количество ложных обнаружений.

## Рисование найденных объектов

После фильтрации можно визуализировать результат:

```python
result = image.copy()

for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    x, y, w, h = cv2.boundingRect(contour)

    cv2.rectangle(
        result,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        2
    )

    cv2.putText(
        result,
        f"Area: {int(area)}",
        (x, y - 10),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.6,
        (0, 255, 0),
        2
    )
```

Теперь изображение содержит информацию о найденном объекте.

## Полный пример

Рассмотрим простой конвейер:

```python
import cv2

image = cv2.imread("objects.jpg")

if image is None:
    raise RuntimeError("Не удалось загрузить изображение")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)

_, mask = cv2.threshold(
    blurred,
    100,
    255,
    cv2.THRESH_BINARY
)

contours, _ = cv2.findContours(
    mask,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

result = image.copy()

for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    x, y, w, h = cv2.boundingRect(contour)

    center_x = x + w // 2
    center_y = y + h // 2

    cv2.rectangle(
        result,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        2
    )

    cv2.circle(
        result,
        (center_x, center_y),
        5,
        (0, 0, 255),
        -1
    )

    print(
        f"Object: x={x}, y={y}, "
        f"w={w}, h={h}, area={area}"
    )

cv2.imshow("Objects", result)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Логика:

```text
Изображение
    ↓
Grayscale
    ↓
Blur
    ↓
Threshold
    ↓
Контуры
    ↓
Фильтрация
    ↓
Bounding box
    ↓
Центр объекта
```

## Несколько объектов

Предположим, на изображении три детали:

```text

|   ##       ######               |
|  ####     ########       ###     |
|   ##       ######       #####    |
|                          ###     |
|                                  |
+----------------------------------+
```

После обработки можно получить:

```text
Объект 1
Объект 2
Объект 3
```

Для каждого будут отдельные данные.

Например:

```text
Object 1:

x=300
y=90
w=120
h=100

Object 3:
x=600

w=60

```

Это уже структура данных, с которой может работать программа.

## Выделение объекта из изображения

Если есть маска, можно получить только объект:

```python
object_image = cv2.bitwise_and(
    image,
    image,
    mask=mask
)
```

Например:

```text
Исходное изображение
        ↓
       Маска
        ↓
Объект
```

Это полезно, если после обнаружения нужно дополнительно проанализировать сам объект.

## Поиск объектов по цвету

Можно использовать не только яркость, но и цвет.

Например:

```text
камера
  ↓
BGR
  ↓
HSV
  ↓
inRange
  ↓
маска красного
  ↓
контуры
  ↓
объекты
```

Таким способом можно найти все объекты определённого цвета.

## Важное ограничение

Контуры и простая сегментация хорошо работают, если условия относительно контролируемые.

Например:

```text
объект
+
контрастный фон
+
стабильное освещение
```

Но если изображение выглядит так:

```text
много объектов
перекрытия
сложный фон
тени
разные размеры
разные положения
```

простые правила могут оказаться недостаточными.

В таких случаях применяются более сложные методы:

* признаки;
* классификаторы;
* нейронные сети;
* детекторы объектов;
* сегментационные модели.

К ним мы придём позже.

## Практический пример из робототехники

Представим конвейер:

```text
                Камера
                  ↓
       +---------------------+
       |                     |
       |   детали на ленте   |
       |                     |
       +---------------------+
                  ↓
             Компьютер
                  ↓
       Найдены координаты
                  ↓
          Робот-манипулятор
```

Компьютерное зрение может определить:

```text
объект 1 → (250, 180)
объект 2 → (470, 220)
```

После этого отдельная система преобразует координаты изображения в координаты рабочего пространства робота.

Важно:

> координаты пикселей сами по себе ещё не являются координатами робота.

Для такого преобразования позже понадобятся геометрия, калибровка и информация о камере.

## Главное

Теперь у нас есть полный базовый конвейер поиска простых объектов:

```text
Изображение
    ↓
Предварительная обработка
    ↓
Сегментация
    ↓
Маска
    ↓
Контуры
    ↓
Фильтрация
    ↓
Объекты
    ↓
Координаты и размеры
```

Запомните:

* объект можно искать через его маску и контур;
* `boundingRect()` даёт ограничивающий прямоугольник;
* центр можно вычислить по прямоугольнику или моментам;
* площадь помогает фильтровать шум;
* ширина и высота позволяют анализировать размер;
* отношение сторон помогает анализировать форму;
* положение объекта можно использовать для дальнейшего управления;
* простые методы хорошо работают при контролируемых условиях.
