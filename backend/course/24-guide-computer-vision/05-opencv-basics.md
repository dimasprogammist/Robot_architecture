## Что такое OpenCV

**OpenCV (Open Source Computer Vision Library)** — библиотека с большим набором инструментов для обработки изображений, видео и задач компьютерного зрения.

Она широко используется в:

* Python;
* C++;
* робототехнике;
* автоматизации;
* исследованиях;
* компьютерном зрении;
* обработке видео.

OpenCV позволяет не писать каждый алгоритм с нуля.

Например, вместо самостоятельной реализации Gaussian Blur можно использовать готовую функцию:

```python
cv2.GaussianBlur(...)
```

В этом уроке мы познакомимся с базовыми возможностями библиотеки.

## Установка

Для Python библиотеку можно установить через `pip`:

```bash
pip install opencv-python
```

После установки проверим импорт:

```python
import cv2

print(cv2.__version__)
```

Если версия библиотеки вывелась без ошибки, OpenCV установлен.

## Загрузка изображения

Для загрузки изображения используется:

```python
cv2.imread()
```

Пример:

```python
import cv2

image = cv2.imread("image.jpg")
```

После выполнения переменная `image` содержит изображение в виде массива данных.

Важно проверять, удалось ли загрузить файл:

```python
import cv2

image = cv2.imread("image.jpg")

if image is None:
    print("Не удалось загрузить изображение")
else:
    print("Изображение загружено")
```

Если путь к файлу неправильный или файл отсутствует, `cv2.imread()` не сможет его загрузить.

## Отображение изображения

Для отображения используется:

```python
cv2.imshow()
```

Например:

```python
import cv2

image = cv2.imread("image.jpg")

cv2.imshow("Image", image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

Здесь происходят три действия.

### `cv2.imshow()`

Создаёт окно с изображением:

```python
cv2.imshow("Image", image)
```

Первый аргумент — название окна.

Второй — само изображение.

### `cv2.waitKey()`

Ожидает нажатия клавиши:

```python
cv2.waitKey(0)
```

Значение `0` означает ждать бесконечно.

### `cv2.destroyAllWindows()`

Закрывает созданные окна:

```python
cv2.destroyAllWindows()
```

## Размер изображения

Размер изображения можно узнать через `shape`:

```python
print(image.shape)
```

Для цветного изображения результат обычно имеет вид:

```text
(1080, 1920, 3)
```

Это означает:

```text
1080 → высота
1920 → ширина
3    → количество каналов
```

Важно: в NumPy и OpenCV порядок обычно такой:

```text
height × width × channels
```

а не:

```text
width × height × channels
```

## Изменение размера

Для изменения размера используется:

```python
cv2.resize()
```

Например:

```python
small = cv2.resize(image, (640, 480))
```

Теперь размер изображения:

```text
640 × 480
```

Полный пример:

```python
import cv2

image = cv2.imread("image.jpg")

if image is None:
    raise RuntimeError("Не удалось загрузить изображение")

small = cv2.resize(image, (640, 480))

cv2.imshow("Original", image)
cv2.imshow("Resized", small)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

## Сохранение изображения

Для сохранения используется:

```python
cv2.imwrite()
```

Например:

```python
cv2.imwrite("result.jpg", image)
```

Можно сохранить обработанную версию:

```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

cv2.imwrite("gray.jpg", gray)
```

## Преобразование в оттенки серого

Для преобразования цветного изображения в grayscale используется:

```python
cv2.cvtColor()
```

Например:

```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
```

Здесь:

```text
BGR → Gray
```

Важно использовать `COLOR_BGR2GRAY`, потому что OpenCV обычно загружает цветные изображения в порядке BGR.

После преобразования изображение имеет только один канал.

Можно проверить:

```python
print(gray.shape)
```

Например:

```text
(480, 640)
```

Третьего измерения больше нет.

## Gaussian Blur

Для размытия используется:

```python
cv2.GaussianBlur()
```

Пример:

```python
blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)
```

Здесь:

```text
gray
```

— исходное изображение,

```text
(5, 5)
```

— размер ядра,

```text
0
```

— параметр, позволяющий OpenCV определить стандартное отклонение автоматически.

Размытие часто применяется перед поиском границ и другими алгоритмами.

## Пороговая обработка

Для простой бинаризации можно использовать:

```python
cv2.threshold()
```

Например:

```python
_, binary = cv2.threshold(
    gray,
    100,
    255,
    cv2.THRESH_BINARY
)
```

Логика:

```text
если pixel > 100:
    255
иначе:
    0
```

Получаем изображение, состоящее в основном из двух значений:

```text
0
255
```

Такую маску можно использовать для поиска объектов и их областей.

## Полный простой пример

Объединим несколько операций:

```python
import cv2

image = cv2.imread("image.jpg")

if image is None:
    raise RuntimeError("Не удалось загрузить изображение")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)

_, binary = cv2.threshold(
    blurred,
    100,
    255,
    cv2.THRESH_BINARY
)

cv2.imshow("Original", image)
cv2.imshow("Gray", gray)
cv2.imshow("Binary", binary)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Получается простой конвейер:

```text
Исходное изображение
        ↓
Grayscale
        ↓
Gaussian Blur
        ↓
Threshold
        ↓
Бинарное изображение
```

Это уже настоящий небольшой конвейер компьютерного зрения.

## Доступ к отдельному пикселю

Так как изображение является массивом NumPy, можно получить отдельный пиксель.

Для цветного изображения:

```python
pixel = image[100, 200]

print(pixel)
```

Здесь:

```text
100 → координата Y
200 → координата X
```

То есть:

```text
image[y, x]
```

Для BGR-изображения результат содержит три значения:

```text
[B, G, R]
```

Например:

```python
b, g, r = image[100, 200]

print("B:", b)
print("G:", g)
print("R:", r)
```

## Работа с областью изображения

Можно получить часть изображения с помощью среза NumPy.

Например:

```python
roi = image[100:400, 200:600]
```

Здесь:

```text
100:400 → диапазон Y
200:600 → диапазон X
```

То есть выбирается прямоугольная область:

```text
y = 100 ... 399
x = 200 ... 599
```

Можно отобразить её:

```python
cv2.imshow("ROI", roi)
```

ROI особенно полезен, если нас интересует только определённая область изображения.

## Работа с камерой

OpenCV умеет получать изображения с камеры.

Для этого используется:

```python
cv2.VideoCapture()
```

Простейший пример:

```python
import cv2

camera = cv2.VideoCapture(0)

while True:
    ret, frame = camera.read()

    if not ret:
        print("Не удалось получить кадр")
        break

    cv2.imshow("Camera", frame)

    if cv2.waitKey(1) == 27:
        break

camera.release()
cv2.destroyAllWindows()
```

Разберём этот код.

### Открытие камеры

```python
camera = cv2.VideoCapture(0)
```

Число `0` обычно означает первую доступную камеру.

Если подключено несколько камер, могут использоваться другие индексы:

```text
0
1
2
...
```

### Получение кадра

```python
ret, frame = camera.read()
```

`frame` содержит полученное изображение.

`ret` показывает, удалось ли получить кадр.

### Цикл

Кадры считываются один за другим:

```text
Кадр 1
  ↓
Кадр 2
  ↓
Кадр 3
  ↓
Кадр 4
  ↓
...
```

Поэтому видео можно обрабатывать практически так же, как последовательность отдельных изображений.

### Выход

В примере:

```python
if cv2.waitKey(1) == 27:
    break
```

Число `27` соответствует клавише `Esc`.

После выхода камеру нужно освободить:

```python
camera.release()
```

## Базовые функции OpenCV

На этом этапе полезно запомнить несколько функций:

```text
cv2.imread()
    загрузка изображения

cv2.imwrite()
    сохранение изображения

cv2.imshow()
    отображение изображения

cv2.waitKey()
    ожидание клавиши

cv2.destroyAllWindows()
    закрытие окон

cv2.resize()
    изменение размера

cv2.cvtColor()
    преобразование цветового пространства

cv2.GaussianBlur()
    гауссово размытие

cv2.threshold()
    пороговая обработка

cv2.VideoCapture()
    получение кадров с камеры
```

Это только небольшая часть OpenCV.

Библиотека содержит большое количество инструментов для дальнейшего анализа изображений и видео.

## Типичный рабочий процесс

Простейшая программа компьютерного зрения часто выглядит примерно так:

```text
Получить изображение
        ↓
Проверить изображение
        ↓
Предварительно обработать
        ↓
Выполнить основной алгоритм
        ↓
Получить результат
        ↓
Показать / сохранить / передать результат
```

Например:

```text
Камера
  ↓
frame
  ↓
Grayscale
  ↓
Blur
  ↓
Threshold
  ↓
Поиск объекта
  ↓
Координаты объекта
```

Это уже основа для более сложных систем.
