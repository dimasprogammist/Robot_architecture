# Контуры и границы объектов

## Цель урока

После этого урока вы должны понимать:

* что такое граница объекта на изображении;
* чем границы отличаются от контуров;
* что такое алгоритм Canny;
* как получать контуры с помощью OpenCV;
* что можно узнать из контура;
* как находить площадь, периметр и ограничивающий прямоугольник;
* почему контуры особенно полезны для анализа геометрических объектов.

## Зачем искать границы

До этого момента мы рассматривали изображение как набор пикселей.

Но часто нас интересует не каждый отдельный пиксель, а форма объекта.

Например, камера видит деталь:

```text
+---------------------------+
|                           |
|        #########          |
|      #############        |
|     ###############       |
|      #############        |
|        #########          |
|                           |
+---------------------------+
```

Для человека очевидно, где находится объект.

Программе нужно каким-то образом определить:

```text
где заканчивается фон
и
где начинается объект
```

Для этого можно искать границы.

## Что такое граница

**Граница** — это область изображения, где резко изменяются значения пикселей.

Например:

```text
фон → фон → фон → объект → объект
```

В момент перехода:

```text
фон | объект
```

происходит резкое изменение яркости или цвета.

Если объект тёмный на светлом фоне:

```text
255 255 255 255 30 30 30 30
```

между `255` и `30` находится сильный переход.

Такой переход можно рассматривать как границу объекта.

## Границы не обязательно являются контурами

Это важное различие.

**Граница** — это изменение изображения.

**Контур** — это последовательность точек, описывающая форму объекта или области.

Можно представить так:

```text
Изображение
    ↓
Поиск границ
    ↓
Набор точек
    ↓
Контур
    ↓
Анализ формы
```

Контур уже удобно использовать для геометрических вычислений.

## Алгоритм Canny

Один из наиболее известных алгоритмов поиска границ — **Canny Edge Detector**.

В OpenCV он доступен через:

```python
cv2.Canny()
```

Пример:

```python
import cv2

image = cv2.imread("image.jpg")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)

edges = cv2.Canny(
    blurred,
    50,
    150
)

cv2.imshow("Edges", edges)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Результатом будет изображение, на котором выделены участки резкого изменения.

## Параметры Canny

Вызов:

```python
cv2.Canny(
    image,
    50,
    150
)
```

содержит два порога.

В данном случае:

```text
50  → нижний порог
150 → верхний порог
```

Изменение этих параметров влияет на количество найденных границ.

Если пороги слишком низкие, алгоритм может обнаружить слишком много лишних границ:

```text
шум
текстура
мелкие детали
```

Если пороги слишком высокие, реальные границы могут быть потеряны.

Поэтому параметры подбираются под конкретную задачу.

## Почему перед Canny часто используют Blur

Шум тоже может создавать резкие изменения яркости.

Например:

```text
Полезная граница
+
случайный шум
```

может привести к большому количеству ложных границ.

Поэтому часто используют:

```text
Изображение
    ↓
Grayscale
    ↓
Gaussian Blur
    ↓
Canny
```

Размытие уменьшает мелкие случайные изменения, после чего поиск границ становится стабильнее.

## Поиск контуров

После получения бинарной маски или другого подходящего изображения можно искать контуры.

В OpenCV используется:

```python
cv2.findContours()
```

Пример:

```python
import cv2

image = cv2.imread("image.jpg")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

_, binary = cv2.threshold(
    gray,
    100,
    255,
    cv2.THRESH_BINARY
)

contours, hierarchy = cv2.findContours(
    binary,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
```

Теперь `contours` содержит найденные контуры.

## Что такое `RETR_EXTERNAL`

Вызов:

```python
cv2.findContours(
    binary,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
```

содержит режим поиска:

```python
cv2.RETR_EXTERNAL
```

Он означает, что нас интересуют внешние контуры.

Это удобно, когда нужно найти сами объекты, не анализируя их внутренние отверстия.

Например:

```text
+----------------+
|                |
|    ######      |
|   ##    ##     |
|   ##    ##     |
|    ######      |
|                |
+----------------+
```

При использовании внешних контуров можно получить внешний контур фигуры.

Другие режимы позволяют анализировать иерархию вложенных контуров.

## Рисование контуров

Для отображения найденных контуров используется:

```python
cv2.drawContours()
```

Пример:

```python
result = image.copy()

cv2.drawContours(
    result,
    contours,
    -1,
    (0, 255, 0),
    2
)

cv2.imshow("Contours", result)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Число:

```text
-1
```

означает нарисовать все найденные контуры.

## Количество объектов

Если каждый объект на изображении имеет отдельный контур, можно примерно оценить количество объектов:

```python
print("Найдено контуров:", len(contours))
```

Например:

```text
Найдено контуров: 5
```

Но это не означает автоматически, что на изображении ровно пять объектов.

Один объект может иметь несколько контуров, а шум может создавать ложные контуры.

Поэтому контуры нужно дополнительно фильтровать и анализировать.

## Площадь контура

OpenCV позволяет вычислить площадь контура:

```python
area = cv2.contourArea(contour)
```

Например:

```python
for contour in contours:
    area = cv2.contourArea(contour)
    print(area)
```

Это полезно, если нужно удалить слишком маленькие области.

Например:

```python
for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    # Работаем с объектом
```

Так можно избавиться от части мелкого шума.

## Периметр

Периметр контура можно получить через:

```python
cv2.arcLength()
```

Пример:

```python
perimeter = cv2.arcLength(
    contour,
    True
)
```

Второй аргумент:

```text
True
```

означает, что контур замкнут.

Для объекта:

```text
      ####
    ##    ##
   ##      ##
    ##    ##
      ####
```

периметр соответствует длине его внешней границы.

## Ограничивающий прямоугольник

Для многих задач нужно быстро получить прямоугольник, в который помещается объект.

Используется:

```python
cv2.boundingRect()
```

Пример:

```python
x, y, w, h = cv2.boundingRect(contour)
```

Получаем:

```text
x → координата левой границы
y → координата верхней границы
w → ширина
h → высота
```

Можно нарисовать прямоугольник:

```python
cv2.rectangle(
    result,
    (x, y),
    (x + w, y + h),
    (0, 255, 0),
    2
)
```

Получается:

```text
+-----------------------+
|                       |
|     +-----------+     |
|     |   объект  |     |
|     +-----------+     |
|                       |
+-----------------------+
```

## Центр объекта

По контуру можно вычислить его моменты.

Например:

```python
M = cv2.moments(contour)
```

Если площадь ненулевая, координаты центра можно определить:

```python
cx = int(M["m10"] / M["m00"])
cy = int(M["m01"] / M["m00"])
```

Получаем:

```text
(cx, cy)
```

Это приблизительное положение центра объекта.

Такая информация особенно полезна в робототехнике.

Например:

```text
Камера
  ↓
Контур детали
  ↓
Центр детали
  ↓
(cx, cy)
  ↓
Расчёт положения
  ↓
Робот
```

## Пример анализа объектов

Можно объединить несколько операций:

```python
import cv2

image = cv2.imread("objects.jpg")

if image is None:
    raise RuntimeError("Не удалось загрузить изображение")

gray = cv2.cvtColor(
    image,
    cv2.COLOR_BGR2GRAY
)

blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)

_, binary = cv2.threshold(
    blurred,
    100,
    255,
    cv2.THRESH_BINARY
)

contours, _ = cv2.findContours(
    binary,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

result = image.copy()

for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    x, y, w, h = cv2.boundingRect(contour)

    cv2.rectangle(
        result,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        2
    )

cv2.imshow("Result", result)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Здесь происходит:

```text
Изображение
    ↓
Grayscale
    ↓
Blur
    ↓
Threshold
    ↓
Поиск контуров
    ↓
Фильтрация по площади
    ↓
Bounding box
```

Это уже простая система поиска объектов.

## Что можно узнать из контура

Контур позволяет получить достаточно много информации:

```text
Площадь
Периметр
Положение
Размер
Ограничивающий прямоугольник
Форма
Ориентация
Количество объектов
```

На основании этих данных можно классифицировать простые геометрические объекты.

Например:

```text
площадь
периметр
отношение ширины к высоте
круглость
```

могут помочь отличить одну деталь от другой.

## Главное

Контуры являются одним из основных инструментов классического компьютерного зрения.

Запомните:

* граница возникает там, где резко меняются значения изображения;
* Canny позволяет находить границы;
* `findContours()` позволяет находить контуры;
* контур можно использовать для анализа формы объекта;
* `contourArea()` вычисляет площадь;
* `arcLength()` вычисляет периметр;
* `boundingRect()` позволяет получить ограничивающий прямоугольник;
* моменты контура позволяют найти его центр;
* небольшие контуры можно отфильтровать по площади.

В следующем уроке разберём **сегментацию изображений — способы отделить интересующий объект от фона и получить маску, с которой дальше можно работать алгоритмически**.
