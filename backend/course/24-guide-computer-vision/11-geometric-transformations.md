# Геометрические преобразования изображений

## Цель урока

После этого урока вы должны понимать:

* что такое геометрическое преобразование изображения;
* как изменять размер изображения;
* как выполнять поворот;
* как отражать изображение;
* что такое аффинное преобразование;
* что такое перспективное преобразование;
* зачем преобразовывать координаты;
* где такие операции используются в компьютерном зрении.

## Что такое геометрическое преобразование

До этого мы в основном изменяли значения пикселей:

```text
яркость
контраст
цвет
размытие
порог
```

Но изображение можно изменять и геометрически.

Например:

```text
уменьшить
увеличить
повернуть
отразить
сдвинуть
исправить перспективу
```

При этом изменяется положение пикселей.

Например:

```text
Исходное:

######
######
######

        ↓

Поворот:

###
###
###
###
###
###
```

Содержимое объекта осталось тем же, но его положение относительно изображения изменилось.

## Изменение размера

Одна из самых распространённых операций:

```python
cv2.resize()
```

Например:

```python
import cv2

image = cv2.imread("image.jpg")

resized = cv2.resize(
    image,
    (640, 480)
)

cv2.imshow("Resized", resized)

cv2.waitKey(0)
cv2.destroyAllWindows()
```

Теперь изображение имеет размер:

```text
640 × 480
```

## Зачем изменять размер

Уменьшение изображения может значительно ускорить обработку.

Например:

```text
3840 × 2160
```

содержит гораздо больше пикселей, чем:

```text
1280 × 720
```

Если задача не требует высокой детализации, уменьшение изображения может снизить нагрузку.

С другой стороны, слишком сильное уменьшение может уничтожить важные детали.

Например:

```text
маленькая деталь
      ↓
сильное уменьшение
      ↓
деталь практически исчезла
```

Поэтому размер изображения выбирается исходя из задачи.

## Сохранение пропорций

Если изменить ширину и высоту независимо:

```python
cv2.resize(
    image,
    (800, 400)
)
```

объект может растянуться.

Например:

```text
круг
 ↓
овал
```

Поэтому часто нужно сохранять исходное соотношение сторон.

Можно масштабировать изображение через коэффициент:

```python
scale = 0.5

resized = cv2.resize(
    image,
    None,
    fx=scale,
    fy=scale
)
```

Здесь изображение уменьшается в два раза по каждой координате.

## Интерполяция

При изменении размера появляются пиксели, которых не было в исходном изображении.

Поэтому OpenCV должен вычислить их значения.

Этот процесс называется **интерполяцией**.

Например:

```python
resized = cv2.resize(
    image,
    (800, 600),
    interpolation=cv2.INTER_LINEAR
)
```

Распространённые методы:

```text
INTER_NEAREST
INTER_LINEAR
INTER_CUBIC
INTER_AREA
```

Для уменьшения изображения часто хорошо подходит:

```python
cv2.INTER_AREA
```

Например:

```python
resized = cv2.resize(
    image,
    (640, 480),
    interpolation=cv2.INTER_AREA
)
```

## Поворот

Изображение можно повернуть вокруг определённой точки.

OpenCV предоставляет готовые варианты:

```python
cv2.rotate()
```

Например:

```python
rotated = cv2.rotate(
    image,
    cv2.ROTATE_90_CLOCKWISE
)
```

Другие варианты:

```python
cv2.ROTATE_90_COUNTERCLOCKWISE
cv2.ROTATE_180
```

Это удобно для простых случаев.

## Поворот на произвольный угол

Если нужен угол, например:

```text
30°
```

можно создать матрицу поворота:

```python
height, width = image.shape[:2]

center = (
    width // 2,
    height // 2
)

matrix = cv2.getRotationMatrix2D(
    center,
    30,
    1.0
)
```

Затем:

```python
rotated = cv2.warpAffine(
    image,
    matrix,
    (width, height)
)
```

Здесь:

```text
center → центр вращения
30     → угол
1.0    → масштаб
```

## Отражение

Изображение можно отразить:

```python
flipped = cv2.flip(
    image,
    1
)
```

Параметр:

```text
1 → горизонтальное отражение
0 → вертикальное отражение
-1 → оба направления
```

Например:

```python
horizontal = cv2.flip(image, 1)
vertical = cv2.flip(image, 0)
both = cv2.flip(image, -1)
```

## Сдвиг изображения

Изображение можно перемещать относительно исходной системы координат.

Например:

```text
объект был здесь:

   ####
   ####

        ↓ сдвиг

        ####
        ####
```

Для этого можно использовать аффинное преобразование.

## Аффинное преобразование

**Аффинное преобразование** позволяет выполнять комбинации:

```text
сдвига
масштабирования
поворота
отражения
```

При этом параллельные линии остаются параллельными.

В OpenCV можно использовать:

```python
cv2.getAffineTransform()
```

и:

```python
cv2.warpAffine()
```

Для построения преобразования используются соответствующие точки.

Например:

```python
import numpy as np
import cv2

src = np.float32([
    [0, 0],
    [100, 0],
    [0, 100]
])

dst = np.float32([
    [20, 30],
    [120, 20],
    [30, 130]
])

matrix = cv2.getAffineTransform(
    src,
    dst
)

result = cv2.warpAffine(
    image,
    matrix,
    (image.shape[1], image.shape[0])
)
```

Здесь мы задаём соответствие между тремя точками исходного и нового изображения.

## Перспектива

Теперь рассмотрим более интересный случай.

Представим фотографию документа:

```text
+-----------------------+
 \                     /
  \                   /
   \_________________/
```

Документ расположен под углом.

На изображении он имеет форму трапеции.

Но нам хотелось бы получить:

```text
+-----------------------+
|                       |
|       ДОКУМЕНТ        |
|                       |
+-----------------------+
```

Для этого используется **перспективное преобразование**.

## Почему перспектива возникает

Камера видит трёхмерный мир через двумерное изображение.

Поэтому объекты, находящиеся под разными углами относительно камеры, могут выглядеть искажёнными.

Например, прямоугольная деталь может выглядеть как:

```text
   +---------+
  /         /
 /         /
+---------+
```

Хотя в реальности она прямоугольная.

## Perspective Transform

В OpenCV используются:

```python
cv2.getPerspectiveTransform()
```

и:

```python
cv2.warpPerspective()
```

Например:

```python
import numpy as np
import cv2

src = np.float32([
    [100, 100],
    [500, 80],
    [520, 400],
    [90, 420]
])

dst = np.float32([
    [0, 0],
    [400, 0],
    [400, 300],
    [0, 300]
])

matrix = cv2.getPerspectiveTransform(
    src,
    dst
)

result = cv2.warpPerspective(
    image,
    matrix,
    (400, 300)
)
```

Теперь четырём углам исходной области сопоставляется прямоугольная область.

## Где используется перспектива

Перспективные преобразования применяются для:

* распознавания документов;
* исправления фотографий;
* анализа дорожных сцен;
* робототехники;
* измерений;
* анализа плоских деталей;
* преобразования изображения рабочей области.

Например:

```text
Камера
  ↓
Плоская рабочая поверхность
  ↓
Перспективное искажение
  ↓
Коррекция
  ↓
Удобная система координат
```

## ROI и геометрические преобразования

Мы уже использовали ROI:

```python
roi = image[
    100:400,
    200:600
]
```

Геометрические преобразования позволяют сделать ROI ещё полезнее.

Например:

```text
камера
  ↓
рабочая область находится под углом
  ↓
perspective transform
  ↓
прямоугольная область
  ↓
анализ
```

Это часто упрощает дальнейшие алгоритмы.

## Координаты изображения

Напомним систему координат:

```text
(0,0)
  +--------------------→ X
  |
  |
  |
  ↓
  Y
```

Точка:

```text
(x, y)
```

определяет положение пикселя.

После геометрического преобразования координаты меняются.

Например:

```text
до:
(100, 50)

после:
(150, 80)
```

Это означает, что одна и та же точка изображения была перенесена в другое положение.

## Почему это важно для компьютерного зрения

Представим камеру над рабочей областью.

Если камера установлена идеально:

```text
камера
  ↓
+----------------+
|                |
|    рабочая     |
|    область     |
|                |
+----------------+
```

анализ относительно простой.

Но если камера стоит под углом:

```text
камера
  ↓
  \
   \
    \  рабочая область
     \____________
```

координаты изображения уже не соответствуют непосредственно координатам рабочей поверхности.

Преобразование может сделать изображение более удобным для дальнейшего анализа.

## Главное

Запомните:

* геометрические преобразования изменяют положение пикселей;
* `resize()` изменяет размер;
* `rotate()` выполняет стандартный поворот;
* `flip()` отражает изображение;
* `warpAffine()` выполняет аффинное преобразование;
* `warpPerspective()` выполняет перспективное преобразование;
* аффинное преобразование сохраняет параллельность линий;
* перспектива позволяет исправлять искажение плоской области;
* геометрические преобразования особенно полезны, когда положение камеры отличается от идеального.
