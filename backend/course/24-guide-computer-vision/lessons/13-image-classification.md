# Классификация изображений

## Цель урока

После этого урока вы должны понимать:

* что такое классификация изображений;
* чем классификация отличается от поиска объекта;
* что такое класс;
* как выглядит задача классификации;
* как используются признаки;
* почему нейронные сети хорошо подходят для классификации;
* где классификация применяется в робототехнике и автоматизации.

## Что такое классификация

**Классификация изображения** — это определение того, к какому классу относится изображение.

Например:

```text
Изображение
     ↓
Классификатор
     ↓
"Кошка"
```

Или:

```text
Изображение детали
     ↓
Классификатор
     ↓
"Деталь типа A"
```

## Что такое класс

**Класс** — категория, к которой относится объект или изображение.

Например:

```text
Класс 1 → красная деталь
Класс 2 → синяя деталь
Класс 3 → зелёная деталь
```

Или:

```text
Класс 1 → исправная деталь
Класс 2 → дефектная деталь
```

Количество классов зависит от задачи.

## Классификация всего изображения

Представим фотографию:

```text
+----------------------+
|                      |
|       объект         |
|                      |
+----------------------+
```

Классификатор отвечает:

```text
Что изображено?
```

Например:

```text
→ "круглая деталь"
```

При этом классификатор может не сообщать координаты объекта.

## Классификация и детекция

Это принципиально разные задачи.

### Классификация

```text
Изображение
    ↓
Класс
```

Например:

```text
Фото
 ↓
"кошка"
```

### Детекция

```text
Изображение
    ↓
Объекты + координаты
```

Например:

```text
кошка
bounding box
координаты
```

Можно представить:

```text
Classification:

[ КОШКА ]

Detection:

+----------------------+
|                      |
|    +---------+       |
|    |  кошка  |       |
|    +---------+       |
|                      |
+----------------------+
```

## Почему это важно

Если на изображении находится только один объект, классификация может быть достаточной.

Например:

```text
Камера
  ↓
одна деталь
  ↓
классификатор
  ↓
тип детали
```

Но если объектов несколько:

```text
деталь A
деталь B
деталь C
```

нужно сначала определить, где они находятся.

Для этого может потребоваться детекция.

## Простая классификация без нейросети

Не все задачи классификации требуют нейронной сети.

Например, если есть две детали:

```text
круглая
квадратная
```

можно использовать геометрические признаки.

Например:

```text
area
perimeter
width
height
aspect_ratio
```

Можно задать правила:

```python
if aspect_ratio > 1.8:
    class_name = "long"
else:
    class_name = "compact"
```

Это простейший классификатор на правилах.

## Классификация по цвету

Ещё один простой вариант:

```python
if red_pixels > threshold:
    class_name = "red"
```

Такие правила хорошо работают в контролируемых условиях.

Но они плохо масштабируются.

Например, если меняются:

```text
освещение
цвет поверхности
положение
фон
камера
```

правила приходится корректировать.

## Машинное обучение

Вместо ручного написания правил можно обучить модель.

Есть набор примеров:

```text
Изображение → правильный класс
```

Например:

```text
image001.jpg → A
image002.jpg → A
image003.jpg → B
image004.jpg → B
```

Модель изучает закономерности.

После обучения ей можно дать новое изображение:

```text
new_image.jpg
```

и получить:

```text
A
```

## Обучающая выборка

Для обучения обычно нужны данные.

Например:

```text
dataset/
├── class_a/
│   ├── 001.jpg
│   ├── 002.jpg
│   └── 003.jpg
│
└── class_b/
    ├── 001.jpg
    ├── 002.jpg
    └── 003.jpg
```

Модель получает множество примеров каждого класса.

## Почему нужны разные примеры

Если все изображения класса A выглядят одинаково:

```text
один объект
одинаковый угол
одинаковое освещение
```

модель может запомнить конкретный вид изображения.

Но в реальной работе:

```text
объект повернулся
объект переместился
изменилось освещение
появился шум
```

Поэтому данные должны содержать разнообразные варианты.

## Обучение и проверка

Данные обычно разделяют.

Например:

```text
Dataset
   ↓
Training
   ↓
Validation
   ↓
Test
```

### Training

Используется для обучения модели.

### Validation

Используется для настройки и контроля процесса обучения.

### Test

Используется для оценки модели на данных, которые она не использовала для обучения.

Главная идея:

> модель должна работать не только на знакомых изображениях, но и на новых.

## Вероятности классов

Современный классификатор часто возвращает не только класс.

Например:

```text
Класс A → 0.05
Класс B → 0.90
Класс C → 0.05
```

Можно интерпретировать результат как распределение уверенности модели по классам.

Наиболее вероятным является:

```text
B
```

Но вероятность модели не является гарантией правильности.

## Простая схема нейросетевого классификатора

Упрощённо:

```text
Изображение
    ↓
Предобработка
    ↓
Нейронная сеть
    ↓
Признаки
    ↓
Классификация
    ↓
Класс
```

Например:

```text
224 × 224 × 3
       ↓
   CNN / модель
       ↓
   признаки
       ↓
  выход модели
       ↓
"деталь A"
```

## Почему нейросеть может распознавать объект

На разных уровнях обработки сеть может формировать всё более сложные представления.

Условно:

```text
Пиксели
  ↓
Границы
  ↓
Текстуры
  ↓
Фрагменты формы
  ↓
Части объекта
  ↓
Объект
```

Это сильно отличается от ручного написания правил.

## CNN

Для изображений исторически очень важную роль сыграли **свёрточные нейронные сети (CNN)**.

Они хорошо подходят для анализа пространственной структуры изображения.

Упрощённо:

```text
Изображение
    ↓
Свёрточные слои
    ↓
Признаки
    ↓
Более сложные признаки
    ↓
Классификация
```

Современные модели используют и другие архитектуры, но идея извлечения пространственных признаков остаётся важной.

## Аугментация данных

Чтобы модель лучше работала с разными условиями, к изображениям можно применять преобразования:

```text
поворот
масштабирование
отражение
изменение яркости
небольшой шум
```

Например:

```text
одно изображение
      ↓
+ поворот
+ изменение яркости
+ небольшой сдвиг
      ↓
несколько вариантов
```

Это называется **аугментацией данных**.

Она позволяет увеличить разнообразие обучающих примеров.

## Пример в автоматизации

Представим контроль деталей:

```text
Камера
  ↓
Деталь
  ↓
Классификатор
  ↓
A / B / дефект
```

Например:

```text
A → правильная деталь
B → неправильная деталь
C → повреждённая деталь
```

Дальше программа может передать результат системе управления:

```text
Класс A → принять
Класс B → другой маршрут
Класс C → отбраковка
```

Само компьютерное зрение при этом только предоставляет информацию.

## Ограничения классификации

Классификация не отвечает на вопрос:

```text
Где именно объект?
```

Она отвечает:

```text
Что представляет собой изображение?
```

Если нужно:

```text
найти несколько объектов
определить их координаты
определить класс каждого объекта
```

понадобится детекция объектов.

## Главное

Запомните:

* классификация определяет класс изображения;
* класс — категория, к которой относится объект;
* классификация всего изображения не обязательно определяет координаты объекта;
* простую классификацию иногда можно построить на правилах;
* машинное обучение позволяет автоматически изучать закономерности;
* нейронные сети способны извлекать сложные признаки из изображений;
* данные для обучения должны быть разнообразными;
* test-данные нужны для проверки работы на новых изображениях;
* классификация и детекция — разные задачи.

В следующем уроке перейдём к **детекции объектов — определению того, какие объекты находятся на изображении и где именно они расположены**.
