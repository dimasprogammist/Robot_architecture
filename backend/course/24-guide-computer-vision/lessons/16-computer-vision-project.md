# Практический проект компьютерного зрения

## Цель урока

В этом уроке мы соберём вместе основные идеи всего раздела.

После выполнения проекта вы должны понимать полный базовый конвейер:

```text
Камера
  ↓
Кадр
  ↓
Предобработка
  ↓
Сегментация
  ↓
Поиск контуров
  ↓
Фильтрация объектов
  ↓
Координаты и размеры
  ↓
Результат
```

Мы не будем строить промышленную систему.

Цель проекта — увидеть, как отдельные инструменты компьютерного зрения объединяются в одну программу.

## Постановка задачи

Представим простой конвейер.

На нём находятся объекты, которые отличаются от фона.

Камера смотрит на конвейер:

```text
+--------------------------------+
|                                |
|     объект      объект         |
|                                |
|           объект               |
|                                |
+--------------------------------+
             ↓
           камера
```

Наша программа должна:

1. получить изображение;
2. выделить объекты;
3. найти их контуры;
4. отбросить слишком маленькие области;
5. определить положение каждого объекта;
6. нарисовать результат на экране.

## Архитектура проекта

Получится такая схема:


Это простой, но уже настоящий конвейер компьютерного зрения.

Для работы понадобится Python и OpenCV.

Установка:



## Шаг 1. Получение камеры

Начнём с камеры:

```python
import cv2

camera = cv2.VideoCapture(0)

if not camera.isOpened():
    raise RuntimeError("Не удалось открыть камеру")
```

Теперь программа подключилась к камере.

## Шаг 2. Получение кадра

Основной цикл:

```python
while True:
    ret, frame = camera.read()

    if not ret:
        break
```

`frame` содержит текущий кадр.

Можно сразу посмотреть его:

```python
cv2.imshow(
    "Camera",
    frame
)
```

## Шаг 3. Преобразование в grayscale

Для нашего простого проекта цвет не нужен.

Поэтому:

```python
gray = cv2.cvtColor(
    frame,
    cv2.COLOR_BGR2GRAY
)
```

Получаем:

```text
BGR
 ↓
Grayscale
```

Это уменьшает количество каналов:

```text
3 канала
    ↓
1 канал
```

## Шаг 4. Размытие

Добавим Gaussian Blur:

```python
blurred = cv2.GaussianBlur(
    gray,
    (5, 5),
    0
)
```

Это уменьшает мелкие изменения и часть шума.

Получается:

```text
Grayscale
    ↓
Blur
```

## Шаг 5. Сегментация

Теперь нужно отделить объект от фона.

Для простого случая можно использовать threshold:

```python
_, mask = cv2.threshold(
    blurred,
    100,
    255,
    cv2.THRESH_BINARY
)
```

Получаем:

```text
фон → 0
объект → 255
```

Но значение `100` не является универсальным.

Для другой камеры или освещения может понадобиться другое значение.

## Шаг 6. Поиск контуров

Теперь ищем контуры:

```python
contours, _ = cv2.findContours(
    mask,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
```

Теперь программа получила набор областей.

## Шаг 7. Фильтрация

Не каждый контур является объектом.

Например:

```text
большой объект
+
мелкий шум
+
мелкий шум
```

Поэтому используем площадь:

```python
for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue
```

Теперь маленькие области игнорируются.

## Шаг 8. Bounding box

Для каждого оставшегося объекта получаем прямоугольник:

```python
x, y, w, h = cv2.boundingRect(
    contour
)
```

Теперь известны:

```text
x
y
width
height
```

## Шаг 9. Центр

Вычислим центр:

```python
center_x = x + w // 2
center_y = y + h // 2
```

Получаем:

```text
(center_x, center_y)
```

Это положение центра объекта в координатах изображения.

## Шаг 10. Визуализация

Нарисуем прямоугольник:

```python
cv2.rectangle(
    frame,
    (x, y),
    (x + w, y + h),
    (0, 255, 0),
    2
)
```

И центр:

```python
cv2.circle(
    frame,
    (center_x, center_y),
    5,
    (0, 0, 255),
    -1
)
```

Теперь пользователь видит результат непосредственно на изображении.

## Шаг 11. Вывод информации

Можно вывести координаты:

```python
print(
    f"Object: "
    f"x={x}, "
    f"y={y}, "
    f"w={w}, "
    f"h={h}, "
    f"area={int(area)}"
)
```

Например:

```text
Object: x=120, y=80, w=150, h=100, area=12000
```

## Полная программа

Теперь объединим всё:

```python
import cv2

camera = cv2.VideoCapture(0)

if not camera.isOpened():
    raise RuntimeError("Не удалось открыть камеру")

while True:
    ret, frame = camera.read()

    if not ret:
        print("Не удалось получить кадр")
        break

    gray = cv2.cvtColor(
        frame,
        cv2.COLOR_BGR2GRAY
    )

    blurred = cv2.GaussianBlur(
        gray,
        (5, 5),
        0
    )

    _, mask = cv2.threshold(
        blurred,
        100,
        255,
        cv2.THRESH_BINARY
    )

    contours, _ = cv2.findContours(
        mask,
        cv2.RETR_EXTERNAL,
        cv2.CHAIN_APPROX_SIMPLE
    )

    for contour in contours:
        area = cv2.contourArea(contour)

        if area < 500:
            continue

        x, y, w, h = cv2.boundingRect(
            contour
        )

        center_x = x + w // 2
        center_y = y + h // 2

        cv2.rectangle(
            frame,
            (x, y),
            (x + w, y + h),
            (0, 255, 0),
            2
        )

        cv2.circle(
            frame,
            (center_x, center_y),
            5,
            (0, 0, 255),
            -1
        )

        cv2.putText(
            frame,
            f"({center_x}, {center_y})",
            (x, y - 10),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.5,
            (0, 255, 0),
            2
        )

    cv2.imshow(
        "Computer Vision",
        frame
    )

    cv2.imshow(
        "Mask",
        mask
    )

    if cv2.waitKey(1) == 27:
        break

camera.release()
cv2.destroyAllWindows()
```

Клавиша:

```text
Esc
```

завершает программу.

## Почему проект может работать плохо

Если камера показывает:

```text
объект почти такого же цвета, как фон
```

threshold может не отделить его.

Если освещение меняется:

```text
яркость объекта меняется
```

фиксированный порог может перестать работать.

Если много шума:

```text
появляются лишние контуры
```

Если объект слишком маленький:

```text
он может исчезнуть после обработки
```

Это нормальные ограничения простого алгоритма.

## Как улучшить проект

### Использовать HSV

Если объект отличается цветом:

```python
hsv = cv2.cvtColor(
    frame,
    cv2.COLOR_BGR2HSV
)

mask = cv2.inRange(
    hsv,
    lower,
    upper
)
```

Это может быть значительно устойчивее, чем простой threshold по яркости.

### Использовать морфологию

Можно очистить маску:

```python
kernel = cv2.getStructuringElement(
    cv2.MORPH_ELLIPSE,
    (5, 5)
)

mask = cv2.morphologyEx(
    mask,
    cv2.MORPH_OPEN,
    kernel
)
```

### Использовать ROI

Если объект находится только в определённой области:

```python
roi = frame[
    100:500,
    200:800
]
```

Можно обрабатывать только её.

Это уменьшает вычислительную нагрузку и количество ложных обнаружений.

## Добавление счётчика объектов

Можно посчитать найденные объекты:

```python
object_count = 0

for contour in contours:
    area = cv2.contourArea(contour)

    if area < 500:
        continue

    object_count += 1
```

После цикла:

```python
cv2.putText(
    frame,
    f"Objects: {object_count}",
    (20, 40),
    cv2.FONT_HERSHEY_SIMPLEX,
    1,
    (0, 255, 0),
    2
)
```

Теперь система показывает количество найденных объектов.

## Добавление траектории

Если камера неподвижна, можно сохранять положение объекта между кадрами.

Например:

```python
trajectory = []
```

После определения центра:

```python
trajectory.append(
    (center_x, center_y)
)
```

И рисовать линию:

```python
for i in range(1, len(trajectory)):
    cv2.line(
        frame,
        trajectory[i - 1],
        trajectory[i],
        (0, 255, 0),
        2
    )
```

Теперь можно видеть движение объекта.

## Связь с робототехникой

Представим полноценный роботизированный участок:

```text
                КАМЕРА
                   ↓
             ВИДЕОПОТОК
                   ↓
         КОМПЬЮТЕРНОЕ ЗРЕНИЕ
                   ↓
       +-----------+-----------+
       |                       |
    Объект                 Координаты
       |                       |
       +-----------+-----------+
                   ↓
             Система управления
                   ↓
                 РОБОТ
```

Компьютерное зрение предоставляет информацию.

Но для физического действия нужны дополнительные системы:

```text
геометрия
управление
приводы
датчики
безопасность
```

Поэтому компьютерное зрение является частью робототехнической системы, а не всей системой целиком.
