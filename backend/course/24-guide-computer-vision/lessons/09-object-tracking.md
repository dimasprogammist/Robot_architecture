# Отслеживание объектов на видео

## Цель урока

После этого урока вы должны понимать:

* чем обнаружение объекта отличается от его отслеживания;
* почему видео можно рассматривать как последовательность кадров;
* что такое траектория объекта;
* как отслеживать положение простого объекта;
* почему идентификатор объекта важен;
* какие простые методы отслеживания можно использовать;
* чем отличается простое отслеживание от современных трекеров.

## Обнаружение и отслеживание — не одно и то же

Рассмотрим видеопоток:

```text
Кадр 1 → Кадр 2 → Кадр 3 → Кадр 4
```

На каждом кадре можно отдельно искать объект.

Например:

```text
Кадр 1 → объект найден в (100, 200)
Кадр 2 → объект найден в (110, 205)
Кадр 3 → объект найден в (120, 210)
Кадр 4 → объект найден в (130, 215)
```

Это **обнаружение** объекта на каждом кадре.

Но если мы хотим понимать:

> это тот же самый объект, который был найден на предыдущем кадре?

нам нужно отслеживание.

## Что такое tracking

**Отслеживание объекта (object tracking)** — это определение положения одного и того же объекта на последовательности кадров.

Например:

```text
Кадр 1
   объект A
      ↓
Кадр 2
   объект A
      ↓
Кадр 3
   объект A
      ↓
Кадр 4
   объект A
```

Система должна сохранять связь:

```text
A → A → A → A
```

а не считать каждый кадр новым объектом.

## Зачем отслеживать объекты

Отслеживание позволяет получить дополнительную информацию:

* направление движения;
* скорость;
* траекторию;
* время нахождения в области;
* пересечение линии;
* вход объекта в зону;
* выход объекта из зоны.

Например:

```text
объект
  ↓
движется вправо
  ↓
пересёк линию
  ↓
событие
```

Это уже намного полезнее, чем просто знать, что объект существует.

## Видео как последовательность кадров

В OpenCV видеопоток можно получать через:

```python
camera = cv2.VideoCapture(0)
```

Затем:

```python
while True:
    ret, frame = camera.read()

    if not ret:
        break
```

Каждый `frame` — отдельное изображение.

Можно обработать его:

```text
frame 1
   ↓
обнаружение

frame 2
   ↓
обнаружение

frame 3
   ↓
обнаружение
```

А затем сравнивать результаты между кадрами.

## Самый простой вариант отслеживания

Если на изображении находится только один объект, задача становится относительно простой.

Допустим, на каждом кадре мы получаем:

```text
центр объекта
```

Например:

```text
Кадр 1 → (100, 200)
Кадр 2 → (110, 205)
Кадр 3 → (120, 210)
Кадр 4 → (130, 215)
```

Можно соединить эти точки:

```text
(100,200)
      \
       (110,205)
          \
           (120,210)
              \
               (130,215)
```

Получаем приблизительную траекторию.

## Хранение траектории

В Python можно хранить точки:

```python
trajectory = []

trajectory.append(
    (center_x, center_y)
)
```

Затем использовать их для анализа.

Например:

```python
for point in trajectory:
    print(point)
```

Можно ограничить количество последних точек:

```python
trajectory.append(
    (center_x, center_y)
)

if len(trajectory) > 50:
    trajectory.pop(0)
```

Так программа хранит только последние 50 положений.

## Рисование траектории

Можно рисовать линию между соседними точками:

```python
for i in range(1, len(trajectory)):
    cv2.line(
        frame,
        trajectory[i - 1],
        trajectory[i],
        (0, 255, 0),
        2
    )
```

На изображении получится приблизительная траектория движения.

## Вычисление смещения

Если известны две позиции:

```text
(x1, y1)
(x2, y2)
```

можно вычислить:

```text
dx = x2 - x1
dy = y2 - y1
```

Например:

```python
dx = current_x - previous_x
dy = current_y - previous_y
```

Если:

```text
dx > 0
```

объект перемещается вправо.

Если:

```text
dx < 0
```

объект перемещается влево.

Аналогично:

```text
dy > 0 → вниз
dy < 0 → вверх
```

## Расстояние между положениями

Можно вычислить расстояние:

```python
import math

distance = math.sqrt(
    dx * dx + dy * dy
)
```

Получаем величину перемещения объекта между двумя кадрами.

Если известно время между кадрами, можно оценить скорость в пикселях в секунду.

Например:

```text
перемещение = 20 пикселей
время = 0.1 секунды
```

Тогда:

```text
скорость = 20 / 0.1 = 200 пикселей/с
```

Это ещё не физическая скорость объекта в метрах в секунду.

Для этого нужно знать геометрическое соответствие между пикселями и реальными размерами сцены.

## Простой трекер по ближайшему объекту

Если на кадре находится несколько объектов, можно сопоставлять объекты между соседними кадрами по расстоянию между центрами.

Например:

```text
Кадр 1:

A → (100, 100)
B → (400, 200)

Кадр 2:

? → (110, 105)
? → (395, 205)
```

Очевидно, что:

```text
(100,100) → (110,105)
(400,200) → (395,205)
```

потому что эти точки находятся близко друг к другу.

Это очень упрощённый вариант трекинга.

## Проблема нескольких объектов

Представим:

```text
Кадр 1:
A → (100,100)
B → (120,100)

Кадр 2:
? → (110,100)
? → (115,100)
```

Теперь однозначно определить соответствие сложнее.

Объекты могут:

* сближаться;
* пересекаться;
* исчезать;
* появляться;
* перекрываться.

Поэтому реальные трекеры используют более сложные методы сопоставления.

## Идентификатор объекта

При отслеживании удобно присваивать объекту ID.

Например:

```text
ID 1
ID 2
ID 3
```

Видеопоток может выглядеть так:

```text
Кадр 1:
ID 1 → (100,100)
ID 2 → (400,200)

Кадр 2:
ID 1 → (110,105)
ID 2 → (395,205)
```

Теперь программа понимает, какой объект куда перемещается.

## Обнаружение и tracking часто работают вместе

На практике можно использовать схему:

```text
Детектор
    ↓
Нашёл объекты
    ↓
Трекер
    ↓
Следит за ними между кадрами
```

Это может быть эффективнее, чем запускать сложный детектор на каждом кадре.

Например:

```text
Кадр 1 → детекция
Кадр 2 → tracking
Кадр 3 → tracking
Кадр 4 → tracking
Кадр 5 → детекция
```

При необходимости детектор может периодически уточнять положение объектов.

## Простая система отслеживания одного объекта

Рассмотрим концептуальный пример:

```python
import cv2

camera = cv2.VideoCapture(0)

trajectory = []

while True:
    ret, frame = camera.read()

    if not ret:
        break

    gray = cv2.cvtColor(
        frame,
        cv2.COLOR_BGR2GRAY
    )

    _, mask = cv2.threshold(
        gray,
        100,
        255,
        cv2.THRESH_BINARY
    )

    contours, _ = cv2.findContours(
        mask,
        cv2.RETR_EXTERNAL,
        cv2.CHAIN_APPROX_SIMPLE
    )

    largest_contour = None
    largest_area = 0

    for contour in contours:
        area = cv2.contourArea(contour)

        if area > largest_area:
            largest_area = area
            largest_contour = contour

    if largest_contour is not None and largest_area > 500:
        x, y, w, h = cv2.boundingRect(
            largest_contour
        )

        center = (
            x + w // 2,
            y + h // 2
        )

        trajectory.append(center)

        cv2.circle(
            frame,
            center,
            5,
            (0, 255, 0),
            -1
        )

    for i in range(1, len(trajectory)):
        cv2.line(
            frame,
            trajectory[i - 1],
            trajectory[i],
            (0, 255, 0),
            2
        )

    cv2.imshow("Tracking", frame)

    if cv2.waitKey(1) == 27:
        break

camera.release()
cv2.destroyAllWindows()
```

Это не универсальный трекер.

Он просто:

```text
ищет самый большой объект
        ↓
находит его центр
        ↓
сохраняет центр
        ↓
рисует траекторию
```

Но именно на таком простом примере хорошо видно основную идею tracking.

## Почему этот подход ограничен

Если:

* объект перекрывается;
* освещение меняется;
* появляется другой объект крупнее;
* объект исчезает;
* несколько объектов похожи;

программа может потерять объект.

Поэтому реальные системы используют специализированные алгоритмы отслеживания.

## Современные трекеры

В компьютерном зрении существуют различные подходы:

* корреляционные трекеры;
* трекеры на основе признаков;
* Kalman Filter;
* SORT;
* Deep SORT;
* ByteTrack;
* другие методы.

Некоторые трекеры используют только геометрию движения.

Другие дополнительно используют визуальные признаки объекта.

Например, Kalman Filter может оценивать следующее положение объекта на основе его предыдущего движения.

## Tracking и нейронные сети

Важно различать:

```text
обнаружение объекта
```

и

```text
отслеживание объекта
```

Современная система может использовать нейронную сеть для обнаружения:

```text
Камера
  ↓
Нейросетевой детектор
  ↓
Объекты
  ↓
Трекер
  ↓
ID и траектории
```

Но tracking сам по себе не обязательно должен быть нейросетевым.

## Практическое применение

Отслеживание используется для:

* подсчёта объектов;
* анализа движения;
* наблюдения за транспортом;
* робототехники;
* анализа поведения объектов;
* контроля конвейеров;
* определения пересечения зон;
* оценки траекторий.

Например:

```text
Конвейер
   ↓
Камера
   ↓
Объект обнаружен
   ↓
ID = 12
   ↓
движется вправо
   ↓
пересёк контрольную линию
   ↓
счётчик +1
```

## Главное

Запомните:

* detection отвечает на вопрос «где объект?»;
* tracking отвечает на вопрос «где тот же объект сейчас?»;
* видео состоит из последовательности кадров;
* положение объекта можно хранить как координаты центра;
* последовательность координат образует траекторию;
* объекты удобно идентифицировать через ID;
* простейший tracking можно строить на сопоставлении положений;
* при нескольких объектах задача становится значительно сложнее;
* реальные системы используют специализированные алгоритмы трекинга;
* детектор и трекер часто работают вместе.
