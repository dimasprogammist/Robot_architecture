# JSON

## Цель

Сериализовать структуры Python в JSON и обратно.

Понять JSON как обменный текстовый формат.

## Что уже пройдено

Вы читаете и пишете текстовые файлы.

JSON — согласованный формат поверх тех же файлов и сетевых тел.

## Объяснение с нуля

JSON: объекты, массивы, строки, числа, bool, null. Модуль json: dumps/loads и dump/load.

Зачем: конфиги, API, логи. Не исполняет код (в отличие от неосторожного pickle). Не все типы Python сериализуемы по умолчанию (set, свои классы). Соответствия: object→dict, array→list, null→None.

## Термины

- **Сериализация / десериализация**.

- **dumps / loads / dump / load**.

- **null ↔ None**.

- **Схема данных**.

- **UTF-8**.

- **JSONDecodeError**.

- **ensure_ascii**.

## Внутреннее устройство

json обходит структуру и пишет токены; при чтении строит новые объекты в куче.

После load — независимые dict/list. Ошибки формата — JSONDecodeError.

## Пример

```python

import json

from pathlib import Path

data = {"name": "Ana", "scores": [5, 4, 5], "active": True}

Path("data.json").write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")

loaded = json.loads(Path("data.json").read_text(encoding="utf-8"))

print(loaded["scores"], type(loaded))

```

## Разбор

dumps строит читаемую строку; loads восстанавливает dict/list.

Дальше — обычные операции Python.

## Ошибки

- Сериализовать set без преобразования.

- Путать dump и dumps.

- Открывать JSON как исполняемый код.

- Ломать запятые правкой вручную.

- Ждать сохранения произвольных классов «сами».

## Что запомнить

JSON — текстовый снимок структур.

json строит обычные dict/list.

Не всё из Python сериализуемо напрямую.
