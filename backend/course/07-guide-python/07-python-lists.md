# Списки и работа с коллекциями

## Зачем нужны коллекции

До этого мы хранили одно значение в одной переменной:

```python
temperature = 72.5
```

Но реальные программы обычно работают сразу с большим количеством данных.

Например:

```text
температуры нескольких датчиков
скорости нескольких двигателей
координаты точек
список деталей
номера ошибок
значения измерений
```

Можно создать:

```python
temperature1 = 21.5
temperature2 = 22.0
temperature3 = 22.7
```

Но такой подход быстро становится неудобным.

Для хранения набора значений используются **коллекции**.

Одна из самых важных коллекций Python — `list`.

---

## Что такое список

Список создаётся квадратными скобками:

```python
temperatures = [21.5, 22.0, 22.7]
```

В нём три элемента.

Можно хранить числа:

```python
values = [10, 20, 30]
```

строки:

```python
names = ["Motor-1", "Motor-2", "Motor-3"]
```

или даже объекты разных типов:

```python
data = [10, "Motor", True, 3.14]
```

---

## Индексы

Каждый элемент списка имеет индекс.

Например:

```python
motors = ["M1", "M2", "M3"]
```

Индексы:

```text
M1 → 0
M2 → 1
M3 → 2
```

Поэтому:

```python
print(motors[0])
```

даст:

```text
M1
```

а:

```python
print(motors[2])
```

даст:

```text
M3
```

---

## Индексация начинается с нуля

Это очень важно:

```python
values = [10, 20, 30]
```

не означает:

```text
1 → 10
2 → 20
3 → 30
```

В Python:

```text
0 → 10
1 → 20
2 → 30
```

---

## Отрицательные индексы

Python позволяет обращаться к элементам с конца.

Например:

```python
values = [10, 20, 30, 40]
```

Последний элемент:

```python
print(values[-1])
```

Результат:

```text
40
```

Предпоследний:

```python
print(values[-2])
```

Результат:

```text
30
```

Это очень удобно.

---

## Изменение элемента

Список является изменяемым.

Например:

```python
speeds = [1000, 1200, 1400]

speeds[1] = 1300

print(speeds)
```

Получим:

```text
[1000, 1300, 1400]
```

---

## Добавление элемента

Метод `append()` добавляет элемент в конец:

```python
values = [10, 20, 30]

values.append(40)

print(values)
```

Получим:

```text
[10, 20, 30, 40]
```

---

## Добавление нескольких элементов

Можно использовать `extend()`:

```python
values = [10, 20]

values.extend([30, 40, 50])

print(values)
```

Результат:

```text
[10, 20, 30, 40, 50]
```

---

## Разница между `append()` и `extend()`

Рассмотрим:

```python
values = [1, 2]

values.append([3, 4])

print(values)
```

Получим:

```text
[1, 2, [3, 4]]
```

Список `[3, 4]` стал одним элементом.

А:

```python
values = [1, 2]

values.extend([3, 4])

print(values)
```

даст:

```text
[1, 2, 3, 4]
```

Это важное различие.

---

## Вставка элемента

Метод `insert()` позволяет вставить элемент в определённую позицию:

```python
values = [10, 20, 30]

values.insert(1, 15)

print(values)
```

Получим:

```text
[10, 15, 20, 30]
```

---

## Удаление элемента

Можно удалить элемент по значению:

```python
values = [10, 20, 30]

values.remove(20)

print(values)
```

Результат:

```text
[10, 30]
```

Если такого значения нет, `remove()` вызовет ошибку.

---

## Удаление по индексу

Можно использовать `pop()`:

```python
values = [10, 20, 30]

value = values.pop(1)

print(value)
print(values)
```

Получим:

```text
20
[10, 30]
```

Если вызвать:

```python
values.pop()
```

будет удалён последний элемент.

---

## Длина списка

Функция `len()`:

```python
values = [10, 20, 30, 40]

print(len(values))
```

Результат:

```text
4
```

Это особенно полезно при обработке данных.

---

## Проверка наличия элемента

Используем `in`:

```python
motors = ["M1", "M2", "M3"]

if "M2" in motors:
    print("Motor found")
```

Это намного удобнее, чем вручную сравнивать каждый элемент.

---

## Перебор списка

Самый естественный способ:

```python
temperatures = [45, 51, 63, 72]

for temperature in temperatures:
    print(temperature)
```

Это одна из самых часто используемых конструкций Python.

---

## Индекс и значение

Иногда нужен не только элемент, но и его индекс.

Можно использовать `enumerate()`:

```python
motors = ["M1", "M2", "M3"]

for index, motor in enumerate(motors):
    print(index, motor)
```

Получим:

```text
0 M1
1 M2
2 M3
```

---

## Срезы

Список можно частично извлекать с помощью срезов.

```python
values = [10, 20, 30, 40, 50]
```

Например:

```python
print(values[1:4])
```

Получим:

```text
[20, 30, 40]
```

Правая граница не включается.

---

## Срез с начала

```python
print(values[:3])
```

Получим:

```text
[10, 20, 30]
```

---

## Срез до конца

```python
print(values[2:])
```

Получим:

```text
[30, 40, 50]
```

---

## Копирование списка

Очень важно понимать, что:

```python
a = [1, 2, 3]
b = a
```

не создаёт независимую копию списка.

Оба имени относятся к одному объекту.

Поэтому:

```python
b.append(4)

print(a)
```

тоже даст:

```text
[1, 2, 3, 4]
```

Для копии можно использовать:

```python
b = a.copy()
```

Теперь списки независимы:

```python
a = [1, 2, 3]
b = a.copy()

b.append(4)

print(a)
print(b)
```

Результат:

```text
[1, 2, 3]
[1, 2, 3, 4]
```

---

## Сортировка

Можно отсортировать список:

```python
values = [30, 10, 50, 20]

values.sort()

print(values)
```

Получим:

```text
[10, 20, 30, 50]
```

В обратном порядке:

```python
values.sort(reverse=True)
```

---

## `sorted()`

Есть и функция `sorted()`:

```python
values = [30, 10, 50, 20]

result = sorted(values)

print(result)
```

В отличие от `sort()`, функция `sorted()` возвращает новый список.

Исходный:

```python
values
```

остаётся неизменённым.

---

## Минимум и максимум

Python имеет готовые функции:

```python
values = [10, 20, 5, 40]

print(min(values))
print(max(values))
```

Получим:

```text
5
40
```

Также:

```python
print(sum(values))
```

даст:

```text
75
```

## Список измерений

Представим данные от датчика:

```python
temperatures = [62.5, 63.1, 64.0, 65.2, 64.8]
```

Можно вычислить:

```python
average = sum(temperatures) / len(temperatures)

print(average)
```

Так строятся многие простые алгоритмы обработки данных.

---

## Фильтрация данных

Можно пройти по списку и выбрать нужные элементы:

```python
temperatures = [45, 72, 81, 63, 95, 55]

high = []

for temperature in temperatures:
    if temperature > 80:
        high.append(temperature)

print(high)
```

Получим:

```text
[81, 95]
```

---

## Списки списков

Список может содержать другие списки:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

Можно получить:

```python
print(matrix[0])
```

или конкретный элемент:

```python
print(matrix[1][2])
```

Результат:

```text
6
```

Это особенно важно для:

* матриц;
* изображений;
* таблиц;
* координатных сеток.

---

## Практический пример: роботы

Допустим, есть список расстояний:

```python
distances = [120, 95, 70, 35, 18, 10]
```

Можно найти первое опасное значение:

```python
for distance in distances:
    if distance < 20:
        print("Obstacle:", distance)
        break
```

## Главное

Список — одна из основных структур данных Python.

Нужно уверенно понимать:

```python
values[0]
```

доступ к элементу,

```python
values.append(...)
```

добавление,

```python
values.remove(...)
```

удаление по значению,

```python
values.pop(...)
```

удаление по индексу,

```python
len(values)
```

размер,

```python
for value in values:
    ...
```

перебор,

```python
values[1:4]
```

срез.

Списки станут основой для изучения более сложных структур данных и алгоритмов.
