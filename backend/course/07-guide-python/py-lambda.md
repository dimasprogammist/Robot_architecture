# lambda

## Цель

Понять lambda как короткое анонимное функциональное выражение.

Отличать уместный lambda от случая для def.

## Что уже пройдено

Вы объявляете функции через def.

lambda — сжатая форма для простых выражений.

## Объяснение с нуля

lambda создаёт тот же вид function object, но тело — одно выражение: `lambda args: expr`.

Уместна как key для sorted/map/callback. Дать длинное имя через присваивание почти всегда хуже, чем def.

Ограничение грамматики, не «стиль ради стиля». Условное выражение `a if c else b` допустимо. Не ускоряет код.

## Термины

- **lambda**.

- **Анонимная функция**.

- **Выражение vs оператор**.

- **key-функция**.

- **Замыкание**.

- **callable**.

- **Читаемость**.

## Внутреннее устройство

def и lambda создают function object; разница в синтаксисе и том, что lambda — выражение.

Захват enclosing имён одинаков. Ловушка цикла: `lambda: i` видит финальное i — фиксируйте `k=k` в параметре.

Вызов в байткоде как у маленькой функции.

## Пример

```python

users = [{"name": "Bob", "age": 30}, {"name": "Ana", "age": 25}]

by_age = sorted(users, key=lambda u: u["age"])

print([u["name"] for u in by_age])

funcs = [lambda n, k=k: n + k for k in (1, 2, 3)]

print(funcs[0](10), funcs[2](10))

```

## Разбор

key получает callable для сравнения.

`k=k` фиксирует значение на итерации. Эквивалент — маленькая def.

## Ошибки

- Сложная логика в lambda.

- Захват счётчика цикла без default.

- Думать, что lambda быстрее.

- Длинное имя = lambda вместо def.

- Несколько операторов в теле.

## Что запомнить
