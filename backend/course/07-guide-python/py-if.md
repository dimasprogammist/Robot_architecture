# Условия

## Цель

Направлять выполнение через if/elif/else.

Понять истинность объекта и выбор ветки в байткоде.

## Что уже пройдено

Вы знаете контейнеры и скаляры.

Условия связывают данные с выбором следующего шага.

## Объяснение с нуля

Условие выбирает фрагмент кода. Истинность — не только bool: 0/None/пустые ложны. Для None пишите `is None`, когда ноль валиден.

Цепочки `a < b < c` осмысленны. `and`/`or` коротко замыкаются. Вложенные if быстро портят читаемость — чаще ранний return или плоский elif.

## Термины

- **Условие / ветка**.

- **elif / else**.

- **Булев контекст**.

- **Короткое замыкание**.

- **Сравнение / is / in**.

- **Мёртвый код**.

- **Ранний return**.

## Внутреннее устройство

Компилятор даёт условные переходы в байткоде.

`x and y` возвращает последний вычисленный операнд, не обязательно bool. Для None принято `is None` — синглтон.

## Пример

```python

def access(role, active):

    if not active:

        return "denied: inactive"

    if role == "admin":

        return "full"

    elif role in {"user", "guest"}:

        return "limited"

    else:

        return "denied: unknown role"



print(access("user", True))

print(access("admin", False))

```

## Разбор

Сначала отсев inactive. Множество ролей — читаемый in.

admin без active всё равно denied — приоритет проверки.

## Ошибки

- Присваивание в условии как в C.

- Путать == и is.

- `if x:` когда 0 валиден.

- Глубокая лесенка if.

- Забывать ложность пустого списка.

## Что запомнить

Условия выбирают ветку по истинности.

and/or коротко замыкаются.

Для None — is None.

## Задание

Оценка балла 0–100 → fail/pass/good/excellent.

Защита от значений вне диапазона.
