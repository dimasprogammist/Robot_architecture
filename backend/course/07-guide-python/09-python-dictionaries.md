# Словари и данные в формате ключ-значение

## Зачем нужны словари

До этого мы хранили данные в списках:

```python
motor = ["Motor-01", 1500, 65.5, True]
```

Но здесь возникает проблема.

Что означает:

```python
motor[1]
```

Человек должен помнить, что индекс `1` означает скорость.

А:

```python
motor[2]
```

температуру.

Это неудобно.

Гораздо понятнее хранить данные с именами:

```text
name → Motor-01
speed → 1500
temperature → 65.5
enabled → True
```

Для этого в Python используется **словарь (`dict`)**.

---

## Создание словаря

Пример:

```python
motor = {
    "name": "Motor-01",
    "speed": 1500,
    "temperature": 65.5,
    "enabled": True
}
```

Теперь данные имеют понятные ключи.

---

## Ключ и значение

Каждая запись состоит из:

```text
ключ → значение
```

Например:

```python
"name": "Motor-01"
```

Здесь:

```text
"name"
```

— ключ,

а:

```text
"Motor-01"
```

— значение.

---

## Получение значения

Можно обратиться по ключу:

```python
print(motor["name"])
```

Получим:

```text
Motor-01
```

И:

```python
print(motor["temperature"])
```

получим:

```text
65.5
```

---

## Изменение значения

Словарь изменяемый.

Например:

```python
motor["speed"] = 1600
```

Теперь:

```python
print(motor["speed"])
```

даст:

```text
1600
```

---

## Добавление нового поля

Можно просто присвоить значение новому ключу:

```python
motor["current"] = 4.2
```

Теперь словарь содержит:

```text
name
speed
temperature
enabled
current
```

---

## Удаление поля

Можно использовать `del`:

```python
del motor["current"]
```

После этого ключ исчезнет.

---

## Проверка существования ключа

Можно использовать `in`:

```python
if "temperature" in motor:
    print("Temperature available")
```

Это особенно полезно при работе с данными, которые могут иметь разные поля.

---

## Что будет при отсутствии ключа

Если написать:

```python
print(motor["pressure"])
```

когда такого ключа нет, Python выдаст ошибку `KeyError`.

Иногда это нормально, если поле обязательно.

Но если поле необязательное, лучше использовать `get()`.

---

## Метод `get()`

```python
pressure = motor.get("pressure")
```

Если ключ отсутствует, результатом будет:

```python
None
```

Можно указать значение по умолчанию:

```python
pressure = motor.get("pressure", 0)
```

Теперь если `pressure` отсутствует, будет получено `0`.

---

## Практический пример

```python
motor = {
    "name": "Motor-01",
    "speed": 1500
}

temperature = motor.get("temperature", 0)

print(temperature)
```

Получим:

```text
0
```

---

## Перебор ключей

Можно получить ключи:

```python
for key in motor:
    print(key)
```

Например:

```text
name
speed
temperature
enabled
```

---

## Перебор значений

Метод `values()`:

```python
for value in motor.values():
    print(value)
```

---

## Перебор ключей и значений

Наиболее полезный вариант:

```python
for key, value in motor.items():
    print(key, value)
```

Получим:

```text
name Motor-01
speed 1500
temperature 65.5
enabled True
```

---

## Словарь как описание объекта

Словари особенно удобны, когда нужно представить сущность:

```python
robot = {
    "name": "Robot-01",
    "x": 100.5,
    "y": 50.2,
    "battery": 78,
    "enabled": True
}
```

Теперь можно обращаться:

```python
print(robot["name"])
print(robot["battery"])
```

Это намного понятнее, чем:

```python
robot[0]
robot[3]
```

---

## Вложенные словари

Словарь может содержать другие словари.

Например:

```python
robot = {
    "name": "Robot-01",
    "position": {
        "x": 100.5,
        "y": 50.2,
        "angle": 90
    }
}
```

Получить координату:

```python
print(robot["position"]["x"])
```

---

## Список словарей

Очень распространённая структура:

```python
motors = [
    {
        "name": "M1",
        "speed": 1200
    },
    {
        "name": "M2",
        "speed": 1500
    },
    {
        "name": "M3",
        "speed": 900
    }
]
```

Можно перебрать:

```python
for motor in motors:
    print(motor["name"], motor["speed"])
```

Результат:

```text
M1 1200
M2 1500
M3 900
```

Такая структура очень часто встречается в реальных программах.

---

## Словари и JSON

Словари Python тесно связаны с форматом JSON.

Например:

```json
{
    "name": "Robot-01",
    "battery": 78,
    "enabled": true
}
```

В Python похожая структура:

```python
robot = {
    "name": "Robot-01",
    "battery": 78,
    "enabled": True
}
```

Разница есть, но концепция ключ-значение очень похожа.

Поэтому понимание `dict` особенно важно для работы с API и веб-приложениями.

---

## Словарь настроек

Например:

```python
config = {
    "host": "192.168.1.100",
    "port": 4840,
    "timeout": 5,
    "enabled": True
}
```

Теперь программа может получать настройки по именам:

```python
host = config["host"]
port = config["port"]
```

---

## Словарь и подсчёт

Словарь можно использовать для подсчёта количества событий.

Например:

```python
errors = ["E01", "E02", "E01", "E03", "E01", "E02"]

counts = {}

for error in errors:
    if error not in counts:
        counts[error] = 0

    counts[error] += 1

print(counts)
```

Получим:

```text
{'E01': 3, 'E02': 2, 'E03': 1}
```

Это уже реальный алгоритм обработки данных.

---

## Более удобный вариант `get()`

Тот же алгоритм можно записать:

```python
counts = {}

for error in errors:
    counts[error] = counts.get(error, 0) + 1
```

Здесь:

```python
counts.get(error, 0)
```

возвращает текущее количество либо `0`, если ошибки ещё не было.

---

## Словари и вложенные данные

Например, система может хранить информацию:

```python
system = {
    "name": "Line-01",
    "status": "RUNNING",
    "temperature": 64.5,
    "motors": [
        {
            "name": "M1",
            "speed": 1200
        },
        {
            "name": "M2",
            "speed": 1500
        }
    ]
}
```

Получить скорость второго двигателя:

```python
print(system["motors"][1]["speed"])
```

Это выглядит сложнее, но структура вполне логична:

```text
system
  ↓
motors
  ↓
элемент с индексом 1
  ↓
speed
```

---

## Словарь как состояние системы

Можно хранить состояние:

```python
state = {
    "connected": True,
    "running": False,
    "alarm": False,
    "temperature": 55.2
}
```

После изменения:

```python
state["running"] = True
```

состояние обновляется.

Такие структуры широко используются в программном обеспечении автоматизации.

## Главное

Словарь хранит данные в формате:

```text
ключ → значение
```

Основные операции:

```python
data["key"]
```

получить значение,

```python
data["key"] = value
```

изменить или добавить,

```python
data.get("key")
```

безопасно получить значение,

```python
key in data
```

проверить наличие ключа,

```python
data.items()
```

перебрать ключи и значения.

Словари являются одной из самых важных структур Python.

Они постоянно встречаются в:

* API;
* конфигурациях;
* JSON;
* веб-разработке;
* обработке данных;
* автоматизации;
* робототехнике.
