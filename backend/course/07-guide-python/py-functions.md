# Функции def

## Цель

Выделять логику в функции через def.

Понять локальный namespace, return и ловушку изменяемых умолчаний.

## Что уже пройдено

Вы пишете условия и циклы на верхнем уровне.

Функции упаковывают шаги в вызываемый объект.

## Объяснение с нуля

`def` создаёт function object и привязывает имя. Параметры — локальные имена при вызове. Без return — None.

Зачем: меньше копипасты, тестируемость, импорт. Вызов создаёт frame; после return он исчезает.

Умолчания вычисляются один раз при def — `def f(xs=[])` делит один список. Шаблон: `None` + создание внутри.

## Термины

- **def / параметр / аргумент**.

- **Локальное пространство имён**.

- **return**.

- **Значение по умолчанию**.

- **Frame**.

- **Побочный эффект**.

- **global / nonlocal** (обзорно).

## Внутреннее устройство

`def` не исполняет тело: упаковывает code object. Вызов — новый frame и байткод тела.

Поиск имён: local → enclosing → global → builtins. Умолчания в `__defaults__`.

## Пример

```python

def add_item(item, bucket=None):

    if bucket is None:

        bucket = []

    bucket.append(item)

    return bucket



print(add_item("a"))

print(add_item("b"))

print(add_item("c", ["x"]))

```

## Разбор

None-умолчание даёт новый список каждый раз.

Первые два вызова независимы; третий мутирует переданный список.

## Ошибки

- Изменяемое умолчание [].

- Путать print и return.

- Ждать изменения глобали без global.

- Тихие мутации входа.

- Гигантские функции без структуры.

## Что запомнить

def создаёт объект; вызов — frame.

Локальные имена живут в вызове.

Изменяемые умолчания — почти всегда ошибка.

## Задание

clamp(x,lo,hi) и среднее списка с явным контрактом на пустой вход.

Вызовы с именованными аргументами.
