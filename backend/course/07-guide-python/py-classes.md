# Классы

## Цель

Описывать типы через class и создавать экземпляры.

Связать атрибуты экземпляра с его namespace.

## Что уже пройдено

Вы пользовались встроенными типами и функциями.

Класс — чертёж объектов с данными и поведением.

## Объяснение с нуля

`class` создаёт тип; вызов ClassName(...) — экземпляр. `__init__` инициализирует; self — текущий объект.

Зачем: связать состояние и операции (сессия, устройство, счётчик). Атрибуты экземпляра обычно в __dict__. Не всё обязано быть классом — иногда хватит функции и dict.

## Термины

- **Класс / экземпляр**.

- **self**.

- **`__init__`**.

- **Атрибут / метод**.

- **`__dict__`**.

- **Bound method**.

- **Контракт операций**.

## Внутреннее устройство

Тело class исполняется в namespace, затем создаётся type object. Вызов класса: allocate + __init__.

obj.method создаёт bound method с подставленным self. Два экземпляра — два набора атрибутов, один класс.

## Пример

```python

class Counter:

    def __init__(self, start=0):

        self.value = start

    def inc(self, step=1):

        self.value += step

        return self.value



c1, c2 = Counter(), Counter(10)

c1.inc(); c2.inc(5)

print(c1.value, c2.value)

```

## Разбор

Отдельные объекты со своим value. Методы меняют self. Класс общий, состояние — нет.

## Ошибки

- Забыть self.

- Изменяемое состояние на атрибуте класса неожиданно разделяется.

- Путать класс и экземпляр.

- Бог-объект на всё.

- Ждать автокопирования больших структур.

## Что запомнить

class → тип; вызов → экземпляр.

self — текущий объект.

Состояние — атрибуты-ссылки.
