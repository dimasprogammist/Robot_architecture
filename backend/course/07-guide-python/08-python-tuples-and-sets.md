# Кортежи и множества

## Зачем нужны разные коллекции

Мы уже познакомились со списками:

```python
values = [10, 20, 30]
```

Но разные задачи требуют разных способов хранения данных.

В Python есть несколько основных коллекций:

```text
list    список
tuple   кортеж
set     множество
dict    словарь
```

У них разные свойства и назначение.

В этом уроке разберём `tuple` и `set`.

---

# Кортежи

## Что такое tuple

Кортеж — это последовательность значений, которая после создания не изменяется.

Например:

```python
point = (10, 20)
```

Здесь хранятся две координаты.

Можно создать:

```python
rgb = (255, 128, 0)
```

или:

```python
robot_position = (10.5, 20.3, 0.0)
```

---

## Доступ к элементам

Как и у списка, индексы начинаются с нуля:

```python
point = (10, 20)

print(point[0])
print(point[1])
```

Получим:

```text
10
20
```

---

## Кортеж нельзя изменить

Рассмотрим:

```python
point = (10, 20)

point[0] = 30
```

Это приведёт к ошибке.

Кортеж предназначен для данных, которые не должны изменяться после создания.

Например:

```python
robot_position = (10.5, 20.3, 0.0)
```

Если координата должна измениться, обычно создаётся новый кортеж:

```python
robot_position = (30.0, 20.3, 0.0)
```

---

## Зачем нужен неизменяемый объект

Неизменяемость может быть полезной.

Например, если функция получает кортеж:

```python
point = (10, 20)
```

она не сможет случайно изменить его элементы.

Это делает намерение программы более очевидным:

> эти данные представляют фиксированную структуру.

---

## Список и кортеж

Список:

```python
point = [10, 20]
```

можно изменить:

```python
point[0] = 30
```

Кортеж:

```python
point = (10, 20)
```

изменить нельзя.

Упрощённо:

```text
list  → изменяемая последовательность
tuple → неизменяемая последовательность
```

---

## Когда использовать tuple

Кортеж удобен, когда набор значений представляет одну фиксированную сущность.

Например:

```python
position = (100, 200)
```

```python
rgb = (255, 128, 0)
```

```python
size = (1920, 1080)
```

```python
version = (1, 4, 2)
```

---

## Распаковка кортежа

Можно получить значения сразу в несколько переменных:

```python
point = (10, 20)

x, y = point

print(x)
print(y)
```

Получим:

```text
10
20
```

Это называется распаковкой.

---

## Практический пример

Пусть функция возвращает координаты:

```python
def get_position():
    return (10.5, 20.3)
```

Можно написать:

```python
x, y = get_position()

print(x)
print(y)
```

Позже функции будут изучены подробно.

---

## Кортеж из одного элемента

Есть небольшой синтаксический нюанс.

Это:

```python
value = (10)
```

не кортеж.

Это обычное число:

```python
10
```

Для создания кортежа из одного элемента нужна запятая:

```python
value = (10,)
```

Теперь это `tuple`.

# Множества

## Что такое set

Множество (`set`) хранит уникальные значения.

Например:

```python
values = {1, 2, 3, 4}
```

Если попытаться добавить значение повторно:

```python
values.add(3)
```

новой копии `3` не появится.

---

## Уникальность

Рассмотрим:

```python
values = {1, 2, 2, 3, 3, 3}

print(values)
```

В результате останутся только уникальные значения:

```text
{1, 2, 3}
```

Это одна из главных особенностей множества.

---

## Зачем нужны множества

Множества очень полезны, когда важно знать:

> какие уникальные значения вообще встречались?

Например, программа получила:

```python
errors = [
    "E01",
    "E02",
    "E01",
    "E03",
    "E02"
]
```

Можно получить уникальные ошибки:

```python
unique_errors = set(errors)

print(unique_errors)
```

Получим набор уникальных кодов.

---

## Проверка наличия

Операция `in` работает очень удобно:

```python
errors = {"E01", "E02", "E03"}

if "E02" in errors:
    print("Error exists")
```

Это полезно для проверки принадлежности.

---

## Добавление элемента

Используется `add()`:

```python
errors = {"E01", "E02"}

errors.add("E03")

print(errors)
```

---

## Удаление элемента

Можно использовать:

```python
errors.remove("E02")
```

Но если элемента нет, возникнет ошибка.

Безопаснее в некоторых ситуациях:

```python
errors.discard("E02")
```

Если элемента нет, `discard()` ничего не делает.

---

## Порядок элементов

Не следует воспринимать множество как обычный список.

Например:

```python
values = {10, 20, 30}
```

не нужно использовать как:

```python
values[0]
```

Множество не предназначено для доступа к элементам по индексу.

Его основная идея:

```text
уникальность
+
проверка принадлежности
+
операции над множествами
```

---

## Объединение множеств

Например:

```python
a = {1, 2, 3}
b = {3, 4, 5}
```

Можно получить объединение:

```python
result = a | b

print(result)
```

Получим:

```text
{1, 2, 3, 4, 5}
```

---

## Пересечение

Можно найти общие элементы:

```python
result = a & b
```

Результат:

```text
{3}
```

То есть `3` присутствует в обоих множествах.

---

## Разность

Можно найти элементы, которые есть в `a`, но нет в `b`:

```python
result = a - b
```

Получим:

```text
{1, 2}
```

---

## Практический пример с датчиками

Представим две группы устройств:

```python
group_a = {"sensor1", "sensor2", "sensor3"}
group_b = {"sensor2", "sensor3", "sensor4"}
```

Общие устройства:

```python
common = group_a & group_b
```

Получим:

```text
{"sensor2", "sensor3"}
```

Только в первой группе:

```python
only_a = group_a - group_b
```

---

## Преобразование списка в множество

Очень полезный приём:

```python
values = [10, 20, 10, 30, 20, 40]

unique_values = set(values)

print(unique_values)
```

Получим уникальные значения.

Если снова нужен список:

```python
unique_values = list(set(values))
```

Однако при таком преобразовании не следует рассчитывать на исходный порядок элементов.

---

## `tuple`, `list` и `set`

Теперь можно сравнить:

| Тип | Изменяемый | Индексы | Повторения |
|---|---|---|---|
| `list` | да | да | да |
| `tuple` | нет | да | да |
| `set` | да | нет | нет |

Это не просто разные варианты одного и того же.

Они решают разные задачи.

---

## Как выбрать структуру

Если нужна изменяемая последовательность:

```python
values = [10, 20, 30]
```

используйте `list`.

Если нужна неизменяемая последовательность:

```python
point = (10, 20)
```

используйте `tuple`.

Если нужны только уникальные значения:

```python
errors = {"E01", "E02", "E03"}
```

используйте `set`.

---

## Практическая задача

Есть список кодов ошибок:

```python
errors = [
    "E01",
    "E02",
    "E01",
    "E03",
    "E02",
    "E04",
    "E03"
]
```

Получите:

1. список всех ошибок;
2. множество уникальных ошибок;
3. количество уникальных ошибок;
4. проверьте, встречается ли `"E03"`.

---

## Задание с роботами

Есть координаты робота:

```python
position = (125.5, 80.2, 0.0)
```

Распакуйте их:

```python
x, y, angle = position
```

и выведите:

```text
X: ...
Y: ...
Angle: ...
```

Затем создайте множество:

```python
available_modes = {"AUTO", "MANUAL", "SERVICE"}
```

Проверьте наличие режимов:

```text
AUTO
DEBUG
SERVICE
```

---

## Главное

Теперь мы знаем ещё две важные структуры:

```text
tuple
```

для неизменяемых последовательностей,

и:

```text
set
```

для уникальных значений.

Общая картина коллекций Python начинает выглядеть так:

```text
list
 └─ изменяемая последовательность

tuple
 └─ неизменяемая последовательность

set
 └─ уникальные значения

dict
 └─ ключ → значение
```

Следующая структура — `dict` — особенно важна, потому что позволяет хранить данные в виде именованных полей.
