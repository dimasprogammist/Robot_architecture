# Запуск программ

## Цель

Уметь запускать файл `.py` и понимать отличие от REPL.

Освоить `__main__`, `sys.argv` и роль рабочего каталога.

## Что уже пройдено

Вы понимаете конвейер: исходник, байткод, объекты, namespaces.

Теперь машина должна исполнять целые файлы.

## Объяснение с нуля

Файл `.py` — модуль. `python hello.py` создаёт процесс, компилирует файл как `__main__` и исполняет сверху вниз.

REPL удобен для проб; программа живёт в файле: повторяемость, аргументы, контроль версий. IDE вызывает тот же интерпретатор — важно знать какой.

`if __name__ == "__main__":` отделяет «запустили как программу» от «импортировали». Аргументы после файла — строки в `sys.argv`.

## Термины

- **Модуль** — единица кода, обычно файл `.py`.

- **`__main__`** — имя модуля-точки входа.

- **`sys.argv`** — аргументы командной строки.

- **Рабочий каталог** — cwd процесса.

- **Точка входа** — начало осмысленного запуска.

- **Побочный эффект** — I/O при импорте.

- **`sys.modules`** — кэш модулей процесса.

## Внутреннее устройство

ОС стартует процесс; CPython готовит `sys.path`, исполняет code object в frame `__main__`.

Верхний уровень бежит сразу. `def`/`class` создают объекты и кладут имена в dict модуля. Импорт другого модуля — один раз за процесс.

Блок `__main__` срабатывает только при прямом запуске; при import — нет. Тяжёлый код на верхнем уровне всё равно исполнится при импорте.

## Пример

```python

# greet.py

import sys



def greet(name):

    print(f"Hello, {name}")



if __name__ == "__main__":

    who = sys.argv[1] if len(sys.argv) > 1 else "world"

    greet(who)

```

```text

python greet.py

python greet.py Ana

```

## Разбор

При прямом запуске блок активен. Без аргумента — `world`, с аргументом — `Ana`.

При `import greet` приветствие само не печатается — появляется только функция.

Относительные пути зависят от cwd процесса, не обязательно от папки файла.

## Ошибки

- Весь код на верхнем уровне без защиты `__main__`.

- Путать cwd с папкой скрипта.

- Запускать не тот интерпретатор из IDE.

- Ждать автоперезагрузки долгого процесса.

- Считать элементы argv числами.
