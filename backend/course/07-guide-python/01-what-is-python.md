# Что такое Python и как устроена программа на Python

## Зачем нужен этот урок

Python часто описывают очень просто: «это язык программирования с понятным синтаксисом».

Это правда, но такого объяснения недостаточно.

Чтобы нормально изучать Python дальше, важно сначала понять:

* что вообще такое язык программирования;
* что происходит после запуска программы;
* чем Python отличается от компилируемых языков;
* что такое интерпретатор;
* из чего состоит программа на Python;
* почему Python так часто используется для автоматизации, анализа данных, серверов, машинного обучения и робототехники.

Python не является отдельной магической средой, которая «сама всё делает». В основе всё равно находятся обычные вычисления, память, процессор, операционная система и алгоритмы.

---

## Что такое язык программирования

Компьютер работает с машинными инструкциями, которые процессор умеет выполнять непосредственно.

Человеку неудобно писать программы в таком виде:

```text
10110000 00000001
10110001 00000010
...
```

Поэтому существуют языки программирования.

Язык программирования позволяет описывать алгоритмы в форме, которую человеку значительно проще читать и изменять.

Например:

```python
a = 10
b = 20
result = a + b

print(result)
```

Здесь программа говорит:

1. создать значение `10`;
2. связать его с именем `a`;
3. создать значение `20`;
4. связать его с именем `b`;
5. сложить значения;
6. получить результат;
7. вывести его.

Это уже полноценная программа, хотя она очень маленькая.

---

## Что такое Python

**Python** — это высокоуровневый язык программирования общего назначения.

Слово «высокоуровневый» означает, что программист работает с удобными абстракциями, а не напрямую с машинными инструкциями процессора.

Например, в Python можно написать:

```python
numbers = [10, 20, 30, 40]

print(sum(numbers))
```

И не заниматься вручную:

* выделением памяти под каждый элемент;
* вычислением адресов элементов;
* освобождением памяти;
* преобразованием чисел в машинный формат.

Большую часть этой работы выполняет среда выполнения Python.

---

## Для чего используют Python

Python применяется в самых разных областях.

### Автоматизация

Например:

```python
for filename in files:
    process(filename)
```

Программа может автоматически обрабатывать тысячи файлов.

### Серверы

Python используется для создания:

* веб-сервисов;
* API;
* внутренних корпоративных систем;
* систем автоматизации.

Например, популярным инструментом является FastAPI.

### Анализ данных

Python позволяет работать с большими наборами данных:

```python
average = sum(values) / len(values)
```

А специальные библиотеки позволяют выполнять гораздо более сложные операции.

### Машинное обучение

Python широко используется в нейронных сетях и машинном обучении.

Например:

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0])
print(x)
```

### Компьютерное зрение

Python используется вместе с OpenCV и другими библиотеками для:

* обработки изображений;
* анализа видео;
* поиска объектов;
* машинного зрения.

### Робототехника

Python может использоваться для:

* управления логикой робота;
* обработки данных датчиков;
* компьютерного зрения;
* взаимодействия с сетевыми устройствами;
* работы с базами данных;
* создания управляющих серверов.

При этом Python не заменяет микроконтроллеры, PLC или низкоуровневое ПО во всех задачах. Он занимает своё место в общей архитектуре системы.

---

## Python — это не просто программа

Важно различать три вещи:

* язык Python;
* интерпретатор Python;
* программу, написанную на Python.

Например, файл:

```text
main.py
```

содержит исходный код.

А Python interpreter — программа, которая умеет этот код выполнять.

Когда мы запускаем:

```text
python main.py
```

операционная система запускает интерпретатор Python и передаёт ему файл программы.

---

## Что происходит при запуске программы

Рассмотрим:

```python
x = 10
y = 20

result = x + y

print(result)
```

Упрощённо процесс выглядит так:

```text
Исходный код
     ↓
Python
     ↓
Разбор программы
     ↓
Выполнение инструкций
     ↓
Результат
```

На самом деле внутренняя реализация сложнее.

Например, стандартная реализация CPython преобразует исходный код во внутреннее представление, которое затем выполняется виртуальной машиной Python.

Для начинающего программиста сейчас достаточно понимать главное:

**`.py`-файл — это исходный код, а Python runtime — среда, которая этот код выполняет.**

---

## Первая программа

Создадим файл:

```text
main.py
```

В нём:

```python
print("Hello, Python!")
```

Запускаем:

```bash
python main.py
```

Получим:

```text
Hello, Python!
```

Функция `print()` выводит информацию в стандартный вывод программы.

---

## Программа выполняется сверху вниз

Рассмотрим:

```python
print("Первый")
print("Второй")
print("Третий")
```

Результат:

```text
Первый
Второй
Третий
```

По умолчанию инструкции выполняются последовательно.

Это одна из фундаментальных идей программирования.

Позже мы научимся менять этот порядок с помощью:

* условий;
* циклов;
* функций;
* исключений;
* других конструкций.

---

## Python выполняет не только числа

Можно работать с текстом:

```python
name = "Dmitry"

print(name)
```

С логическими значениями:

```python
connected = True

print(connected)
```

С коллекциями:

```python
temperatures = [21.5, 22.1, 23.0]

print(temperatures)
```

С объектами:

```python
class Motor:
    pass
```

То есть Python предоставляет большое количество различных абстракций.

## Комментарии

Комментарии позволяют оставлять пояснения непосредственно в коде.

Однострочный комментарий начинается с `#`:

```python
# Температура двигателя
temperature = 72.5
```

Python не выполняет текст после `#` как программную инструкцию.

Комментарии нужны для объяснения кода, а не для замены нормального кода.

Например:

```python
# Увеличиваем счётчик
counter = counter + 1
```

полезно.

Но огромные комментарии, которые просто повторяют код:

```python
# Прибавляем один к counter
counter = counter + 1
```

не всегда необходимы.

---

## Отступы имеют значение

Это одна из важнейших особенностей Python.

В некоторых языках блоки программы обозначаются специальными символами:

```text
{
    ...
}
```

Python использует отступы.

Например:

```python
temperature = 75

if temperature > 70:
    print("Температура высокая")
```

Строка `print()` находится внутри блока `if`, потому что имеет отступ.

Если написать:

```python
temperature = 75

if temperature > 70:
print("Температура высокая")
```

программа будет некорректной.

Обычно используется отступ в **4 пробела**.

---

## Почему Python удобен для обучения

Python позволяет достаточно быстро перейти от простых программ к реальным задачам.

Например, можно начать с:

```python
a = 10
b = 20

print(a + b)
```

Затем изучить:

```python
if a > b:
    ...
```

Потом:

```python
for value in values:
    ...
```

Потом функции:

```python
def calculate(a, b):
    return a + b
```

После этого можно работать с файлами, сетью, базами данных, API, изображениями и машинным обучением.

То есть язык постепенно раскрывается вместе со сложностью задач.

---

## Python и другие языки

Python не является «лучше всех остальных языков».

У разных языков разные особенности.

Например:

**C++** часто используется там, где особенно важны:

* производительность;
* управление ресурсами;
* низкоуровневый доступ;
* работа с системным и аппаратным ПО.

**Python** особенно удобен там, где важны:

* скорость разработки;
* большое количество библиотек;
* автоматизация;
* обработка данных;
* машинное обучение;
* прототипирование.

На практике языки часто используются вместе.

Например, роботизированная система может содержать:

```text
Микроконтроллер
      ↓
     C/C++
      ↓
Контроллер робота
      ↓
   Python
      ↓
Компьютерное зрение
      ↓
    Сервер
```

Выбор языка определяется задачей.

## Практика

Создайте `main.py`:

```python
name = "Robot"
temperature = 42.5
motor_enabled = True

print("Имя:", name)
print("Температура:", temperature)
print("Двигатель включён:", motor_enabled)
```

Запустите программу и убедитесь, что все три значения выводятся.

После этого измените значения и снова запустите программу.

## Небольшое задание

Создайте программу, которая выводит информацию о некотором устройстве:

```text
Device: Motor-01
Temperature: 64.2
Speed: 1500
Enabled: True
```

Пока не нужно использовать сложные конструкции.

Цель упражнения — привыкнуть к структуре Python-программы и запуску `.py`-файлов.

## Главное

После этого урока важно понимать не синтаксис каждой команды, а общую картину:

```text
Python-код
    ↓
.py файл
    ↓
Python interpreter
    ↓
Выполнение программы
    ↓
Работа с памятью, процессором, ОС и внешними ресурсами
    ↓
Результат
```

Python — это инструмент, с помощью которого мы описываем алгоритмы на достаточно высоком уровне.

В следующих уроках мы начнём разбирать язык уже непосредственно: синтаксис, переменные, значения и типы данных.
