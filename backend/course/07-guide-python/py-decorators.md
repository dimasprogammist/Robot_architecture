# Декораторы

## Цель

Понять декоратор как функцию над функцией, возвращающую обёртку.

Читать @decorator через модель объектов функций.

## Что уже пройдено

Вы знаете функции как объекты и композицию.

Декоратор — композиция вокруг callable.

## Объяснение с нуля

Функции можно передавать и возвращать. Декоратор принимает функцию и возвращает новую — лог, проверка, кэш, таймер.

`@deco` над def означает `f = deco(f)`. Обёртка замыкает оригинал; functools.wraps сохраняет имя/doc. Декораторы с аргументами — фабрики декораторов.

## Термины

- **Декоратор / wrapper**.

- **Замыкание**.

- **@syntax**.

- **functools.wraps**.

- **Higher-order function**.

- **Побочное поведение**.

- **Фабрика декораторов**.

## Внутреннее устройство

После def есть function object; декоратор — обычный вызов с перепривязкой имени.

Вызов декорированной функции идёт в wrapper, затем в оригинал — лишний frame в traceback.

## Пример

```python

import functools, time

def timed(func):

    @functools.wraps(func)

    def wrapper(*args, **kwargs):

        t0 = time.perf_counter()

        result = func(*args, **kwargs)

        print(func.__name__, time.perf_counter() - t0)

        return result

    return wrapper

@timed

def work(n):

    return sum(range(n))

print(work(10000))

```

## Разбор

timed возвращает wrapper, заменяющий work.

wraps сохраняет имя. Эквивалент: work = timed(work).

## Ошибки

- Не вернуть результат оригинала.

- Потерять *args/**kwargs.

- Декоратор с аргументами без лишнего уровня.

- Игнорировать wraps.

- Десяток декораторов «на будущее».

## Что запомнить

@deco = перепривязка к deco(func).

Обёртка — замыкание.

Сохраняйте метаданные через wraps.
