# Типы данных Python

## Почему существуют типы данных

В программе встречаются совершенно разные данные.

Например:

```text
25
3.14
"Motor-01"
True
[10, 20, 30]
```

Число, текст, логическое значение и список — это разные сущности.

Python должен понимать, как с каждым значением работать.

Для этого существуют **типы данных**.

Тип определяет, какие данные представлены объектом и какие операции с ними допустимы.

---

## Основные типы Python

На начальном этапе особенно важны:

```text
int       целые числа
float     числа с плавающей точкой
str       строки
bool      логические значения
None      отсутствие значения
```

Позже мы подробно изучим:

```text
list
tuple
dict
set
```

и другие структуры данных.

---

## Целые числа — int

Целые числа имеют тип `int`:

```python
count = 10
speed = 1500
temperature = -5
```

Проверить тип можно через `type()`:

```python
speed = 1500

print(type(speed))
```

Результат:

```text
<class 'int'>
```

---

## Отрицательные числа

`int` может быть отрицательным:

```python
temperature = -10
offset = -25
```

Также:

```python
zero = 0
```

является целым числом.

---

## Большие целые числа

Python позволяет работать с очень большими целыми числами:

```python
value = 1000000000000000000000000

print(value)
```

Для обычного программиста не нужно вручную выбирать размер `int`, например 32 или 64 бита.

Python сам управляет размером целого числа.

Это отличается от некоторых низкоуровневых языков, где размер целочисленного типа имеет более непосредственное значение.

---

## Числа с плавающей точкой — float

Для дробных чисел используется `float`:

```python
temperature = 72.5
voltage = 24.0
error = 0.125
```

Проверка:

```python
print(type(temperature))
```

Результат:

```text
<class 'float'>
```

---

## Почему float называется плавающей точкой

Компьютер хранит вещественные числа в специальном формате.

Упрощённо число можно представить как:

```text
значащая часть × основание ^ степень
```

Это позволяет хранить очень маленькие и очень большие значения.

Но такой способ хранения имеет важное следствие:

**не каждое десятичное число можно представить в памяти абсолютно точно.**

---

## Проблема точности

Например:

```python
print(0.1 + 0.2)
```

результат может выглядеть так:

```text
0.30000000000000004
```

Это не ошибка Python.

Это следствие представления вещественных чисел в двоичной системе.

Поэтому нельзя бездумно сравнивать некоторые `float` через `==`.

Например:

```python
a = 0.1 + 0.2

print(a == 0.3)
```

может дать:

```text
False
```

Для инженерных задач способ сравнения зависит от требований к точности.

---

## Строки — str

Строка хранит текст.

Например:

```python
name = "Motor-01"
message = "Hello"
status = "Connected"
```

Строку можно создавать с одинарными:

```python
name = 'Motor-01'
```

или двойными кавычками:

```python
name = "Motor-01"
```

Оба варианта корректны.

---

## Строка — это последовательность символов

Например:

```python
word = "Python"
```

Можно обращаться к отдельным символам:

```python
print(word[0])
```

Получим:

```text
P
```

И:

```python
print(word[1])
```

получим:

```text
y
```

Нумерация начинается с нуля.

---

## Длина строки

Функция `len()` возвращает длину:

```python
word = "Python"

print(len(word))
```

Результат:

```text
6
```

Это часто используется при обработке текста.

---

## Объединение строк

Строки можно объединять:

```python
first_name = "Dmitry"
last_name = "Panfilov"

full_name = first_name + " " + last_name

print(full_name)
```

Получим:

```text
Dmitry Panfilov
```

---

## Повторение строк

Можно умножать строку на целое число:

```python
print("Hi " * 3)
```

Результат:

```text
Hi Hi Hi
```

Это пример того, что операция `*` зависит от типов операндов.

---

## Логический тип — bool

Логический тип имеет только два значения:

```python
True
False
```

Например:

```python
connected = True
alarm = False
enabled = True
```

`bool` используется для представления состояний.

Например:

```text
датчик активен?
соединение установлено?
двигатель включён?
авария присутствует?
```

---

## Логические значения

Можно написать:

```python
motor_enabled = True

if motor_enabled:
    print("Motor is running")
```

Позже мы подробно изучим `if`.

Сейчас важно понять:

```python
True
```

и:

```python
False
```

являются значениями типа `bool`.

---

## None

Особое значение:

```python
None
```

обозначает отсутствие значения.

Например:

```python
sensor_value = None
```

Это может означать:

> значение датчика пока отсутствует.

`None` не равно:

```text
0
```

и не равно:

```text
""
```

Это отдельное значение.

Например:

```python
value = None

print(type(value))
```

получим:

```text
<class 'NoneType'>
```

---

## Почему тип имеет значение

Рассмотрим:

```python
a = 10
b = 20

print(a + b)
```

Получим:

```text
30
```

Но:

```python
a = "10"
b = "20"

print(a + b)
```

даст:

```text
1020
```

Почему?

Потому что в первом случае `+` складывает числа:

```text
10 + 20 = 30
```

а во втором объединяет строки:

```text
"10" + "20" = "1020"
```

Один и тот же оператор может иметь разное поведение в зависимости от типов.

---

## Преобразование типов

Иногда необходимо преобразовать значение.

Например:

```python
text = "123"

number = int(text)

print(number)
print(type(number))
```

Теперь `number` имеет тип `int`.

---

## Преобразование в float

```python
text = "12.5"

value = float(text)

print(value)
```

Получим число:

```text
12.5
```

---

## Преобразование в строку

Можно превратить значение в строку:

```python
speed = 1500

text = str(speed)

print(text)
print(type(text))
```

---

## Преобразование bool

Можно преобразовать значения к `bool`, например:

```python
print(bool(1))
print(bool(0))
```

Результат:

```text
True
False
```

Но правила истинности Python более широкие.

Например, пустая строка:

```python
bool("")
```

даёт:

```text
False
```

а непустая:

```python
bool("hello")
```

даёт:

```text
True
```

Это станет особенно полезно при изучении условий.

---

## `input()` и типы

Очень важный пример:

```python
age = input("Age: ")

print(type(age))
```

Даже если пользователь вводит:

```text
25
```

тип будет:

```text
str
```

Если нужно число:

```python
age = int(input("Age: "))
```

Теперь `age` будет `int`.

---

## Практический пример с датчиком

Представим, что значение пришло от внешнего устройства как текст:

```python
raw_value = "72.5"

temperature = float(raw_value)

print(temperature)
```

Теперь программа может выполнять математические операции:

```python
temperature = float(raw_value)

limit = 70

difference = temperature - limit

print(difference)
```

---

## Списки — list

Список позволяет хранить несколько значений:

```python
temperatures = [21.5, 22.0, 23.1, 22.7]
```

Проверим:

```python
print(type(temperatures))
```

Получим:

```text
<class 'list'>
```

Список может содержать разные объекты:

```python
values = [10, 20.5, "hello", True]
```

Хотя на практике часто удобно хранить элементы одного назначения.

---

## Доступ к элементам списка

```python
temperatures = [21.5, 22.0, 23.1]

print(temperatures[0])
print(temperatures[1])
```

Получим:

```text
21.5
22.0
```

Индекс начинается с нуля.

---

## Словари — dict

Словарь хранит пары:

```text
ключ → значение
```

Например:

```python
motor = {
    "name": "Motor-01",
    "speed": 1500,
    "temperature": 62.5
}
```

Получить значение:

```python
print(motor["speed"])
```

Результат:

```text
1500
```

Словари очень важны в Python и будут подробно изучены позже.

---

## Как узнать тип

Для проверки типа используется:

```python
type(value)
```

Например:

```python
value = 42

print(type(value))
```

Но в реальном коде не следует постоянно проверять типы без необходимости.

Часто структура программы уже предполагает, какие данные используются.

---

## Практика

Создайте программу:

```python
robot_name = "Robot-01"
battery_voltage = 24.5
motor_speed = 1200
connected = True
error_code = None
```

Выведите тип каждого значения:

```python
print(type(robot_name))
print(type(battery_voltage))
print(type(motor_speed))
print(type(connected))
print(type(error_code))
```

Затем создайте:

```python
temperatures = [45.2, 47.1, 49.8]
```

и выведите:

* весь список;
* первый элемент;
* количество элементов.

Попросите пользователя ввести:

```text
имя робота
скорость
напряжение батареи
```

Например:

name = input("Robot name: ")

---

## Главное

Ключевая идея этого урока:

**тип определяет, с какими данными мы работаем и какие операции над ними выполняются.**

Основные типы:

```text
int    → целое число
float  → дробное число
str    → текст
bool   → True / False
None   → отсутствие значения
list   → последовательность значений
dict   → ключ → значение
```

Понимание типов необходимо практически для всего дальнейшего Python.
