# Словари

## Цель

Освоить dict как отображение ключ→значение.

Связать идею словаря с пространствами имён языка.

## Что уже пройдено

Вы умеете работать с множествами.

Словарь — та же хеш-таблица, но с значениями.

## Объяснение с нуля

Словарь сопоставляет хешируемый ключ значению. Литерал `{"a":1}`. Доступ `d[k]`, безопаснее `d.get`.

Изменяем: присвоение вставляет/обновляет. Порядок вставки сохраняется в современном CPython, но dict не замена списку позиций.

Namespaces модулей и часто `__dict__` объектов идейно близки к dict: `x=1` на верхнем уровне — имя в dict модуля.

## Термины

- **dict**.

- **Ключ / значение**.

- **get / setdefault / pop**.

- **items()**.

- **KeyError**.

- **Порядок вставки**.

- **Пространство имён ≈ dict**.

## Внутреннее устройство

Компактная хеш-таблица с порядком. Поиск/вставка в среднем быстрые.

Ключ хранится с хешем; значение — ссылка. Поиск глобального имени функции смотрит dict модуля, затем builtins.

## Пример

```python

user = {"id": 7, "name": "Ana"}

user["role"] = "admin"

print(user.get("email", "—"))

for key, value in user.items():

    print(key, value)

```

## Разбор

Новый ключ расширяет dict. get даёт умолчание без исключения.

items — пары в порядке вставки. Выбор `[]` vs get — «ошибка» vs «умолчание».

## Ошибки

- Список как ключ.

- `d.keys()[0]` как в старом Python.

- Мутация dict во время итерации.

- Путать `[]` и get.

- Считать равные dict одним объектом (`is`).
