# Аннотации типов и dataclass

Класс из предыдущего урока с `__init__` на три поля — много шума. Часто нужен именно «набор полей с именами и типами», без хитрой логики. **`dataclass`** генерирует `__init__`, `__repr__`, сравнение по полям.

```python
from dataclasses import dataclass


@dataclass
class Point:
    x: float
    y: float


p = Point(3.0, 4.0)
print(p.x, p)
```

`x: float` — **аннотация типа**. Для интерпретатора при обычном запуске это не крепость: `Point("a", "b")` не упадёт сам по себе. Польза — людям, редактору, отдельным проверщикам (mypy, pyright). В следующем уроке про typing глубже; здесь — привычка подписывать поля.

Значения по умолчанию:

```python
@dataclass
class Sensor:
    id: str
    celsius: float = 0.0
    ok: bool = True
```

Поля без умолчания — раньше полей с умолчанием, как в обычном `def`.

`frozen=True` — экземпляр как неизменяемый: удобно для ключей и «не трогай конфиг». Без freeze поля можно менять: `p.x = 1.0`.

Аннотации у функций:

```python
def distance(a: Point, b: Point) -> float:
    ...
```

`-> float` — обещание возврата. Снова не проверка в runtime без доп. инструментов.

Не аннотируйте всё `Any` «чтобы было». Не заменяйте dataclass'ом класс с серьёзным инвариантом в `__init__` (нормализация вектора, проверка диапазона) — тогда обычный класс или `__post_init__`.
