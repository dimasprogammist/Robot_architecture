# Операторы и выражения

**Выражение** — кусок кода, у которого есть значение: `2 + 3`, `len(name)`, `speed > 1`. **Оператор** — знак или слово, которое связывает операнды: `+`, `*`, `==`, `and`.

Арифметика: `+ - * /`. Деление `/` в Python 3 всегда даёт float: `5 / 2` это `2.5`. Целочисленное деление `//` — к минус бесконечности для отрицательных, для положительных привычное «сколько раз влезло». Остаток `%`. Степень `**`.

Сравнение: `==` равенство значений, `!=` не равно, `< > <= >=`. **Не путайте `=` и `==`.** `x = 3` присваивает. `x == 3` спрашивает. В условии нужен вопрос.

Логика: `and`, `or`, `not` — слова, не `&&`. Вычисляются лениво: в `a and b` если `a` ложно, `b` могут даже не смотреть. Важно, если справа вызов с побочным эффектом.

```python
distance = 12.0
near = distance < 5.0
ok = near and (battery > 20)
```

Скобки не стыдно. `a or b and c` читается не всеми одинаково с первого взгляда. Явные скобки — доброта к следующему читателю, часто себе через неделю.

Плюс для строк — склейка: `"a" + "b"` → `"ab"`. Умножение строки на int: `"ab" * 3` → `"ababab"`. Сложить строку и число без `str(...)` — `TypeError`. Это не вредность языка: он не знает, хотели `"12"` или `3`.

Оператор `is` — «тот же объект в памяти», не «равны по содержимому». Для чисел и коротких строк иногда кажется, что `is` совпал с `==` — не опирайтесь. Для `None` принято `x is None`, потому что `None` один.

Приоритет: степень раньше умножения, умножение раньше сложения, сравнения раньше `and`. Когда сомневаетесь — скобки, не таблица в голове на экзамене.
