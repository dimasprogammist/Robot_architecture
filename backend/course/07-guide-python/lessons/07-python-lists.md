# Списки и работа с коллекциями

Список — упорядоченная **изменяемая** последовательность. Несколько значений под одним именем, доступ по номеру.

```python
temps = [21.0, 21.5, 22.0]
print(temps[0])      # 21.0
temps.append(22.4)   # добавить в конец
temps[1] = 21.6      # заменить
```

Индексация **с нуля**. Последний элемент: `temps[-1]`. Срез `temps[1:3]` — с 1 включительно по 3 **не** включая. Срез — новый список, исходный не обязан измениться.

`len(temps)` — длина. Пустой список `[]`, длина 0. `if temps:` ложно на пустом.

Список хранит ссылки на объекты. Два имени на один список:

```python
a = [1, 2, 3]
b = a
b.append(4)
# a тоже [1, 2, 3, 4]
```

Копия содержимого верхнего уровня: `a.copy()` или `a[:]`. Вложенные списки копируются как те же внутренние объекты — для учебной глубины достаточно знать, что «копия» бывает неглубокой.

`for x in temps:` — элементы. `temps.append` в том же цикле раздувает список, по которому идёте — легко уехать в бесконечность. Добавляйте в *другой* список.

Полезные методы: `append`, `extend` (добавить все из другой последовательности), `insert`, `pop` (снять с конца или по индексу), `remove` (первое вхождение значения — медленнее и путает, если значения повторяются). `sort` меняет список на месте; `sorted(xs)` возвращает новый.

`in`: `21.0 in temps` — есть ли значение. Для длинных списков это перебор. Словарь и множество ищут иначе — следующие уроки.

Список списков — таблица. `grid[row][col]`. Сначала строка, потом столбец — если вы так договорились. Перепутать — «робот едет в стену на картинке».

Не используйте список как набор уникальных id, если часто спрашиваете «есть ли»: это работа множества.
