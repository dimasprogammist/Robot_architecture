# Циклы и повторение действий

Опросить десять датчиков одной копипастой `print` — путь к опечатке на девятом. Цикл говорит: повторяй, пока есть смысл.

`for` — когда есть **последовательность** или известный диапазон:

```python
for i in range(5):
    print(i)
```

`range(5)` даёт 0, 1, 2, 3, 4 — пять чисел, верхняя граница **не входит**. `range(2, 6)` — 2…5. `range(0, 10, 2)` — шаг 2. Это не список в памяти из миллиона элементов, а ленивый диапазон; для понимания можно думать «числа подряд».

`for item in items:` ходит по элементам списка, строки, любого итерируемого. Часто не нужен индекс. Если нужен и индекс, и элемент: `enumerate(items)`.

`while` — пока условие истинно:

```python
while distance > 0.1:
    step()
    distance = read_distance()
```

Остановка должна быть в теле: иначе вечный цикл. Классика: забыли увеличить счётчик, датчик всегда «далеко», `distance` не обновляют.

`break` выходит из цикла сразу. `continue` переходит к следующей итерации. Оба читаются хуже, если ими прыгают через три экрана. Один `break` по «нашли / авария» обычно честен.

`else` у цикла в Python срабатывает, если цикл **не** вышли через `break` — редкая конструкция, новичка путает с `else` у `if`. Можно жить без неё годами.

Вложенные циклы: для каждой строки таблицы — каждый столбец. Сложность растёт как произведение длин. Для 1000×1000 уже миллион шагов — нормально; для «в каждом шаге ещё сеть» — уже думать.

Не модифицируйте список, по которому сейчас идёт `for`, удаляя элементы с начала: индексы поедут. Собирайте новый список или идите с конца — позже, когда будут списки.
