# Области видимости и пространства имён

Имя `x` в одной функции и `x` в другой — не одна ячейка. **Пространство имён** — таблица «имя → объект». **Область видимости** — правило, из какого места какое имя видно.

Внутри функции присваивание создаёт (или перевязывает) **локальное** имя, если вы не сказали иное:

```python
count = 0


def bump():
    count = 1
    print("внутри", count)


bump()
print("снаружи", count)  # всё ещё 0
```

Внутри `bump` имя `count` — другое. Снаружи глобальное не изменилось. Чтобы намеренно писать в глобальное, есть `global count` — в обычном коде почти всегда хуже, чем `return` нового значения. Глобальные счётчики, которые крутят три функции, не отладить ночью.

Чтение глобального без присваивания внутри функции работает: Python найдёт имя снаружи. Смешали чтение и присваивание без `global` — часто `UnboundLocalError`: язык решил, что имя локальное (раз есть присваивание в функции), а прочитали раньше, чем присвоили.

Вложенные функции и `nonlocal` — когда внутренняя пишет во внешнюю (не глобальную). Для старта достаточно знать, что такое бывает; чаще вынесите состояние в объект или в явный аргумент.

Параметры — локальные имена, уже связанные с аргументами на входе.

Цикл `for i in ...` в модуле оставляет `i` после цикла — сюрприз, если думали, что `i` умер. Внутри функции умрёт вместе с вызовом.

Правило на практику: данные входят аргументами, выходят `return` (или явной порчей переданного списка, если это и есть контракт). Не ловите переменную «с потолка глобалов».
