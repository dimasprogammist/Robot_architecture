# Что такое Python и как устроена программа на Python

Раздел «Основы программирования» говорит, *что* такое программа, переменная, цикл. Этот раздел — *как это выглядит и живёт в Python*: конкретный синтаксис, типы, файлы, ошибки, модули. Идея алгоритма не меняется. Меняется запись и то, что делает машина, когда вы запускаете файл.

Python — язык, на котором вы пишете текст. Этот текст читает **интерпретатор**: программа, которая разбирает строки и выполняет их. Обычно файл называют `script.py` и запускают так:

```text
python script.py
```

Интерпретатор идёт сверху вниз. Дошёл до `print(...)` — напечатал. Дошёл до ошибки — остановился и показал, *где* и *какого рода* сбой. Компилировать в отдельный `.exe` для учёбы не нужно: цикл «правка → запуск → смотрим вывод» короткий. За это Python любят в автоматизации, серверах, анализе данных и скриптах робота. Цена: на голом железе он не «быстрее C++»; он удобнее человеку.

Минимальная программа:

```python
print("робот готов")
```

`print` — вызов функции из языка: взять значение и отправить в стандартный вывод (окно терминала). Кавычки — это **строка**, текст, а не имя переменной.

Программа на Python — не «магия в облаке». Процессор по-прежнему считает, оперативная память держит объекты, операционная система запускает процесс интерпретатора. Python прячет машинные инструкции за именами вроде `list` и `open`.

Две путаницы с порога.

Первая: **язык** и **интерпретатор**. Язык — правила записи. Интерпретатор — конкретная программа (`python`, часто CPython). Без установленного интерпретатора файл `.py` — просто текст.

Вторая: **интерактивная оболочка** и **файл**. Можно открыть `python` без имени файла и печатать строки по одной — удобно проверить `2 + 2`. Нормальная программа живёт в файле: её можно повторить, положить в репозиторий, вызвать завтра.

Python чувствителен к отступам. Блок «внутри if» — это не фигурные скобки, а одинаковый отступ пробелами. Смешать табы и пробелы — классическая ловушка. Договоритесь: четыре пробела.

Дальше в разделе: имена и значения, типы, условия, циклы, коллекции, функции, файлы, ошибки, модули. Не пытайтесь выучить «весь Python» из этого урока. Цель сейчас — понять, *что запускается*, когда вы говорите `python`.
