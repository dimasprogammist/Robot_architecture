# Работа с CSV и табличными данными

Таблица: строки записей, столбцы полей. В тексте это часто CSV: значения через запятую (или точку с запятой в некоторых локалях). Первая строка — заголовки.

Не склеивайте CSV руками через `+ ","`: кавычки, запятые внутри поля, переносы сломают разбор. Модуль `csv` знает правила.

```python
import csv
from pathlib import Path

path = Path("temps.csv")
with path.open("w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["id", "celsius"])
    writer.writeheader()
    writer.writerow({"id": "t-1", "celsius": "21.4"})

with path.open("r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["id"], row["celsius"])
```

`newline=""` на всех ОС — рекомендация документации `csv`, иначе лишние пустые строки на Windows.

Всё приходит **строками**. `"21.4"` не float, пока не сделаете `float(row["celsius"])`. Пустая ячейка — `""`, не `None`. Заголовок опечатали — `KeyError` на `row["celsuis"]`.

Разделитель: `delimiter=";"` если файл из таблицы, где запятая — десятичная. Угадывать молча опасно: откройте глазами первую строку.

Excel иногда сохраняет не UTF-8. Тогда `encoding` другой или экспорт явно UTF-8. Для курса держите UTF-8.

CSV не типы, не связи таблиц, не транзакции. Много записей, поиск по id, обновление одной строки — уже повод смотреть SQLite позже. CSV прекрасен как обмен с человеком и как простой лог «время, значение».
