# Типы данных Python

Имя одно, а «что лежит» разное. `3` — целое. `3.0` — вещественное. `"3"` — текст из одного символа «3». Складывать их «просто плюсом» Python часто откажется: он не обязан угадывать, хотели вы `6` или `"33"`.

Базовые типы, с которых начинают:

- `int` — целые: счётчики, индексы, коды. Размер «как хватит памяти», не как 32-битный `int` в C.
- `float` — вещественные: температура, секунды, координата. Двоичная дробь, как в разделе математики: `0.1 + 0.2` не обязано быть в точности `0.3`.
- `str` — строка: текст в кавычках `'ok'` или `"ok"`.
- `bool` — `True` и `False`. Именно с большой буквы. Это не строки `"True"`.

Узнать тип: `type(x)`. В живом коде чаще смотрят поведение, чем печатают тип, но для учёбы это полезно.

```python
n = 10
t = 36.6
name = "base"
ready = True
print(type(n), type(t), type(name), type(ready))
```

Преобразования явные: `int("12")` → `12`. `int("12.5")` упадёт: это не целая запись. `int(12.9)` отрежет дробь к нулю, не «округлит по школьным правилам». `str(12)` → `"12"`. `float("1e-3")` поймёт научную запись.

Пустая строка `""`, число `0`, `None` и `False` в условиях ведут себя как «нет» — но это разные вещи. `None` значит «значения нет», не ноль. Датчик «ещё не прислал» лучше держать `None`, чем `0.0`, если ноль — законная температура.

Строки **нельзя** менять по месту: `s[0] = "A"` не сработает. Можно собрать новую: `s = "A" + s[1:]`. Списки (позже) менять можно. Путаница «почему число не меняется внутри функции, а список меняется» вырастет из этого различия.

Не сравнивайте float на точное равенство, если это физика. Не храните деньги в float без нужды. Не используйте строку `"true"` как булево.
