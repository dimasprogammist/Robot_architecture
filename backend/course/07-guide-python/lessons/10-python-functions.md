# Функции и разбиение программы на части

Когда один и тот же расчёт — расстояние, перевод АЦП, печать состояния — нужен в трёх местах, копипаста разъедется. **Функция** — именованный кусок с входом и выходом.

```python
def distance(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    return (dx * dx + dy * dy) ** 0.5


d = distance(0, 0, 3, 4)
```

`def` — определение. Имя, скобки, параметры, двоеточие, тело с отступом. `return` отдаёт значение туда, где функцию **вызвали**. Без `return` функция всё равно возвращает `None`. Забыть `return` и потом удивляться `None` — классика.

Параметры — имена внутри функции. Аргументы — то, что передали при вызове. Можно по имени: `distance(x1=0, y1=0, x2=3, y2=4)`. Значения по умолчанию: `def step(dt=0.1):` — удобно, пока не становится «магией десяти аргументов с дефолтами».

Тело функции — своя область имён (следующий урок глубже). Присваивание `x =` внутри не меняет `x` снаружи для чисел и строк. Для списка `xs.append` изменит **тот же** список, если передали его: передаётся ссылка на объект, не «копия мира».

```python
def add_flag(flags, name):
    flags.append(name)


items = []
add_flag(items, "ready")
# items == ["ready"]
```

Имена функций — глаголы и смысл: `celsius_from_adc`, не `do` и не `f`. Одна функция — одна работа. «Посчитать и записать файл и послать сеть» потом не протестировать.

Документирующая строка сразу под `def` в тройных кавычках — для людей и для `help()`. Не дублируйте очевидное `return x`.

Рекурсия в Python возможна, лимит глубины конечный. Для обхода дерева ок; для «суммы 1…n» цикл яснее.
