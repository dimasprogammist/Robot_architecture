# Кортежи и множества

Список — «ряд, который можно править». Иногда ряд править **нельзя** по смыслу: точка `(x, y)`, пара «имя команды и аргумент», ключ из нескольких полей. Тогда **кортеж** (`tuple`).

```python
point = (3.0, 4.0)
x, y = point          # распаковка
# point[0] = 1.0     # ошибка: кортеж неизменяем
```

Скобки часто можно опустить: `point = 3.0, 4.0`. Кортеж из одного элемента — запятая обязательна: `(3,)`, иначе это просто `3` в скобках.

Неизменяемость — договор с программистом и с языком: кортеж можно класть в множество и делать ключом словаря, список — нельзя (как ключ). Если внутри кортежа лежит список, *внутренний* список всё ещё меняется. «Неизменяем» про сам контейнер, не про глубокую заморозку мира.

**Множество** (`set`) — набор уникальных элементов без порядка (порядок обхода не обещайте в логике).

```python
seen = {1, 2, 2, 3}
# seen == {1, 2, 3}
print(2 in seen)      # быстро по смыслу «есть / нет»
seen.add(4)
```

Пустое множество — `set()`, не `{}`: `{}` это пустой **словарь**.

Операции: объединение `|`, пересечение `&`, разность `-`. Удобно «какие датчики были в обеих сменах». Элементы должны быть хешируемыми: числа, строки, кортежи из таких. Список внутрь множества не положить.

Когда что. Нужен порядок и дубли — список. Нужна пара координат как одно значение — кортеж. Нужно часто спрашивать «мы это уже обработали?» — множество id. Нужна подпись к значению — словарь, следующий урок.
