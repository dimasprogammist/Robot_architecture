# Исключения try/except

## Цель

Обрабатывать сбои через try/except/else/finally.

Понять исключения как объекты и раскрутку стека кадров.

## Что уже пройдено

Вы пишете функции и включения; вызовы могут сбоить.

Исключения — штатный канал «нельзя продолжить обычный путь».

## Объяснение с нуля

При невозможной операции CPython создаёт исключение и ищет обработчик вверх по стеку. Нет обработчика — traceback и завершение.

try помечает участок; except ловит тип; else — если не было исключения; finally — всегда (очистка).

Не глушите всё голым except. Ловите конкретно. raise сообщает о нарушении контракта.

## Термины

- **Исключение / traceback**.

- **try / except / else / finally**.

- **raise**.

- **Exception**.

- **Раскрутка стека**.

- **Подавление ошибок**.

- **from e** (цепочка причин).

## Внутреннее устройство

Создаётся экземпляр и traceback; eval-loop ищет совместимый except.

finally выполняется даже при return в try. Исключения — обычные объекты.

## Пример

```python

def parse_int(text):

    try:

        value = int(text)

    except ValueError as e:

        raise ValueError(f"bad int: {text!r}") from e

    else:

        return value



for s in ["10", "x"]:

    try:

        print(parse_int(s))

    except ValueError as err:

        print("handled", err)

```

## Разбор

Внутренний except оборачивает причину через from.

else возвращает только успех. Внешний цикл ловит на точке входа.

## Ошибки

- Голый except без лога.

- Исключения вместо обычного if без нужды.

- Глотать KeyboardInterrupt широким except.

- Очистка только в except без finally/with.

- Терять причину без from.

## Что запомнить

Исключение ищет except по стеку.

Ловите конкретно; очищайте в finally/with.

raise — сигнал невозможности контракта.

## Задание

Безопасное деление → None при нуле с print-логом.

Вариант с осмысленным raise.
