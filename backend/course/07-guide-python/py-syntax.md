# Синтаксис и отступы

## Цель

Освоить правила записи Python, где отступ — часть грамматики.

Научиться читать блоки так, как их видит компилятор.

## Что уже пройдено

Вы умеете запускать файлы и понимаете `__main__`.

Пора писать составные конструкции без сюрпризов отступов.

## Объяснение с нуля

Границы блоков задаёт **отступ**, не фигурные скобки. После `if`/`for`/`def`/`class` — двоеточие и углубление.

Это грамматика: компилятор строит AST по INDENT/DEDENT. Сбитый отступ меняет смысл или ломает разбор.

Смешение табов и пробелов — TabError. Принято 4 пробела. Комментарий — `#` до конца строки. Длинные выражения продолжают в скобках.

## Термины

- **Отступ** — пробелы/табы, задающие вложенность.

- **Блок (suite)** — тело после двоеточия.

- **Двоеточие** — маркер начала блока.

- **IndentationError / TabError** — ошибки отступов.

- **PEP 8** — обычно 4 пробела.

- **Логическая строка** — выражение на нескольких физических.

- **AST** — дерево синтаксиса.

## Внутреннее устройство

Лексер выдаёт NEWLINE/INDENT/DEDENT — аналоги `{` `}`. Парсер собирает suites; компилятор даёт байткод с переходами.

Неверный Dedent → SyntaxError до исполнения. «Почти правильный» отступ опасен: программа может выполнить не ту ветку.

## Пример

```python

def abs_value(n):

    if n < 0:

        return -n

    return n



for i in range(3):

    print(i, abs_value(i - 1))

```

## Разбор

Тело `def` и `if` выделены отступом. `return n` на уровне `if`, иначе при `n>=0` вернётся `None`.

Цикл требует блока; сдвиг `return` меняет семантику или даёт ошибку.

## Ошибки

- Смешивать табы и пробелы.

- Визуально «под if», но с тем же отступом.

- Забывать двоеточие.

- Копировать неразрывные пробелы из чата.

- Думать, что пустая строка закрывает блок.

## Что запомнить

Отступ = структура программы.

4 пробела — устойчивая привычка.

Ошибка отступа часто ломает разбор до запуска.
