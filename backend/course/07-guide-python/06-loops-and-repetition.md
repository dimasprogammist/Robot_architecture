# Циклы и повторение действий

## Зачем нужны циклы

До этого наши программы выполняли инструкции один раз.

Например:

```python
print("Motor started")
print("Motor started")
print("Motor started")
```

Если нужно выполнить действие сто раз, писать одну и ту же строку сто раз было бы бессмысленно.

Для повторения действий используются **циклы**.

Цикл позволяет сказать программе:

> выполни этот блок несколько раз.

В Python основные циклы:

```text
for
while
```

Они решают похожую задачу, но используются в разных ситуациях.

---

## Первый цикл `for`

Самый простой пример:

```python
for i in range(5):
    print(i)
```

Результат:

```text
0
1
2
3
4
```

Цикл выполнил тело пять раз.

---

## Как работает `range()`

В примере:

```python
range(5)
```

создаёт последовательность чисел:

```text
0
1
2
3
4
```

Важно:

**правая граница не включается.**

Поэтому:

```python
range(5)
```

содержит пять значений, начиная с нуля.

---

## Почему счёт начинается с нуля

Нумерация с нуля широко используется в программировании.

Например:

```python
for i in range(3):
    print(i)
```

получим:

```text
0
1
2
```

Количество повторений — три.

Это не означает, что цикл «начинается с нулевого раза». Переменная `i` просто получает значения из последовательности.

---

## Имя переменной цикла

Обычно используют:

```python
for i in range(5):
    ...
```

Но имя может быть любым:

```python
for counter in range(5):
    print(counter)
```

Или:

```python
for step in range(5):
    print(step)
```

Лучше выбирать имя, объясняющее назначение переменной.

---

## `range(start, stop)`

Можно задать начало и конец:

```python
for i in range(2, 6):
    print(i)
```

Результат:

```text
2
3
4
5
```

То есть:

```text
start включается
stop не включается
```

---

## `range(start, stop, step)`

Можно задать шаг:

```python
for i in range(0, 10, 2):
    print(i)
```

Получим:

```text
0
2
4
6
8
```

Шаг равен `2`.

Можно использовать отрицательный шаг:

```python
for i in range(10, 0, -2):
    print(i)
```

Результат:

```text
10
8
6
4
2
```

---

## Цикл без использования счётчика

Иногда значение переменной цикла нам не нужно.

Например:

```python
for _ in range(5):
    print("Motor check")
```

Символ `_` показывает:

> значение этой переменной мне не требуется.

---

## Цикл по списку

`for` особенно полезен при работе с коллекциями.

Например:

```python
temperatures = [21.5, 22.0, 23.1, 22.7]

for temperature in temperatures:
    print(temperature)
```

Получим:

```text
21.5
22.0
23.1
22.7
```

Здесь цикл последовательно получает каждый элемент списка.

---

## Что происходит внутри

Для:

```python
temperatures = [21.5, 22.0, 23.1]
```

цикл:

```python
for temperature in temperatures:
    print(temperature)
```

можно мысленно представить так:

```text
temperature → 21.5
print()

temperature → 22.0
print()

temperature → 23.1
print()
```

Это очень важная модель.

---

## `for` и строки

Цикл может проходить по символам строки:

```python
word = "Python"

for char in word:
    print(char)
```

Получим:

```text
P
y
t
h
o
n
```

Строка является последовательностью символов.

---

## Цикл и условия

Циклы часто используются вместе с `if`.

Например:

```python
temperatures = [45, 52, 78, 91, 64]

for temperature in temperatures:
    if temperature > 80:
        print("High temperature:", temperature)
```

Программа проверяет каждый элемент.

Результат:

```text
High temperature: 91
```

---

## Подсчёт количества элементов

Например:

```python
temperatures = [45, 82, 73, 91, 64]

count = 0

for temperature in temperatures:
    if temperature > 80:
        count += 1

print(count)
```

Результат:

```text
2
```

Так можно подсчитывать количество аварий, ошибок, деталей и других событий.

---

## Суммирование

Циклы позволяют выполнять накопительные вычисления.

```python
values = [10, 20, 30, 40]

total = 0

for value in values:
    total += value

print(total)
```

Получим:

```text
100
```

Здесь:

```python
total += value
```

постепенно увеличивает накопленную сумму.

---

## Среднее значение

Можно вычислить среднее:

```python
values = [10, 20, 30, 40]

total = 0

for value in values:
    total += value

average = total / len(values)

print(average)
```

Результат:

```text
25.0
```

Позже мы узнаем, что для таких задач существуют готовые функции и библиотеки.

Но понимание ручного алгоритма очень важно.

---

## `while`

Второй основной тип цикла:

```python
while
```

Он выполняется, пока условие истинно.

Например:

```python
counter = 0

while counter < 5:
    print(counter)
    counter += 1
```

Результат:

```text
0
1
2
3
4
```

---

## Как работает `while`

Логика:

```text
проверить условие
      ↓
    True?
   /     \
 да       нет
 ↓         ↓
тело      конец
 ↓
снова проверить
```

В примере:

```python
counter < 5
```

проверяется перед каждой итерацией.

---

## Очень важно изменять состояние

Рассмотрим:

```python
counter = 0

while counter < 5:
    print(counter)
```

Здесь `counter` никогда не меняется.

Условие:

```text
counter < 5
```

всегда остаётся истинным.

Получится бесконечный цикл.

Поэтому обычно внутри `while` должно происходить изменение состояния, которое в какой-то момент сделает условие ложным.

```python
counter += 1
```

---

## Бесконечные циклы

Иногда бесконечный цикл нужен намеренно.

Например, управляющая программа может постоянно проверять оборудование:

```python
while True:
    check_sensors()
    process_data()
```

Но внутри должен существовать механизм остановки, ошибки или выхода.

Для обычных учебных задач бесконечные циклы нужно использовать осторожно.

---

## `break`

Оператор `break` немедленно завершает цикл.

Например:

```python
for number in range(10):
    if number == 5:
        break

    print(number)
```

Результат:

```text
0
1
2
3
4
```

Когда `number` становится равным `5`, цикл завершается.

---

## `continue`

`continue` пропускает текущую итерацию и переходит к следующей.

Например:

```python
for number in range(5):
    if number == 2:
        continue

    print(number)
```

Получим:

```text
0
1
3
4
```

Число `2` было пропущено.

---

## Когда использовать `for`, а когда `while`

Хорошая практическая подсказка:

### `for`

Используйте, когда:

* нужно пройти по коллекции;
* известно количество повторений;
* есть последовательность значений.

Например:

```python
for temperature in temperatures:
    ...
```

### `while`

Используйте, когда:

* количество повторений заранее неизвестно;
* действие продолжается до наступления некоторого состояния.

Например:

```python
while not connected:
    try_connect()
```

---

## Практический пример: контроль температуры

Представим список измерений:

```python
temperatures = [55, 62, 71, 83, 79, 91]
```

Нужно найти все значения выше допустимого уровня:

```python
limit = 80

for temperature in temperatures:
    if temperature > limit:
        print("Alarm:", temperature)
```

Получим:

```text
Alarm: 83
Alarm: 91
```

---

## Практический пример: запуск двигателя

Допустим, система должна делать несколько попыток запуска:

```python
for attempt in range(3):
    print("Start attempt:", attempt + 1)
```

Результат:

```text
Start attempt: 1
Start attempt: 2
Start attempt: 3
```

Если двигатель запустился, можно остановить цикл:

```python
for attempt in range(3):
    print("Attempt:", attempt + 1)

    started = check_motor()

    if started:
        print("Motor started")
        break
```

---

## Практический пример `while`

Пусть контроллер ждёт, пока температура опустится:

```python
temperature = 90

while temperature > 70:
    print("Cooling:", temperature)
    temperature -= 5

print("Temperature normal")
```

Результат:

```text
Cooling: 90
Cooling: 85
Cooling: 80
Cooling: 75
Temperature normal
```

В реальном оборудовании вместо искусственного уменьшения температуры программа получала бы новое значение от датчика.

---

## Вложенные циклы

Цикл может находиться внутри другого цикла:

```python
for row in range(3):
    for column in range(4):
        print(row, column)
```

Это даёт пары координат:

```text
0 0
0 1
0 2
0 3
1 0
1 1
...
```

Вложенные циклы используются при обработке:

* таблиц;
* матриц;
* изображений;
* координат;
* сеток.

## Практическое задание

Создайте список:

```python
values = [10, 25, 3, 42, 18, 51, 7]
```

С помощью цикла найдите:

1. сумму всех значений;
2. количество значений больше `20`;
3. количество чётных чисел;
4. самое большое значение.

Пока не используйте `sum()` и `max()` — реализуйте алгоритмы самостоятельно.

---

## Задание с роботом

Создайте:

```python
distances = [120, 95, 80, 45, 30, 18, 12]
```

Пусть робот должен остановиться, если расстояние стало меньше `20`.

Пройдите значения циклом и выведите:

```text
Obstacle detected
```

при первом опасном значении.

После этого цикл должен завершиться.

Используйте `break`.

---

## Главное

Циклы позволяют автоматизировать повторяющиеся действия.

Главные конструкции:

```python
for ...
```

и:

```python
while ...
```

Для управления циклом используются:

```python
break
continue
```

А типичная программа уже может выглядеть так:

```text
получить данные
      ↓
перебрать данные циклом
      ↓
проверить каждое значение
      ↓
принять решение
      ↓
сохранить результат
```

Это уже основа реальных алгоритмов обработки данных.

Следующий важный шаг — научиться работать с коллекциями данных более системно, начиная со списков.
