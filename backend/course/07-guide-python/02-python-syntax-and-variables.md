# Синтаксис Python, переменные и значения

## Зачем нужны переменные

Практически любая программа работает с данными.

Например, системе управления роботом могут понадобиться:

```text
скорость двигателя
температура
координаты
состояние датчика
номер детали
состояние соединения
```

Программе необходимо где-то хранить эти данные.

Для этого используются переменные.

Простейший пример:

```python
temperature = 72.5
```

Здесь мы создаём имя `temperature` и связываем его со значением `72.5`.

---

## Переменная — это имя, а не коробка

Для начала удобно представлять переменную как имя, связанное со значением:

```text
temperature ─────→ 72.5
```

После:

```python
temperature = 80
```

связь изменяется:

```text
temperature ─────→ 80
```

Это более точная модель, чем представление о переменной как о физической коробке в памяти.

В Python имя переменной ссылается на объект.

На начальном этапе достаточно понимать:

**переменная позволяет обращаться к некоторому значению по имени.**

---

## Присваивание

Для присваивания используется оператор `=`:

```python
speed = 1500
```

Это не означает математическое равенство.

В программировании:

```python
speed = 1500
```

означает:

> свяжи имя `speed` со значением `1500`.

Можно изменить значение:

```python
speed = 1500
speed = 1800
```

Теперь:

```python
print(speed)
```

выведет:

```text
1800
```

---

## Использование переменных

Переменные можно использовать в выражениях:

```python
a = 10
b = 20

c = a + b

print(c)
```

Получим:

```text
30
```

Здесь Python сначала получает значения `a` и `b`, выполняет сложение и сохраняет результат в `c`.

---

## Имена переменных

Хорошее имя должно объяснять, что хранится в переменной.

Плохо:

```python
x = 72.5
```

Лучше:

```python
temperature = 72.5
```

Ещё лучше, если контекст сложный:

```python
motor_temperature = 72.5
```

Имена:

```python
motor_speed
target_temperature
sensor_value
connection_status
```

обычно гораздо понятнее:

```python
a
b
x1
q
```

---

## Стиль имён

В Python обычно используется стиль `snake_case`:

```python
motor_speed = 1500
target_temperature = 70
sensor_value = 123
```

Несколько слов соединяются символом `_`.

Не рекомендуется писать:

```python
motorSpeed = 1500
```

если только это не требуется стилем конкретного проекта.

---

## Какие имена допустимы

Имя переменной может содержать:

* латинские буквы;
* цифры;
* `_`.

Но цифра не может быть первым символом.

Можно:

```python
sensor1 = 100
sensor_1 = 100
```

Нельзя:

```python
1sensor = 100
```

Нельзя использовать пробел:

```python
motor speed = 1500
```

Правильно:

```python
motor_speed = 1500
```

---

## Регистр имеет значение

Python различает большие и маленькие буквы:

```python
temperature = 50
Temperature = 70
```

Это два разных имени.

Например:

```python
temperature = 50

print(Temperature)
```

приведёт к ошибке, потому что `Temperature` и `temperature` — разные имена.

Поэтому лучше придерживаться одного стиля.

---

## Значения

Переменная сама по себе не является значением.

Например:

```python
speed = 1500
```

Здесь:

```text
speed
```

— имя,

а:

```text
1500
```

— значение.

В Python значение представлено объектом.

Позже мы подробно разберём объекты и типы данных.

---

## Несколько переменных

Можно создавать сколько угодно переменных:

```python
name = "Motor-01"
speed = 1500
temperature = 65.2
enabled = True
```

Затем использовать их:

```python
print(name)
print(speed)
print(temperature)
print(enabled)
```

Получим:

```text
Motor-01
1500
65.2
True
```

---

## Переменные можно использовать друг в друге

Например:

```python
speed = 1000
increase = 250

new_speed = speed + increase

print(new_speed)
```

Результат:

```text
1250
```

После этого:

```python
speed = new_speed
```

можно сохранить новое значение как текущую скорость.

---

## Присваивание справа налево

Рассмотрим:

```python
a = 10
b = a
```

Сначала создаётся значение `10` и имя `a` начинает ссылаться на него.

Затем Python получает значение, на которое ссылается `a`, и связывает с ним имя `b`.

Получается:

```text
a ──┐
    ├──→ 10
b ──┘
```

Если после этого выполнить:

```python
a = 20
```

то `a` будет связано с `20`, а `b` останется связано с `10`:

```text
a ──→ 20

b ──→ 10
```

Поэтому:

```python
a = 10
b = a

a = 20

print(a)
print(b)
```

даст:

```text
20
10
```

---

## Можно присваивать несколько значений

Python позволяет писать:

```python
a, b = 10, 20
```

Это означает:

```text
a → 10
b → 20
```

Можно обменять значения:

```python
a = 10
b = 20

a, b = b, a
```

Теперь:

```text
a → 20
b → 10
```

Без необходимости создавать временную переменную.

---

## Константы

Python не запрещает изменять любую переменную.

Но иногда значение логически должно оставаться постоянным.

Например:

```python
MAX_SPEED = 3000
```

В Python существует соглашение:

**имена констант пишут заглавными буквами.**

Это не делает значение физически неизменяемым.

Например:

```python
MAX_SPEED = 3000
MAX_SPEED = 5000
```

технически допустимо.

Но по соглашению программист сообщает:

> эту переменную не следует менять.

---

## Синтаксис Python

Синтаксис — это правила, по которым должна быть записана программа.

Например:

```python
temperature = 70
```

корректно.

А:

```python
temperature 70
```

некорректно, потому что между именем и значением отсутствует оператор присваивания.

Python должен однозначно понимать структуру программы.

---

## Отступы

Отступы в Python являются частью синтаксиса.

Например:

```python
temperature = 75

if temperature > 70:
    print("High temperature")
```

После `:` начинается блок.

Все инструкции блока имеют отступ:

```python
if temperature > 70:
    print("High temperature")
    print("Check the motor")
```

Если строка не должна находиться внутри блока, отступ заканчивается:

```python
if temperature > 70:
    print("High temperature")

print("Program continues")
```

---

## Пустые строки

Пустые строки не обязательны, но помогают структурировать код.

Например:

```python
name = "Motor-01"
speed = 1500
temperature = 65.5


print(name)
print(speed)
print(temperature)
```

В реальных программах пустые строки помогают визуально отделять логические части.

---

## Длинные выражения

Python позволяет разбивать некоторые выражения на несколько строк с помощью скобок:

```python
total = (
    motor_speed
    + correction
    + compensation
)
```

Это особенно полезно, когда выражение становится большим.

---

## Ввод данных

Для получения текста от пользователя используется `input()`:

```python
name = input("Enter your name: ")

print("Hello,", name)
```

Если пользователь вводит:

```text
Dmitry
```

получим:

```text
Hello, Dmitry
```

Важно понимать:

`input()` возвращает текст.

Даже если пользователь введёт:

```text
25
```

результатом будет строка `"25"`.

Преобразование в число мы рассмотрим позже.

---

## Вывод данных

Основной инструмент вывода — `print()`:

```python
speed = 1500

print(speed)
```

Можно вывести несколько значений:

```python
name = "Motor-01"
speed = 1500

print(name, speed)
```

Можно использовать f-строки:

```python
print(f"Motor: {name}, speed: {speed}")
```

Это особенно удобно для формирования сообщений.

---

## Практический пример

Представим двигатель:

```python
motor_name = "Motor-01"
speed = 1450
temperature = 62.5
enabled = True

print(f"Name: {motor_name}")
print(f"Speed: {speed} rpm")
print(f"Temperature: {temperature} °C")
print(f"Enabled: {enabled}")
```

Такой код уже напоминает маленькую часть реальной программы автоматизации.
