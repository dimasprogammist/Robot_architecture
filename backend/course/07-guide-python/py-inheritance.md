# Наследование

## Цель

Расширять поведение типа через наследование.

Увидеть поиск атрибутов по MRO без глубоких иерархий.

## Что уже пройдено

Вы создаёте классы и экземпляры.

Наследование связывает новый класс с существующим типом.

## Объяснение с нуля

`class Child(Parent)` расширяет Parent. Дочерний экземпляр использует методы родителя, если не переопределил. super() вызывает следующую реализацию в MRO.

Уместно для настоящей специализации; часто композиция яснее. Полиморфизм: код ждёт Parent, работает с Child при соблюдении контракта.

## Термины

- **Наследование / переопределение**.

- **super()**.

- **MRO**.

- **isinstance / issubclass**.

- **Полиморфизм**.

- **Базовый класс**.

- **Кооперативное наследование** (обзор).

## Внутреннее устройство

У type object есть MRO — порядок поиска атрибутов.

super() — прокси продолжения поиска. Экземпляр ребёнка — один объект, не «копия родителя внутри».

## Пример

```python

class Animal:

    def speak(self):

        return "..."

class Dog(Animal):

    def speak(self):

        return "woof"

class LoudDog(Dog):

    def speak(self):

        return super().speak().upper()

print(LoudDog().speak())

print(isinstance(LoudDog(), Animal))

```

## Разбор

LoudDog → Dog.speak через super → upper. MRO: LoudDog, Dog, Animal, object.

isinstance подтверждает родство.

## Ошибки

- Глубокие иерархии «на всякий случай».

- Забыть super().__init__.

- Ломать контракт родителя.

- Путать наследование с import.

- Наследовать ради одной функции.

## Что запомнить

Наследование специализирует тип через MRO.

super помогает вызвать родителя.

Предпочитайте мелкие иерархии.
