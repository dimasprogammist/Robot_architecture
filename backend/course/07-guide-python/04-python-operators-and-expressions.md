# Операторы и выражения

## Что такое выражение

Выражение — это конструкция, которую Python может вычислить и получить из неё значение.

Например:

```python
10 + 20
```

является выражением.

Результат:

```text
30
```

Переменная тоже может участвовать в выражении:

```python
speed + 100
```

А целая строка:

```python
new_speed = speed + 100
```

содержит выражение справа от `=`.

---

## Что такое оператор

Оператор задаёт действие над значениями.

Например:

```python
+
```

— оператор сложения.

Другие математические операторы:

```text
+   сложение
-   вычитание
*   умножение
/   деление
//  целочисленное деление
%   остаток от деления
**  возведение в степень
```

---

## Сложение

```python
a = 10
b = 20

result = a + b

print(result)
```

Получим:

```text
30
```

---

## Вычитание

```python
temperature = 80
limit = 70

difference = temperature - limit

print(difference)
```

Результат:

```text
10
```

---

## Умножение

```python
speed = 100
factor = 2

result = speed * factor

print(result)
```

Результат:

```text
200
```

---

## Деление

Оператор `/` выполняет обычное деление:

```python
result = 10 / 3

print(result)
```

Получим приблизительно:

```text
3.3333333333333335
```

Результат `/` имеет тип `float`.

Даже:

```python
10 / 2
```

даст:

```text
5.0
```

---

## Целочисленное деление

Оператор `//` отбрасывает дробную часть результата:

```python
result = 10 // 3

print(result)
```

Получим:

```text
3
```

Это полезно, когда нужна целая часть результата.

---

## Остаток от деления

Оператор `%` возвращает остаток:

```python
result = 10 % 3

print(result)
```

Результат:

```text
1
```

Почему?

```text
10 = 3 × 3 + 1
```

Остаток равен `1`.

---

## Практическое применение `%`

Оператор `%` часто используется для проверки чётности:

```python
number = 10

if number % 2 == 0:
    print("Even")
```

Если остаток от деления на `2` равен нулю, число чётное.

Условия мы подробно рассмотрим в следующем уроке.

---

## Возведение в степень

```python
result = 2 ** 3

print(result)
```

Результат:

```text
8
```

То есть:

```text
2 × 2 × 2 = 8
```

---

## Приоритет операторов

Python выполняет операции в определённом порядке.

Например:

```python
result = 2 + 3 * 4
```

Сначала:

```text
3 × 4 = 12
```

затем:

```text
2 + 12 = 14
```

Поэтому:

```python
print(2 + 3 * 4)
```

даст:

```text
14
```

---

## Скобки

Если нужно изменить порядок, используйте скобки:

```python
result = (2 + 3) * 4
```

Теперь:

```text
2 + 3 = 5
5 × 4 = 20
```

Результат:

```text
20
```

Хорошее правило:

**если выражение сложно читать, используйте скобки даже тогда, когда приоритет и так очевиден.**

---

## Операторы сравнения

Python позволяет сравнивать значения.

Основные операторы:

```text
==    равно
!=    не равно
>     больше
<     меньше
>=    больше или равно
<=    меньше или равно
```

Результат сравнения — `True` или `False`.

Например:

```python
temperature = 75

print(temperature > 70)
```

Получим:

```text
True
```

---

## Равенство и присваивание — не одно и то же

Это очень важная разница.

Присваивание:

```python
speed = 1500
```

Сравнение:

```python
speed == 1500
```

Один знак:

```text
=
```

означает присваивание.

Два:

```text
==
```

означают сравнение.

---

## Сравнение строк

Можно сравнивать строки:

```python
status = "OK"

print(status == "OK")
```

Результат:

```text
True
```

Можно проверить:

```python
print(status != "ERROR")
```

---

## Логические операторы

Основные логические операторы:

```text
and
or
not
```

Они позволяют объединять условия.

### and

```python
temperature = 65
enabled = True

result = temperature < 70 and enabled

print(result)
```

`and` даёт `True`, только если оба условия истинны.

---

## or

```python
temperature = 80
alarm = False

result = temperature > 90 or alarm

print(result)
```

`or` даёт `True`, если хотя бы одно условие истинно.

---

## not

`not` меняет логическое значение:

```python
connected = True

print(not connected)
```

Получим:

```text
False
```

---

## Комбинирование условий

Можно написать:

```python
temperature = 65
enabled = True
connected = True

ready = (
    temperature < 70
    and enabled
    and connected
)
```

Теперь `ready` будет `True`, если все три условия выполняются.

Такой подход часто встречается в системах автоматизации:

```text
температура нормальная
+
оборудование включено
+
связь установлена
=
можно работать
```

---

## Составные операторы присваивания

Вместо:

```python
speed = speed + 100
```

можно написать:

```python
speed += 100
```

Аналогично:

```python
speed -= 100
speed *= 2
speed /= 2
```

Например:

```python
counter = 0

counter += 1
counter += 1
counter += 1

print(counter)
```

Результат:

```text
3
```

---

## Операторы для строк

Некоторые операторы работают со строками.

Например:

```python
first = "Hello"
second = "Python"

message = first + " " + second

print(message)
```

Получим:

```text
Hello Python
```

Также:

```python
print("ha" * 3)
```

получим:

```text
hahaha
```

---

## Оператор `in`

Оператор `in` позволяет проверить наличие элемента.

Для строки:

```python
text = "Python"

print("Py" in text)
```

Результат:

```text
True
```

Для списка:

```python
sensors = ["temperature", "pressure", "speed"]

print("speed" in sensors)
```

Получим:

```text
True
```

Это очень полезная операция при работе с коллекциями.

---

## Приоритет логических операций

Например:

```python
result = a > 10 and b < 20
```

Python сначала выполняет сравнения:

```text
a > 10
b < 20
```

а затем применяет `and`.

Если выражение сложное, лучше использовать скобки:

```python
result = (a > 10) and (b < 20)
```

Так код легче читать.

---

## Практический пример

Представим систему контроля двигателя:

```python
temperature = 65
max_temperature = 80

speed = 1200
max_speed = 1500

enabled = True
```

Можно вычислить:

```python
temperature_ok = temperature < max_temperature
speed_ok = speed <= max_speed

ready = temperature_ok and speed_ok and enabled

print("Temperature OK:", temperature_ok)
print("Speed OK:", speed_ok)
print("Ready:", ready)
```

Здесь операторы позволяют постепенно построить логическое состояние системы.

## Практика

Создайте программу, которая рассчитывает:

```python
distance = 120
time = 3
```

Вычислите среднюю скорость:

```text
speed = distance / time
```

Затем добавьте:

```python
max_speed = 50
```

и получите логическое значение:

```text
speed превышает максимальную?
```
