# Рабочий цикл команды

## Цель

Собрать повседневный цикл: ветка → снимки → push → PR → обновление main.

## Что уже пройдено

Все кирпичи модели уже были. Нужен ритуал без магии.

## Объяснение с нуля

Типичный цикл (одна из разумных схем):

1. Обновить знание о `main` (`fetch` / `pull` по правилам команды).
2. Создать ветку от актуального `main`.
3. Делать маленькие коммиты-снимки с понятными сообщениями.
4. Пушить ветку, открыть PR.
5. Учесть review, не переписывать общую историю без нужды.
6. После merge — обновить локальный `main`, удалить слитую ветку при желании.

Смысл ритуала — держать указатели и снимки предсказуемыми для людей. Инструменты можно менять; модель blob/tree/commit и refs остаётся.

## Термины

- **Feature branch** — ветка задачи.
- **Protected main** — на remote нельзя пушить в обход PR (часто).
- **Короткий цикл** — маленькие снимки чаще.

## Внутреннее устройство

```text
main@C10 → ветка feat → C11—C12 → PR → main@M → локально fetch → main@M
```

## Пример

```bash
git fetch origin
git switch -c feat/sensor-filter origin/main
# работа, add, commit...
git push -u origin feat/sensor-filter
# PR → merge
git switch main
git pull
```

## Разбор

Цикл защищает от «финал2» и от потери чужих снимков. Если команда договорилась о rebase-only или merge-only — следуйте договору, не «истинному пути интернета».

## Ошибки

- Неделя работы без push.
- Коммиты «wip» без чистки перед PR, если команда против.
- Держать локальный main вечно грязным и расходящимся.

## Что запомнить

Ежедневный Git — движение указателей и обмен объектами вокруг маленьких снимков. Модель важнее кнопок.

## Задание

Пройдите цикл на учебном репозитории от ветки до воображаемого PR и обновления main. Нарисуйте указатели на каждом шаге.

## Связь со следующим уроком

Модуль Git завершён. Дальше — язык-независимое введение в программирование: что такое программа и алгоритм.

## Ещё раз тем же смыслом

Git не угадывает намерение: он двигает указатели и создаёт объекты по правилам. Рисуйте стрелки «ветка → commit → tree → blob». Контрпример («а если push после rebase?») проявляет цену переписывания хешей. Перескажите урок за две минуты без списка флагов — только снимки и refs. Свой учебный репозиторий ценнее чужого длинного учебника. Сначала модель, потом команда.
