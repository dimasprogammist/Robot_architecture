# Reset: двигать указатель

## Цель

Понять reset как перемещение ветки (и опционально индекса/дерева) к другому commit.

## Что уже пройдено

Теги стабильны. Reset — инструмент переписать, где стоит ветка.

## Объяснение с нуля

**Reset** двигает текущую ветку на выбранный коммит. Режимы отличаются тем, что происходит с индексом и рабочим деревом:

- **soft** — только ветка; индекс и диск как были.
- **mixed** (часто по умолчанию) — ветка + индекс под целевой снимок; диск не трогать.
- **hard** — ветка + индекс + диск под целевой снимок; незакоммиченное в этих путях пропадёт с витрины.

Reset не «удаляет объекты мгновенно»; он меняет, куда указывает ветка. Коммиты могут стать недостижимы из ветки.

## Термины

- **soft / mixed / hard** — глубина синхронизации с целевым commit.
- **Недостижимый коммит** — нет refs; ещё может жить в reflog.

## Внутреннее устройство

```text
main → C3 ; reset --soft C2 → main→C2, индекс всё ещё как после C3
reset --hard C2 → main, индекс, диск = дерево C2
```

## Пример

```bash
git reset --soft HEAD~1
git reset --hard HEAD~1   # опасно для незакоммиченного
```

## Разбор

На уже запушенных коммитах reset+force push ломает историю коллегам. Локально до push — нормальный способ пересобрать край ветки.

## Ошибки

- hard без необходимости.
- reset общей ветки.
- Путать reset с revert.

## Что запомнить

Reset двигает указатель ветки; режимы решают, что сделать с индексом и диском.

## Задание

На учебной ветке сделайте лишний коммит и уберите его через soft reset. Объясните, где остались изменения.

## Связь со следующим уроком

Дальше — revert: новый коммит, отменяющий эффект старого, без переписывания общей истории.

## Ещё раз тем же смыслом

Git не угадывает намерение: он двигает указатели и создаёт объекты по правилам. Рисуйте стрелки «ветка → commit → tree → blob». Контрпример («а если push после rebase?») проявляет цену переписывания хешей. Перескажите урок за две минуты без списка флагов — только снимки и refs. Свой учебный репозиторий ценнее чужого длинного учебника. Сначала модель, потом команда.
