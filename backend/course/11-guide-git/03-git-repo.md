# Репозиторий

## Цель

Понять репозиторий как рабочую папку плюс базу объектов и указателей.

## Что уже пройдено

Боль копий ясна. Нужно место, где живут снимки.

## Объяснение с нуля

**Репозиторий** — каталог проекта, внутри которого Git завёл скрытую базу `.git`. Снаружи — обычные файлы. Внутри — объекты, ссылки (ветки, теги) и служебные файлы.

Пока `.git` нет, это просто папка. База появляется через инициализацию с нуля или через копирование чужой истории. Три слоя, которые путают:

1. Рабочее дерево — файлы в редакторе.
2. Индекс — черновик следующего снимка.
3. База объектов — сами снимки в `.git`.

Слово «репозиторий» обычно значит: есть `.git` и история.

## Термины

- **`.git`** — каталог базы.
- **Объект** — запись с типом; адрес — хеш.
- **Ссылка (ref)** — имя → хеш коммита.
- **HEAD** — «где я сейчас», чаще всего указывает на имя ветки.

## Внутреннее устройство

В `.git/objects` лежат **blob** (байты файла без имени), **tree** (имена → blob/tree), **commit** (корневое tree, родители, автор, сообщение). Ветка — файл вроде `refs/heads/main` с хешем. Передвинуть ветку — переписать хеш.

```text
commit ──► tree (корень)
             ├─ "src" ──► tree ──► "app.py" ──► blob
             └─ "README" ──► blob
```

## Пример

```bash
mkdir demo && cd demo
git init
git status
```

Появится `.git`. История пока пуста: коммитов нет, хотя файлы можно положить рядом.

## Разбор

`git init` не уносит файлы в облако. Он создаёт пустую базу рядом с ними. Без снимка история пуста, даже если в папке уже есть код.

## Ошибки

- Удалить `.git` «для чистоты» — стереть историю.
- Считать репозиторий = только GitHub.
- Без нужды вкладывать репозиторий в репозиторий.

## Что запомнить

Репозиторий = дерево на диске + `.git` с объектами и refs. Снимок собирается из blob/tree/commit.

## Задание

Выполните `git init` в учебной папке, найдите `.git` и перечислите видимые подкаталоги (objects, refs…).

## Связь со следующим уроком

Дальше — рабочее дерево: витрина на диске vs объекты в базе.

## Ещё раз тем же смыслом

Git не угадывает намерение: он двигает указатели и создаёт объекты по правилам. Рисуйте стрелки «ветка → commit → tree → blob». Контрпример («а если push после rebase?») проявляет цену переписывания хешей. Перескажите урок за две минуты без списка флагов — только снимки и refs. Свой учебный репозиторий ценнее чужого длинного учебника. Сначала модель, потом команда.
