# Проблема без контроля версий

Файл `motor.md`: понедельник — корректное описание, вторник — ток, среда — обороты. Четверг: «вчера работало». Где вчерашняя **пара** ток+обороты вместе?

Копии `motor_вт.md` и `motor_финал.md` через две недели содержат старый ток и новый текст про обороты. Связи «эти значения стояли одновременно» нет.

Два человека правят разные абзацы в своих копиях и шлют файл целиком — побеждает последний отправитель. Нет модели «оба изменения живут, пока их явно не соберут».

Корень в файловой системе: один путь — одно текущее содержимое. Имена копий — костыль, не линия истории. Облачные «версии файла» тоже не граф веток и слияний.

```text
день 1: ток 2A, 1000 об/мин
день 2: копия, ток 2.2A
день 3: в «основном» уже 1200 об/мин
день 4: какая пара была во вторник? неизвестно
```

Нужны содержимое на момент и связь состояний. Снимки с родителями дают цепочку. Git рядом с рабочей папкой держит много состояний; файлы, которые вы видите — выбранная витрина.
