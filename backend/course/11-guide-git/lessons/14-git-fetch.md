# Fetch

**Fetch** забирает новые объекты и двигает `origin/*`. Ваша текущая ветка и рабочее дерево **не** меняются. Это «узнать, что там», не «влить в мои файлы».

После fetch можно смотреть `log HEAD..origin/main`, смотреть diff, решать: merge, rebase, или ничего. Без fetch все сравнения с origin — про вчерашний снимок закладок.

Fetch не требует чистого дерева. Конфликтов fetch не делает: конфликт родится, когда вы сами сольёте.

Несколько remote — `git fetch origin`, `git fetch upstream`. `fetch --all` — все закладки.
