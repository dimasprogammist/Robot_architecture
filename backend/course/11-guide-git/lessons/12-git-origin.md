# origin

**origin** — всего лишь обычное имя remote, которое `clone` ставит по умолчанию. Никакой магии «главный сервер вселенной». Можно назвать иначе. Договорённость команды: origin — каноническая копия, куда пушим основную работу.

Upstream ветки: локальная `feat` может следить за `origin/feat`. `status` тогда пишет «ahead 1, behind 2». Это сравнение с **последним fetch**, не с секретарем на сайте в эту секунду.

Первый push новой ветки задаёт, куда она привязана (`-u`). Без привязки каждый push просит имя remote и ветки.

Не путайте origin с веткой `main`. origin — репозиторий, main — указатель внутри него.

Удалить origin — забыть URL, история локально останется. Добавить заново — снова закладка.
