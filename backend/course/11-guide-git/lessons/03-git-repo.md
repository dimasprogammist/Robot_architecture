# Репозиторий

**Репозиторий** — проект вместе с историей. На диске это обычные файлы плюс каталог `.git`: объекты, ссылки, настройки. Без `.git` папка — просто дерево файлов. `git init` создаёт базу в выбранном каталоге. Вложенный init во вложенной папке — второй репозиторий, путаница «почему статус не видит файлы».

Рабочие файлы — не «Git». Git смотрит на них и на `.git`. Удалить `.git` — стереть историю, оставить текущие байты. Копировать проект без `.git` — отдать снимок без прошлого.

Один репозиторий — одна логическая единица. Не кладите в него полдомашнего каталога и не мешайте два несвязанных продукта. Секреты и гигабайты сборок — не сюда: история раздует и утечёт.

```bash
mkdir demo && cd demo
git init
ls -a   # появится .git
```

Пока нет коммитов, истории как графа ещё нет, но репозиторий уже есть: место, куда снимки лягут. Имя ветки по умолчанию зависит от настроек (`main` / `master`); это ярлык, не магия.

Чужой репозиторий обычно получают `clone` — об этом позже: копия истории и рабочее дерево. Сейчас важно: репозиторий локален. Сервер — ещё один экземпляр, не «настоящий Git».
