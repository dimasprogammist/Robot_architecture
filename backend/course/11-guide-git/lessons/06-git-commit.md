# Коммит

**Коммит** — снимок: указатель на дерево файлов, родитель (или несколько), автор, время, сообщение. Хеш объекта — идентификатор. Переписали историю — хеш другой, даже если «те же правки глазами».

`git commit` забирает **индекс**, оформляет tree, пишет commit, двигает текущую ветку. Пустой индекс (нет изменений относительно HEAD) — нечего фиксировать, кроме редких исключений вроде `--allow-empty` для служебных меток.

Сообщение — для человека через полгода: что и зачем, не «правки». Первый абзац короткий, детали ниже. Врут сообщения — история бесполезна, сколько ни коммитьте.

Коммит локален. Пока нет push, его нет на сервере. Пока нет push, его ещё можно переписать у себя — цена растёт, когда другие уже взяли этот хеш.

```bash
git add motor.md
git commit -m "Зафиксировать ток 2.2 A для стенда B"
```

Первый коммит без родителя — корень истории. Дальше каждый обычный коммит знает родителя: цепочка.

Не коммитьте секреты: они останутся в объектах даже после «удаления из файла». Не мешайте в одном снимке несвязанные темы: откат и revert потом режут больнее.

### Задание 2. Без add
