# Stash

Нужно срочно переключить ветку, а в дереве грязь, коммитить рано. **Stash** кладёт снимок незакоммиченных правок в отдельную стопку и пытается вернуть дерево к HEAD.

По умолчанию часто не берёт неотслеживаемые файлы — новый `notes.md` останется и помешает switch. `-u` включает их. Секреты в stash живут в `.git` — это не помойка вне репозитория.

`stash pop` применяет и снимает с вершины; `apply` оставляет запись. Конфликт при pop — как при merge, запись может остаться.

Stash — не ветка и не бэкап на месяц. Имена легко забыть, стопка копится. Долгую работу лучше коммитить на ветке (хоть «wip»).

Не stash'ьте огромные бинарники «на всякий». Не путайте с reset: stash можно вернуть, hard — нет.

### Задание 2. Untracked

Новый файл не ушёл в stash. Какой флаг и почему Git осторожничает по умолчанию?

### Задание 3. pop vs apply

Когда apply безопаснее pop? Что будет при конфликте pop?

### Задание 4. Не вечный карман

Три stash без сообщений через месяц. Почему ветка `wip/motor` честнее?
