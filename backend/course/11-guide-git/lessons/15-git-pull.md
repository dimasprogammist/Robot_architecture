# Pull

**Pull** = fetch, затем интеграция в **текущую** ветку: merge или rebase (настройка `pull.rebase`). Это удобство и источник сюрпризов: люди думают, что pull «просто скачивает».

Если разошлись и merge — может появиться merge-коммит или конфликт в рабочем дереве. Если rebase — переписываются ваши локальные коммиты поверх скачанного.

Грязное дерево + конфликтующие чужие правки = боль. Спрятать в stash или закоммитить своё до pull — спокойнее.

Pull не заменяет понимание fetch. Когда нужно только обновить `origin/*`, fetch достаточно и безопаснее для экспериментальных веток.
