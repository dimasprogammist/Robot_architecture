# Рабочее дерево

Файлы, которые открывает редактор — **рабочее дерево** (working tree): витрина выбранного снимка плюс ваши несохранённые в Git правки. Git сравнивает дерево с индексом и с последним коммитом (HEAD) и говорит: что изменилось.

Не каждый файл в витрине должен попасть в историю. Сборка, кэш, секреты — живут рядом, но игнорируются (урок про ignore). `status` показывает неотслеживаемые именно поэтому.

Переключение ветки переписывает витрину под другой снимок. Незафиксированные правки могут помешать: Git не хочет затереть черновик. Отсюда привычка: либо коммит, либо stash, либо осознанный сброс.

Второй checkout того же репозитория в другую папку (worktree) — продвинутый приём: две витрины, одна база `.git`. Пока достаточно одной папки.

```bash
git status
git diff          # рабочее дерево против индекса
```

`diff` без аргументов не показывает уже добавленное в индекс — другой слой, следующий урок.

Редактор «сохранил» — изменилось дерево. История молчит, пока не будет add и commit.
