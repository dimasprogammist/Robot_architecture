# История и журнал

Коммиты образуют цепочку (позже — граф). `git log` показывает её с текущего HEAD назад по родителям. Это не «список патчей на почте», а прогулка по снимкам.

Полезные проекции: однострочный лог, график веток (`--graph --oneline --decorate`), файл (`git log -- путь`) — только коммиты, трогавшие путь. `git show HASH` — снимок и diff к родителю.

`git blame` — кто последним трогал строку в **текущей** версии файла. Это не суд, а навигация. Переписанная история меняет имена в blame.

История локальна, пока не fetch/pull. «На GitHub уже есть» не значит, что ваш `log` это видит.

```bash
git log --oneline -n 10
git log -- motor.md
```

Первый коммит в логе — конец ветки, не «начало времён». Листать вниз — в прошлое.

Не используйте log как замену сообщений: если все «fix», график красив и бесполезен.
