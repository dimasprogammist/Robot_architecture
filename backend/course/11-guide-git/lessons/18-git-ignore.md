# .gitignore

Рабочее дерево полно мусора: `__pycache__`, сборки, секреты, IDE. **`.gitignore`** говорит: не предлагай это в `status`/`add`. Уже отслеживаемые файлы ignore **не выкинет** — шаблон действует на неотслеживаемое.

Секреты, однажды закоммиченные, живут в истории даже после удаления из дерева и дописывания ignore. Нужна отдельная чистка истории (и смена ключей). Ignore — профилактика, не шредер.

Шаблоны: `*.o`, каталоги `build/`, отрицание `!важно.txt`. Файл `.gitignore` сам обычно коммитят, чтобы команда делила правила. Личное — `.git/info/exclude` или глобальный exclude.

Артефакты робота (логи прогона, bag-файлы) — в ignore. Исходники и конфиги, без которых не собрать стенд — нет.
