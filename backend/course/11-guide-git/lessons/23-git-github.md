# GitHub как хостинг

GitHub (GitLab, Gitea…) — **не** Git. Это сервер с копией репозитория плюс люди, права, Issues, Actions. Модель снимков та же. Можно жить с голым SSH-репозиторием на своей машине.

Полезное: issues рядом с кодом, веб-просмотр diff, защита `main` (нельзя force, нужен PR), CI на push. Вредное: новичок думает, что «история = сайт», и не понимает локальный log.

Clone/push по HTTPS или SSH — транспорт. Права (write в repo) решает хостинг, не алгоритм merge.

Fork — ваша копия репозитория на том же хостинге со своим URL. Upstream — чужой канон. PR из fork в upstream — запрос «возьмите мои коммиты».

Не храните секреты в публичном репо: история вечная для клонировавших. `.gitignore` не лечит уже запушенное.
