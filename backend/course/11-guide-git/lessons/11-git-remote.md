# Удалённые репозитории

Git полный и без сети. **Remote** — именованный адрес другого экземпляра истории: URL и короткое имя (`origin` чаще всего). Это не «облако внутри Git», а закладка: куда fetch/push.

`git remote -v` список. Несколько remote — норма (upstream чужого проекта и ваш fork). Имя — ярлык, URL можно сменить.

Удалённые ветки локально видны как `origin/main`: **снимок того, что вы последний раз скачали**, не живая веб-страница. Пока не fetch, `origin/main` может врать относительно сервера.

Push публикует ваши коммиты. Fetch забирает объекты и обновляет `origin/*`. Pull — fetch плюс слияние (или rebase, как настроите) в текущую ветку. Их путают — думают, что `status` «уже как на GitHub».

Сервер не обязателен: remote может быть путь к другому каталогу. Хостинг удобен правами и PR, не «настоящестью» Git.
