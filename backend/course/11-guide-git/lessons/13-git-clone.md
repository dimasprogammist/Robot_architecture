# Клонирование

**Clone** — создать локальный репозиторий с историей (обычно полной) и рабочей копией выбранной ветки. Это не «скачать zip без `.git`»: zip — снимок файлов, clone — ещё объекты, ссылки, remote.

По умолчанию появляется `origin` на исходный URL, checkout одной ветки, остальные remote-tracking (`origin/feat`) без локальных имён, пока не `switch`. Мелкий clone (`--depth`) режет историю: bisect и часть blame страдают.

Клонировать в непустой каталог Git не любит. Права на сервере и SSH/HTTPS — отдельный слой, не модель снимков.

После clone вы уже можете коммитить офлайн. Связь с origin понадобится на fetch/push.

Не путать clone с копированием папки проекта мышкой: так легко получить второе дерево без понимания remote или, наоборот, случайно утащить чужой `.git`.
