# Ветки как указатели

**Ветка** — имя, указывающее на коммит, не копия папки. Создать ветку — записать новое имя на тот же хеш. Дёшево.

Пока два имени смотрят на один коммит, линии не разошлись. Новый коммит двигает **ту** ветку, на которую смотрит HEAD. Другая остаётся. Так появляется развилка.

HEAD обычно содержит `ref: refs/heads/main`, не голый хеш. **Detached HEAD** — вы на хеше напрямую: новые коммиты не двигают ветку, их легко «потерять» из `log` обычных имён (reflog ещё помнит).

```text
main ──► C2
feat ──► C2
коммит на feat:
feat ──► C3
main ──► C2
```

```bash
git branch feat
git switch feat
```

Переключение обновляет рабочее дерево под целевой снимок. Имена живут в `refs/heads/` (или packed-refs) — обычные маленькие файлы с хешем.

Не плодите ветки «на всякий случай» без задачи. Не держите вечную ветку, которую никто не сольёт: она гниёт относительно `main`.
