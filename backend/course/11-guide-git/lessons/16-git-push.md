# Push

**Push** отправляет объекты и просит remote двинуть указатель ветки. Отклонят, если на remote есть коммиты, которых нет у вас: иначе вы затрёте чужую историю. Тогда fetch, интеграция, снова push.

Force (`--force`) двигает указатель даже если это не fast-forward. `--force-with-lease` чуть добрее: откажется, если remote ушёл с тех пор, как вы fetch'или. Публичные общие ветки force не делают без ритуала команды.

Первый push ветки создаёт её на remote. Удаление ветки на remote — отдельная операция (`push origin --delete`), не «просто перестать пушить».

Push не отправляет незакоммиченное и неотправляет чужие ветки, если вы не указали. Теги — по желанию (`--tags`).
