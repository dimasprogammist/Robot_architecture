# Графы: вершины, рёбра и представление графа

Карта дорог между городами, структура ссылок между веб-страницами, иерархия зависимостей между модулями программы, социальная сеть друзей — все эти на первый взгляд разные вещи описываются одной и той же математической структурой: набором объектов и связей между ними. Эту структуру называют графом, и она — один из самых универсальных инструментов для моделирования отношений.

## Вершины и рёбра

**Граф** состоит из **вершин** (узлов — городов, страниц, людей, модулей) и **рёбер** — связей между парами вершин (дорог, ссылок, зависимостей, дружеских связей). Граф удобно рисовать как точки, соединённые линиями:

```text
     A ─── B
     │     │
     │     │
     C ─── D
```

Здесь четыре вершины ($A, B, C, D$) и четыре ребра, соединяющие их попарно.

## Ориентированные и неориентированные графы

В **неориентированном графе** ребро не имеет направления — связь симметрична: если $A$ дружит с $B$, то и $B$ дружит с $A$. В **ориентированном графе** у каждого ребра есть направление — ссылка на веб-странице ведёт от одной страницы к другой, но это не означает автоматически ссылку в обратную сторону. Подписчик в социальной сети подписывается на другого человека — это тоже направленная связь, не обязательно взаимная.

```text
  Неориентированный        Ориентированный
      A ─── B                  A ──→ B
                                 ↑    │
                                 │    ↓
                                 └─── C
```

## Степень вершины

**Степень вершины** — это количество рёбер, которые в неё входят (для неориентированного графа — просто число соседей). В ориентированном графе различают **исходящую степень** (сколько рёбер выходит из вершины) и **входящую степень** (сколько рёбер входит в неё) — это разные числа, и их легко перепутать. Степень вершины — простая, но содержательная характеристика: вершина социальной сети с огромной входящей степенью (на неё много кто подписан) — это, по сути, математическое определение понятия «влиятельный аккаунт», без всякой дополнительной интерпретации.

## Взвешенные графы

Часто ребро несёт не только сам факт связи, но и некоторую числовую характеристику — **вес**: расстояние между городами, пропускную способность сетевого канала, стоимость перехода между состояниями. Такой граф называют **взвешенным**, и это открывает дорогу к практически важным задачам вроде поиска кратчайшего пути — не просто любого маршрута от одной вершины до другой, а маршрута с наименьшей суммарной стоимостью.

```python
graph = {
    "A": {"B": 5, "C": 2},
    "B": {"D": 1},
    "C": {"D": 7},
    "D": {},
}
# Путь A -> C -> D стоит 2+7=9, путь A -> B -> D стоит 5+1=6 — он короче
```

## Путь, цикл, связность

**Путь** — это последовательность рёбер, по которым можно пройти от одной вершины к другой. **Цикл** — путь, который возвращается в ту же вершину, с которой начался, не повторяя рёбер. Граф называют **связным**, если от любой его вершины можно добраться до любой другой, следуя по рёбрам, — если же граф распадается на несколько групп вершин, между которыми вообще нет пути, такие группы называют компонентами связности.

Распознавание цикла — не абстрактная задача: зависимости между модулями программы (модуль A использует модуль B, B использует C) образуют ориентированный граф, и обнаружение цикла в этом графе (A, в конце концов, опять зависит от A через цепочку) сигнализирует о проблеме циклических зависимостей, которую нужно устранить до того, как она сломает сборку или вызовет бесконечную рекурсию при загрузке модулей.

## Представление графа: матрица смежности и список смежности

Чтобы работать с графом (в том числе вычислительно), его нужно как-то записать, а не просто нарисовать. Есть два стандартных способа.

**Матрица смежности** — квадратная таблица размером (число вершин) × (число вершин), где на пересечении строки $i$ и столбца $j$ стоит 1, если есть ребро от вершины $i$ к вершине $j$ (и 0, если ребра нет), или сам вес ребра, если граф взвешенный:

```text
        A  B  C  D
    A [ 0  1  1  0 ]
    B [ 1  0  0  1 ]
    C [ 1  0  0  1 ]
    D [ 0  1  1  0 ]
```

Для неориентированного графа эта матрица всегда симметрична относительно диагонали (если $i$ связана с $j$, то и $j$ связана с $i$) — ровно то свойство матричной симметрии, с которым мы могли бы столкнуться и в блоке про линейную алгебру.

**Список смежности** хранит для каждой вершины просто список её соседей:

```python
graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C"],
}
```

Выбор между представлениями — не формальность, а вопрос эффективности: матрица смежности занимает место, пропорциональное квадрату числа вершин, даже если рёбер на самом деле мало (такой граф называют разреженным), тогда как список смежности хранит ровно столько данных, сколько реально рёбер в графе, — поэтому для больших разреженных графов (а большинство графов реального мира, включая социальные сети и карты дорог, именно такие) список смежности почти всегда экономичнее.

## Типичные ошибки

Частая ошибка — не учитывать, ориентирован граф или нет, при построении модели реальной связи: дружба симметрична, подписка — нет, и смешение этих двух случаев в одной модели данных приводит к неверным выводам. Вторая — путать входящую и исходящую степень вершины в ориентированном графе. Третья — выбрать матрицу смежности для огромного разреженного графа «по умолчанию», не задумываясь о том, сколько памяти она на самом деле займёт по сравнению со списком смежности.

## Что нужно запомнить

Граф состоит из вершин и рёбер, которые могут быть ориентированными или нет, взвешенными или нет. Степень вершины считает число связанных с ней рёбер, а для ориентированных графов различают входящую и исходящую степень. Матрица смежности и список смежности — два стандартных способа хранить граф, и выбор между ними — вопрос эффективности, особенно важный для разреженных графов с большим числом вершин.

## Задачи

1. Нарисуйте (опишите словами) граф с вершинами {A, B, C} и рёбрами A-B, B-C. Является ли он связным?
2. Для графа из задачи 1 постройте матрицу смежности.
3. Для того же графа постройте список смежности.
4. В ориентированном графе есть рёбра A→B, B→C, C→A. Найдите входящую и исходящую степень каждой вершины.
5. Является ли граф из задачи 4 связным? Есть ли в нём цикл?
6. Дан взвешенный граф с рёбрами A-B (вес 3), B-C (вес 5), A-C (вес 10). Сравните стоимость пути A-B-C и прямого пути A-C.
7. Объясните, почему матрица смежности неориентированного графа всегда симметрична.
8. Граф имеет 1000 вершин, но только 2000 рёбер. Какое представление — матрица или список смежности — будет эффективнее по памяти? Обоснуйте численно (матрица 1000×1000 против списка из 2000 записей).
