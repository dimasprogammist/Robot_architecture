# Ранг матрицы

В прошлом уроке мы разобрали базис и размерность — минимальный набор независимых направлений, которым можно описать пространство. Теперь применим эту идею не к абстрактному пространству, а к конкретной матрице: сколько в ней на самом деле независимых строк (или столбцов), а сколько — избыточных, выражающихся через другие?

## Что такое ранг

**Ранг** матрицы — это число линейно независимых строк (что эквивалентно числу линейно независимых столбцов — для любой матрицы эти два числа всегда совпадают). Иначе говоря, ранг показывает, сколько строк матрицы реально несут новую, независимую информацию, а сколько — лишь повторяют уже имеющуюся в виде линейной комбинации остальных.

Возьмём матрицу

$$
A = \begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}
$$

Вторая строка — это первая, умноженная на 2, то есть линейно зависима от первой (мы уже встречали именно этот пример в уроке про линейную независимость). Поэтому ранг этой матрицы равен 1, хотя формально в ней две строки.

```python
import numpy as np

A = np.array([[1, 2], [2, 4]])
print(np.linalg.matrix_rank(A))  # 1

B = np.array([[1, 2], [3, 4]])
print(np.linalg.matrix_rank(B))  # 2 — строки независимы
```

## Полный ранг и его связь с определителем

Если ранг квадратной матрицы размера $n \times n$ равен $n$ (максимально возможному значению), матрицу называют матрицей **полного ранга**. Это условие напрямую связано с темой прошлого урока: квадратная матрица имеет полный ранг тогда и только тогда, когда её определитель не равен нулю, а значит, тогда и только тогда, когда у неё существует обратная матрица. Ранг, определитель и обратимость — это, по сути, три разных способа смотреть на один и тот же вопрос: не «схлопывает» ли матрица пространство в меньшую размерность.

```text
   ранг = n (полный)         ранг < n (неполный)
   det ≠ 0                    det = 0
   обратная матрица есть      обратной матрицы нет
```

## Ранг прямоугольной матрицы

В отличие от определителя, который определён только для квадратных матриц, ранг имеет смысл для матрицы любого размера $m \times n$ — и не может превышать меньшее из чисел $m$ и $n$: у матрицы размером $3 \times 5$ ранг не может быть больше 3, просто потому что независимых строк физически не может быть больше, чем самих строк.

```python
C = np.array([[1, 2, 3], [2, 4, 6]])  # 2x3, вторая строка = первая * 2
print(np.linalg.matrix_rank(C))  # 1, хотя формально 2 строки и 3 столбца
```

## Зачем ранг нужен на практике

Ранг — это количественный ответ на вопрос «сколько в этих данных реально независимой информации», с которым мы уже сталкивались качественно в уроке про базис применительно к избыточным признакам в наборе данных. Если матрица, составленная из признаков объектов (строка — объект, столбец — признак), имеет ранг заметно меньше числа столбцов, значит, часть признаков линейно выражается через другие и не добавляет новой информации — это прямой сигнал к тому, что данные можно сжать без потери содержательной информации, на чём и строятся методы вроде PCA, упомянутые ранее в курсе.

Ранг также диагностирует проблемы при решении систем линейных уравнений: если ранг матрицы коэффициентов меньше числа переменных, система либо не имеет решения, либо имеет их бесконечно много — однозначного решения, которое мы искали через обратную матрицу в прошлом уроке, в таком случае не существует.

## Типичные ошибки

Частая ошибка — считать ранг равным числу строк или столбцов матрицы «по умолчанию», не проверяя линейную зависимость между ними. Вторая — путать ранг с размером матрицы: матрица $100\times100$ вполне может иметь ранг 3, если 97 строк из 100 линейно выражаются через оставшиеся три. Третья — забывать, что неполный ранг квадратной матрицы автоматически означает нулевой определитель и отсутствие обратной матрицы — эти три факта о матрице всегда идут вместе, не по отдельности.

## Что нужно запомнить

Ранг матрицы — число линейно независимых строк (или столбцов), то есть мера того, сколько в ней реально независимой информации. Квадратная матрица обратима тогда и только тогда, когда её ранг максимален (полный), что эквивалентно ненулевому определителю. Ранг прямоугольной матрицы ограничен меньшим из чисел строк и столбцов и на практике используется, чтобы находить избыточность в данных и диагностировать системы уравнений без единственного решения.
