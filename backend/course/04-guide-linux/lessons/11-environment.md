# Окружение и конфигурация системы

Модель `export` и PATH уже была в терминале. На Linux конфиг **специально** размазан по слоям.

Ядро: sysctl, cmdline — на всю машину. `/etc` — демоны и политика. Окружение процесса — одна программа. `~/.bashrc` — интерактив **этого** пользователя. Экспорт в bash не виден systemd: службе нужны `Environment=` / `EnvironmentFile=` или конфиг самого приложения.

Демон часто не читает ваш профиль. Путь конфига — в документации пакета. Правка → reload/restart по правилам программы. Свои изменения — в `*.d/` drop-in, не в середину файла пакета: апдейт меньше ругается.

Секреты: не git, не `644`. `600`, отдельный файл, не world-readable Environment в unit без нужды. Часовой пояс, hostname, локаль, DNS влияют на логи и сертификаты: `timedatectl`, `hostnamectl`, resolv при «странном времени».

Cloud-init/ansible закрепляют хост. Даже без них запишите, зачем костыль в `/etc`.

```bash
systemctl show-environment | head
sysctl net.ipv4.ip_forward 2>/dev/null || true
```

«В SSH работает» — login-сессия с профилем. Служба — другой UID, другой cwd, другой envp.
