# HTTP-запрос

## Цель

Разобрать метод, URL, заголовки, тело запроса.

## Что уже нужно знать

Клиент-сервер.

## Объяснение с нуля

HTTP-запрос: стартовая строка (метод + путь + версия), заголовки, опциональное тело. Метод говорит о намерении: GET читать, POST создавать, PUT/PATCH обновлять, DELETE удалять — в рамках вашего API-соглашения.

Тело часто JSON. Заголовки несут Content-Type, Authorization, Cookie.

## Термины

- **Метод**, **путь**, **заголовки**, **тело**.
- **Query string** — параметры после ?.

## Внутреннее устройство

Сервер парсит байты сокета в структуру request.

## Пример

GET /tasks?user_id=5 HTTP/1.1\nHost: api.local\nAuthorization: Bearer ...

## Разбор

Метод GET, путь /tasks, query user_id=5, заголовок авторизации. Тела нет.

## Код

```http
POST /tasks HTTP/1.1
Host: api.local
Content-Type: application/json

{"title":"Молоко"}
```

## Практика

Разберите свой запрос из DevTools на метод/путь/заголовки/тело.

## Типичные ошибки

- Класть секрет в query-логи.
- Игнорировать Content-Type.

## Что запомнить

Запрос = метод + URL + заголовки + тело.
