# Валидация

## Цель

Проверять входные данные схемой до бизнес-логики.

## Что уже нужно знать

Middleware.

## Объяснение с нуля

Валидация проверяет типы, обязательность, диапазоны, форматы. Делается на границе API (Pydantic и аналоги). Бизнес-правила («лимит 100 задач») — в сервисе, но тоже явно.

Невалидно → 400 с полями ошибок.

## Термины

- **Schema validation**.
- **Sanitize vs validate**.

## Внутреннее устройство

JSON → модель → ошибки или объект.

## Пример

title: str min_length=1 max_length=200; done: bool.

## Разбор

title="" → 400 fields.title.

## Код

```python
from pydantic import BaseModel, Field
class TaskCreate(BaseModel):
    title: str = Field(min_length=1, max_length=200)
```

## Типичные ошибки

- Доверять клиенту после UI-проверок.
- Молча обрезать данные.

## Что запомнить

Сначала схема, потом бизнес.

## Задание

Схема TaskUpdate (опциональные поля).
