# Таблица

## Цель

Научиться описывать таблицу: имя, столбцы, типы, смысл строки.

## Что уже нужно знать

Реляционная модель.

## Объяснение с нуля

Таблица — именованный набор столбцов. Каждая строка — экземпляр факта. Тип столбца ограничивает значения: INTEGER, TEXT, BOOLEAN, TIMESTAMP и т.д. Имя таблицы должно отражать сущность в единственном или принятом в команде числе (tasks, users).

Плохая таблица смешивает несколько сущностей в одной строке. Хорошая — один факт, понятные столбцы, явные ключи.

## Термины

- **Столбец** — атрибут с типом.
- **NULL** — отсутствие значения (не путать с 0 или '').
- **DEFAULT** — значение по умолчанию.

## Внутреннее устройство

CREATE TABLE задаёт схему. ALTER меняет. Данные живут отдельно от кода приложения, но код зависит от схемы.

## Пример

```sql
CREATE TABLE tasks (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  done BOOLEAN NOT NULL DEFAULT FALSE,
  created_at TIMESTAMP NOT NULL
);
```

## Разбор

Строка обязана иметь title и created_at. done по умолчанию false. id — идентификатор.

## Код

```sql
INSERT INTO tasks (id, title, done, created_at)
VALUES (1, 'Купить молоко', FALSE, '2026-09-25T10:00:00');
```

## Практика

Добавьте столбец priority и объясните, зачем DEFAULT.

## Типичные ошибки

- NULL везде «на всякий случай».
- title без NOT NULL.
- Хранить несколько фактов в одном TEXT через разделители.

## Что запомнить

Таблица = имя + столбцы + типы + смысл строки.
