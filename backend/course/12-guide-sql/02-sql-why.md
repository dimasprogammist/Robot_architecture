# Зачем SQL

## Цель

Понять SQL как декларативный язык над таблицами.

## Что уже нужно знать

Роль СУБД.

## Объяснение с нуля

SQL задаёт операции над реляционными данными: выбрать, вставить, обновить, удалить, соединить. Вы описываете результат. Оптимизатор выбирает способ: индекс или полное сканирование.

Декларативность не отменяет стоимость: корректный запрос может сканировать миллионы строк. Параметры (плейсхолдеры) обязательны вместо склейки строк.

## Термины

- **DML / DQL / DDL** — данные, выборка, схема.
- **Диалект** — расширения конкретной СУБД.
- **Плейсхолдер** — безопасная подстановка значений.

## Внутреннее устройство

SQL-текст → парсер → дерево → оптимизатор → исполнитель → строки клиенту.

## Пример

Нужны id и title незавершённых задач пользователя 5.

## Разбор

```sql
SELECT id, title FROM tasks
WHERE user_id = 5 AND done = FALSE
ORDER BY id DESC;
```
Вернутся только строки пользователя 5 с done=false, новые id сверху.

## Код

```python
cur.execute(
    "SELECT id, title FROM tasks WHERE user_id = ? AND done = 0 ORDER BY id DESC",
    (5,),
)
print(cur.fetchall())
```

## Практика

Придумайте 6 строк и отметьте попавшие в запрос.

## Типичные ошибки

- SQL через f-строку с вводом пользователя.
- SELECT * без нужды в API.
- Учить команды без примера таблицы.

## Что запомнить

SQL описывает «что получить»; план — «как».
