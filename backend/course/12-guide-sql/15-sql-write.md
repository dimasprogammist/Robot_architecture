# INSERT UPDATE DELETE

## Цель

Изменять данные осознанно: что пишем, сколько строк затронем.

## Что уже нужно знать

SELECT.

## Объяснение с нуля

INSERT добавляет строки. UPDATE меняет существующие. DELETE удаляет. Критичен WHERE: UPDATE без WHERE обновляет всю таблицу.

RETURNING (в PostgreSQL) возвращает изменённые строки — удобно API.

## Термины

- **rowcount** — число затронутых строк.
- **UPSERT** — вставить или обновить.

## Внутреннее устройство

Изменения пишутся в рамках транзакции. Пока нет COMMIT — другие могут не видеть (зависит от изоляции).

## Пример

UPDATE done=true WHERE id=3 — одна строка. DELETE WHERE done=true — все завершённые.

## Разбор

Сверьте rowcount с ожиданием.

## Код

```python
cur.execute("UPDATE tasks SET done = 1 WHERE id = ?", (3,))
print(cur.rowcount)  # 1
conn.commit()
cur.execute("DELETE FROM tasks WHERE done = 1")
print(cur.rowcount)
conn.commit()
```

## Практика

Напишите безопасный UPDATE title только если задача не done.

## Типичные ошибки

- UPDATE/DELETE без WHERE.
- Игнорировать rowcount=0.

## Что запомнить

Любая запись — проверьте условие и число строк.

## Задание
