# Строки и столбцы

## Цель

Различать строку как факт и столбец как атрибут; проекция и фильтрация.

## Что уже нужно знать

Таблица и типы.

## Объяснение с нуля

Строка содержит значения всех столбцов (или NULL). Столбец — вертикальный срез одного атрибута по всем строкам. SELECT выбирает столбцы (проекция) и строки (селективность WHERE).

Путать «удалить столбец» и «удалить строки» опасно: одно меняет схему, другое — данные.

## Термины

- **Проекция** — выбор столбцов.
- **Селекция** — выбор строк.
- **Кардинальность** — число строк.

## Внутреннее устройство

Физически строки упакованы в страницы. Логически для SQL важны значения и условия.

## Пример

| id | title | done |
| 1 | A | 0 |
| 2 | B | 1 |
| 3 | C | 0 |

## Разбор

SELECT title FROM tasks WHERE done = 0 вернёт A и C — два значения одного столбца из двух строк.

## Код

```sql
SELECT title FROM tasks WHERE done = 0;
-- A
-- C
```

## Практика

Что вернёт SELECT done FROM tasks без WHERE? Сколько строк?

## Типичные ошибки

- Думать, что SELECT title удаляет другие столбцы из таблицы.
- Путать отсутствие строк с ошибкой запроса.

## Что запомнить

Строка = факт; столбец = атрибут; SELECT режет оба измерения.

## Задание

Напишите проекцию id, title для done=1 и проверьте на таблице выше.
