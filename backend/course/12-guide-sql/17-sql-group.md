# GROUP BY и агрегаты

## Цель

Считать агрегаты: COUNT/SUM/AVG с группировкой.

## Что уже нужно знать

JOIN.

## Объяснение с нуля

Агрегат схлопывает множество строк в одно значение. GROUP BY делит на корзины. HAVING фильтрует уже группы (после агрегации), WHERE — исходные строки.

Частая задача: число задач на пользователя.

## Термины

- **COUNT, SUM, AVG, MIN, MAX**.
- **HAVING**.

## Внутреннее устройство

Сначала WHERE, потом группировка, потом HAVING, потом SELECT список.

## Пример

tasks user_id: 1,1,2,1,2,3 → COUNT по user: 1→3, 2→2, 3→1.

## Разбор

HAVING COUNT(*) >= 2 оставит пользователей 1 и 2.

## Код

```sql
SELECT user_id, COUNT(*) AS cnt
FROM tasks
GROUP BY user_id
HAVING COUNT(*) >= 2;
```

## Практика

Посчитайте среднее priority по done.

## Типичные ошибки

- Писать в SELECT столбец не из GROUP BY и не агрегат.
- Путать WHERE и HAVING.

## Что запомнить

GROUP BY = корзины; агрегаты = метрики корзин.
