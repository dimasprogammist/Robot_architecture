# Зачем SQL

СУБД уже умеет хранить строки. Чтобы не изобретать для каждой программы свой язык «дай незакрытые задачи пользователя 5», договорились о **SQL**. Вы описываете **какой** результат нужен. Движок сам выбирает **как**: пройтись по всей таблице или прыгнуть по индексу.

Это называют декларативностью. Она не бесплатна: тот же корректный `SELECT` на миллионе строк без индекса будет долгим. Текст запроса при этом может не измениться — изменится **план**. Поэтому «SQL сработал на десяти строках» не доказывает, что он готов к продакшену.

Нужны id и заголовки незакрытых задач пользователя 5, новые сверху:

```sql
SELECT id, title
FROM tasks
WHERE user_id = 5 AND done = FALSE
ORDER BY id DESC;
```

Возьмите шесть строк на бумаге и вычеркните тех, кто не пользователь 5 или уже `done`. Оставшиеся отсортируйте по `id`. SQL говорит это целиком, без цикла `for` в Python.

Тот же смысл из приложения, значения не склеивают в строку:

```python
cur.execute(
    "SELECT id, title FROM tasks WHERE user_id = ? AND done = 0 ORDER BY id DESC",
    (5,),
)
print(cur.fetchall())
```

Плейсхолдер `?` подставляет значение безопасно. Если склеить f-строкой и в поле попадёт кавычка или кусок чужого SQL, запрос станет другим — это уже не «удобная подстановка», а дыра.

Грубо внутри: текст → разбор → дерево → оптимизатор → исполнитель → строки клиенту. Диалекты (SQLite, PostgreSQL) расходятся в деталях функций и типов; ядро SELECT/INSERT общее. DDL меняет схему (`CREATE TABLE`), DML — данные, выборка — чтение. На первых уроках вам нужен SELECT и понимание, что схема — отдельный разговор.

`SELECT *` в горячем API тащит столбцы, которые экрану не нужны, и мешает индексам. Учите запрос на конкретной таблице, не как заклинание без столбцов.

## Практика

### Задание 1. Шесть строк

Нарисуйте 6 строк `tasks`. Какие попадут в запрос `user_id = 5 AND done = FALSE`? Выпишите id по убыванию.

### Задание 2. OR

На том же наборе: `user_id = 5 OR done = FALSE`. Почему строк может стать больше, чем с `AND`? Приведите одну строку, которая проходит только OR.

### Задание 3. Плейсхолдер

Пользователь ввёл в поле заголовок с кавычкой. Что будет с запросом через f-строку? Что сделает `?`?

### Задание 4. Текст и план

Один и тот же SELECT. Сначала таблицы без индекса, потом индекс по `user_id`. Что обязано совпасть в результате? Что может измениться во времени работы?
