# Указатели и массивы

## Цель

Массивы и указатели тесно связаны в C++. Чтобы уверенно понимать работу с памятью, недостаточно знать их по отдельности. Нужно понимать, почему имя массива во многих выражениях связано с адресом первого элемента и как с помощью указателей можно перемещаться между элементами.

Эта тема особенно важна для понимания старого C-style API, работы с буферами, низкоуровневым кодом и внутреннего устройства массивов.

После урока вы должны понимать:

* как массив располагается в памяти;
* почему имя массива связано с адресом первого элемента;
* как обращаться к элементам через указатель;
* что такое арифметика указателей;
* как работают `pointer + 1` и `pointer - 1`;
* как массивы передаются в функции;
* почему нужно следить за границами массива.

---

## Массив в памяти

Рассмотрим массив:

```cpp
int values[4] = {10, 20, 30, 40};
```

В памяти элементы располагаются последовательно.

Упрощённо можно представить:

```text
values
  ↓
┌────┬────┬────┬────┐
│ 10 │ 20 │ 30 │ 40 │
└────┴────┴────┴────┘
  0    1    2    3
```

Каждый элемент занимает определённое количество байт.

Если `int` занимает 4 байта, адреса элементов будут отличаться на 4 байта:

```text
values[0] → +0
values[1] → +4
values[2] → +8
values[3] → +12
```

Конкретный размер `int` зависит от платформы, поэтому в программе лучше использовать `sizeof(int)`, а не предполагать конкретное значение.

---

## Адрес первого элемента

Для массива:

```cpp
int values[4] = {10, 20, 30, 40};
```

можно получить адрес первого элемента:

```cpp
int* pointer = &values[0];
```

Теперь:

```cpp
*pointer
```

даст:

```text
10
```

Можно также написать:

```cpp
int* pointer = values;
```

В большинстве выражений имя массива `values` преобразуется в указатель на его первый элемент.

Поэтому:

```cpp
values
```

в таком контексте соответствует адресу:

```cpp
&values[0]
```

---

## Доступ к элементам через указатель

Если:

```cpp
int* pointer = values;
```

то:

```cpp
*pointer
```

это первый элемент:

```cpp
values[0]
```

А:

```cpp
*(pointer + 1)
```

это второй элемент:

```cpp
values[1]
```

Дальше:

```cpp
*(pointer + 2)
```

соответствует:

```cpp
values[2]
```

и так далее.

---

## Арифметика указателей

Указатель можно увеличивать:

```cpp
pointer++;
```

Если `pointer` указывает на `values[0]`, после:

```cpp
pointer++;
```

он будет указывать на `values[1]`.

Важно понимать, что увеличение указателя зависит от типа.

Если:

```cpp
int* pointer;
```

то:

```cpp
pointer + 1
```

перемещает указатель на следующий `int`, а не просто на один байт.

Если `int` занимает 4 байта, физически адрес увеличится на 4 байта.

---

## Почему pointer + 1 зависит от типа

Рассмотрим:

```cpp
double* pointer;
```

Если `double` занимает 8 байт, то:

```cpp
pointer + 1
```

переместится на следующий `double`, то есть примерно на 8 байт.

Для:

```cpp
char* pointer;
```

переход к следующему элементу обычно означает перемещение на один байт.

Таким образом, тип указателя сообщает компилятору размер элемента, между которыми нужно перемещаться.

---

## Индексация через указатель

Запись:

```cpp
pointer[index]
```

связана с арифметикой указателей.

Фактически:

```cpp
pointer[index]
```

эквивалентно:

```cpp
*(pointer + index)
```

Например:

```cpp
int values[3] = {10, 20, 30};

int* pointer = values;

std::cout << pointer[0] << '\n';
std::cout << pointer[1] << '\n';
std::cout << pointer[2] << '\n';
```

получим:

```text
10
20
30
```

---

## Связь массива и указателя

Важно не говорить, что массив и указатель — одно и то же.

Они разные.

```cpp
int values[4];
int* pointer = values;
```

`values` — массив из четырёх `int`.

`pointer` — отдельная переменная, содержащая адрес элемента.

Однако в большинстве выражений имя массива автоматически преобразуется в указатель на первый элемент.

Это различие становится особенно важным при использовании `sizeof`.

---

## sizeof массива

Рассмотрим:

```cpp
int values[4];
```

Выражение:

```cpp
sizeof(values)
```

возвращает размер всего массива в байтах.

Если `sizeof(int) == 4`, результат будет:

```text
16
```

А:

```cpp
sizeof(values[0])
```

даст размер одного элемента:

```text
4
```

Количество элементов можно получить:

```cpp
sizeof(values) / sizeof(values[0])
```

Например:

```cpp
int count = sizeof(values) / sizeof(values[0]);
```

---

## Почему это не работает с обычным указателем

Рассмотрим:

```cpp
int values[4];

int* pointer = values;
```

Здесь:

```cpp
sizeof(values)
```

знает размер всего массива.

Но:

```cpp
sizeof(pointer)
```

возвращает размер самого указателя.

Указатель не знает, сколько элементов находится за адресом, который он содержит.

Это одна из причин, почему при передаче обычного массива в функцию информация о количестве элементов обычно передаётся отдельно.

---

## Массив в функции

Можно написать:

```cpp
void printArray(int values[], int size)
{
    for (int i = 0; i < size; i++)
    {
        std::cout << values[i] << '\n';
    }
}
```

В параметрах функции запись:

```cpp
int values[]
```

фактически используется как указатель:

```cpp
int* values
```

Поэтому функция не знает размер массива автоматически.

Нужно передать:

```cpp
printArray(values, 4);
```

---

## Передача массива и изменение элементов

Поскольку функция получает доступ к исходному массиву, она может менять его элементы:

```cpp
void setFirstElement(int values[])
{
    values[0] = 100;
}
```

Использование:

```cpp
int values[3] = {10, 20, 30};

setFirstElement(values);

std::cout << values[0];
```

получим:

```text
100
```

Изменяется исходный массив.

---

## Указатель и const

Если функция должна только читать массив, можно использовать указатель на `const`:

```cpp
void printArray(const int* values, int size)
{
    for (int i = 0; i < size; i++)
    {
        std::cout << values[i] << '\n';
    }
}
```

Теперь внутри функции нельзя изменить элемент:

```cpp
values[0] = 100;
```

Это ошибка.

Такая запись хорошо выражает намерение:

> функция получает доступ к данным, но не должна их изменять.

---

## Выход за границы

Одна из самых опасных особенностей обычных C-style массивов — отсутствие автоматической проверки границ при использовании `[]`.

Например:

```cpp
int values[3] = {10, 20, 30};

std::cout << values[5];
```

Индекс `5` находится за пределами массива.

Программа может:

* вывести мусор;
* случайно прочитать данные другой области памяти;
* завершиться с ошибкой;
* продолжить работу с неопределённым поведением.

Компилятор не обязан автоматически остановить такую ошибку.

---

## Почему границы так важны

Рассмотрим цикл:

```cpp
int values[5];

for (int i = 0; i <= 5; i++)
{
    values[i] = i;
}
```

Правильные индексы:

```text
0
1
2
3
4
```

Но условие:

```cpp
i <= 5
```

позволяет выполнить итерацию с:

```text
i = 5
```

и программа обращается к:

```cpp
values[5]
```

Это ошибка.

Правильный вариант:

```cpp
for (int i = 0; i < 5; i++)
{
    values[i] = i;
}
```

---

## Указатель на конец массива

Можно получить указатель сразу за последним элементом:

```cpp
int values[4] = {10, 20, 30, 40};

int* begin = values;
int* end = values + 4;
```

Здесь:

```text
begin → values[0]
end   → позиция после values[3]
```

Сам адрес `end` нельзя разыменовывать:

```cpp
*end
```

это ошибка.

Но такой указатель удобно использовать как границу диапазона.

---

## Обход массива через указатели

Можно написать:

```cpp
int values[4] = {10, 20, 30, 40};

int* begin = values;
int* end = values + 4;

for (int* current = begin; current != end; ++current)
{
    std::cout << *current << '\n';
}
```

Здесь `current` перемещается от первого элемента до позиции после последнего.

Такой стиль часто встречается в низкоуровневом C++ и в реализации некоторых механизмов стандартной библиотеки.

---

## Современный C++

В обычном прикладном коде не всегда нужно использовать сырые указатели для работы с массивами.

Часто лучше использовать:

```cpp
std::array
```

или:

```cpp
std::vector
```

Они предоставляют дополнительные возможности и делают код безопаснее и удобнее.

Но понимание связи:

```text
массив → адрес первого элемента → указатель → арифметика указателей
```

необходимо для понимания низкоуровневого C++.

---

## Практический пример

Рассмотрим обработку массива значений датчиков:

```cpp
#include <iostream>

void increaseAll(double* values, int size, double amount)
{
    for (int i = 0; i < size; i++)
    {
        values[i] += amount;
    }
}

void printValues(const double* values, int size)
{
    for (int i = 0; i < size; i++)
    {
        std::cout << values[i] << '\n';
    }
}

int main()
{
    double sensors[4] = {
        10.5,
        20.2,
        15.7,
        18.1
    };

    increaseAll(sensors, 4, 1.0);

    printValues(sensors, 4);

    return 0;
}
```

Функция `increaseAll()` получает адрес первого элемента и количество элементов. Благодаря этому она может обработать весь массив.

---

## Главное

Массив хранит элементы последовательно в памяти, а имя массива в большинстве выражений преобразуется в указатель на первый элемент.

Основные связи:

```cpp
values
```

обычно означает адрес первого элемента;

```cpp
values[i]
```

эквивалентно:

```cpp
*(values + i)
```

А:

```cpp
pointer + 1
```

перемещает указатель на следующий элемент соответствующего типа.

При работе с массивами особенно важно контролировать границы, потому что выход за пределы обычного массива может привести к неопределённому поведению.
