# std::vector

## Цель

`std::vector` — один из самых важных контейнеров современного C++. Его используют настолько часто, что уверенная работа с `vector` является практически обязательным навыком для C++ разработчика.

После урока вы должны понимать:

* что такое `std::vector`;
* как создавать вектор;
* как добавлять и удалять элементы;
* как получать доступ к элементам;
* чем отличаются `size()` и `capacity()`;
* как передавать `vector` в функции;
* что происходит с памятью при увеличении вектора.

---

## Что такое vector

`std::vector` — контейнер стандартной библиотеки C++, который хранит последовательность элементов.

Упрощённо его можно представить как динамический массив:

```text
[10][20][30][40]
```

Но в отличие от обычного массива:

```cpp
int numbers[4];
```

размер `std::vector` может изменяться во время работы программы.

Например:

```cpp
std::vector<int> numbers;

numbers.push_back(10);
numbers.push_back(20);
numbers.push_back(30);
```

Теперь вектор содержит три элемента.

---

## Подключение

Для использования `std::vector` нужно подключить:

```cpp
#include <vector>
```

Простейшая программа:

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> numbers = {10, 20, 30};

    for (int number : numbers)
    {
        std::cout << number << '\n';
    }

    return 0;
}
```

---

## Создание пустого vector

Можно создать пустой контейнер:

```cpp
std::vector<int> numbers;
```

На этом этапе элементов нет.

Проверить количество:

```cpp
std::cout << numbers.size();
```

Результат:

```text
0
```

---

## Инициализация значениями

Можно сразу указать элементы:

```cpp
std::vector<int> numbers = {
    10,
    20,
    30,
    40
};
```

Или использовать краткую запись:

```cpp
std::vector<int> numbers{10, 20, 30, 40};
```

Оба варианта создают один и тот же тип объекта.

---

## Тип элементов

В скобках указывается тип элементов:

```cpp
std::vector<int>
```

означает:

```text
vector целых чисел
```

Можно использовать:

```cpp
std::vector<double>
```

```cpp
std::vector<std::string>
```

```cpp
std::vector<bool>
```

или собственный класс:

```cpp
std::vector<Motor>
```

---

## Добавление элементов

Основной метод добавления:

```cpp
push_back()
```

Например:

```cpp
std::vector<int> numbers;

numbers.push_back(10);
numbers.push_back(20);
numbers.push_back(30);
```

Получается:

```text
[10][20][30]
```

Каждый вызов добавляет новый элемент в конец.

---

## Добавление объекта

`push_back()` работает не только с числами.

Например:

```cpp
std::vector<std::string> names;

names.push_back("Motor");
names.push_back("Camera");
names.push_back("Battery");
```

Получится:

```text
["Motor"]["Camera"]["Battery"]
```

---

## emplace_back

Для объектов существует ещё:

```cpp
emplace_back()
```

Например:

```cpp
std::vector<std::string> names;

names.emplace_back("Motor");
```

При простых типах разница обычно несущественна. При работе со сложными объектами `emplace_back()` может позволить создать объект непосредственно внутри контейнера.

На практике оба метода будут встречаться очень часто.

---

## Доступ по индексу

Как и у обычного массива, элементы `vector` имеют индексы.

```cpp
std::vector<int> numbers = {
    10, 20, 30
};
```

Доступ:

```cpp
numbers[0]
numbers[1]
numbers[2]
```

Например:

```cpp
std::cout << numbers[1];
```

выведет:

```text
20
```

Индексация начинается с нуля.

---

## Изменение элементов

Элемент можно изменить через индекс:

```cpp
numbers[1] = 500;
```

Если было:

```text
10 20 30
```

станет:

```text
10 500 30
```

---

## at()

Есть альтернативный способ доступа:

```cpp
numbers.at(1)
```

Например:

```cpp
std::cout << numbers.at(1);
```

Основное отличие в том, что `at()` проверяет границы.

Если индекс недопустим:

```cpp
numbers.at(100);
```

будет выброшено исключение `std::out_of_range`.

А обращение:

```cpp
numbers[100];
```

не выполняет такую проверку и при неправильном индексе приводит к неопределённому поведению.

---

## Размер vector

Количество элементов можно получить через:

```cpp
numbers.size()
```

Например:

```cpp
std::vector<int> numbers = {
    10, 20, 30
};

std::cout << numbers.size();
```

Результат:

```text
3
```

Тип возвращаемого значения — `std::size_t`.

Поэтому в циклах часто пишут:

```cpp
for (std::size_t i = 0; i < numbers.size(); ++i)
{
    std::cout << numbers[i] << '\n';
}
```

---

## Проверка на пустоту

Можно проверить:

```cpp
numbers.empty()
```

Например:

```cpp
if (numbers.empty())
{
    std::cout << "Vector is empty\n";
}
```

Метод возвращает `true`, если элементов нет.

Часто это удобнее, чем:

```cpp
if (numbers.size() == 0)
```

---

## Первый и последний элемент

Есть специальные методы:

```cpp
numbers.front()
numbers.back()
```

Например:

```cpp
std::cout << numbers.front();
std::cout << numbers.back();
```

Для:

```text
10 20 30 40
```

результат будет:

```text
10
40
```

Но обращаться к `front()` или `back()` у пустого вектора нельзя.

---

## Удаление последнего элемента

Для удаления последнего элемента используется:

```cpp
pop_back()
```

Например:

```cpp
std::vector<int> numbers = {
    10, 20, 30
};

numbers.pop_back();
```

Теперь:

```text
10 20
```

Метод удаляет именно последний элемент.

---

## Очистка vector

Чтобы удалить все элементы:

```cpp
numbers.clear();
```

После этого:

```cpp
numbers.empty()
```

вернёт:

```text
true
```

Важно понимать, что `clear()` удаляет элементы, но не обязательно возвращает выделенную память операционной системе.

Это связано с понятием `capacity`.

---

## size и capacity

У `vector` есть два разных свойства:

```cpp
size()
capacity()
```

`size()` показывает количество существующих элементов.

`capacity()` показывает, сколько элементов вектор способен вместить в текущем выделенном блоке памяти без нового выделения.

Например:

```text
size = 3
capacity = 8
```

Это означает:

```text
есть 3 элемента

[10][20][30][ ][ ][ ][ ][ ]
<--------- capacity -------->
```

---

## Почему capacity больше size

Когда вектор увеличивается, он не обязательно выделяет память для каждого нового элемента отдельно.

Если бы происходило:

```text
push
выделить память

push
выделить память

push
выделить память
```

это было бы дорого.

Вместо этого `vector` обычно выделяет память с запасом.

Например:

```text
capacity = 8
```

и может спокойно добавить несколько элементов без нового выделения памяти.

Конкретная стратегия роста зависит от реализации стандартной библиотеки.

---

## reserve()

Можно заранее зарезервировать память:

```cpp
std::vector<int> numbers;

numbers.reserve(1000);
```

Теперь вектор имеет возможность разместить до 1000 элементов без необходимости увеличивать выделенный блок при каждом добавлении.

При этом:

```cpp
numbers.size()
```

по-прежнему равно:

```text
0
```

`reserve()` не добавляет элементы. Он резервирует память.

---

## resize()

`resize()` работает иначе:

```cpp
numbers.resize(10);
```

После этого размер вектора становится равен 10.

Если элементов было меньше, новые элементы будут созданы.

Например:

```cpp
std::vector<int> numbers;

numbers.resize(5);
```

получится:

```text
[0][0][0][0][0]
```

Для `int` новые элементы инициализируются нулём.

---

## reserve и resize — не одно и то же

Это важно запомнить:

```cpp
reserve(100);
```

означает:

> Подготовь память примерно под 100 элементов.

А:

```cpp
resize(100);
```

означает:

> Сделай так, чтобы в контейнере было 100 элементов.

То есть:

```text
reserve → capacity
resize  → size
```

---

## Перебор через range-based for

Самый удобный способ перебрать элементы:

```cpp
for (int number : numbers)
{
    std::cout << number << '\n';
}
```

Если менять элементы не нужно, лучше использовать `const`:

```cpp
for (const int number : numbers)
{
    std::cout << number << '\n';
}
```

Для объектов обычно используют ссылку:

```cpp
for (const Motor& motor : motors)
{
    motor.print();
}
```

Так объект не копируется.

---

## Удаление элемента по итератору

Можно удалить конкретный элемент:

```cpp
numbers.erase(numbers.begin() + 2);
```

Например:

```text
10 20 30 40
```

После:

```cpp
numbers.erase(numbers.begin() + 2);
```

получится:

```text
10 20 40
```

Потому что индекс `2` соответствовал числу `30`.

---

## Удаление диапазона

Можно удалить сразу несколько элементов:

```cpp
numbers.erase(
    numbers.begin() + 1,
    numbers.begin() + 3
);
```

Здесь удаляется диапазон:

```text
[1, 3)
```

То есть элементы с индексами `1` и `2`.

---

## Сортировка vector

`vector` отлично работает с алгоритмами STL:

```cpp
#include <algorithm>

std::sort(
    numbers.begin(),
    numbers.end()
);
```

Для сортировки по убыванию:

```cpp
std::sort(
    numbers.begin(),
    numbers.end(),
    std::greater<int>()
);
```

Для этого понадобится:

```cpp
#include <functional>
```

---

## Поиск элемента

Можно использовать:

```cpp
auto it = std::find(
    numbers.begin(),
    numbers.end(),
    30
);
```

Проверка:

```cpp
if (it != numbers.end())
{
    std::cout << "Found\n";
}
```

Итератор можно разыменовать:

```cpp
std::cout << *it;
```

если элемент действительно найден.

---

## Передача vector в функцию

Можно передавать вектор по значению:

```cpp
void print(std::vector<int> numbers)
{
}
```

Но в этом случае будет создана копия.

Для чтения обычно лучше:

```cpp
void print(const std::vector<int>& numbers)
{
    for (int number : numbers)
    {
        std::cout << number << '\n';
    }
}
```

Здесь:

```cpp
const std::vector<int>&
```

означает, что функция получает ссылку на существующий объект и не должна его изменять.

---

## Изменение vector через функцию

Если функция должна менять исходный вектор:

```cpp
void addNumber(
    std::vector<int>& numbers,
    int value
)
{
    numbers.push_back(value);
}
```

Использование:

```cpp
std::vector<int> numbers;

addNumber(numbers, 100);
```

Теперь исходный вектор содержит `100`.

---

## Vector и память

Внутри `vector` элементы обычно находятся в непрерывном участке памяти.

Это позволяет эффективно обращаться к элементу по индексу:

```cpp
numbers[100];
```

Доступ к элементу по индексу выполняется за постоянное время.

Именно поэтому `vector` во многих задачах является хорошим вариантом по умолчанию для последовательности данных.

---

## Перераспределение памяти

Если текущей `capacity` недостаточно, `vector` должен выделить новый участок памяти.

Упрощённо происходит следующее:

```text
Старая память:

[10][20][30][40]

        ↓

Новый участок памяти:

[10][20][30][40][50][ ][ ][ ]
```

Существующие элементы перемещаются или копируются в новый участок, после чего старая память освобождается.

Это называется **reallocation**.

Поэтому увеличение `vector` иногда может быть дорогой операцией.

---

## Почему reserve может быть полезен

Если заранее известно приблизительное количество элементов:

```cpp
std::vector<Sensor> sensors;

sensors.reserve(1000);
```

то можно уменьшить количество перераспределений памяти при добавлении большого количества объектов.

Это не значит, что `reserve()` всегда нужно вызывать. Если размер заранее неизвестен или данных немного, обычный `vector` прекрасно справляется сам.

---

## Практический пример

Представим набор измерений датчика:

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<double> temperatures;

    temperatures.reserve(5);

    temperatures.push_back(21.5);
    temperatures.push_back(22.1);
    temperatures.push_back(22.8);
    temperatures.push_back(23.0);
    temperatures.push_back(22.7);

    for (double temperature : temperatures)
    {
        std::cout << temperature << '\n';
    }

    std::cout << "Count: "
              << temperatures.size()
              << '\n';

    return 0;
}
```

Такой подход очень типичен для программ, которые собирают последовательность измерений.

## Vector в робототехнике

Можно хранить список датчиков:

```cpp
struct Sensor
{
    std::string name;
    double value;
};
```

Создадим:

```cpp
std::vector<Sensor> sensors;
```

Добавим:

```cpp
sensors.push_back({
    "Temperature",
    24.5
});

sensors.push_back({
    "Pressure",
    101.3
});
```

И выведем:

```cpp
for (const Sensor& sensor : sensors)
{
    std::cout << sensor.name
              << ": "
              << sensor.value
              << '\n';
}
```

В реальных системах подобные структуры встречаются постоянно.

---

## Главное

`std::vector` — динамическая последовательность элементов.

Нужно хорошо знать:

```text
push_back()
emplace_back()
size()
empty()
front()
back()
pop_back()
clear()
resize()
reserve()
erase()
```

Также важно понимать:

```text
size     → сколько элементов существует
capacity → сколько элементов помещается в текущую память
```

В большинстве задач, где нужна изменяемая последовательность элементов, `std::vector` является первым контейнером, который стоит рассмотреть.
