# Арифметические и логические операции

## Цель

Программа постоянно выполняет операции над данными.

Например:

```text
сложить два числа
сравнить значения
проверить условие
изменить переменную
рассчитать расстояние
определить состояние устройства
```

Для этого C++ предоставляет операторы.

В этом уроке разберём:

* арифметические операторы;
* операторы сравнения;
* логические операторы;
* присваивание;
* сокращённые операции;
* увеличение и уменьшение значения;
* приоритет операторов.

---

# Что такое оператор

Оператор — специальный символ или комбинация символов, задающая определённую операцию.

Например:

```cpp
+
```

означает сложение.

```cpp
-
```

означает вычитание.

```cpp
==
```

сравнивает два значения.

```cpp
&&
```

обозначает логическое И.

---

# Арифметические операторы

Основные арифметические операторы:

| Оператор | Значение |
|---|---|
| `+` | сложение |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `%` | остаток от деления |

Пример:

```cpp
int a = 10;
int b = 3;

std::cout << a + b << '\n';
std::cout << a - b << '\n';
std::cout << a * b << '\n';
std::cout << a / b << '\n';
std::cout << a % b << '\n';
```

---

# Сложение

```cpp
int a = 10;
int b = 20;

int result = a + b;
```

Получим:

```text
30
```

Сложение работает не только с числами.

Например, для строк существуют специальные правила объединения строк.

Но сейчас сосредоточимся на числах.

---

# Вычитание

```cpp
int a = 20;
int b = 7;

int result = a - b;
```

Результат:

```text
13
```

Можно получить и отрицательное значение:

```cpp
int result = 7 - 20;
```

Результат:

```text
-13
```

---

# Умножение

Используется:

```cpp
*
```

Например:

```cpp
int width = 10;
int height = 5;

int area = width * height;
```

Результат:

```text
50
```

---

# Деление

Используется:

```cpp
/
```

Например:

```cpp
double a = 10.0;
double b = 4.0;

double result = a / b;
```

Получим:

```text
2.5
```

Для `int` действует целочисленное деление:

```cpp
int result = 10 / 4;
```

Результат:

```text
2
```

---

# Остаток от деления

Оператор:

```cpp
%
```

возвращает остаток.

```cpp
int result = 10 % 4;
```

Получим:

```text
2
```

Потому что:

```text
10 = 4 * 2 + 2
```

---

# Сравнение

Программе часто нужно понять, равны ли два значения.

Для этого используются операторы сравнения.

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

Результатом сравнения является логическое значение:

```text
true
```

или:

```text
false
```

---

# Равно: ==

Например:

```cpp
int a = 10;
int b = 10;

bool result = (a == b);
```

Результат:

```text
true
```

Если:

```cpp
int b = 20;
```

то:

```cpp
a == b
```

будет:

```text
false
```

---

# Не равно: !=

Оператор:

```cpp
!=
```

означает "не равно".

Например:

```cpp
int a = 10;
int b = 20;

bool result = (a != b);
```

Результат:

```text
true
```

потому что значения отличаются.

---

# Больше и меньше

Например:

```cpp
int speed = 100;

bool result = speed > 80;
```

Получим:

```text
true
```

Потому что:

```text
100 > 80
```

Другой пример:

```cpp
bool result = speed < 80;
```

Получим:

```text
false
```

---

# Больше или равно

Оператор:

```cpp
>=
```

означает:

```text
больше ИЛИ равно
```

Например:

```cpp
int temperature = 80;

bool result = temperature >= 80;
```

Результат:

```text
true
```

---

# Меньше или равно

Оператор:

```cpp
<=
```

означает:

```text
меньше ИЛИ равно
```

Например:

```cpp
int battery = 20;

bool result = battery <= 20;
```

Результат:

```text
true
```

---

# Логические операторы

Часто нужно проверить несколько условий одновременно.

Для этого используются:

```text
&&
||
!
```

---

# Логическое И: &&

Оператор:

```cpp
&&
```

означает:

> оба условия должны быть истинными.

Например:

```cpp
int temperature = 50;
int battery = 80;

bool ok = temperature < 80 && battery > 20;
```

Проверяем:

```text
temperature < 80
```

это `true`.

И:

```text
battery > 20
```

это `true`.

Значит:

```text
true && true
```

даёт:

```text
true
```

---

# Логическое ИЛИ: ||

Оператор:

```cpp
||
```

означает:

> достаточно, чтобы хотя бы одно условие было истинным.

Например:

```cpp
bool warning = temperature > 80 || battery < 20;
```

Предположим:

```text
temperature = 90
battery = 80
```

Первое условие:

```text
temperature > 80
```

истинно.

Второе:

```text
battery < 20
```

ложно.

Но:

```text
true || false
```

даёт:

```text
true
```

---

# Логическое НЕ: !

Оператор:

```cpp
!
```

инвертирует логическое значение.

Если:

```text
true
```

то:

```text
!true
```

даёт:

```text
false
```

И наоборот:

```text
!false
```

даёт:

```text
true
```

Например:

```cpp
bool connected = true;

bool disconnected = !connected;
```

Получим:

```text
disconnected = false
```

---

# Таблица логики

Для `&&`:

```text
true  && true  → true
true  && false → false
false && true  → false
false && false → false
```

Для `||`:

```text
true  || true  → true
true  || false → true
false || true  → true
false || false → false
```

Для `!`:

```text
!true  → false
!false → true
```

---

# Оператор присваивания

Оператор:

```cpp
=
```

означает присваивание.

Например:

```cpp
int value = 10;
```

Здесь значение `10` записывается в `value`.

Позже:

```cpp
value = 20;
```

Теперь:

```text
value = 20
```

Важно не путать:

```cpp
=
```

и:

```cpp
==
```

`=` — присваивание.

`==` — сравнение.

---

# Очень распространённая ошибка

Неправильно воспринимать:

```cpp
a = b;
```

как:

> проверить, равны ли `a` и `b`.

Нет.

Это означает:

> записать значение `b` в `a`.

Для проверки равенства:

```cpp
a == b
```

---

# Сокращённое присваивание

Представим:

```cpp
int value = 10;

value = value + 5;
```

Получим:

```text
15
```

В C++ можно написать короче:

```cpp
value += 5;
```

Это означает то же самое.

---

# Другие сокращённые операции

Можно использовать:

```cpp
value += 5;
value -= 5;
value *= 5;
value /= 5;
value %= 5;
```

Например:

```cpp
int value = 10;

value += 5;
```

результат:

```text
15
```

---

# Инкремент

Оператор:

```cpp
++
```

увеличивает значение на единицу.

Например:

```cpp
int counter = 0;

counter++;
```

Теперь:

```text
counter = 1
```

Ещё раз:

```cpp
counter++;
```

Получим:

```text
counter = 2
```

---

# Декремент

Оператор:

```cpp
--
```

уменьшает значение на единицу.

```cpp
int counter = 10;

counter--;
```

Теперь:

```text
counter = 9
```

---

# Постфиксная и префиксная формы

Существуют два варианта:

```cpp
counter++;
```

и:

```cpp
++counter;
```

Оба увеличивают значение на единицу.

Разница становится важной, когда оператор используется внутри другого выражения.

Например:

```cpp
int a = 5;
int b = a++;
```

После операции:

```text
a = 6
b = 5
```

А:

```cpp
int a = 5;
int b = ++a;
```

даст:

```text
a = 6
b = 6
```

На первых этапах лучше не усложнять код без необходимости.

---

# Приоритет операторов

Рассмотрим:

```cpp
int result = 2 + 3 * 4;
```

Получится:

```text
14
```

а не:

```text
20
```

Потому что умножение выполняется раньше сложения:

```text
3 * 4 = 12
2 + 12 = 14
```

---

# Скобки

Если нужно изменить порядок операций, используются скобки:

```cpp
int result = (2 + 3) * 4;
```

Теперь:

```text
2 + 3 = 5
5 * 4 = 20
```

Поэтому скобки часто делают выражение понятнее.

---

# Пример с роботом

Представим систему контроля робота:

```cpp
double temperature = 65.0;
int battery = 80;
bool emergencyStop = false;

bool canWork =
    temperature < 80.0 &&
    battery > 20 &&
    !emergencyStop;
```

Здесь программа проверяет сразу три условия:

```text
температура ниже 80
И
батарея выше 20
И
аварийная остановка не активна
```

Если все условия выполняются:

```text
canWork = true
```

# Главное

Нужно уверенно различать:

```text
+   -   *   /   %
```

арифметические операции.

```text
==  !=  >  <  >=  <=
```

сравнение.

```text
&&  ||  !
```

логические операции.

А также:

```text
=    присваивание
+=   прибавить и присвоить
-=   вычесть и присвоить
*=   умножить и присвоить
/=   разделить и присвоить
++   увеличить на 1
--   уменьшить на 1
```

Особенно важно не путать:

```cpp
=
```

и:

```cpp
==
```

Это одна из самых частых ошибок начинающих.
