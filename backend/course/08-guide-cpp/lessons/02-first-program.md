# Установка компилятора и первая программа

## Цель

В прошлом уроке мы разобрались, что такое C++ и зачем он нужен.

Теперь создадим настоящую программу на C++, скомпилируем её и запустим.

После урока вы должны уметь:

* понимать, что такое компилятор;
* отличать компилятор от редактора кода;
* проверить наличие компилятора;
* создать файл `.cpp`;
* скомпилировать программу;
* запустить программу;
* понимать основные сообщения об ошибках компиляции.

---

# Что нужно для разработки на C++

Для разработки программы на C++ нужны как минимум:

```text
исходный код
    +
компилятор
    +
среда для написания кода
```

Например:

```text
VS Code
    ↓
main.cpp
    ↓
GCC
    ↓
program.exe
```

Важно понимать, что **редактор и компилятор — разные вещи**.

---

# Редактор кода

Редактор позволяет писать и изменять исходный код.

Например:

* Visual Studio Code;
* Cursor;
* Vim;
* Notepad++;
* Visual Studio.

Редактор сам по себе не превращает C++ код в программу.

Например, можно написать:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello!\n";
    return 0;
}
```

в обычном текстовом редакторе.

Но для создания исполняемого файла понадобится компилятор.

---

# Компилятор

Популярные варианты:

## GCC

GCC — один из самых распространённых наборов инструментов для компиляции C и C++.

Команда обычно выглядит так:

```bash
g++
```

Проверить его наличие:

```bash
g++ --version
```

---

## Clang

Другой популярный компилятор:

```bash
clang++
```

Проверка:

```bash
clang++ --version
```

---

## MSVC

В Windows широко используется компилятор Microsoft Visual C++.

Он поставляется вместе с инструментами Visual Studio.

Для работы с MSVC обычно используется специальная среда командной строки Visual Studio.

---

# Какой компилятор выбрать

Для изучения C++ не нужно устанавливать сразу несколько компиляторов.

Достаточно одного рабочего набора.

Если вы работаете в Windows и используете MSYS2, можно установить GCC и использовать `g++`.

Если работаете с Visual Studio, можно использовать MSVC.

Если работаете в Linux, GCC обычно устанавливается стандартными средствами системы.

Главное на этом этапе — получить возможность выполнить:

```bash
g++ --version
```

и увидеть информацию о компиляторе.

# Первая программа

Создадим папку:

```text
cpp-learning
```

Внутри неё создадим файл:

```text
main.cpp
```

Запишем:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";

    return 0;
}
```

Это наша первая программа.

---

# Разберём программу

Пока не нужно запоминать каждую деталь.

Мы подробно разберём структуру программы в следующем уроке.

Сейчас достаточно увидеть общую картину.

Строка:

```cpp
#include <iostream>
```

подключает стандартные средства для работы с вводом и выводом.

Функция:

```cpp
int main()
```

является точкой входа программы.

Команда:

```cpp
std::cout << "Hello, C++!\n";
```

выводит текст.

А:

```cpp
return 0;
```

завершает функцию `main` с кодом успешного завершения.

---

# Компиляция

Откройте терминал в папке с `main.cpp`.

Выполните:

```bash
g++ main.cpp -o program
```

Если компиляция прошла успешно, ошибок не будет.

В папке появится исполняемый файл.

В Windows:

```text
program.exe
```

В Linux:

```text
program
```

---

# Что произошло

Команда:

```bash
g++ main.cpp -o program
```

может быть разобрана так:

```text
g++
```

компилятор C++.

```text
main.cpp
```

исходный файл.

```text
-o
```

параметр, задающий имя выходного файла.

```text
program
```

имя программы.

Получается:

```text
main.cpp
    ↓
   g++
    ↓
program.exe
```

---

# Запуск программы

В Windows PowerShell:

```powershell
.\program.exe
```

В Linux:

```bash
./program
```

Результат:

```text
Hello, C++!
```

Поздравляем: это уже настоящая скомпилированная программа.

---

# Изменим программу

Изменим текст:

```cpp
#include <iostream>

int main() {
    std::cout << "My first C++ program!\n";

    return 0;
}
```

Снова выполним:

```bash
g++ main.cpp -o program
```

А затем:

```powershell
.\program.exe
```

Получим:

```text
My first C++ program!
```

Это важная идея разработки:

```text
изменили код
      ↓
скомпилировали
      ↓
запустили
      ↓
проверили результат
```

---

# Что будет, если не компилировать

Допустим, мы изменили:

```cpp
std::cout << "Hello!\n";
```

на:

```cpp
std::cout << "Goodbye!\n";
```

Но не выполнили компиляцию.

Если после этого запустить старый `program.exe`, он может продолжить выводить:

```text
Hello!
```

Почему?

Потому что исполняемый файл был создан из старой версии исходного кода.

Получается:

```text
main.cpp
```

и

```text
program.exe
```

— это два разных файла.

Изменение `main.cpp` автоматически не изменяет уже созданный `program.exe`.

---

# Первая ошибка компиляции

Теперь специально сделаем ошибку.

Например:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello!\n"
    return 0;
}
```

После строки `std::cout` отсутствует `;`.

Попробуем скомпилировать:

```bash
g++ main.cpp -o program
```

Компилятор сообщит об ошибке.

Текст сообщения зависит от компилятора.

Например, можно получить сообщение вроде:

```text
error: expected ';' before 'return'
```

Это означает, что компилятор ожидал символ `;`.

---

# Ошибки — нормальная часть программирования

При разработке программ ошибки появляются постоянно.

Например:

```text
ошибка синтаксиса
ошибка типа
ошибка имени
ошибка подключения
ошибка линковки
ошибка выполнения
```

Не нужно воспринимать сообщение компилятора как что-то страшное.

Обычно нужно:

1. найти первую ошибку;
2. прочитать сообщение;
3. посмотреть указанную строку;
4. исправить проблему;
5. снова запустить компиляцию.

---

# Где находится программа

После выполнения:

```bash
g++ main.cpp -o program
```

у нас могут быть:

```text
cpp-learning/
├── main.cpp
└── program.exe
```

`main.cpp` — исходный код.

`program.exe` — готовая программа.

Это фундаментальная схема разработки C++.

---

# Компиляция нескольких файлов

Позже программы перестанут помещаться в один файл.

Например:

```text
project/
├── main.cpp
├── robot.cpp
├── robot.h
├── sensor.cpp
└── sensor.h
```

Тогда компилятор должен обработать несколько исходных файлов.

Например:

```bash
g++ main.cpp robot.cpp sensor.cpp -o robot
```

Сейчас достаточно понимать сам принцип.

# Главное

Запомните:

* редактор кода и компилятор — разные инструменты;
* исходный файл C++ обычно имеет расширение `.cpp`;
* компилятор переводит исходный код в исполняемую программу;
* после изменения исходного кода программу нужно снова скомпилировать;
* ошибки компиляции — нормальная часть разработки;
* `main.cpp` и `program.exe` — разные файлы;
* команда `g++ main.cpp -o program` компилирует программу;
* готовую программу можно запускать отдельно от исходного кода.
