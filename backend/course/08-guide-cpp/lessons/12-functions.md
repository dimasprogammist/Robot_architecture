# Функции

## Цель

По мере роста программы код начинает повторяться. Если одна и та же операция нужна в нескольких местах, копировать её вручную неудобно: при изменении логики придётся исправлять каждый экземпляр.

Функции позволяют объединять связанные инструкции в отдельные блоки, давать им имена и вызывать их тогда, когда это необходимо. Это один из главных механизмов организации программ на C++.

После урока вы должны понимать:

* зачем нужны функции;
* как объявлять и определять функции;
* что такое параметры;
* что такое возвращаемое значение;
* чем аргумент отличается от параметра;
* как использовать `void`;
* как передавать несколько аргументов;
* зачем нужны значения параметров по умолчанию.

---

# Зачем нужны функции

Представим программу, которая несколько раз вычисляет площадь прямоугольника.

Без функции код может выглядеть так:

```cpp
int width1 = 10;
int height1 = 5;
int area1 = width1 * height1;

int width2 = 20;
int height2 = 7;
int area2 = width2 * height2;

int width3 = 15;
int height3 = 4;
int area3 = width3 * height3;
```

Логика вычисления повторяется.

Вместо этого можно создать функцию:

```cpp
int calculateArea(int width, int height) {
    return width * height;
}
```

Теперь:

```cpp
int area1 = calculateArea(10, 5);
int area2 = calculateArea(20, 7);
int area3 = calculateArea(15, 4);
```

Логика вычисления находится в одном месте.

# Простая функция

Пример:

```cpp
void sayHello() {
    std::cout << "Hello!\n";
}
```

Функция называется:

```text
sayHello
```

и не принимает никаких параметров.

Вызвать её можно так:

```cpp
sayHello();
```

Полная программа:

```cpp
#include <iostream>

void sayHello() {
    std::cout << "Hello!\n";
}

int main() {
    sayHello();

    return 0;
}
```

Результат:

```text
Hello!
```

---

# Что означает void

Перед именем функции находится:

```cpp
void
```

Это означает, что функция не возвращает значение.

Например:

```cpp
void sayHello() {
    std::cout << "Hello!\n";
}
```

Функция что-то делает, но не возвращает результат вызывающему коду.

---

# Функция с возвращаемым значением

Функция может вернуть результат.

Например:

```cpp
int add(int a, int b) {
    return a + b;
}
```

Здесь:

```cpp
int
```

означает, что функция возвращает целое число.

Вызов:

```cpp
int result = add(10, 20);
```

После выполнения:

```text
result = 30
```

---

# return

Оператор:

```cpp
return
```

возвращает значение из функции.

Например:

```cpp
int square(int value) {
    return value * value;
}
```

Вызов:

```cpp
int result = square(5);
```

Функция вычисляет:

```text
5 * 5 = 25
```

и возвращает:

```text
25
```

---

# Параметры

В функции:

```cpp
int add(int a, int b)
```

переменные:

```cpp
a
b
```

называются параметрами.

Они получают значения во время вызова функции.

Например:

```cpp
add(10, 20);
```

Здесь:

```text
a = 10
b = 20
```

---

# Аргументы

Значения, которые передаются при вызове функции, называются аргументами.

Например:

```cpp
add(10, 20);
```

Здесь:

```text
10
20
```

— аргументы.

А в определении:

```cpp
int add(int a, int b)
```

`a` и `b` — параметры.

В повседневной речи эти термины иногда используют почти как синонимы, но технически это разные понятия.

---

# Несколько параметров

Функция может принимать любое необходимое количество параметров.

Например:

```cpp
double calculateAverage(double a, double b, double c) {
    return (a + b + c) / 3.0;
}
```

Использование:

```cpp
double average = calculateAverage(10.0, 20.0, 30.0);
```

Результат:

```text
20
```

---

# Типы параметров

Параметры могут иметь разные типы:

```cpp
void printRobot(
    std::string name,
    int battery,
    double temperature
) {
    std::cout << "Name: " << name << '\n';
    std::cout << "Battery: " << battery << '\n';
    std::cout << "Temperature: " << temperature << '\n';
}
```

Вызов:

```cpp
printRobot("R2D2", 85, 42.5);
```

---

# Порядок параметров имеет значение

Рассмотрим:

```cpp
void printRobot(std::string name, int battery) {
    ...
}
```

При вызове:

```cpp
printRobot("R2D2", 80);
```

получаем:

```text
name = R2D2
battery = 80
```

Если поменять порядок:

```cpp
printRobot(80, "R2D2");
```

это уже не соответствует объявленной функции.

Типы и порядок аргументов должны соответствовать параметрам функции.

---

# Функция может вызываться несколько раз

Например:

```cpp
int square(int value) {
    return value * value;
}
```

Можно написать:

```cpp
std::cout << square(2) << '\n';
std::cout << square(5) << '\n';
std::cout << square(10) << '\n';
```

Результат:

```text
4
25
100
```

Одна функция используется много раз.

---

# Локальные переменные

Переменная, созданная внутри функции, обычно существует только внутри этой функции.

Например:

```cpp
int calculate() {
    int value = 10;

    return value * 2;
}
```

Переменная:

```cpp
value
```

недоступна непосредственно из `main()`.

Это называется областью видимости.

Подробно области видимости мы разберём дальше, но уже сейчас важно понимать, что функции помогают отделять части программы друг от друга.

---

# Функция может вызывать другую функцию

Например:

```cpp
int square(int value) {
    return value * value;
}

int calculateArea(int width, int height) {
    return width * height;
}
```

Одна функция может использовать другую:

```cpp
int calculateSomething(int value) {
    return square(value) + 10;
}
```

Так программы можно строить из небольших компонентов.

---

# Объявление функции

Иногда функция определена после `main()`.

Например:

```cpp
#include <iostream>

int add(int a, int b);

int main() {
    std::cout << add(10, 20) << '\n';

    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

Строка:

```cpp
int add(int a, int b);
```

называется объявлением функции.

Она сообщает компилятору, что такая функция существует.

---

# Почему объявление нужно раньше вызова

Компилятор обрабатывает исходный код с учётом доступных ему объявлений.

Если написать:

```cpp
int main() {
    std::cout << add(10, 20);
}

int add(int a, int b) {
    return a + b;
}
```

компилятор в точке вызова ещё не знает о функции `add`.

Поэтому можно предварительно объявить её:

```cpp
int add(int a, int b);
```

Позже, когда программа станет больше, объявления функций обычно выносят в заголовочные файлы.

---

# Значения параметров по умолчанию

Параметру можно задать значение по умолчанию.

Например:

```cpp
void greet(std::string name = "User") {
    std::cout << "Hello, " << name << "!\n";
}
```

Теперь можно написать:

```cpp
greet("Dmitry");
```

Получим:

```text
Hello, Dmitry!
```

А можно:

```cpp
greet();
```

Тогда будет использовано:

```text
User
```

---

# Возвращаемое значение и условие

Функция может содержать обычную логику:

```cpp
bool isBatteryLow(int battery) {
    return battery < 20;
}
```

Теперь:

```cpp
if (isBatteryLow(15)) {
    std::cout << "Warning!\n";
}
```

Функция превращает отдельную проверку в понятную операцию.

Это очень важный принцип проектирования программ.

---

# Функции как действия

Хорошая функция часто отвечает на вопрос:

> Что именно она делает?

Например:

```cpp
readTemperature()
```

```cpp
calculateAverage()
```

```cpp
startMotor()
```

```cpp
isBatteryLow()
```

```cpp
printStatus()
```

По имени должно быть понятно назначение функции.

---

# Слишком большие функции

Плохой вариант:

```cpp
void processRobot() {
    // 500 строк кода
}
```

Если функция становится огромной, её трудно читать и тестировать.

Лучше разделить логику:

```cpp
readSensors();
calculateState();
checkSafety();
updateMotors();
sendStatus();
```

Каждая функция выполняет свою отдельную задачу.

---

# Практический пример

Создадим несколько функций для робота:

```cpp
#include <iostream>

double calculateAverage(double a, double b, double c) {
    return (a + b + c) / 3.0;
}

bool isBatteryLow(int battery) {
    return battery < 20;
}

void printStatus(int battery, double temperature) {
    std::cout << "Battery: " << battery << "%\n";
    std::cout << "Temperature: " << temperature << '\n';
}

int main() {
    int battery = 75;
    double temperature = 45.0;

    printStatus(battery, temperature);

    if (isBatteryLow(battery)) {
        std::cout << "Low battery!\n";
    }

    double average = calculateAverage(10.0, 20.0, 30.0);

    std::cout << "Average: " << average << '\n';

    return 0;
}
```

Теперь `main()` не содержит всю логику программы. Он организует работу отдельных функций.

# Главное

Функция — это именованный блок кода, который выполняет отдельную задачу.

Основная структура:

```cpp
return_type function_name(parameters) {
    // код
    return value;
}
```

Например:

```cpp
int add(int a, int b) {
    return a + b;
}
```

Важно различать:

```text
параметры
```

— переменные в определении функции,

и:

```text
аргументы
```

— конкретные значения при вызове.

Функции позволяют:

* не дублировать код;
* разделять программу на части;
* давать операциям понятные имена;
* повторно использовать одну и ту же логику;
* упрощать тестирование и отладку.

По мере роста программы именно функции начинают превращать набор инструкций в организованную систему.
