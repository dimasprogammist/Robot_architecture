# Что такое C++

## Цель

В этом уроке разберёмся, что такое C++, зачем он нужен и почему этот язык до сих пор широко используется.

После урока вы должны понимать:

* что такое C++;
* чем C++ отличается от языков вроде Python;
* что означает компиляция программы;
* где применяется C++;
* почему C++ особенно важен для системного программирования, электроники и робототехники.

---

## Что такое C++

**C++ — это язык программирования общего назначения**, который позволяет создавать программы от небольших консольных утилит до операционных системных компонентов, игровых движков и программ для роботов.

C++ появился как развитие языка C.

Одной из главных особенностей C++ является возможность работать на достаточно высоком уровне абстракции, но при этом при необходимости получать прямой контроль над памятью, объектами и ресурсами компьютера.

Именно поэтому C++ находится примерно посередине между двумя мирами:

* можно писать удобные структуры высокого уровня;
* можно работать с памятью и аппаратными ресурсами практически напрямую.

Например, на C++ можно написать:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, world!\n";
    return 0;
}
```

Программа выводит текст:

```text
Hello, world!
```

На первый взгляд это простая программа. Но за ней стоит целая система:

```text
исходный код
    ↓
компилятор
    ↓
машинный код
    ↓
процессор
    ↓
результат
```

---

## Почему C++ называется C++

C++ появился на основе языка C.

Название связано с оператором `++`.

В C и C++ оператор:

```cpp
a++;
```

означает увеличение значения `a` на единицу.

Поэтому название C++ можно условно воспринимать как:

> C, который получил дополнительные возможности.

При этом современный C++ давно стал самостоятельным большим языком и значительно отличается от исходного C.

# Компилируемый язык

Одно из важных свойств C++ — программы обычно **компилируются**.

Допустим, мы создаём файл:

```text
main.cpp
```

Внутри находится исходный код:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello!\n";
    return 0;
}
```

Этот текст сам по себе не является инструкциями, которые процессор может непосредственно выполнить.

Сначала его обрабатывает компилятор.

Упрощённо процесс выглядит так:

```text
main.cpp
   ↓
компилятор
   ↓
машинный код
   ↓
исполняемый файл
```

В Windows результатом часто становится:

```text
program.exe
```

В Linux исполняемый файл может не иметь специального расширения:

```text
program
```

После этого операционная система запускает программу, а процессор выполняет машинные инструкции.

---

# Что такое компилятор

**Компилятор** — программа, которая переводит исходный код на C++ в код, пригодный для выполнения компьютером.

Популярные компиляторы:

* GCC;
* Clang;
* Microsoft Visual C++ (MSVC).

Например, при использовании GCC команда может выглядеть так:

```bash
g++ main.cpp -o program
```

Здесь:

```text
g++
```

— компилятор C++.

```text
main.cpp
```

— исходный файл.

```text
-o program
```

— имя создаваемого исполняемого файла.

После компиляции можно запустить программу.

Linux:

```bash
./program
```

Windows:

```powershell
.\program.exe
```

# C++ и Python

Если вы уже знакомы с Python, C++ поначалу может показаться гораздо более сложным.

Например, в Python:

```python
name = "Dmitry"
print(name)
```

В C++:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "Dmitry";

    std::cout << name << '\n';

    return 0;
}
```

Почему C++ выглядит сложнее?

Потому что язык требует явно описывать многие вещи.

Например:

```cpp
int number = 10;
```

Здесь мы явно говорим, что `number` имеет тип `int`.

В Python:

```python
number = 10
```

тип определяется автоматически во время выполнения.

C++ предоставляет программисту больше контроля, но за этот контроль приходится платить дополнительной сложностью.

# Где применяется C++

C++ используется во множестве областей.

## Операционные системы

C++ применяется для разработки компонентов операционных систем и системного программного обеспечения.

Здесь особенно важны:

* скорость;
* контроль памяти;
* работа с аппаратными ресурсами;
* предсказуемость выполнения.

---

## Игры

C++ широко используется в игровых движках и высокопроизводительных играх.

Например, игровые движки могут выполнять огромное количество операций:

```text
физика
 ↓
графика
 ↓
звук
 ↓
искусственный интеллект
 ↓
сеть
 ↓
рендеринг
```

При этом всё должно работать достаточно быстро.

---

## Робототехника

Для робототехники C++ особенно интересен.

Робот может одновременно:

* читать датчики;
* управлять двигателями;
* обмениваться данными по сети;
* обрабатывать изображения;
* выполнять алгоритмы управления.

Например:

```text
датчики
   ↓
C++ программа
   ↓
алгоритм управления
   ↓
контроллер
   ↓
двигатели
```

C++ позволяет создавать достаточно производительные программы, которые работают непосредственно рядом с аппаратной частью системы.

---

## Микроконтроллеры

C++ используется и в разработке программ для микроконтроллеров.

Например:

```text
микроконтроллер
 ├── GPIO
 ├── UART
 ├── SPI
 ├── I2C
 ├── таймеры
 └── ADC
```

Программа может напрямую взаимодействовать с этими аппаратными блоками.

---

## Серверное программирование

C++ используется и на серверах, где важна производительность.

Например:

* сетевые сервисы;
* базы данных;
* высоконагруженные системы;
* обработка больших потоков данных;
* инфраструктурное программное обеспечение.

---

# Почему C++ важен для изучения

C++ заставляет хорошо понимать устройство программы.

При изучении C++ постепенно становятся понятнее:

* память;
* адреса;
* указатели;
* ссылки;
* типы данных;
* процесс компиляции;
* операционная система;
* процессы и потоки;
* работа с файлами;
* сеть;
* аппаратное обеспечение.

Поэтому C++ полезен не только как язык программирования.

Он помогает понять, **что происходит внутри компьютера**.

# C++ и управление ресурсами

В высокоуровневых языках многие ресурсы скрыты от программиста.

В C++ можно работать с ними гораздо ближе к системе.

Например, программа может управлять:

```text
памятью
файлами
сетевыми соединениями
потоками
дескрипторами
аппаратными ресурсами
```

Современный C++ при этом предоставляет инструменты, которые позволяют безопаснее работать с ресурсами.

Например:

```cpp
#include <memory>

int main() {
    auto value = std::make_unique<int>(42);

    return 0;
}
```

Здесь используется умный указатель.

До умных указателей мы ещё дойдём в следующих разделах.

---

# C++ не является "быстрым Python"

Иногда C++ описывают просто как более быстрый Python.

Это слишком сильное упрощение.

Языки отличаются самой моделью работы.

Например:

```text
Python
    ↓
интерпретация / выполнение среды Python
    ↓
операции программы
```

В классическом случае C++:

```text
C++ код
    ↓
компиляция
    ↓
машинный код
    ↓
процессор
```

Но реальная производительность зависит не только от языка.

Большую роль играют:

* алгоритмы;
* структура данных;
* архитектура программы;
* количество операций;
* работа с памятью;
* компилятор;
* настройки оптимизации;
* аппаратное обеспечение.

---

# Когда стоит использовать C++

C++ особенно полезен, когда нужны:

* высокая производительность;
* контроль над памятью;
* работа с аппаратным обеспечением;
* системное программирование;
* низкие задержки;
* работа с большим количеством вычислений;
* существующие C/C++ библиотеки.

При этом для многих обычных приложений C++ может быть избыточным.

Например, простой скрипт обработки файлов зачастую проще написать на Python.

Важно не просто знать язык, а понимать, **для какой задачи какой инструмент подходит**.
