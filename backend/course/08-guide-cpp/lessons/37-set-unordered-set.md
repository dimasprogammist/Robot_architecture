# std::set и std::unordered_set

## Цель

В прошлом уроке мы рассмотрели контейнеры, которые хранят пары «ключ → значение». Теперь рассмотрим контейнеры, которые хранят только **уникальные значения**.

Мы разберём `std::set` и `std::unordered_set`, научимся добавлять, удалять и искать элементы, а также поймём, чем множество отличается от `std::vector`.

---

## Что такое множество

В математике множество — это набор элементов, где каждый элемент присутствует только один раз.

Например:

```text
{1, 2, 3, 4}
```

Число `3` нельзя добавить туда второй раз как отдельный элемент.

Такая структура данных часто нужна и в программах.

Представим список идентификаторов устройств:

```text
101
102
103
102
101
```

Если нас интересуют только уникальные устройства, результат должен быть:

```text
101
102
103
```

Для этого подходит `std::set`.

---

## std::set

Простейший пример:

```cpp
#include <iostream>
#include <set>

int main() {
    std::set<int> numbers;

    numbers.insert(10);
    numbers.insert(20);
    numbers.insert(10);

    for (int number : numbers) {
        std::cout << number << '\n';
    }
}
```

Результат:

```text
10
20
```

Повторная вставка `10` ничего не изменила.

---

## Уникальность элементов

Главная особенность `std::set` — каждый элемент уникален.

Например:

```cpp
std::set<std::string> sensors;

sensors.insert("temperature");
sensors.insert("pressure");
sensors.insert("temperature");
sensors.insert("humidity");
```

В контейнере будет только:

```text
temperature
pressure
humidity
```

---

## std::set хранит элементы отсортированными

Как и `std::map`, `std::set` поддерживает порядок элементов.

Например:

```cpp
std::set<int> numbers;

numbers.insert(50);
numbers.insert(10);
numbers.insert(30);
numbers.insert(20);
```

При переборе получим:

```text
10
20
30
50
```

Это важное отличие от `std::unordered_set`.

---

## Проверка наличия

Для проверки элемента можно использовать `contains()`:

```cpp
if (numbers.contains(30)) {
    std::cout << "Number exists\n";
}
```

Можно использовать и `find()`:

```cpp
auto it = numbers.find(30);

if (it != numbers.end()) {
    std::cout << "Found: " << *it << '\n';
}
```

---

## Добавление элементов

Используется:

```cpp
insert()
```

Например:

```cpp
std::set<int> ids;

ids.insert(100);
ids.insert(200);
ids.insert(300);
```

`insert()` возвращает информацию о результате вставки.

Можно написать:

```cpp
auto [it, inserted] = ids.insert(100);

if (inserted) {
    std::cout << "Inserted\n";
} else {
    std::cout << "Already exists\n";
}
```

Если значение уже было в множестве, `inserted` будет `false`.

---

## Удаление

Удалить элемент можно по значению:

```cpp
ids.erase(200);
```

После этого `200` больше нет в контейнере.

Можно удалить элемент через итератор:

```cpp
auto it = ids.find(300);

if (it != ids.end()) {
    ids.erase(it);
}
```

---

## Размер и очистка

Как и у других STL-контейнеров:

```cpp
ids.size();
ids.empty();
ids.clear();
```

Например:

```cpp
std::cout << ids.size() << '\n';

ids.clear();

std::cout << ids.empty() << '\n';
```

---

## std::unordered_set

Теперь рассмотрим:

```cpp
std::unordered_set
```

Он также хранит только уникальные элементы:

```cpp
#include <iostream>
#include <unordered_set>

int main() {
    std::unordered_set<int> numbers;

    numbers.insert(10);
    numbers.insert(20);
    numbers.insert(10);

    for (int number : numbers) {
        std::cout << number << '\n';
    }
}
```

Повторяющиеся элементы также не сохраняются.

Главное отличие — элементы не сортируются.

---

## Как работает unordered_set

`unordered_set` использует хеш-таблицу.

Упрощённо:

```text
значение
   ↓
 hash()
   ↓
хеш-таблица
```

Поэтому поиск элемента обычно выполняется за O(1) в среднем.

Для `std::set` поиск обычно занимает O(log n).

---

## Сравнение

| Характеристика | `std::set` | `std::unordered_set` |
|---|---:|---:|
| уникальные элементы | Да | Да |
| сортировка | Да | Нет |
| поиск | O(log n) | O(1) в среднем |
| вставка | O(log n) | O(1) в среднем |
| удаление | O(log n) | O(1) в среднем |

Как и в случае с `map`, O(1) для `unordered_set` — средняя ожидаемая сложность, а не абсолютная гарантия для каждого случая.

---

## set против vector

Может показаться, что `std::set` просто заменяет `std::vector`.

Но у них разные задачи.

`vector` отлично подходит для последовательности элементов:

```text
[10, 20, 30, 40]
```

Вектор сохраняет порядок добавления.

`set` больше похож на математическое множество:

```text
{10, 20, 30, 40}
```

Он автоматически удаляет дубликаты и поддерживает сортировку.

---

## Удаление дубликатов

Предположим, у нас есть вектор:

```cpp
std::vector<int> ids = {
    10, 20, 10, 30, 20, 40
};
```

Можно получить уникальные значения через `set`:

```cpp
std::set<int> uniqueIds(
    ids.begin(),
    ids.end()
);
```

Теперь:

```text
10
20
30
40
```

---

## Когда set особенно удобен

Множества часто используются, когда нужно:

* проверить наличие элемента;
* удалить дубликаты;
* хранить только уникальные значения;
* поддерживать отсортированный набор;
* выполнять операции над множествами.

Например, система может получать идентификаторы устройств из нескольких источников:

```text
Источник A:
101 102 103

Источник B:
102 103 104
```

После объединения можно получить:

```text
101 102 103 104
```

---

## Практический пример

Представим систему регистрации активных датчиков:

```cpp
#include <iostream>
#include <set>
#include <string>

int main() {
    std::set<std::string> activeSensors;

    activeSensors.insert("temperature");
    activeSensors.insert("pressure");
    activeSensors.insert("temperature");

    for (const auto& sensor : activeSensors) {
        std::cout << sensor << '\n';
    }
}
```

`temperature` будет выведен только один раз.

---

## Работа с диапазонами

У `std::set` есть интересная возможность искать диапазоны.

Например:

```cpp
std::set<int> values = {
    10, 20, 30, 40, 50, 60
};
```

Можно найти первый элемент, который не меньше `30`:

```cpp
auto it = values.lower_bound(30);
```

И первый элемент, который строго больше `30`:

```cpp
auto it = values.upper_bound(30);
```

Это одна из причин, почему `std::set` полезен там, где нужен упорядоченный набор данных.

---

## Важное ограничение

У `set` нет доступа по индексу:

```cpp
values[0];
```

так делать нельзя.

Это принципиальное отличие от `vector` и `array`.

Если вам нужен элемент по числовому индексу, вероятно, нужен другой контейнер.

---

## Главное

`std::set` хранит уникальные элементы в отсортированном порядке.

`std::unordered_set` также хранит уникальные элементы, но использует хеш-таблицу и не гарантирует порядок.

Основные операции:

```cpp
insert()
contains()
find()
erase()
size()
empty()
clear()
```

Выбирайте `set`, когда важен порядок и операции над диапазонами. Выбирайте `unordered_set`, когда порядок не нужен, а основной сценарий — быстрые проверки наличия.
