# Что такое STL

## Цель

До этого мы много работали с базовыми возможностями C++: переменными, массивами, функциями, классами, указателями и ссылками. Теперь начинается важная часть языка — стандартная библиотека C++ и прежде всего **STL**.

После урока вы должны понимать:

* что такое STL;
* зачем нужны стандартные контейнеры;
* что такое алгоритмы STL;
* какую роль играют итераторы;
* чем стандартная библиотека отличается от языка C++;
* почему `std::vector`, `std::map` и другие контейнеры используются настолько часто.

---

## Что такое STL

STL расшифровывается как **Standard Template Library** — стандартная библиотека шаблонных компонентов.

Сегодня под STL обычно имеют в виду набор стандартных контейнеров, алгоритмов, итераторов и других обобщённых компонентов C++.

Например, вместо того чтобы самостоятельно писать динамический массив, можно использовать:

```cpp
std::vector<int> numbers;
```

Вместо самостоятельной реализации словаря:

```cpp
std::unordered_map<std::string, int> scores;
```

Вместо написания собственного алгоритма сортировки:

```cpp
std::sort(numbers.begin(), numbers.end());
```

Это позволяет решать типовые задачи готовыми и хорошо проверенными средствами.

---

## STL не является отдельным языком

STL — часть стандартной библиотеки C++.

Например:

```cpp
int main()
{
    std::vector<int> numbers = {1, 2, 3};

    return 0;
}
```

Сам язык C++ предоставляет синтаксис классов, функций, указателей, шаблонов и других конструкций.

А `std::vector` является библиотечным типом, который реализован с использованием возможностей языка.

---

## Основные части STL

Упрощённо STL можно разделить на несколько важных частей:

```text
STL
├── Контейнеры
├── Итераторы
├── Алгоритмы
└── Функциональные объекты и лямбды
```

Контейнеры хранят данные.

Итераторы позволяют перемещаться по данным.

Алгоритмы выполняют операции над диапазонами элементов.

Лямбды и функциональные объекты позволяют задавать дополнительное поведение.

---

## Контейнеры

Контейнер — это объект, предназначенный для хранения набора элементов.

Например:

```cpp
std::vector<int> numbers;
```

Здесь `vector` хранит несколько значений типа `int`.

Можно представить:

```text
vector

[10][20][30][40][50]
```

Другие контейнеры организуют данные по-другому.

Например:

```cpp
std::map<std::string, int>
```

может хранить пары:

```text
"temperature" -> 25
"speed"       -> 100
"voltage"     -> 24
```

---

## Основные контейнеры

В стандартной библиотеке есть много контейнеров, но на первых этапах особенно важны:

```text
std::vector
std::array
std::string
std::map
std::unordered_map
std::set
std::unordered_set
```

У каждого контейнера своё предназначение.

Например:

```text
vector        последовательность элементов
array         массив фиксированного размера
string        текст
map           ключ → значение
set           множество уникальных элементов
```

Не нужно пытаться использовать один контейнер для всех задач.

---

## vector

Самый часто используемый контейнер — `std::vector`.

```cpp
#include <vector>

int main()
{
    std::vector<int> numbers = {10, 20, 30};

    return 0;
}
```

Вектор похож на динамический массив.

Он может изменять количество элементов во время выполнения программы.

Например:

```cpp
numbers.push_back(40);
numbers.push_back(50);
```

Теперь в нём пять элементов.

---

## array

`std::array` используется, когда размер известен заранее и должен оставаться фиксированным.

```cpp
#include <array>

std::array<int, 3> numbers = {10, 20, 30};
```

Количество элементов здесь равно `3`.

В отличие от `std::vector`, нельзя просто добавить четвёртый элемент через `push_back()`.

---

## map

`std::map` хранит пары ключ-значение.

```cpp
#include <map>
#include <string>

std::map<std::string, int> sensors;

sensors["temperature"] = 25;
sensors["pressure"] = 100;
```

Теперь можно получить значение по ключу:

```cpp
std::cout << sensors["temperature"];
```

Такая структура удобна, когда данные нужно искать по идентификатору.

---

## set

`std::set` хранит уникальные значения.

```cpp
#include <set>

std::set<int> numbers;

numbers.insert(10);
numbers.insert(20);
numbers.insert(10);
```

В результате значение `10` не появится дважды.

Можно представить:

```text
{10, 20}
```

Это удобно, когда сама уникальность элементов является частью задачи.

---

## Алгоритмы

Контейнеры хранят данные, а алгоритмы выполняют операции над ними.

Например:

```cpp
std::sort(numbers.begin(), numbers.end());
```

Сортировка не является методом `std::vector`.

Это отдельный стандартный алгоритм.

Такой подход позволяет использовать один алгоритм с разными контейнерами и структурами данных.

---

## Пример сортировки

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> numbers = {
        50, 10, 40, 20, 30
    };

    std::sort(numbers.begin(), numbers.end());

    for (int number : numbers)
    {
        std::cout << number << ' ';
    }

    return 0;
}
```

Результат:

```text
10 20 30 40 50
```

Мы не писали алгоритм сортировки самостоятельно.

---

## Итераторы

Чтобы алгоритмы могли работать с разными контейнерами, используется понятие **итератора**.

Например:

```cpp
numbers.begin()
```

возвращает итератор на первый элемент.

А:

```cpp
numbers.end()
```

указывает на позицию сразу после последнего элемента.

Поэтому:

```cpp
std::sort(numbers.begin(), numbers.end());
```

можно читать примерно так:

> Отсортировать диапазон от начала `numbers` до конца `numbers`.

---

## Диапазон

Очень важная идея STL — работа с диапазонами.

Диапазон обычно задаётся двумя итераторами:

```cpp
[first, last)
```

Последняя позиция не входит в диапазон.

Например:

```cpp
std::sort(numbers.begin(), numbers.end());
```

означает:

```text
begin()
   ↓
[10][50][20][30][40]
                         ↑
                       end()
```

`end()` не указывает на последний элемент. Это позиция после него.

---

## Алгоритм find

Например, можно найти элемент:

```cpp
#include <algorithm>

auto it = std::find(
    numbers.begin(),
    numbers.end(),
    30
);
```

Если значение найдено, итератор указывает на него.

Можно проверить:

```cpp
if (it != numbers.end())
{
    std::cout << "Found\n";
}
```

Если:

```cpp
it == numbers.end()
```

значение не найдено.

---

## Алгоритм count

Можно посчитать количество одинаковых элементов:

```cpp
int count = std::count(
    numbers.begin(),
    numbers.end(),
    10
);
```

Если `10` встречается три раза, `count` будет равен:

```text
3
```

---

## Алгоритм reverse

Можно развернуть диапазон:

```cpp
std::reverse(
    numbers.begin(),
    numbers.end()
);
```

Например:

```text
1 2 3 4 5
```

превратится в:

```text
5 4 3 2 1
```

---

## Лямбды

Многие алгоритмы позволяют передать функцию, описывающую нужное действие.

Например:

```cpp
std::sort(
    numbers.begin(),
    numbers.end(),
    [](int a, int b)
    {
        return a > b;
    }
);
```

Теперь сортировка выполняется по убыванию.

Лямбда:

```cpp
[](int a, int b)
{
    return a > b;
}
```

говорит алгоритму, как сравнивать элементы.

Подробно лямбды мы рассмотрим позже.

---

## STL и шаблоны

STL активно использует шаблоны.

Поэтому один и тот же контейнер можно использовать с разными типами.

Например:

```cpp
std::vector<int> numbers;
```

или:

```cpp
std::vector<double> values;
```

или:

```cpp
std::vector<std::string> names;
```

Структура контейнера остаётся той же, но тип элементов меняется.

---

## Контейнер объектов

STL-контейнеры могут хранить не только встроенные типы.

Например:

```cpp
class Motor
{
public:
    int speed;
};

std::vector<Motor> motors;
```

Теперь `vector` содержит объекты `Motor`.

Можно добавлять их:

```cpp
motors.push_back(Motor{100});
motors.push_back(Motor{200});
```

Это особенно важно для больших программ.

---

## STL в робототехнике

Представим робота с несколькими датчиками:

```cpp
class Sensor
{
public:
    std::string name;
    double value;
};
```

Можно хранить их:

```cpp
std::vector<Sensor> sensors;
```

Обрабатывать:

```cpp
for (const Sensor& sensor : sensors)
{
    std::cout << sensor.name
              << ": "
              << sensor.value
              << '\n';
}
```

Таким образом, стандартные контейнеры становятся строительными блоками более крупных программ.

---

## Почему STL так важна

Без STL разработчику пришлось бы постоянно писать собственные реализации:

```text
динамического массива
словаря
множества
сортировки
поиска
перестановки элементов
```

STL предоставляет стандартные решения этих задач.

Это не только экономит время. Использование стандартных контейнеров и алгоритмов делает код более узнаваемым для других C++ разработчиков.

---

## Как выбирать контейнер

На первых этапах можно использовать такую простую схему:

```text
Нужна изменяемая последовательность?
        ↓
    std::vector

Размер фиксирован?
        ↓
    std::array

Нужен текст?
        ↓
    std::string

Нужен ключ → значение?
        ↓
    std::map / std::unordered_map

Нужны только уникальные значения?
        ↓
    std::set / std::unordered_set
```

Это только начальная схема. Позже мы разберём характеристики каждого контейнера подробнее.

---

## Главное

STL — одна из фундаментальных частей практического C++.

Нужно запомнить несколько основных идей:

* контейнеры хранят данные;
* алгоритмы работают с данными;
* итераторы задают диапазоны;
* шаблоны позволяют использовать контейнеры с разными типами;
* `std::vector` — динамическая последовательность;
* `std::array` — массив фиксированного размера;
* `std::map` — структура ключ → значение;
* `std::set` хранит уникальные элементы;
* алгоритмы вроде `sort`, `find` и `count` позволяют не писать типовой код самостоятельно.

Дальше мы начнём разбирать наиболее важные контейнеры STL подробно. Первым будет `std::vector`.
