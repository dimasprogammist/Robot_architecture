# Константы и `const`

## Цель

В предыдущем уроке мы создавали переменные и изменяли их значения.

Но не каждое значение программы должно изменяться.

Например:

```text
число Пи
количество элементов
размер буфера
номер порта
коэффициент
лимит
версия протокола
```

Если значение не должно изменяться после создания, в C++ можно использовать `const`.

В этом уроке разберём:

* что такое константа;
* зачем нужен `const`;
* как объявлять константы;
* почему `const` делает код безопаснее;
* чем константа отличается от обычной переменной;
* почему именованные константы лучше "магических чисел".

---

# Обычная переменная

Рассмотрим:

```cpp
int speed = 100;
```

Значение можно изменить:

```cpp
speed = 120;
```

После этого:

```text
speed = 120
```

Это обычная переменная.

---

# Константа

Теперь напишем:

```cpp
const int maxSpeed = 100;
```

`const` означает, что значение нельзя изменить после инициализации.

Например:

```cpp
const int maxSpeed = 100;

maxSpeed = 120;
```

Такой код приведёт к ошибке компиляции.

Компилятор сообщит, что нельзя изменить значение константного объекта.

---

# Почему это полезно

Представим программу управления двигателем.

У нас есть ограничение:

```cpp
const double maxTemperature = 80.0;
```

Это значение не должно случайно измениться где-нибудь в программе.

Если написать:

```cpp
double maxTemperature = 80.0;
```

другой участок программы теоретически сможет сделать:

```cpp
maxTemperature = 150.0;
```

Теперь ограничение изменилось.

Используя:

```cpp
const double maxTemperature = 80.0;
```

мы явно говорим:

> это значение не должно изменяться.

Компилятор поможет обнаружить случайную попытку его изменить.

---

# Инициализация обязательна

Для `const` нужно сразу указать значение.

Правильно:

```cpp
const int maxSpeed = 100;
```

Нельзя просто написать:

```cpp
const int maxSpeed;
```

а потом:

```cpp
maxSpeed = 100;
```

Потому что после создания `const` объект уже нельзя изменять.

Поэтому значение должно быть задано при инициализации.

---

# Константа и обычная переменная

Сравним:

```cpp
int speed = 100;
speed = 120;
```

Значение можно менять.

А:

```cpp
const int maxSpeed = 100;
maxSpeed = 120;
```

нельзя изменить.

Упрощённо:

```text
int
 ↓
значение можно менять

const int
 ↓
значение менять нельзя
```

---

# Константы в формулах

Представим расчёт площади круга.

Можно написать:

```cpp
double area = 3.14159 * radius * radius;
```

Но число:

```text
3.14159
```

не объясняет само себя.

Гораздо понятнее:

```cpp
const double pi = 3.14159;

double area = pi * radius * radius;
```

Теперь код говорит сам за себя.

---

# Магические числа

Число, которое появляется в коде без понятного объяснения, часто называют **магическим числом**.

Например:

```cpp
if (temperature > 80) {
    // ...
}
```

Почему именно `80`?

Что это?

```text
80 градусов?
80 процентов?
80 единиц?
80 секунд?
```

Из кода это не всегда понятно.

Лучше:

```cpp
const double maxTemperature = 80.0;

if (temperature > maxTemperature) {
    // ...
}
```

Теперь смысл значения очевиден.

---

# Именованные константы

Хорошая практика:

```cpp
const int maxRetries = 3;
const double maxTemperature = 80.0;
const int defaultPort = 8080;
```

Вместо:

```cpp
if (retryCount < 3) {
    // ...
}
```

можно написать:

```cpp
if (retryCount < maxRetries) {
    // ...
}
```

Второй вариант проще читать.

---

# Константы в программе

Например:

```cpp
#include <iostream>

int main() {
    const double maxTemperature = 80.0;
    double temperature = 75.5;

    std::cout << "Temperature: " << temperature << '\n';
    std::cout << "Limit: " << maxTemperature << '\n';

    return 0;
}
```

Здесь:

```cpp
temperature
```

может изменяться.

А:

```cpp
maxTemperature
```

изменять нельзя.

---

# Можно ли изменить значение через вычисление

Нет.

Например:

```cpp
const int maxSpeed = 100;

int newSpeed = maxSpeed + 20;
```

Так делать можно.

Мы не изменяем `maxSpeed`.

Мы создаём новую переменную:

```text
maxSpeed = 100
newSpeed = 120
```

А вот:

```cpp
maxSpeed = maxSpeed + 20;
```

нельзя.

---

# const с разными типами

`const` можно использовать с разными типами.

Целое число:

```cpp
const int maxCount = 100;
```

Дробное число:

```cpp
const double pi = 3.14159;
```

Символ:

```cpp
const char separator = ',';
```

Логическое значение:

```cpp
const bool enabled = true;
```

Строка:

```cpp
const std::string programName = "Robot Controller";
```

Для `std::string` понадобится:

```cpp
#include <string>
```

---

# const не означает "известно во время компиляции"

Это важный момент.

Например:

```cpp
int value;

std::cin >> value;

const int limit = value;
```

Здесь `limit` является `const`.

После создания:

```cpp
limit
```

нельзя изменить.

Но его значение стало известно только во время выполнения программы.

Получается:

```text
программа запускается
      ↓
пользователь вводит значение
      ↓
создаётся const
      ↓
после этого значение нельзя изменить
```

Это всё ещё константный объект.

---

# Константы и ввод пользователя

Например:

```cpp
#include <iostream>

int main() {
    int value;

    std::cin >> value;

    const int selectedValue = value;

    std::cout << selectedValue << '\n';

    return 0;
}
```

Пользователь вводит:

```text
42
```

После этого:

```text
selectedValue = 42
```

и изменить `selectedValue` уже нельзя.

---

# const помогает компилятору

Одна из главных ценностей `const` заключается в том, что компилятор может обнаружить неправильное использование значения.

Например:

```cpp
const int maxRetries = 3;

maxRetries = 10;
```

Компилятор остановит сборку.

Это полезно, потому что ошибка обнаруживается не во время работы программы, а уже при её компиляции.

---

# const делает намерения понятнее

Сравним:

```cpp
int timeout = 5000;
```

и:

```cpp
const int connectionTimeoutMs = 5000;
```

Во втором случае сразу понятно:

```text
connectionTimeoutMs
```

— это время ожидания соединения.

И значение не должно изменяться.

То есть `const` одновременно:

* защищает значение;
* документирует намерение программиста;
* делает код понятнее.

---

# Пример из робототехники

Представим контроллер двигателя.

```cpp
const double maxMotorTemperature = 85.0;
const int maxMotorSpeed = 3000;

double motorTemperature = 72.5;
int motorSpeed = 2500;
```

Теперь программа может проверять:

```cpp
if (motorTemperature > maxMotorTemperature) {
    // остановить двигатель
}
```

и:

```cpp
if (motorSpeed > maxMotorSpeed) {
    // ограничить скорость
}
```

Названия сразу объясняют назначение значений.

---

# Константы для настроек

Можно вынести настройки в начало программы:

```cpp
#include <iostream>

int main() {
    const int serverPort = 8080;
    const int timeoutMs = 5000;
    const int maxRetries = 3;

    std::cout << serverPort << '\n';
    std::cout << timeoutMs << '\n';
    std::cout << maxRetries << '\n';

    return 0;
}
```

Теперь основные параметры программы находятся в одном месте.

Если разрешённое значение действительно должно быть неизменяемым внутри программы, `const` хорошо отражает это правило.

---

# const и безопасность кода

Представим большую программу.

В ней есть значение:

```cpp
const int maxConnections = 100;
```

Через несколько сотен строк кто-то случайно написал:

```cpp
maxConnections = 500;
```

Компилятор сообщит об ошибке.

Без `const` такая ошибка могла бы остаться незамеченной.

Поэтому `const` — не просто способ "обозначить число".

Это инструмент контроля правильности программы.

---

# Полный пример

```cpp
#include <iostream>

int main() {
    const double maxTemperature = 80.0;
    const int maxRetries = 3;

    double temperature = 75.5;
    int retries = 1;

    std::cout << "Temperature: " << temperature << '\n';
    std::cout << "Temperature limit: " << maxTemperature << '\n';

    std::cout << "Retries: " << retries << '\n';
    std::cout << "Maximum retries: " << maxRetries << '\n';

    return 0;
}
```

Здесь:

```text
maxTemperature
maxRetries
```

— постоянные значения.

А:

```text
temperature
retries
```

— изменяемые переменные.

# Главное

Запомните:

* `const` запрещает изменение значения после инициализации;
* `const` нужно инициализировать при создании;
* константы помогают защитить важные значения от случайного изменения;
* именованные константы делают код понятнее;
* `const` помогает убрать магические числа;
* `const` может иметь разные типы;
* значение `const` не обязательно должно быть известно во время компиляции;
* константы особенно полезны для лимитов, настроек, коэффициентов и других значений, которые не должны изменяться внутри программы.

Хороший принцип:

```cpp
const int maxRetries = 3;
```

обычно понятнее и безопаснее, чем многократно использовать в коде просто:

```cpp
3
```
