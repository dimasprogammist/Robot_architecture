# Массивы

## Цель

До этого момента мы хранили значения в отдельных переменных:

```cpp
int a = 10;
int b = 20;
int c = 30;
```

Но если значений становится много, такой подход быстро становится неудобным.

Например, если нужно хранить:

```text
100 температур
1000 измерений датчика
50 скоростей
10000 чисел
```

создавать отдельную переменную для каждого значения невозможно.

Для этого существуют массивы.

В этом уроке разберём:

* что такое массив;
* как создать массив;
* индексы;
* чтение и изменение элементов;
* цикл по массиву;
* размер массива;
* многомерные массивы;
* типичные ошибки при работе с индексами.

---

# Что такое массив

Массив — структура, которая хранит несколько элементов одного типа.

Например:

```cpp
int numbers[5];
```

создаёт массив из пяти элементов типа `int`.

Можно представить его так:

```text
numbers

┌────┬────┬────┬────┬────┐
│    │    │    │    │    │
└────┴────┴────┴────┴────┘
  0    1    2    3    4
```

Под каждым элементом находится индекс.

---

# Индексы начинаются с нуля

Это очень важное правило.

Для массива:

```cpp
int numbers[5];
```

индексы:

```text
0
1
2
3
4
```

Всего пять элементов.

Последний индекс:

```text
4
```

а не `5`.

---

# Создание массива

Например:

```cpp
int numbers[5];
```

Мы создали массив из пяти элементов.

Можно сразу задать значения:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};
```

Получим:

```text
индекс:   0   1   2   3   4
значение: 10  20  30  40  50
```

---

# Доступ к элементу

Чтобы получить элемент массива, используются квадратные скобки:

```cpp
numbers[0]
```

Например:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

std::cout << numbers[0] << '\n';
```

Результат:

```text
10
```

Второй элемент:

```cpp
numbers[1]
```

Результат:

```text
20
```

---

# Последний элемент

Для массива:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};
```

последний элемент:

```cpp
numbers[4]
```

Потому что индексация начинается с нуля.

---

# Изменение элемента

Элемент массива можно изменить:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

numbers[2] = 100;
```

Теперь массив:

```text
10
20
100
40
50
```

---

# Массив и цикл

Массивы особенно удобно обрабатывать с помощью циклов.

Например:

```cpp
#include <iostream>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << '\n';
    }

    return 0;
}
```

Результат:

```text
10
20
30
40
50
```

Переменная:

```cpp
i
```

принимает значения:

```text
0
1
2
3
4
```

---

# Почему условие i < 5

Массив содержит пять элементов:

```text
0
1
2
3
4
```

Поэтому цикл:

```cpp
for (int i = 0; i < 5; i++)
```

обрабатывает все элементы.

Если написать:

```cpp
i <= 5
```

цикл попробует обратиться к:

```cpp
numbers[5]
```

А такого элемента нет.

---

# Выход за границы массива

Обращение:

```cpp
numbers[5]
```

для массива из пяти элементов является ошибкой.

Допустимые индексы:

```text
0–4
```

Недопустимые:

```text
5
6
7
...
```

Такую ошибку называют **выходом за границы массива**.

Она особенно опасна тем, что программа не обязательно сразу завершится с понятной ошибкой.

---

# Размер массива

Можно использовать:

```cpp
sizeof
```

Например:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

std::cout << sizeof(numbers) << '\n';
```

Это вернёт общий размер массива в байтах.

Чтобы получить количество элементов:

```cpp
sizeof(numbers) / sizeof(numbers[0])
```

Например:

```cpp
int numbers[5] = {10, 20, 30, 40, 50};

std::size_t count = sizeof(numbers) / sizeof(numbers[0]);

std::cout << count << '\n';
```

Получим:

```text
5
```

---

# std::size

В современном C++ можно использовать:

```cpp
std::size()
```

Для этого удобно подключить:

```cpp
#include <iterator>
```

Например:

```cpp
#include <iostream>
#include <iterator>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};

    std::cout << std::size(numbers) << '\n';

    return 0;
}
```

Результат:

```text
5
```

Такой вариант проще читать.

---

# Автоматическое определение размера

Можно не указывать размер вручную:

```cpp
int numbers[] = {10, 20, 30, 40, 50};
```

Компилятор сам определит, что элементов пять.

---

# Сумма элементов

Массив удобно использовать для расчётов.

Например:

```cpp
#include <iostream>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};

    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum += numbers[i];
    }

    std::cout << "Sum: " << sum << '\n';

    return 0;
}
```

Результат:

```text
Sum: 150
```

---

# Поиск максимального значения

Можно найти максимальный элемент:

```cpp
#include <iostream>

int main() {
    int numbers[] = {10, 45, 12, 80, 31};

    int maxValue = numbers[0];

    for (int i = 1; i < 5; i++) {
        if (numbers[i] > maxValue) {
            maxValue = numbers[i];
        }
    }

    std::cout << "Maximum: " << maxValue << '\n';

    return 0;
}
```

Результат:

```text
Maximum: 80
```

---

# Массив строк

Массив может содержать не только числа.

Например:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string names[] = {
        "Dmitry",
        "Alex",
        "Ivan"
    };

    for (int i = 0; i < 3; i++) {
        std::cout << names[i] << '\n';
    }

    return 0;
}
```

Результат:

```text
Dmitry
Alex
Ivan
```

# Массив bool

Можно создать массив логических значений:

```cpp
bool sensors[] = {
    true,
    true,
    false,
    true
};
```

Например:

```text
датчик 0 → true
датчик 1 → true
датчик 2 → false
датчик 3 → true
```

# Массив и ввод пользователя

Можно заполнить массив с помощью цикла:

```cpp
#include <iostream>

int main() {
    int numbers[5];

    for (int i = 0; i < 5; i++) {
        std::cin >> numbers[i];
    }

    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << '\n';
    }

    return 0;
}
```

Пользователь может ввести:

```text
10
20
30
40
50
```

Программа сохранит все пять значений.

# Двумерный массив

Массив может иметь несколько измерений.

Например:

```cpp
int matrix[3][4];
```

Это:

```text
3 строки
4 столбца
```

Можно представить:

```text
┌────┬────┬────┬────┐
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
└────┴────┴────┴────┘
```

---

# Заполнение двумерного массива

Для работы с двумерным массивом удобно использовать два цикла:

```cpp
#include <iostream>

int main() {
    int matrix[3][4] = {};

    for (int row = 0; row < 3; row++) {
        for (int column = 0; column < 4; column++) {
            matrix[row][column] = row + column;
        }
    }

    return 0;
}
```

Внешний цикл управляет строкой.

Внутренний — столбцом.

---

# Вывод двумерного массива

```cpp
for (int row = 0; row < 3; row++) {
    for (int column = 0; column < 4; column++) {
        std::cout << matrix[row][column] << ' ';
    }

    std::cout << '\n';
}
```

Получится таблица значений.

# Массивы в робототехнике

Массивы очень часто встречаются в робототехнике.

Например, робот может иметь несколько датчиков:

```cpp
double temperatures[8];
```

или:

```cpp
double distances[12];
```

или:

```cpp
int motorSpeed[6];
```

Тогда можно обработать все значения циклом:

```cpp
for (int i = 0; i < 6; i++) {
    std::cout << "Motor " << i << ": "
              << motorSpeed[i] << '\n';
}
```

Это гораздо удобнее, чем создавать:

```text
motor1
motor2
motor3
motor4
motor5
motor6
```

# Ограничения обычного массива

Обычный массив C++ имеет фиксированный размер.

Например:

```cpp
int numbers[5];
```

Он рассчитан на пять элементов.

Нельзя просто сделать:

```cpp
numbers = новый массив из 10 элементов;
```

Для динамических структур в современном C++ обычно используют:

```cpp
std::vector
```

С ним мы познакомимся позже.

---

# Обычный массив и std::array

В современном C++ существует также:

```cpp
std::array
```

Например:

```cpp
#include <array>

std::array<int, 5> numbers = {
    10, 20, 30, 40, 50
};
```

`std::array` безопаснее и удобнее обычного C-массива во многих ситуациях.

Но сначала важно хорошо понять сам принцип массива.

# Главное

Запомните:

* массив хранит несколько элементов одного типа;
* элементы массива имеют индексы;
* индексация начинается с `0`;
* для массива из пяти элементов индексы находятся в диапазоне `0–4`;
* элемент получают через `numbers[index]`;
* элементы можно изменять;
* циклы очень удобно использовать для обработки массивов;
* выход за границы массива — серьёзная ошибка;
* обычный массив имеет фиксированный размер;
* двумерные массивы можно использовать для таблиц и матриц;
* в современном C++ для фиксированного массива часто используется `std::array`;
* для динамического количества элементов позже будем использовать `std::vector`.

Главная схема:

```text
массив
   ↓
индекс
   ↓
элемент
   ↓
обработка
```

Например:

```cpp
numbers[i]
```

означает:

> взять элемент массива `numbers` с индексом `i`.
