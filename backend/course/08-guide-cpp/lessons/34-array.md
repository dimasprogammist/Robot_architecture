# std::array

## Цель

Обычные массивы C++ существуют давно и остаются частью языка. Однако современный C++ предоставляет более удобную альтернативу для массивов фиксированного размера — `std::array`.

После урока вы должны понимать:

* что такое `std::array`;
* чем он отличается от обычного массива;
* чем `std::array` отличается от `std::vector`;
* как получать размер массива;
* как обращаться к элементам;
* как использовать `std::array` с алгоритмами STL;
* когда стоит выбирать фиксированный массив.

---

## Что такое std::array

`std::array` — контейнер стандартной библиотеки, который хранит фиксированное количество элементов одного типа.

Например:

```cpp
std::array<int, 5> numbers;
```

означает:

> массив из пяти элементов типа `int`.

Размер задаётся при компиляции и не изменяется во время выполнения.

---

## Подключение

Нужно подключить:

```cpp
#include <array>
```

Пример:

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 5> numbers = {
        10, 20, 30, 40, 50
    };

    for (int number : numbers)
    {
        std::cout << number << '\n';
    }

    return 0;
}
```

---

## Обычный массив

До этого мы уже встречали:

```cpp
int numbers[5] = {
    10, 20, 30, 40, 50
};
```

Это встроенный массив языка C++.

Он работает, но предоставляет меньше удобных возможностей стандартной библиотеки.

Например, для обычного массива:

```cpp
int numbers[5];
```

нельзя просто написать:

```cpp
numbers.size();
```

А для `std::array` можно:

```cpp
numbers.size();
```

---

## Размер std::array

Например:

```cpp
std::array<int, 5> numbers;
```

Количество элементов:

```cpp
numbers.size()
```

вернёт:

```text
5
```

Причём размер является частью типа.

Следующие типы различаются:

```cpp
std::array<int, 5>
```

и:

```cpp
std::array<int, 10>
```

Это разные типы.

---

## Индексация

Как и обычный массив, `std::array` поддерживает индексы:

```cpp
std::array<int, 3> numbers = {
    10, 20, 30
};

std::cout << numbers[0];
std::cout << numbers[1];
std::cout << numbers[2];
```

Индексы начинаются с нуля.

---

## Изменение элемента

Элемент можно изменить:

```cpp
numbers[1] = 500;
```

После этого:

```text
10 500 30
```

`std::array` не является неизменяемым только потому, что его размер фиксирован.

Фиксирован именно размер контейнера.

---

## at()

Как и `vector`, `std::array` имеет:

```cpp
at()
```

Например:

```cpp
std::cout << numbers.at(1);
```

При выходе за границы будет выброшено исключение.

Это удобно, когда нужна проверка индекса.

---

## front() и back()

Можно получить первый элемент:

```cpp
numbers.front()
```

и последний:

```cpp
numbers.back()
```

Например:

```cpp
std::cout << numbers.front();
std::cout << numbers.back();
```

Для:

```text
10 20 30 40
```

получим:

```text
10
40
```

---

## std::array не может менять размер

У `std::vector` есть:

```cpp
push_back()
pop_back()
resize()
```

У `std::array` таких операций изменения размера нет.

Например:

```cpp
std::array<int, 3> numbers = {
    10, 20, 30
};
```

нельзя превратить в массив из четырёх элементов:

```text
10 20 30 40
```

Тип `std::array<int, 3>` всегда содержит три элемента.

---

## Когда использовать array

`std::array` подходит, когда количество элементов известно заранее.

Например:

```text
RGB → 3 компонента
XYZ → 3 координаты
матрица 4×4 → 16 элементов
семь дней недели → 7 элементов
фиксированный набор каналов → известное количество
```

Например:

```cpp
std::array<double, 3> position = {
    10.0,
    20.0,
    30.0
};
```

Размер позиции всегда равен трём координатам.

---

## Когда использовать vector

Если количество элементов может изменяться, обычно нужен `std::vector`.

Например:

```cpp
std::vector<Sensor> sensors;
```

Сегодня у робота может быть:

```text
5 датчиков
```

завтра:

```text
8 датчиков
```

Поэтому фиксированный `std::array` здесь может быть неудобен.

---

## Главное различие

Можно запомнить:

```text
std::array
    ↓
размер известен заранее

std::vector
    ↓
размер может изменяться
```

Например:

```cpp
std::array<int, 4> fixed;
```

и:

```cpp
std::vector<int> dynamic;
```

---

## Перебор элементов

Для `std::array` отлично подходит range-based `for`:

```cpp
for (int number : numbers)
{
    std::cout << number << '\n';
}
```

Если элементы не должны изменяться:

```cpp
for (const int number : numbers)
{
    std::cout << number << '\n';
}
```

Для объектов:

```cpp
for (const Sensor& sensor : sensors)
{
    sensor.print();
}
```

---

## Работа с алгоритмами STL

Одна из главных причин использовать `std::array` — он хорошо интегрирован с STL.

Например:

```cpp
#include <algorithm>
#include <array>

std::array<int, 5> numbers = {
    50, 10, 40, 20, 30
};

std::sort(
    numbers.begin(),
    numbers.end()
);
```

После сортировки:

```text
10 20 30 40 50
```

---

## begin() и end()

У `std::array` есть:

```cpp
numbers.begin()
numbers.end()
```

Поэтому можно использовать:

```cpp
std::sort(
    numbers.begin(),
    numbers.end()
);
```

Также можно использовать:

```cpp
std::find()
```

```cpp
auto it = std::find(
    numbers.begin(),
    numbers.end(),
    30
);
```

---

## Заполнение одинаковым значением

Есть удобный метод:

```cpp
numbers.fill(0);
```

Например:

```cpp
std::array<int, 5> numbers;

numbers.fill(0);
```

Получится:

```text
0 0 0 0 0
```

Это удобно для инициализации фиксированного набора значений.

---

## Массив значений датчиков

Представим, что контроллер имеет ровно четыре аналоговых канала:

```cpp
std::array<double, 4> channels = {
    2.1,
    4.8,
    3.2,
    1.9
};
```

Можно обратиться к каждому:

```cpp
std::cout << channels[0];
std::cout << channels[1];
```

Количество каналов является частью конструкции устройства и не меняется во время работы программы.

Здесь `std::array` подходит естественно.

---

## Передача std::array в функцию

Можно передавать массив по ссылке:

```cpp
void print(
    const std::array<int, 5>& numbers
)
{
    for (int number : numbers)
    {
        std::cout << number << '\n';
    }
}
```

Использование:

```cpp
std::array<int, 5> numbers = {
    1, 2, 3, 4, 5
};

print(numbers);
```

Тип и размер массива здесь являются частью сигнатуры функции.

---

## Шаблонная функция для любого размера

Можно написать функцию, которая принимает `std::array` любого размера:

```cpp
template <typename T, std::size_t N>
void print(const std::array<T, N>& values)
{
    for (const T& value : values)
    {
        std::cout << value << '\n';
    }
}
```

Теперь она работает с:

```cpp
std::array<int, 3>
```

и:

```cpp
std::array<double, 10>
```

и:

```cpp
std::array<std::string, 5>
```

Это один из примеров силы шаблонов C++.

---

## std::array и память

`std::array` не использует динамическое изменение размера.

Упрощённо можно представить:

```text
std::array<int, 4>

[10][20][30][40]
```

Размер известен заранее.

Это делает контейнер удобным для структур с фиксированным количеством элементов.

---

## std::array и производительность

`std::array` обычно не требует отдельного динамического выделения памяти для своих элементов, когда сам объект размещён автоматически.

Например:

```cpp
void function()
{
    std::array<int, 100> values;
}
```

Здесь массив является частью объекта `values`.

Это отличается от `std::vector`, который хранит свои элементы в динамически выделяемой памяти.

Важно не превращать это в правило «array всегда быстрее vector». Выбор контейнера должен зависеть прежде всего от структуры данных и требований программы.

---

## Матрица

`std::array` удобно использовать для небольших фиксированных матриц.

Например:

```cpp
std::array<std::array<int, 3>, 3> matrix = {{
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
}};
```

Можно обратиться:

```cpp
std::cout << matrix[1][2];
```

Здесь будет:

```text
6
```

Такая структура полезна в математике, компьютерном зрении, робототехнике и других областях.

---

## Пример с координатами

Можно хранить координаты точки:

```cpp
std::array<double, 3> position = {
    10.5,
    20.0,
    3.2
};
```

И использовать:

```cpp
double x = position[0];
double y = position[1];
double z = position[2];
```

При этом сам тип говорит нам, что координат ровно три.

---

## Сравнение array и vector

```text
std::array
────────────────────────
Размер фиксирован
Размер является частью типа
Нет push_back()
Нет resize()
Хорошо подходит для фиксированных структур


std::vector
────────────────────────
Размер изменяемый
Есть push_back()
Есть resize()
Есть reserve()
Хорошо подходит для динамических коллекций
```

Оба контейнера поддерживают:

```text
operator[]
at()
front()
back()
begin()
end()
size()
```

и хорошо работают с алгоритмами STL.

---

## Практический пример

Представим четыре двигателя робота:

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 4> motorSpeeds = {
        100,
        100,
        95,
        95
    };

    for (std::size_t i = 0;
         i < motorSpeeds.size();
         ++i)
    {
        std::cout << "Motor "
                  << i
                  << ": "
                  << motorSpeeds[i]
                  << '\n';
    }

    return 0;
}
```

Количество двигателей в данной конструкции известно заранее, поэтому `std::array` подходит хорошо.

---

## Главное

`std::array` — современный контейнер для массива фиксированного размера.

Запомните:

```text
std::array<T, N>
```

где:

```text
T → тип элемента
N → фиксированное количество элементов
```

Он удобнее обычного C-массива и отлично работает с STL.

Если количество элементов должно изменяться — используйте `std::vector`.

Если количество элементов известно заранее и является частью структуры данных — `std::array` часто будет естественным выбором.
