# Структура программы C++

## Цель

Мы уже создали и запустили первую программу.

Теперь разберём её подробнее.

Нужно понять, из каких частей состоит программа на C++, зачем нужен `main`, что делают фигурные скобки, почему в конце инструкций ставится `;` и какую роль играют комментарии.

После урока вы сможете читать простые программы на C++ и понимать их общую структуру.

---

# Самая простая программа

Начнём с минимального примера:

```cpp
int main() {
    return 0;
}
```

В программе есть:

```text
int main()
{
    return 0;
}
```

Разберём её по частям.

---

# Функция main

Главная функция программы называется:

```cpp
main
```

Запись:

```cpp
int main()
```

означает объявление функции `main`, которая возвращает значение типа `int`.

Именно с `main` начинается выполнение обычной C++ программы.

Упрощённо:

```text
запуск программы
       ↓
     main()
       ↓
выполнение команд
       ↓
завершение
```

---

# Что такое функция

Функция — это именованный блок программы, который выполняет определённую задачу.

Например:

```cpp
int add(int a, int b) {
    return a + b;
}
```

У этой функции есть:

```text
имя       → add
параметры → a, b
результат → int
```

Функции позволяют разбивать большую программу на отдельные части.

Пока достаточно запомнить:

> `main()` — главная функция, с которой начинается выполнение программы.

Подробно функции мы изучим позже.

---

# Тип int

В записи:

```cpp
int main()
```

слово:

```text
int
```

означает тип возвращаемого значения.

`int` — целочисленный тип.

Например:

```cpp
int number = 10;
```

означает, что `number` хранит целое число.

Функция:

```cpp
int main()
```

должна вернуть целое значение.

Именно для этого используется:

```cpp
return 0;
```

---

# return 0

Строка:

```cpp
return 0;
```

завершает выполнение функции `main` и возвращает значение `0`.

В контексте `main` значение `0` обычно означает успешное завершение программы.

Получается:

```text
main()
   ↓
return 0
   ↓
программа завершилась успешно
```

---

# Фигурные скобки

Фигурные скобки:

```cpp
{
}
```

обозначают блок кода.

Например:

```cpp
int main() {
    return 0;
}
```

Всё между:

```cpp
{
```

и:

```cpp
}
```

относится к функции `main`.

Позже фигурные скобки будут использоваться не только для функций, но и для:

* условий;
* циклов;
* классов;
* структур;
* других блоков программы.

Например:

```cpp
if (number > 10) {
    std::cout << "Big number";
}
```

---

# Точка с запятой

В C++ многие инструкции заканчиваются точкой с запятой:

```cpp
;
```

Например:

```cpp
return 0;
```

или:

```cpp
int number = 10;
```

или:

```cpp
std::cout << "Hello";
```

Точка с запятой сообщает компилятору, что инструкция закончилась.

Сравните:

```cpp
int number = 10;
```

и:

```cpp
int number = 10
```

Второй вариант содержит синтаксическую ошибку.

---

# Почему фигурные скобки не заканчиваются точкой с запятой

У функции:

```cpp
int main() {
    return 0;
}
```

после закрывающей фигурной скобки не требуется:

```cpp
;
```

Потому что фигурная скобка закрывает блок функции.

Но в других конструкциях правила могут отличаться.

Например, объявление класса обычно заканчивается `;`:

```cpp
class Robot {
};
```

Синтаксис C++ нужно изучать постепенно, поэтому не стоит пытаться запомнить все правила сразу.

# Подключение библиотек

В первой программе мы использовали:

```cpp
#include <iostream>
```

Эта строка нужна для работы со стандартным вводом и выводом.

После подключения можно использовать:

```cpp
std::cout
```

Например:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello!\n";
    return 0;
}
```

---

# Что означает #include

Директива:

```cpp
#include
```

говорит препроцессору подключить содержимое указанного заголовочного файла.

В данном случае:

```cpp
#include <iostream>
```

подключает средства стандартной библиотеки для потокового ввода и вывода.

Пока можно воспринимать это упрощённо:

> `#include` позволяет программе получить объявления и возможности из других заголовочных файлов.

Подробнее устройство заголовочных файлов мы рассмотрим позже.

---

# Пространство имён std

В программе:

```cpp
std::cout
```

часть:

```text
std
```

— пространство имён.

А:

```text
cout
```

— объект вывода.

Два двоеточия:

```cpp
::
```

используются для обращения к элементу пространства имён.

Получается:

```cpp
std::cout
```

можно читать примерно как:

> объект `cout` из пространства имён `std`.

---

# Вывод текста

Команда:

```cpp
std::cout << "Hello!\n";
```

выводит текст в консоль.

Оператор:

```cpp
<<
```

передаёт данные в поток вывода.

Например:

```cpp
std::cout << "Hello!\n";
std::cout << "C++ is interesting.\n";
```

Результат:

```text
Hello!
C++ is interesting.
```

---

# Символ \n

В строке:

```cpp
"Hello!\n"
```

последовательность:

```text
\n
```

означает перевод строки.

Например:

```cpp
std::cout << "First\n";
std::cout << "Second\n";
```

получим:

```text
First
Second
```

Без `\n`:

```cpp
std::cout << "First";
std::cout << "Second";
```

результат будет:

```text
FirstSecond
```

# Комментарии

Комментарии позволяют оставлять пояснения внутри исходного кода.

Однострочный комментарий начинается с:

```cpp
//
```

Например:

```cpp
// Это комментарий
int number = 10;
```

Компилятор не выполняет текст комментария как код.

---

# Многострочные комментарии

Можно написать:

```cpp
/*
    Это многострочный
    комментарий.
*/
```

Например:

```cpp
/*
    Программа выводит
    приветственное сообщение.
*/

#include <iostream>

int main() {
    std::cout << "Hello!\n";
    return 0;
}
```

Комментарии полезны для объяснения сложных участков программы.

Но не стоит комментировать каждую очевидную строку.

Например:

```cpp
int number = 10; // создаём переменную number типа int со значением 10
```

Такой комментарий часто не добавляет полезной информации.

---

# Программа выполняется сверху вниз

Рассмотрим:

```cpp
#include <iostream>

int main() {
    std::cout << "First\n";
    std::cout << "Second\n";
    std::cout << "Third\n";

    return 0;
}
```

Внутри `main` инструкции выполняются последовательно:

```text
1. вывести First
2. вывести Second
3. вывести Third
4. вернуть 0
```

Результат:

```text
First
Second
Third
```

Позже мы научимся менять этот порядок с помощью условий, циклов, функций и других конструкций.

---

# Несколько функций

В программе может быть несколько функций:

```cpp
#include <iostream>

void hello() {
    std::cout << "Hello!\n";
}

int main() {
    hello();

    return 0;
}
```

Здесь есть две функции:

```text
hello()
main()
```

Выполнение начинается с:

```cpp
main()
```

Внутри `main` вызывается:

```cpp
hello();
```

После этого выполнение возвращается обратно в `main`.

Упрощённо:

```text
main()
  ↓
hello()
  ↓
main()
  ↓
завершение
```

# Полная простая программа

Теперь соберём всё вместе:

```cpp
#include <iostream>

// Главная функция программы
int main() {
    std::cout << "Hello!\n";
    std::cout << "I am learning C++.\n";

    return 0;
}
```

Здесь:

```text
#include <iostream>
```

подключает средства ввода-вывода.

```text
int main()
```

объявляет главную функцию.

```text
{
}
```

определяют тело функции.

```text
std::cout
```

выводит информацию.

```text
return 0;
```

завершает функцию.

# Типичная структура программы

На первых этапах большинство небольших программ будет выглядеть примерно так:

```cpp
#include <iostream>

int main() {
    // код программы

    return 0;
}
```

Позже программа может стать намного сложнее:

```text
заголовочные файлы
      ↓
пространства имён
      ↓
структуры
      ↓
классы
      ↓
функции
      ↓
main()
      ↓
объекты
      ↓
алгоритмы
```

Но основная идея останется той же: программа состоит из инструкций и конструкций языка, организованных в понятную структуру.

# Главное

Нужно понимать следующие элементы:

```cpp
#include <iostream>

int main() {
    std::cout << "Hello!\n";
    return 0;
}
```

* `#include` подключает заголовочные файлы;
* `main()` — главная функция программы;
* `int` — тип возвращаемого значения;
* `{}` обозначают блок кода;
* `;` завершает многие инструкции;
* `std::cout` используется для вывода;
* `return 0` завершает `main` с кодом успешного завершения;
* `//` и `/* ... */` используются для комментариев;
* инструкции внутри обычного блока выполняются последовательно.
