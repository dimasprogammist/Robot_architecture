# Переменные и типы данных

## Цель

Практически любая программа работает с данными.

Программа может хранить:

* числа;
* текст;
* логические значения;
* результаты вычислений;
* состояния устройств;
* координаты;
* измерения датчиков.

В C++ для хранения данных используются **переменные**.

В этом уроке разберём:

* что такое переменная;
* что такое тип данных;
* основные встроенные типы C++;
* объявление и инициализацию;
* изменение значения переменной;
* арифметические операции;
* целочисленное деление;
* оператор `sizeof`.

---

# Что такое переменная

Переменная — это именованная область памяти, в которой программа хранит некоторое значение.

Например:

```cpp
int age = 25;
```

Здесь:

```text
int
```

— тип данных.

```text
age
```

— имя переменной.

```text
25
```

— начальное значение.

Можно представить это так:

```text
age
 ↓
┌─────────┐
│   25    │
└─────────┘
```

Переменная имеет имя, тип и текущее значение.

---

# Зачем нужны типы

Компьютеру нужно понимать, какие данные хранятся в памяти.

Например:

```cpp
int count = 10;
```

и:

```cpp
double temperature = 24.5;
```

хранят разные виды данных.

`count` — целое число.

`temperature` — число с дробной частью.

Тип определяет, какие значения допустимы и какие операции можно выполнять с данными.

---

# int

Тип:

```cpp
int
```

используется для целых чисел.

Например:

```cpp
int age = 30;
int count = 100;
int temperature = -5;
```

Можно выполнять арифметические операции:

```cpp
int a = 10;
int b = 3;

int sum = a + b;
int difference = a - b;
int product = a * b;
```

---

# double

Тип:

```cpp
double
```

используется для чисел с дробной частью.

Например:

```cpp
double temperature = 23.5;
double weight = 72.4;
double voltage = 24.0;
```

Можно выполнять:

```cpp
double a = 10.5;
double b = 2.0;

double result = a / b;
```

Результат:

```text
5.25
```

---

# char

Тип:

```cpp
char
```

предназначен для хранения одного символа.

Например:

```cpp
char letter = 'A';
```

Обратите внимание на одинарные кавычки:

```cpp
'A'
```

Это символ.

А:

```cpp
"A"
```

— строка.

Например:

```cpp
char grade = 'A';
```

---

# bool

Тип:

```cpp
bool
```

может хранить логическое значение:

```text
true
false
```

Например:

```cpp
bool isRunning = true;
bool isError = false;
```

Это особенно полезно для описания состояний.

Например, в программе управления роботом:

```cpp
bool motorEnabled = true;
```

может означать, что двигатель разрешён к работе.

---

# std::string

Для хранения текста используется:

```cpp
std::string
```

Для этого необходимо подключить:

```cpp
#include <string>
```

Например:

```cpp
#include <string>

int main() {
    std::string name = "Dmitry";

    return 0;
}
```

Строка может содержать несколько символов.

```text
D
m
i
t
r
y
```

Подробнее со строками мы разберёмся отдельно.

---

# Основные типы

На данном этапе достаточно знать:

| Тип | Назначение | Пример |
|---|---|---|
| `int` | целые числа | `42` |
| `double` | дробные числа | `3.14` |
| `char` | один символ | `'A'` |
| `bool` | логическое значение | `true` |
| `std::string` | текст | `"Hello"` |

Позже мы рассмотрим и другие типы.

---

# Объявление переменной

Можно сначала объявить переменную:

```cpp
int number;
```

На этом этапе переменная существует, но мы ещё не присвоили ей нужное значение.

Затем:

```cpp
number = 10;
```

Теперь значение:

```text
10
```

---

# Инициализация

Можно сразу создать переменную со значением:

```cpp
int number = 10;
```

Это называется инициализацией.

В большинстве случаев такой вариант удобнее:

```cpp
int number = 10;
```

чем:

```cpp
int number;
number = 10;
```

---

# Изменение значения

Значение обычной переменной можно изменить:

```cpp
int number = 10;

number = 20;
```

Теперь:

```text
number = 20
```

Можно изменить его ещё раз:

```cpp
number = 50;
```

Теперь:

```text
number = 50
```

То есть переменная может менять своё значение во время выполнения программы.

---

# Вывод переменной

Для вывода используем `std::cout`:

```cpp
#include <iostream>

int main() {
    int age = 25;

    std::cout << age << '\n';

    return 0;
}
```

Результат:

```text
25
```

Можно вывести несколько значений:

```cpp
int age = 25;
int year = 2026;

std::cout << age << '\n';
std::cout << year << '\n';
```

---

# Текст и переменные

Можно комбинировать текст и значения:

```cpp
int age = 25;

std::cout << "Age: " << age << '\n';
```

Получим:

```text
Age: 25
```

Другой пример:

```cpp
double temperature = 24.5;

std::cout << "Temperature: " << temperature << '\n';
```

Результат:

```text
Temperature: 24.5
```

---

# Арифметические операции

Для чисел доступны основные арифметические операции.

Сложение:

```cpp
+
```

Вычитание:

```cpp
-
```

Умножение:

```cpp
*
```

Деление:

```cpp
/
```

Остаток от деления:

```cpp
%
```

Например:

```cpp
int a = 10;
int b = 3;

std::cout << a + b << '\n';
std::cout << a - b << '\n';
std::cout << a * b << '\n';
std::cout << a / b << '\n';
std::cout << a % b << '\n';
```

---

# Целочисленное деление

Это важная особенность C++.

Если оба числа имеют тип `int`:

```cpp
int a = 10;
int b = 3;

int result = a / b;
```

результат будет:

```text
3
```

а не:

```text
3.333333
```

Почему?

Потому что выполняется целочисленное деление.

Если нужен дробный результат, нужно использовать тип с дробной частью:

```cpp
double a = 10;
double b = 3;

double result = a / b;
```

Теперь результат будет примерно:

```text
3.33333
```

---

# Остаток от деления

Оператор:

```cpp
%
```

возвращает остаток от целочисленного деления.

Например:

```cpp
int result = 10 % 3;
```

Получим:

```text
1
```

Потому что:

```text
10 = 3 * 3 + 1
```

Остаток равен `1`.

Это часто используется, например, чтобы проверить чётность числа:

```cpp
int number = 10;

int remainder = number % 2;
```

Если остаток:

```text
0
```

число чётное.

---

# Размер типа

Для определения размера типа в памяти можно использовать:

```cpp
sizeof
```

Например:

```cpp
#include <iostream>

int main() {
    std::cout << sizeof(int) << '\n';
    std::cout << sizeof(double) << '\n';
    std::cout << sizeof(char) << '\n';
    std::cout << sizeof(bool) << '\n';

    return 0;
}
```

Результат зависит от платформы и компилятора.

На многих современных системах можно увидеть:

```text
4
8
1
1
```

Числа означают количество байт.

Например:

```text
sizeof(int) == 4
```

означает, что `int` занимает 4 байта на данной системе.

---

# Почему размер типа важен

Память компьютера ограничена.

Если программа работает с небольшим количеством чисел, это может быть незаметно.

Но представьте программу, которая хранит:

```text
100 000 000 чисел
```

Разница между типами данных может стать существенной.

Кроме того, разные типы позволяют представлять разные диапазоны значений.

Поэтому тип данных — это не просто формальность.

Он связан с тем:

* какие значения можно хранить;
* сколько памяти используется;
* какие операции доступны;
* как данные интерпретируются компьютером.

---

# Имена переменных

Хорошее имя должно объяснять назначение переменной.

Плохо:

```cpp
int x = 25;
```

Если `x` означает возраст, лучше:

```cpp
int age = 25;
```

Если это количество изделий:

```cpp
int productCount = 25;
```

Если это температура:

```cpp
double temperature = 25.0;
```

Читаемый код намного проще поддерживать.

---

# Имена в стиле C++

Обычно в C++ часто используется `camelCase`:

```cpp
int productCount;
double targetTemperature;
bool motorEnabled;
```

Также можно встретить `snake_case`:

```cpp
int product_count;
double target_temperature;
bool motor_enabled;
```

Главное — придерживаться единого стиля внутри проекта.

# Полная программа

Рассмотрим небольшой пример:

```cpp
#include <iostream>

int main() {
    int width = 10;
    int height = 5;

    int area = width * height;

    std::cout << "Width: " << width << '\n';
    std::cout << "Height: " << height << '\n';
    std::cout << "Area: " << area << '\n';

    return 0;
}
```

Результат:

```text
Width: 10
Height: 5
Area: 50
```

Здесь программа:

1. создаёт две переменные;
2. выполняет вычисление;
3. сохраняет результат;
4. выводит данные.

# Главное

Запомните:

* переменная хранит значение;
* у каждой переменной есть тип;
* `int` используется для целых чисел;
* `double` — для дробных чисел;
* `char` хранит один символ;
* `bool` хранит `true` или `false`;
* `std::string` используется для текста;
* значение обычной переменной можно изменять;
* `sizeof` позволяет узнать размер типа или объекта в байтах;
* при делении двух `int` получается целочисленный результат;
* `%` возвращает остаток от целочисленного деления;
* хорошие имена переменных делают код понятнее.
