# struct

## Цель

До этого момента мы работали в основном с отдельными переменными: числами, строками, указателями и другими простыми значениями. Но реальные программы работают с объектами, которые состоят сразу из нескольких связанных между собой данных. В C++ для объединения таких данных можно использовать `struct`.

После урока вы должны понимать:

* зачем нужны структуры;
* как объявлять `struct`;
* как создавать переменные-объекты структуры;
* как обращаться к полям через `.`;
* как инициализировать структуры;
* как передавать структуры в функции;
* чем структура отличается от набора отдельных переменных.

---

## Что такое структура

Представим, что программе нужно хранить информацию об устройстве робота. У устройства может быть имя, адрес, напряжение и текущее состояние.

Можно создать несколько отдельных переменных:

```cpp
std::string name = "Motor 1";
int address = 10;
double voltage = 24.0;
bool enabled = true;
```

Проблема в том, что эти переменные логически связаны, но сам язык никак не сообщает об этой связи. Можно случайно использовать `address` от одного устройства вместе с `voltage` другого.

Структура позволяет объединить связанные значения в один тип данных:

```cpp
struct Device
{
    std::string name;
    int address;
    double voltage;
    bool enabled;
};
```

Теперь `Device` становится новым типом данных, который описывает устройство.

---

## Объявление struct

Общая форма структуры выглядит так:

```cpp
struct Имя
{
    тип поле1;
    тип поле2;
    тип поле3;
};
```

Например:

```cpp
struct Point
{
    double x;
    double y;
};
```

Здесь мы создали собственный тип `Point`. Он содержит два поля: `x` и `y`.

После объявления структуры можно создавать переменные этого типа:

```cpp
Point point;

point.x = 10.5;
point.y = 20.0;
```

Точка теперь представляет собой один объект, внутри которого находятся два значения.

---

## Поля структуры

Переменные внутри структуры называются полями.

Например:

```cpp
struct Robot
{
    std::string name;
    int battery;
    double speed;
};
```

У структуры `Robot` есть три поля:

```text
name
battery
speed
```

Создадим объект:

```cpp
Robot robot;

robot.name = "R2";
robot.battery = 87;
robot.speed = 1.5;
```

Для обращения к полю используется оператор `.`:

```cpp
robot.name
robot.battery
robot.speed
```

Точка означает примерно: «получить член этого объекта».

---

## Инициализация структуры

Структуру можно заполнить сразу при создании:

```cpp
Robot robot{"R2", 87, 1.5};
```

Значения записываются в порядке объявления полей:

```cpp
struct Robot
{
    std::string name;
    int battery;
    double speed;
};
```

Поэтому:

```cpp
Robot robot{"R2", 87, 1.5};
```

означает:

```text
name    = "R2"
battery = 87
speed   = 1.5
```

Такой способ удобен, когда все значения известны заранее.

---

## Значения по умолчанию

Можно задать значения полей непосредственно в структуре:

```cpp
struct Robot
{
    std::string name = "Unknown";
    int battery = 0;
    double speed = 0.0;
};
```

Теперь:

```cpp
Robot robot;
```

создаст объект с начальными значениями:

```text
name    = "Unknown"
battery = 0
speed   = 0
```

Это особенно удобно, когда объект должен иметь безопасное начальное состояние.

---

## Несколько объектов одной структуры

Главное преимущество структуры заключается в том, что после определения типа можно создавать сколько угодно объектов.

```cpp
Robot robot1{"R1", 90, 1.2};
Robot robot2{"R2", 70, 1.5};
Robot robot3{"R3", 45, 0.8};
```

Каждый объект имеет собственные значения.

```cpp
std::cout << robot1.name << '\n';
std::cout << robot2.name << '\n';
std::cout << robot3.name << '\n';
```

При этом все три объекта имеют одинаковую структуру.

Можно представить это так:

```text
Robot
 ├── name
 ├── battery
 └── speed

robot1 → свои значения
robot2 → свои значения
robot3 → свои значения
```

## Структуры и функции

Структуры особенно полезны при работе с функциями.

Например:

```cpp
struct Point
{
    double x;
    double y;
};

void printPoint(Point point)
{
    std::cout << "("
              << point.x
              << ", "
              << point.y
              << ")\n";
}
```

Теперь:

```cpp
Point p{10.0, 20.0};

printPoint(p);
```

Функция получает целый объект `Point`.

Для больших объектов обычно не стоит без необходимости копировать структуру. Позже мы подробно разберём передачу объектов по ссылке:

```cpp
void printPoint(const Point& point)
{
    std::cout << point.x << ' ' << point.y << '\n';
}
```

Здесь объект не копируется, а функция получает ссылку на существующий объект.

---

## Изменение структуры через функцию

Если нужно изменить объект, его можно передать по ссылке:

```cpp
struct Robot
{
    std::string name;
    int battery;
};

void charge(Robot& robot)
{
    robot.battery = 100;
}
```

Использование:

```cpp
Robot robot{"R1", 30};

charge(robot);

std::cout << robot.battery;
```

После вызова `charge()` значение `battery` изменится с `30` на `100`.

Здесь используется обычная ссылка `Robot&`, которую мы изучили в предыдущем разделе.

---

## Вложенные структуры

Структуры могут содержать другие структуры.

Например:

```cpp
struct Position
{
    double x;
    double y;
};

struct Robot
{
    std::string name;
    Position position;
};
```

Теперь можно создать робота:

```cpp
Robot robot{
    "R1",
    {10.0, 20.0}
};
```

Доступ к координатам выглядит так:

```cpp
robot.position.x
robot.position.y
```

Такая организация позволяет описывать сложные объекты небольшими понятными частями.

---

## Массив структур

Структуры хорошо сочетаются с массивами:

```cpp
Robot robots[3] =
{
    {"R1", 90},
    {"R2", 70},
    {"R3", 50}
};
```

Теперь можно пройти по всем роботам:

```cpp
for (const Robot& robot : robots)
{
    std::cout << robot.name
              << ": "
              << robot.battery
              << "%\n";
}
```

В реальных программах вместо обычных массивов часто используется `std::vector`, который мы подробно рассмотрим позже.

---

## struct может содержать функции

В C++ структура может содержать не только данные, но и функции.

Например:

```cpp
struct Robot
{
    std::string name;
    int battery;

    void print()
    {
        std::cout << name
                  << ": "
                  << battery
                  << "%\n";
    }
};
```

Теперь:

```cpp
Robot robot{"R1", 80};

robot.print();
```

Функция `print()` является частью структуры.

Это уже начинает напоминать объектно-ориентированное программирование. В следующем уроке мы увидим `class` и разберём, как структуры и классы связаны между собой.

---

## struct и class

В C++ `struct` и `class` очень похожи. Оба позволяют объединять данные и функции в пользовательский тип.

Главное различие по умолчанию связано с доступом к членам:

```cpp
struct Data
{
    int value;
};
```

У `struct` члены по умолчанию `public`.

У `class` они по умолчанию `private`:

```cpp
class Data
{
    int value;
};
```

Это не означает, что `struct` предназначен только для данных, а `class` только для сложных объектов. В C++ оба механизма гораздо гибче.

Обычно `struct` удобно использовать для небольших типов, где данные должны быть открыты, а `class` — когда объект должен скрывать внутреннее состояние и управлять доступом к нему.

---

## Практический пример

Представим небольшую систему мониторинга датчиков:

```cpp
#include <iostream>
#include <string>

struct Sensor
{
    std::string name;
    double value;
    std::string unit;
};

void printSensor(const Sensor& sensor)
{
    std::cout << sensor.name
              << ": "
              << sensor.value
              << " "
              << sensor.unit
              << '\n';
}

int main()
{
    Sensor temperature{
        "Temperature",
        24.5,
        "C"
    };

    Sensor pressure{
        "Pressure",
        1.2,
        "bar"
    };

    printSensor(temperature);
    printSensor(pressure);

    return 0;
}
```

Здесь структура `Sensor` описывает общий формат датчика. Каждый конкретный датчик является отдельным объектом этой структуры.

Такой подход намного понятнее, чем хранить все значения в отдельных массивах или несвязанных переменных.

---

## Главное

`struct` позволяет создать собственный тип данных, объединяющий несколько связанных значений. Поля структуры доступны через оператор `.`:

```cpp
object.field
```

Структуры можно передавать в функции, хранить в массивах, вкладывать друг в друга и даже добавлять в них методы.

В современном C++ `struct` часто используется для небольших типов данных, а `class` — для объектов, у которых важны инкапсуляция и управление состоянием.
