# Динамическая память

## Цель

До этого момента большинство объектов создавались с известным размером и временем жизни. Но в реальных программах количество данных часто становится известно только во время выполнения программы.

Например, программа может получить от пользователя количество устройств, узнать размер сетевого пакета или определить количество элементов после чтения файла. Для таких задач существует динамическое выделение памяти.

После урока вы должны понимать:

* что такое динамическая память;
* зачем она нужна;
* чем она отличается от локальных переменных;
* почему размер данных иногда нельзя определить заранее;
* что означает выделить память во время выполнения;
* что такое динамический массив;
* почему ручное управление памятью требует осторожности;
* почему современный C++ обычно предпочитает контейнеры и умные указатели.

---

## Почему иногда недостаточно обычного массива

Предположим, нам нужно хранить значения десяти датчиков:

```cpp
double values[10];
```

Здесь размер известен заранее.

Но что делать, если количество датчиков вводит пользователь?

```text
Введите количество датчиков:
?
```

В этот момент программа может ещё не знать, сколько элементов потребуется.

В старом стиле C++ можно было создать динамический массив:

```cpp
int size;

std::cin >> size;

int* values = new int[size];
```

Память выделяется во время выполнения программы.

---

## Что такое динамическая память

Динамическая память — это память, которую программа запрашивает во время выполнения.

Упрощённо можно представить память процесса как несколько областей:

```text
Программа
│
├── код
├── глобальные данные
├── стек
└── динамическая память
```

Локальные переменные обычно связаны со стеком, а память, которую программа получает через динамическое выделение, относится к динамической области.

Это упрощённая модель. Реальное устройство памяти процесса зависит от операционной системы, компилятора и архитектуры.

---

## Размер во время выполнения

Рассмотрим:

```cpp
int size;

std::cin >> size;
```

Теперь значение `size` известно только во время выполнения.

Можно запросить память:

```cpp
int* values = new int[size];
```

Если пользователь ввёл:

```text
100
```

будет создано место для 100 элементов `int`.

Если:

```text
10000
```

потребуется место для 10000 элементов.

---

## Динамический массив

После:

```cpp
int* values = new int[size];
```

`values` является указателем на первый элемент выделенной области.

Можно обращаться к элементам:

```cpp
values[0] = 10;
values[1] = 20;
values[2] = 30;
```

Можно использовать цикл:

```cpp
for (int i = 0; i < size; i++)
{
    values[i] = i * 10;
}
```

С точки зрения обращения к элементам динамический массив похож на обычный массив.

---

## Чем динамический массив отличается от обычного

Обычный массив:

```cpp
int values[10];
```

имеет размер, известный при компиляции.

Динамический:

```cpp
int* values = new int[size];
```

получает размер во время выполнения.

Но есть важное отличие: динамическую память необходимо правильно освободить.

Позже это будет подробно разобрано в уроке про `new` и `delete`.

---

## Память и указатель

Когда выполняется:

```cpp
int* values = new int[size];
```

происходит примерно следующее:

```text
динамическая память
┌────┬────┬────┬────┬────┐
│    │    │    │    │ ...│
└────┴────┴────┴────┴────┘
  ↑
values
```

Сам `values` является обычной переменной-указателем.

Он хранит адрес выделенной области.

Важно различать:

```text
values
```

и память, на которую он указывает.

---

## Почему память нельзя просто забыть

Представим:

```cpp
int* values = new int[100];
```

Если программа потеряет значение `values`, она больше не сможет обратиться к выделенной области.

Например:

```cpp
values = nullptr;
```

После этого адрес потерян.

Память всё ещё была выделена, но программа больше не знает, где она находится.

Это называется утечкой памяти.

---

## Утечка памяти

Утечка выглядит примерно так:

```cpp
void test()
{
    int* values = new int[100];

    // работа
}
```

Когда функция завершится, локальная переменная `values` исчезнет.

Но выделенная динамическая память сама по себе не обязана освободиться.

Получается:

```text
values → память
```

а затем:

```text
values уничтожен
       ↓
адрес потерян
       ↓
память осталась занята
```

Это и есть memory leak.

---

## Почему это проблема

Одна маленькая утечка может быть незаметной.

Но если функция вызывается тысячи или миллионы раз:

```cpp
for (int i = 0; i < 1000000; i++)
{
    // выделение памяти
}
```

неосвобождённая память постепенно будет занимать всё больше ресурсов.

Для длительно работающих программ это особенно опасно.

Например:

```text
сервер
↓
работает несколько дней
↓
постепенно теряет память
↓
потребление RAM растёт
↓
система начинает испытывать нехватку памяти
```

---

## Динамическая память и время жизни

Главное отличие динамической памяти от обычной локальной переменной заключается в том, что её время жизни не привязано напрямую к выходу из блока.

Например:

```cpp
void test()
{
    int value = 10;
}
```

`value` уничтожается при выходе из функции.

А:

```cpp
void test()
{
    int* value = new int(10);
}
```

выделенная память не должна рассматриваться как автоматически освобождаемая только потому, что исчез указатель.

Поэтому управление динамической памятью требует отдельного механизма.

---

## Когда динамическая память может быть нужна

Исторически динамическая память активно использовалась, когда:

* размер данных неизвестен заранее;
* объект должен жить дольше текущего блока;
* требуется создать большое количество объектов;
* создаются структуры данных с изменяемым размером;
* требуется ручное управление ресурсами.

Но современный C++ предоставляет более безопасные абстракции.

---

## Современный подход

Вместо:

```cpp
int* values = new int[size];
```

обычно лучше использовать:

```cpp
std::vector<int> values(size);
```

Теперь контейнер сам управляет своей памятью.

Например:

```cpp
std::vector<int> values(size);

for (int i = 0; i < size; i++)
{
    values[i] = i;
}
```

Когда `values` выходит из области видимости, его память автоматически освобождается.

Это значительно снижает количество ошибок.

---

## Динамическая память и объекты

Динамически можно создавать не только числа:

```cpp
class Robot
{
public:
    std::string name;
};
```

Можно написать:

```cpp
Robot* robot = new Robot;
```

Теперь объект `Robot` находится в динамической памяти.

Можно обращаться к нему через:

```cpp
robot->name = "R1";
```

Оператор `->` используется для доступа к члену объекта через указатель.

Позже мы подробнее разберём этот оператор.

---

## Указатель не владеет памятью автоматически

Очень важно не думать:

```cpp
int* pointer;
```

означает, что указатель автоматически управляет памятью.

Нет.

Указатель — это просто переменная, содержащая адрес.

Например:

```cpp
int value = 10;
int* pointer = &value;
```

`pointer` не должен освобождать `value`.

`value` вообще не был создан через `new`.

---

## Владение памятью

Когда программа использует динамическую память, возникает понятие владения.

Нужно понимать:

```text
Кто отвечает за освобождение памяти?
```

Если ответ неизвестен, программа становится опасной.

Например:

```cpp
int* data = new int[100];
```

кто должен отвечать за эту память?

Если один участок программы считает, что память принадлежит ему, а другой считает так же, могут возникнуть ошибки:

```text
двойное освобождение
```

Если никто не считает себя владельцем:

```text
утечка памяти
```

Именно поэтому современный C++ стремится использовать объекты, которые явно управляют временем жизни ресурсов.

---

## Практический пример

Рассмотрим старый стиль создания массива:

```cpp
#include <iostream>

int main()
{
    int size;

    std::cout << "Size: ";
    std::cin >> size;

    int* values = new int[size];

    for (int i = 0; i < size; i++)
    {
        values[i] = i * 10;
    }

    for (int i = 0; i < size; i++)
    {
        std::cout << values[i] << '\n';
    }

    delete[] values;

    return 0;
}
```

Здесь память выделяется:

```cpp
new int[size]
```

а освобождается:

```cpp
delete[] values;
```

Подробно правила `new` и `delete` мы рассмотрим в следующем уроке.

---

## Главное

Динамическая память позволяет программе получать память во время выполнения, когда размер или время жизни данных заранее неизвестны.

Исторически для этого активно использовались:

```cpp
new
delete
new[]
delete[]
```

Но ручное управление памятью связано с большим количеством потенциальных ошибок. В современном C++ для большинства обычных задач предпочтительнее использовать `std::vector`, `std::string`, `std::unique_ptr` и другие RAII-объекты, которые автоматически управляют временем жизни ресурсов.
