# Ссылки

## Цель

В предыдущем уроке мы познакомились с указателями — переменными, которые хранят адрес других объектов. Теперь рассмотрим другой механизм C++, который позволяет работать с существующим объектом через другое имя: ссылку.

Ссылки используются очень часто. Они особенно важны при передаче объектов в функции, потому что позволяют работать с исходным объектом без создания его копии.

После урока вы должны понимать:

* что такое ссылка;
* как объявлять ссылки;
* чем ссылка отличается от указателя;
* как изменять объект через ссылку;
* как передавать аргументы по ссылке;
* зачем нужна `const`-ссылка;
* почему ссылка не является отдельным объектом;
* какие ограничения существуют у ссылок.

---

## Что такое ссылка

Ссылка — это другое имя для уже существующего объекта.

Например:

```cpp
int value = 10;

int& reference = value;
```

Здесь:

```cpp
value
```

является обычной переменной, а:

```cpp
reference
```

является ссылкой на неё.

Теперь обе записи обращаются к одному и тому же объекту:

```cpp
value = 20;

std::cout << reference;
```

Результат:

```text
20
```

Если изменить значение через ссылку:

```cpp
reference = 30;

std::cout << value;
```

получим:

```text
30
```

Никакой второй `int` здесь не создаётся. `reference` — это другое имя для `value`.

---

## Ссылка должна быть инициализирована

Ссылку нельзя просто объявить без объекта:

```cpp
int& reference;
```

Такой код некорректен.

Нужно сразу указать объект:

```cpp
int value = 10;
int& reference = value;
```

После этого `reference` связан с `value`.

---

## Ссылка не является копией

Рассмотрим:

```cpp
int value = 10;
int copy = value;
```

Здесь создаются два отдельных объекта:

```text
value = 10
copy  = 10
```

Изменение:

```cpp
copy = 50;
```

не изменит `value`.

Со ссылкой ситуация другая:

```cpp
int value = 10;
int& reference = value;

reference = 50;
```

Теперь:

```text
value     = 50
reference → value
```

Ссылка не хранит независимую копию значения.

---

## Ссылка и адрес

У объекта и его ссылки будет один и тот же адрес:

```cpp
int value = 10;
int& reference = value;

std::cout << &value << '\n';
std::cout << &reference << '\n';
```

Оба адреса будут одинаковыми.

Это связано с тем, что ссылка является другим именем существующего объекта.

---

## Ссылка в качестве параметра функции

Одна из самых важных областей применения ссылок — передача аргументов в функции.

Рассмотрим обычную передачу по значению:

```cpp
void setZero(int value)
{
    value = 0;
}
```

Вызов:

```cpp
int number = 100;

setZero(number);

std::cout << number;
```

выведет:

```text
100
```

Функция получила копию `number`.

---

## Передача по ссылке

Теперь изменим функцию:

```cpp
void setZero(int& value)
{
    value = 0;
}
```

Вызов:

```cpp
int number = 100;

setZero(number);

std::cout << number;
```

Результат:

```text
0
```

Функция работает непосредственно с исходной переменной.

---

## Почему это полезно

Представим большую структуру:

```cpp
struct Robot
{
    std::string name;
    double x;
    double y;
    double speed;
};
```

Если передать её по значению:

```cpp
void printRobot(Robot robot)
{
    // ...
}
```

создаётся копия объекта.

Для небольших объектов это может быть нормально, но большие объекты копировать без необходимости не стоит.

Можно передать объект по ссылке:

```cpp
void printRobot(Robot& robot)
{
    // ...
}
```

Теперь функция получает доступ к исходному объекту.

---

## const-ссылка

Часто объект нужно передать без копирования, но изменять его нельзя.

Для этого используется `const`-ссылка:

```cpp
void printRobot(const Robot& robot)
{
    std::cout << robot.name << '\n';
}
```

Такая функция:

* не создаёт копию `Robot`;
* может читать объект;
* не может изменять его через `robot`.

Попытка:

```cpp
robot.x = 100;
```

будет ошибкой компиляции.

---

## Почему const-ссылка так распространена

Конструкция:

```cpp
const Type&
```

очень часто используется в C++.

Например:

```cpp
void printName(const std::string& name)
{
    std::cout << name;
}
```

Если строка большая, функция не создаёт лишнюю копию.

При этом `const` защищает исходную строку от изменения.

Поэтому для многих функций, которые только читают сложный объект, удобно использовать:

```cpp
const Type&
```

---

## Ссылка и указатель

Ссылки и указатели позволяют работать с существующими объектами, но между ними есть важные различия.

Указатель:

```cpp
int* pointer = &value;
```

Ссылка:

```cpp
int& reference = value;
```

Через указатель нужно использовать разыменование:

```cpp
*pointer = 20;
```

Через ссылку можно обращаться напрямую:

```cpp
reference = 20;
```

Указатель может быть `nullptr`:

```cpp
int* pointer = nullptr;
```

Обычная ссылка должна ссылаться на существующий объект:

```cpp
int& reference = value;
```

---

## Указатель можно переназначить

Например:

```cpp
int a = 10;
int b = 20;

int* pointer = &a;

pointer = &b;
```

Теперь `pointer` указывает на `b`.

Ссылка работает иначе:

```cpp
int a = 10;
int b = 20;

int& reference = a;
```

После этого `reference` остаётся ссылкой на `a`.

Запись:

```cpp
reference = b;
```

не переключает ссылку на `b`. Она копирует значение `b` в объект `a`.

То есть:

```cpp
reference = b;
```

означает примерно:

```cpp
a = b;
```

---

## У ссылки нет nullptr

Обычная ссылка не может быть пустой:

```cpp
int& reference = nullptr;
```

так сделать нельзя.

Это одно из важных отличий от указателя.

Если функция требует обязательный существующий объект, ссылка часто хорошо отражает это требование:

```cpp
void process(Robot& robot)
{
    // robot должен существовать
}
```

Если объект может отсутствовать, обычно используется другой механизм, например указатель или `std::optional` в зависимости от задачи.

---

## Ссылка как способ изменения объекта

Ссылки позволяют писать функции, которые изменяют объект:

```cpp
void increase(int& value)
{
    value++;
}
```

Использование:

```cpp
int number = 10;

increase(number);

std::cout << number;
```

Получим:

```text
11
```

Функция не возвращает новое значение. Она изменяет существующий объект.

---

## Несколько ссылок на один объект

На один объект может существовать несколько ссылок:

```cpp
int value = 10;

int& first = value;
int& second = value;
```

Теперь:

```cpp
first = 20;
```

изменит `value`.

А:

```cpp
second = 30;
```

изменит тот же объект.

Получается:

```text
first  ─┐
        ├──> value
second ─┘
```

---

## Ссылки и область видимости

Ссылка не продлевает автоматически время жизни объекта, на который она ссылается.

Например, опасная ситуация:

```cpp
int& getValue()
{
    int value = 10;
    return value;
}
```

`value` уничтожается при выходе из функции. Возвращённая ссылка после этого будет ссылаться на объект, которого больше не существует.

Так делать нельзя.

Правильное понимание очень важно:

> Ссылка не владеет объектом и не управляет его временем жизни.

Она только предоставляет другое имя для существующего объекта.

---

## Ссылка на константу

Можно создать ссылку на константный объект:

```cpp
const int value = 10;
const int& reference = value;
```

Через `reference` нельзя изменить `value`:

```cpp
reference = 20;
```

это ошибка.

Такой механизм используется для безопасного чтения данных.

---

## Практический пример

Создадим функцию для изменения координат робота:

```cpp
#include <iostream>

struct Position
{
    double x;
    double y;
};

void move(Position& position, double dx, double dy)
{
    position.x += dx;
    position.y += dy;
}

void printPosition(const Position& position)
{
    std::cout
        << "("
        << position.x
        << ", "
        << position.y
        << ")\n";
}

int main()
{
    Position position{10.0, 20.0};

    printPosition(position);

    move(position, 5.0, -2.0);

    printPosition(position);

    return 0;
}
```

Здесь:

```cpp
Position&
```

используется потому, что `move()` должна изменить исходный объект.

А:

```cpp
const Position&
```

используется в `printPosition()`, потому что функция только читает объект.

Это один из наиболее типичных паттернов использования ссылок в C++.

---

## Главное

Ссылка — это другое имя для существующего объекта.

Основные формы, которые нужно запомнить:

```cpp
Type&        // ссылка с возможностью изменения
const Type&  // ссылка только для чтения
```

Ссылки особенно полезны при передаче объектов в функции. Они позволяют работать с исходным объектом без копирования, а `const`-ссылка дополнительно запрещает изменение объекта через эту ссылку.

Ссылка отличается от указателя тем, что она не используется как самостоятельное хранилище адреса, не может быть `nullptr` и после инициализации не может быть переназначена на другой объект.
