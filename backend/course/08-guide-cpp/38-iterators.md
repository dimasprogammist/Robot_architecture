# Итераторы

## Цель

Итераторы — одна из центральных идей STL. Они позволяют алгоритмам работать с разными контейнерами через единый интерфейс.

После этого урока вы должны понимать, что такое итератор, как получить `begin()` и `end()`, как перемещаться по контейнеру, чем итератор похож на указатель и почему `end()` нельзя разыменовывать.

---

## Зачем вообще нужны итераторы

До STL разные структуры данных могли требовать совершенно разного способа обхода.

Например, массив можно было обходить индексом:

```cpp
for (int i = 0; i < size; ++i) {
    std::cout << values[i] << '\n';
}
```

Но у `std::set` нет оператора `[]`.

А у `std::map` элементы представлены парами ключ-значение.

STL решает эту проблему с помощью итераторов.

Итератор можно представить как объект, который указывает на определённую позицию внутри контейнера.

---

## begin и end

Практически каждый стандартный контейнер предоставляет:

```cpp
begin()
```

и:

```cpp
end()
```

Например:

```cpp
std::vector<int> values = {
    10, 20, 30
};

auto begin = values.begin();
auto end = values.end();
```

`begin()` указывает на первый элемент.

`end()` указывает **не на последний элемент**, а на позицию сразу после последнего.

Это очень важное правило.

---

## Почему end находится после последнего

Представим:

```text
10  20  30
^           ^
|           |
begin       end
```

`end()` используется как специальная граница.

Поэтому стандартный цикл выглядит так:

```cpp
for (auto it = values.begin();
     it != values.end();
     ++it) {

    std::cout << *it << '\n';
}
```

Условие:

```cpp
it != values.end()
```

означает:

> пока итератор не дошёл до конца контейнера.

---

## Разыменование итератора

Итератор можно разыменовать через `*`:

```cpp
auto it = values.begin();

std::cout << *it << '\n';
```

Получим:

```text
10
```

Затем можно перейти к следующему элементу:

```cpp
++it;
```

Теперь:

```cpp
std::cout << *it << '\n';
```

выведет:

```text
20
```

---

## Итератор похож на указатель

Это не обычный указатель, но интерфейс действительно похож.

Для указателя:

```cpp
int* ptr = &value;

std::cout << *ptr;
```

Для итератора:

```cpp
auto it = values.begin();

std::cout << *it;
```

В обоих случаях `*` означает получение объекта, на который указывает текущая позиция.

Но итератор — более абстрактная конструкция.

Он может работать не только с непрерывной памятью.

---

## Полный пример

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> values = {
        10, 20, 30, 40
    };

    for (auto it = values.begin();
         it != values.end();
         ++it) {

        std::cout << *it << '\n';
    }
}
```

Здесь:

```cpp
auto it = values.begin();
```

создаёт итератор на первый элемент.

```cpp
it != values.end()
```

проверяет, не дошли ли мы до конца.

```cpp
++it
```

переходит к следующему элементу.

```cpp
*it
```

получает текущий элемент.

---

## Итератор можно использовать для изменения элемента

Если контейнер не `const`, через итератор можно менять значения:

```cpp
std::vector<int> values = {
    10, 20, 30
};

for (auto it = values.begin();
     it != values.end();
     ++it) {

    *it *= 2;
}
```

После этого:

```text
20 40 60
```

---

## const_iterator

Если менять элементы нельзя, можно использовать `const_iterator`:

```cpp
const std::vector<int> values = {
    10, 20, 30
};

for (auto it = values.begin();
     it != values.end();
     ++it) {

    std::cout << *it << '\n';
}
```

Тип итератора в этом случае будет константным.

Можно также явно использовать:

```cpp
auto it = values.cbegin();
```

и:

```cpp
values.cend();
```

---

## range-based for и итераторы

Цикл:

```cpp
for (const auto& value : values) {
    std::cout << value << '\n';
}
```

выглядит намного проще.

Но концептуально он всё равно связан с идеей итераторов.

Это одна из причин, почему понимание итераторов важно даже тогда, когда вы чаще пишете range-based `for`.

---

## Итераторы std::set

Итераторы особенно важны для контейнеров, где нет индекса.

Например:

```cpp
std::set<int> values = {
    10, 20, 30
};
```

Обход:

```cpp
for (auto it = values.begin();
     it != values.end();
     ++it) {

    std::cout << *it << '\n';
}
```

Здесь нельзя написать:

```cpp
values[0];
```

поэтому итератор становится естественным способом перемещения по контейнеру.

---

## Итераторы std::map

Для `map` итератор указывает на пару:

```cpp
std::map<std::string, int> devices;

devices["motor"] = 4;
devices["camera"] = 2;
```

Можно написать:

```cpp
for (auto it = devices.begin();
     it != devices.end();
     ++it) {

    std::cout << it->first
              << ": "
              << it->second
              << '\n';
}
```

`it->first` — ключ.

`it->second` — значение.

---

## Обратные итераторы

Иногда нужно идти от конца к началу.

Для этого есть:

```cpp
rbegin()
```

и:

```cpp
rend()
```

Например:

```cpp
std::vector<int> values = {
    10, 20, 30
};

for (auto it = values.rbegin();
     it != values.rend();
     ++it) {

    std::cout << *it << '\n';
}
```

Результат:

```text
30
20
10
```

---

## Арифметика итераторов

Не все итераторы поддерживают одинаковые операции.

Для `std::vector` можно использовать:

```cpp
it + 2
```

потому что его итератор является random-access iterator.

Например:

```cpp
auto it = values.begin();

std::cout << *(it + 2);
```

получим третий элемент.

Но такой код нельзя бездумно применять к `std::list` или другим контейнерам.

---

## Категории итераторов

В STL существуют разные возможности итераторов.

Упрощённо можно представить их так:

```text
input
output
forward
bidirectional
random access
contiguous
```

Чем дальше категория, тем больше операций поддерживает итератор.

Например, random-access итератор может поддерживать:

```cpp
it + 5
it - 2
it[3]
```

А простой forward iterator таких операций не обязан поддерживать.

---

## Почему это важно для алгоритмов

Итераторы позволяют алгоритмам STL не зависеть от конкретного контейнера.

Например:

```cpp
std::sort(values.begin(), values.end());
```

Алгоритму не нужно знать, что такое `values` внутри.

Он получает диапазон:

```text
[begin, end)
```

и работает с ним.

---

## Диапазон [begin, end)

Очень часто в STL используется обозначение:

```text
[begin, end)
```

Это означает:

```text
включая begin
но не включая end
```

Например:

```text
10 20 30 40
^          ^
begin      end
```

Диапазон содержит:

```text
10
20
30
40
```

но сама позиция `end` элементом не является.

---

## Почему нельзя разыменовывать end

Так делать нельзя:

```cpp
auto it = values.end();

std::cout << *it;
```

`end()` не указывает на элемент.

Разыменование такого итератора приводит к неопределённому поведению.

Правильный вариант:

```cpp
auto it = values.end();

--it;

std::cout << *it;
```

для контейнера, поддерживающего обратное перемещение.

---

## Поиск через итератор

Например:

```cpp
std::vector<int> values = {
    10, 20, 30, 40
};

auto it = std::find(
    values.begin(),
    values.end(),
    30
);

if (it != values.end()) {
    std::cout << "Found: " << *it << '\n';
}
```

Алгоритм возвращает итератор.

Если элемент не найден, возвращается:

```cpp
values.end()
```

Это очень распространённый паттерн STL.

---

## Практический пример

Представим список ID устройств:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> devices = {
        101, 205, 310, 450
    };

    auto it = std::find(
        devices.begin(),
        devices.end(),
        310
    );

    if (it != devices.end()) {
        std::cout << "Device found\n";
    }
}
```

Здесь алгоритм поиска работает через диапазон итераторов.

---

## Главное

Итератор — это объект, представляющий позицию внутри контейнера.

Основные операции:

```cpp
begin()
end()
++it
*it
```

Для обратного обхода:

```cpp
rbegin()
rend()
```

Для константного обхода:

```cpp
cbegin()
cend()
```

`end()` указывает **за последний элемент**, поэтому его нельзя разыменовывать.

Итераторы позволяют алгоритмам STL работать с разными контейнерами через единый интерфейс.
