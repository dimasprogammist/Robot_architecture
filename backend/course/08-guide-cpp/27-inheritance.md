# Наследование

## Цель

В больших программах классы часто связаны между собой. Например, в робототехнической системе могут существовать разные типы устройств: двигатель, датчик, камера, контроллер. У некоторых объектов могут быть общие свойства и поведение.

Наследование позволяет создать новый класс на основе существующего и переиспользовать его интерфейс и реализацию. При этом производный класс может добавлять собственные поля и методы или изменять поведение базового класса.

После урока вы должны понимать:

* что такое базовый и производный класс;
* как объявляется наследование;
* что получает производный класс;
* зачем нужен `protected`;
* как вызывается конструктор базового класса;
* что такое отношение «является»;
* как использовать наследование в простой иерархии;
* почему наследование не всегда является лучшим способом построения программы.

---

## Что такое наследование

Представим базовый класс:

```cpp
class Device
{
public:
    void powerOn()
    {
        std::cout << "Power on\n";
    }
};
```

Теперь можно создать класс:

```cpp
class Motor : public Device
{
};
```

`Motor` наследует `Device`.

Это означает, что объект `Motor` получает доступ к доступным членам базового класса.

Например:

```cpp
Motor motor;

motor.powerOn();
```

Метод `powerOn()` определён в `Device`, но доступен объекту `Motor`.

---

## Базовый и производный класс

В конструкции:

```cpp
class Motor : public Device
{
};
```

`Device` называется базовым классом.

`Motor` называется производным классом.

Можно представить:

```text
Device
   ↑
 Motor
```

Производный класс расширяет или специализирует базовый.

---

## Пример с робототехникой

Представим базовый класс:

```cpp
class Device
{
public:
    void connect()
    {
        std::cout << "Connected\n";
    }
};
```

И производные классы:

```cpp
class Camera : public Device
{
};

class Lidar : public Device
{
};
```

Теперь:

```cpp
Camera camera;
Lidar lidar;

camera.connect();
lidar.connect();
```

Оба устройства получили общий метод `connect()`.

---

## Добавление собственных методов

Производный класс может добавлять новые возможности:

```cpp
class Motor : public Device
{
public:
    void rotate()
    {
        std::cout << "Motor rotates\n";
    }
};
```

Теперь:

```cpp
Motor motor;

motor.connect();
motor.rotate();
```

Получается:

```text
Device
├── connect()
│
└── Motor
    └── rotate()
```

---

## Добавление собственных полей

Производный класс может иметь собственные данные:

```cpp
class Motor : public Device
{
private:
    double speed = 0;

public:
    void setSpeed(double value)
    {
        speed = value;
    }
};
```

Теперь `Motor` имеет:

```text
общую функциональность Device
+
собственную скорость
```

---

## Что именно наследуется

Наследование не означает, что абсолютно всё базового класса становится доступным напрямую.

На доступ влияют:

```cpp
public
protected
private
```

Например:

```cpp
class Device
{
public:
    void connect();

protected:
    int state = 0;

private:
    int serialNumber = 0;
};
```

Производный класс может напрямую использовать:

```cpp
connect();
state = 1;
```

Но не может напрямую обращаться к:

```cpp
serialNumber
```

потому что это `private`.

---

## protected

`protected` — это уровень доступа, который позволяет использовать член:

* внутри самого класса;
* внутри производных классов.

Например:

```cpp
class Device
{
protected:
    bool connected = false;
};

class Camera : public Device
{
public:
    void connectCamera()
    {
        connected = true;
    }
};
```

`Camera` может обращаться к `connected`.

Но внешний код:

```cpp
Camera camera;

// camera.connected = true;
```

не имеет такого доступа.

---

## public наследование

Наиболее распространённая форма:

```cpp
class Motor : public Device
{
};
```

`public` наследование выражает отношение:

> Motor является Device.

Например:

```text
Motor is a Device
Camera is a Device
Lidar is a Device
```

Это важно не только технически, но и с точки зрения проектирования.

---

## Отношение «является»

Наследование хорошо подходит, когда между объектами действительно существует отношение:

```text
Motor → Device
```

Потому что двигатель является устройством.

Но:

```text
Robot → Engine
```

обычно не является хорошим примером наследования.

Робот не является двигателем.

У робота есть двигатель.

Это уже отношение композиции:

```text
Robot
 └── Motor
```

Разницу между наследованием и композицией важно понимать при проектировании классов.

---

## Конструктор базового класса

Рассмотрим:

```cpp
class Device
{
public:
    Device()
    {
        std::cout << "Device created\n";
    }
};
```

Производный класс:

```cpp
class Motor : public Device
{
public:
    Motor()
    {
        std::cout << "Motor created\n";
    }
};
```

При создании:

```cpp
Motor motor;
```

сначала создаётся базовая часть объекта:

```text
Device constructor
↓
Motor constructor
```

То есть конструктор базового класса выполняется раньше конструктора производного.

---

## Передача параметров базовому классу

Если базовому классу нужен параметр:

```cpp
class Device
{
protected:
    int id;

public:
    Device(int id)
        : id(id)
    {
    }
};
```

Производный класс должен вызвать этот конструктор:

```cpp
class Motor : public Device
{
public:
    Motor(int id)
        : Device(id)
    {
    }
};
```

Теперь:

```cpp
Motor motor(10);
```

сначала создаёт базовую часть через:

```cpp
Device(id)
```

а затем выполняет тело конструктора `Motor`.

---

## Порядок уничтожения

При уничтожении объекта порядок обратный.

Если:

```cpp
Motor motor;
```

то при выходе из области видимости:

```text
Motor destructor
↓
Device destructor
```

Сначала уничтожается производная часть, затем базовая.

Это важно, потому что базовый объект должен оставаться существующим, пока производная часть ещё используется.

---

## Переопределение методов

Производный класс может определить собственный метод с тем же именем:

```cpp
class Device
{
public:
    void info()
    {
        std::cout << "Device\n";
    }
};

class Motor : public Device
{
public:
    void info()
    {
        std::cout << "Motor\n";
    }
};
```

Теперь:

```cpp
Motor motor;

motor.info();
```

выведет:

```text
Motor
```

Но это ещё не настоящий полиморфизм. Для динамического выбора реализации используются виртуальные функции, которые мы рассмотрим позже.

---

## Обращение к базовой реализации

В производном классе можно явно обратиться к базовой реализации:

```cpp
class Motor : public Device
{
public:
    void info()
    {
        Device::info();

        std::cout << "Motor\n";
    }
};
```

Теперь вызов:

```cpp
motor.info();
```

сначала выполнит:

```text
Device
```

а затем:

```text
Motor
```

---

## Наследование и private

Рассмотрим:

```cpp
class Device
{
private:
    int id;
};
```

Производный класс не может напрямую написать:

```cpp
id = 10;
```

Если производному классу действительно нужен контролируемый доступ, можно использовать:

```cpp
protected
```

или, что часто лучше, предоставить защищённый или публичный метод:

```cpp
void setId(int value)
{
    id = value;
}
```

Не стоит автоматически делать все поля `protected`. Инкапсуляция всё равно остаётся важной.

---

## Множественное наследование

C++ позволяет классу наследовать несколько базовых классов:

```cpp
class A
{
};

class B
{
};

class C : public A, public B
{
};
```

Это называется множественным наследованием.

Механизм мощный, но он может усложнять архитектуру программы. Особенно сложными становятся ситуации, когда разные базовые классы имеют одинаковые имена членов или общую базовую часть.

На практике множественное наследование используют осознанно, а многие задачи можно решить через композицию.

---

## Практический пример

Создадим базовое устройство:

```cpp
#include <iostream>
#include <string>

class Device
{
protected:
    std::string name;

public:
    Device(const std::string& name)
        : name(name)
    {
    }

    void connect()
    {
        std::cout << name << " connected\n";
    }
};

class Motor : public Device
{
private:
    double speed = 0;

public:
    Motor(const std::string& name)
        : Device(name)
    {
    }

    void setSpeed(double value)
    {
        speed = value;
    }

    void print()
    {
        std::cout
            << name
            << ": speed = "
            << speed
            << '\n';
    }
};

int main()
{
    Motor motor("Left motor");

    motor.connect();
    motor.setSpeed(50);
    motor.print();

    return 0;
}
```

Здесь `Motor` получает общую функциональность `Device` и добавляет собственную скорость.

---

## Главное

Наследование позволяет построить отношение:

```text
базовый класс
      ↑
производный класс
```

Например:

```cpp
class Motor : public Device
{
};
```

Производный класс получает доступ к доступным членам базового класса и может добавлять собственные поля и методы.

Основные уровни доступа:

```cpp
public
protected
private
```

При создании производного объекта сначала создаётся базовая часть, а затем производная. При уничтожении порядок обратный.

Главное правило проектирования:

> Используйте наследование, когда производный объект действительно является разновидностью базового.
