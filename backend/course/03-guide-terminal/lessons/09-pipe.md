# Конвейер (pipe) — связать вывод с вводом

Конвейер соединяет stdout одной программы со stdin другой без обязательного файла на диске. В shell это `|`. Слева производитель, справа потребитель. Ядро даёт pipe — буфер с концом записи и концом чтения.

Это не «сначала вся левая команда, потом правая». Оба процесса живы сразу. Медленный читатель заполняет буфер — писатель блокируется на write (обратное давление). Писатель закрыл конец — читатель получает EOF.

stderr в pipe по умолчанию не входит. Ошибки слева часто остаются на терминале, данные текут дальше: диагностика видна, следующий фильтр не ест красный текст. Цвет и управляющие коды в автоматизации — яд; для скриптов берут машиночитаемый режим.

Маленькие программы делают одну вещь: `grep` отбирает, `sort` упорядочивает, `uniq` сжимает повторы, `wc` считает. Цепочка — сборка. Длинную не отлаживают целиком: режут, смотрят середину, `tee` пишет копию потока в файл и продолжает stdout.

Код возврата конвейера в bash по умолчанию — код **последней** команды. `false | true` выглядит успехом. `set -o pipefail` считает ошибкой любую стадию — для скриптов это честнее.

```bash
printf 'c\na\nb\na\n' | sort | uniq -c

ls /tmp /нет_такого 2>/dev/null | wc -l

printf 'one\ntwo\n' | tee /tmp/copy.txt | wc -l

set -o pipefail
false | true
echo $?
```

Первый пример нигде не обязан класть промежуточный файл. Второй прячет stderr `ls`. Третий — подсмотреть поток. Четвёртый — ненулевой статус из-за `false`.

Несколько `|` — несколько процессов, у каждого свои дескрипторы. Shell создаёт pipe, подключает концы, ждёт завершения (детали job control зависят от оболочки).

## Практика

### Задание 1. Три стадии

Конвейер над текстовым файлом: отбор строк, сортировка, подсчёт. Вставьте посередине `tee` и сравните промежуточный файл с финалом.

### Задание 2. Ошибки не в трубе

Часть путей `ls` существует, часть нет, stdout уходит дальше. Где сообщение об ошибке по умолчанию? Когда это удобно, когда надо слить потоки?

### Задание 3. pipefail

В bash: `false | true` без `pipefail` и с ним. Почему для скрипта учёт середины безопаснее?

### Задание 4. Длинная цепочка

Десять стадий «не работают». Как разрезать, не бросая идею? Что должно быть стабильно на границе: формат строк, не цвет и ширина колонок.
