# Скрипты оболочки

Скрипт — текстовый файл команд вместо повторного набора. Бэкап, проверка здоровья, обёртка деплоя: клей, не «вторая Python». Когда появляются структуры данных и ветвления на три экрана — выходите в нормальный язык.

Первая строка `#!/usr/bin/env bash` (shebang): ядро при `./script` запускает интерпретатор. `env` ищет `bash` в PATH — гибче жёсткого `/bin/bash`. Вызов `bash script.sh` shebang не требует. Без бита execute остаётся только явный интерпретатор. На FAT/NTFS биты могут врать — проверяйте целевую ФС.

Аргументы: `$1`, `$2`, `"$@"`. Без кавычек пробел в пути режет параметры. `${1:-world}` — значение по умолчанию. `shift` и `getopts` — когда опций больше двух.

`set -euo pipefail`: выход на неуспехе, ошибка на пустой переменной, учёт pipe. Внутри `if` есть тонкости `-e`; для службы всё равно лучше, чем тишина. Код возврата скрипта — последняя команда или `exit N`. CI смотрит на него.

Окружение — как у вызывающего. В cron PATH бедный: задайте явно. cwd враждебен: базу считайте от расположения файла, не от «где я стоял в терминале».

Отладка: `bash -x script.sh` печатает команды. Лучше гадания.

```bash
cat <<'EOF' > /tmp/hello.sh
#!/usr/bin/env bash
set -euo pipefail
name="${1:-world}"
echo "hello, $name"
EOF
chmod +x /tmp/hello.sh
/tmp/hello.sh
/tmp/hello.sh Ada
echo $?
```

Не копируйте скрипт с `curl | bash` в прод без чтения. Не полагайтесь на alias из интерактива: в скрипте вызывайте явные имена.

### Задание 1. Shebang и бит

Скрипт с shebang, `chmod +x`, запуск `./`. Затем снимите execute и запустите через `bash файл`. Чем отличаются два пути для ядра?

### Задание 2. Аргумент с пробелом

Передайте имя каталога с пробелом. Когда `"$1"` спасает и что будет без кавычек?

### Задание 3. Строгий режим

Скрипт со `set -u` и обращением к незаданной переменной. Почему это лучше тихого пустого раскрытия? Где `-e` может удивить внутри `if`?

### Задание 4. Клей vs программа

Три признака, что shell-скрипт пора переписать на Python (обработка JSON, повторные ретраи, разбор таблиц). Что всё же оставить оболочке?
