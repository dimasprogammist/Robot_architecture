# Аргументы — как shell собирает argv

Программа не получает «всю строку, как вы её напечатали». Она получает **массив строк (argv)**. Границы элементов ставит оболочка. Пробел вне кавычек — разделитель. Файл `мой отчёт.txt` без кавычек станет двумя операндами.

В bash одинарные кавычки почти буквальны. Двойные позволяют подстановку переменных. `$()` подставляет вывод команды. Ошибка новичка — закавычить так, что переменная перестаёт раскрываться, или оставить путь с пробелом голым.

**Glob** (`*.log`) раскрывает shell **до** запуска, если шаблон совпал с именами. Программа часто не видит звёздочку — ей уже список. Если совпадений нет, поведение зависит от настроек оболочки.

Многие утилиты трактуют `--` как конец опций. Имя файла `-weird` иначе выглядит как флаг.

Незакавыченная переменная с пробелами в bash может разъехаться на несколько аргументов (**word splitting**). Гигиена: `"$var"` для путей.

PowerShell разбирает параметры иначе. Не копируйте bash-кавычки туда слепо.

Не собирайте команду как строку с недоверенными данными через `eval`. Когда язык позволяет, передавайте **список** аргументов API процесса.

Упрощённый порядок в bash: токены → подстановки → разбиение по пробелам → glob → снятие кавычек. Из-за порядка `"$file"` защищает пробелы, а `$file` — нет. Shell не угадывает смысл `-n`. Это уже `rm` или ваш скрипт.

```bash
touch "my file.txt"
ls -l "my file.txt"
python -c 'import sys; print(sys.argv)' -- -n "a b" "$HOME"
touch -- -n
rm -- -n
```

`touch` с кавычками создаёт одно имя. Python печатает массив — видно, как сложился argv. `rm -- -n` удаляет файл по имени `-n`, а не включает странный режим опций.

В Python для внешних программ: `subprocess.run([...])`, не `shell=True`, когда аргументы приходят снаружи.

## Типичные ошибки

Не закавычивать переменные с путями. Ждать, что программа сама увидит `*.txt`. Кормить `eval` пользовательским вводом. Игнорировать ведущий дефис в имени файла.

## Практика

### Задание 1. Пробел в имени

Создайте файл с пробелом в имени и скопируйте его одной командой так, чтобы путей-аргументов было ровно два. Проверьте печатью argv (или внимательным `ls`), что массив не распался.

### Задание 2. Звёздочка

В каталоге с несколькими `.txt` выполните команду, которая печатает аргументы, со шаблоном `*.txt`. Кто раскрыл шаблон — shell или программа? Что будет в пустом каталоге?

### Задание 3. Дефис

Создайте файл с именем, начинающимся с `-`. Удалите его безопасным способом. Что произойдёт без `--`?

### Задание 4. Список, не строка

Почему передача аргументов списком в программу на Python безопаснее, чем `os.system("cmd " + user_text)`? Свяжите ответ с разбором оболочки, а не с «так принято».
