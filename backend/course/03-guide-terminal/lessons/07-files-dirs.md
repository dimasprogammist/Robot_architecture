# Файлы и каталоги: просмотр, создание, копирование, удаление

Пути уже есть. Теперь операции: посмотреть, создать, скопировать, переименовать, удалить. Это не «другие миры», а короткие программы (кроме `cd` — builtin оболочки), которые просят ядро прочитать каталог, создать запись, убрать имя.

**Просмотр.** `ls` просит перечислить содержимое; флаги меняют формат (скрытые имена, размер, права), не «ускоряют диск». Прочитать файл целиком — вывод на stdout; большой лог удобнее листать постранично, чем вывалить мегабайты в терминал.

**Куда вы стоите.** `pwd` печатает текущий каталог. `cd` меняет его **у shell**, не у внешней программы: отдельный процесс сменил бы каталог только у себя и умер.

**Создание.** `mkdir` заводит новую запись-каталог. Копирование (`cp`) читает байты и пишет новые: исходник жив. Перемещение (`mv`) внутри одной файловой системы часто лишь переименовывает запись — мгновенно при любом размере. Между дисками это копирование плюс удаление исходника, поэтому «тот же mv» вдруг долгий.

**Удаление.** `rm` убирает имя и уменьшает счётчик ссылок на данные. Блоки освобождаются, когда счётчик ноль **и** никто не держит файл открытым. Отсюда классика: удалили большой файл — место не выросло, пока процесс не закрыл дескриптор. `rmdir` снимает пустой каталог; с содержимым нужна рекурсия, и опечатка в пути необратима.

```bash
pwd
ls -la
mkdir project
cd project
cp /etc/hosts ./hosts.copy
mv ./hosts.copy ./hosts.renamed
rm ./hosts.renamed
cd ..
rmdir project
```

Перед рекурсивным удалением напечатайте полный путь и `pwd`. Пробел в некавыченной переменной способен подставить «удалить всё в текущем» вместо «удалить каталог из переменной».

## Практика

### Задание 1. Жизненный цикл каталога

В домашнем каталоге: подкаталог, копия текстового файла, переименование, удаление файла и каталога. На каждом шаге смотрите содержимое.

### Задание 2. Почему `mv` то быстрый, то нет

Внутри раздела — часто мгновенно, между дисками — долго. Объясните через «переименовать запись» против «скопировать байты». Когда в скрипте опасно считать `mv` бесплатным?

### Задание 3. Место не освободилось

Большой файл удалили, место почти не выросло. Гипотезы: счётчик ссылок, процесс держит файл, удалили не то имя. Как различить?

### Задание 4. Рекурсия

Почему перед рекурсивным удалением смотрят `pwd` и полный путь? Ошибка с пробелом в переменной, из-за которой сотрётся не тот каталог.

Дальше искать имена и текст в дереве, не кликая руками.
