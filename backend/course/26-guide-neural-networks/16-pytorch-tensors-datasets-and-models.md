# PyTorch: тензоры, датасеты и модели

## Цель

Познакомиться с PyTorch — одним из основных инструментов для разработки и обучения нейронных сетей на Python.

После урока вы должны понимать:

* что такое тензор;
* чем тензор похож на массив NumPy;
* зачем нейросетям нужны тензоры;
* что такое `Dataset` и `DataLoader`;
* как описывается модель в PyTorch;
* что такое параметры модели;
* как выполняется прямой проход;
* как организуется базовый цикл обучения.

---

## Зачем нужен PyTorch

Мы уже рассмотрели математические основы нейронных сетей:

```text
веса
↓
взвешенная сумма
↓
активация
↓
предсказание
↓
loss
↓
градиенты
↓
обновление параметров
```

Можно написать всё это самостоятельно.

Но реальная модель может содержать:

```text
миллионы параметров
```

Поэтому нужны библиотеки, которые автоматизируют вычисления.

Одна из таких библиотек — **PyTorch**.

---

## Что такое PyTorch

PyTorch — библиотека Python для машинного обучения и работы с нейронными сетями.

Она предоставляет:

* тензоры;
* автоматическое вычисление градиентов;
* слои нейронных сетей;
* функции потерь;
* оптимизаторы;
* инструменты работы с данными;
* поддержку вычислений на GPU.

---

## Тензор

Основной объект PyTorch — **тензор**.

Можно представить его как обобщение обычных чисел, векторов и матриц.

Например, число:

```python
import torch

x = torch.tensor(5.0)
```

Это тензор с нулевым измерением.

---

## Вектор

```python
x = torch.tensor([
    1.0,
    2.0,
    3.0
])
```

Это одномерный тензор.

Его форма:

```text
(3,)
```

---

## Матрица

```python
x = torch.tensor([
    [1.0, 2.0],
    [3.0, 4.0]
])
```

Форма:

```text
(2, 2)
```

Можно воспринимать это как таблицу:

```text
1 2
3 4
```

---

## Изображение тоже можно представить тензором

Например, чёрно-белое изображение размером:

```text
28 × 28
```

может быть представлено:

```text
(28, 28)
```

Цветное изображение обычно содержит отдельные каналы.

Например:

```text
RGB
```

можно представить как:

```text
(3, 28, 28)
```

где:

```text
3 → каналы
28 → высота
28 → ширина
```

---

## Батч изображений

Во время обучения модель обычно обрабатывает несколько примеров одновременно.

Например:

```text
32 изображения
```

каждое:

```text
3 × 28 × 28
```

Тогда форма батча:

```text
(32, 3, 28, 28)
```

Это очень важное понятие.

---

## Shape

У тензора есть форма:

```python
x.shape
```

Например:

```python
import torch

x = torch.zeros(32, 3, 28, 28)

print(x.shape)
```

Получим:

```text
torch.Size([32, 3, 28, 28])
```

---

## Размерность и количество элементов

Можно узнать количество элементов:

```python
print(x.numel())
```

Для:

```text
32 × 3 × 28 × 28
```

это:

```text
75264
```

---

## Тип данных

Тензор хранит значения определённого типа.

Например:

```python
x = torch.tensor(
    [1.0, 2.0, 3.0],
    dtype=torch.float32
)
```

Для нейросетей часто используется:

```text
float32
```

потому что это хороший компромисс между точностью и производительностью.

---

## Операции с тензорами

Можно выполнять обычные математические операции:

```python
a = torch.tensor([1.0, 2.0, 3.0])
b = torch.tensor([4.0, 5.0, 6.0])

c = a + b

print(c)
```

Получим:

```text
tensor([5., 7., 9.])
```

---

## Матричное умножение

Нейронные сети постоянно выполняют матричные операции.

Например:

```python
a = torch.tensor([
    [1.0, 2.0],
    [3.0, 4.0]
])

b = torch.tensor([
    [5.0, 6.0],
    [7.0, 8.0]
])

c = a @ b

print(c)
```

Оператор:

```python
@
```

используется для матричного умножения.

---

## Автоматические градиенты

PyTorch умеет автоматически вычислять производные.

Например:

```python
x = torch.tensor(
    3.0,
    requires_grad=True
)

y = x ** 2

y.backward()

print(x.grad)
```

Получим:

```text
tensor(6.)
```

Потому что:

```text
d(x²)/dx = 2x
```

при:

```text
x = 3
```

получаем:

```text
6
```

---

## Модель

В PyTorch модель обычно создаётся на основе:

```python
nn.Module
```

Пример:

```python
import torch.nn as nn

class SimpleModel(nn.Module):
    def __init__(self):
        super().__init__()

        self.layer = nn.Linear(4, 2)

    def forward(self, x):
        return self.layer(x)
```

---

## Что происходит в `__init__`

Здесь описываются компоненты модели:

```python
self.layer = nn.Linear(4, 2)
```

Это означает:

```text
4 входных значения
↓
2 выходных значения
```

---

## Что происходит в `forward`

Метод:

```python
forward()
```

описывает прохождение данных через модель.

Например:

```python
def forward(self, x):
    return self.layer(x)
```

---

## Последовательная модель

Для простых сетей удобно использовать:

```python
nn.Sequential
```

Например:

```python
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Linear(16, 8),
    nn.ReLU(),
    nn.Linear(8, 1)
)
```

---

## Параметры модели

У каждого `Linear` есть параметры:

```text
weights
bias
```

Можно посмотреть их:

```python
for parameter in model.parameters():
    print(parameter.shape)
```

## Dataset

Теперь нужна не только модель.

Нужны данные.

PyTorch предоставляет класс:

```python
Dataset
```

Он позволяет описывать источник обучающих примеров.

Пример:

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __len__(self):
        return len(self.x)

    def __getitem__(self, index):
        return self.x[index], self.y[index]
```

---

## DataLoader

`DataLoader` организует выдачу данных модели.

Например:

```python
from torch.utils.data import DataLoader

loader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True
)
```

Теперь данные можно получать батчами.

---

## Почему используются батчи

Можно обучать модель по одному примеру:

```text
1 пример
→
loss
→
gradient
→
update
```

Но обычно эффективнее обрабатывать несколько:

```text
32 примера
→
loss
→
gradient
→
update
```

Размер такого набора называется:

```text
batch size
```

---

## Epoch

Одна **эпоха** — это полный проход по обучающему набору данных.

Например:

```text
1000 примеров
batch_size = 100
```

Тогда одна эпоха содержит примерно:

```text
10 батчей
```

---

## Базовый цикл обучения

Упрощённо обучение выглядит так:

```python
for epoch in range(epochs):

    for x, y in loader:

        prediction = model(x)

        loss = loss_function(
            prediction,
            y
        )

        optimizer.zero_grad()

        loss.backward()

        optimizer.step()
```

Это одна из самых важных конструкций всего курса по нейросетям.

---

## Что делает каждая строка

Сначала:

```python
prediction = model(x)
```

выполняется прямой проход.

Затем:

```python
loss = loss_function(
    prediction,
    y
)
```

вычисляется ошибка.

После:

```python
optimizer.zero_grad()
```

очищаются старые градиенты.

Затем:

```python
loss.backward()
```

вычисляются новые градиенты.

И наконец:

```python
optimizer.step()
```

обновляются параметры модели.

---

## Полный пример

Рассмотрим простую задачу:

```text
y = 2x
```

Создадим данные:

```python
import torch

x = torch.tensor([
    [1.0],
    [2.0],
    [3.0],
    [4.0]
])

y = torch.tensor([
    [2.0],
    [4.0],
    [6.0],
    [8.0]
])
```

Создадим модель:

```python
import torch.nn as nn

model = nn.Linear(1, 1)
```

---

## Функция потерь

Для регрессии:

```python
loss_function = nn.MSELoss()
```

---

## Оптимизатор

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01
)
```

---

## Обучение

```python
for epoch in range(1000):

    prediction = model(x)

    loss = loss_function(
        prediction,
        y
    )

    optimizer.zero_grad()

    loss.backward()

    optimizer.step()
```

После обучения модель должна приблизиться к зависимости:

```text
y = 2x
```

---

## Проверка

Можно проверить:

```python
test = torch.tensor([[5.0]])

prediction = model(test)

print(prediction)
```

Ожидаемый результат будет близок к:

```text
10
```

---

## Обучение — это не магия

Внутри происходит всё то, что мы уже изучили:

```text
данные
 ↓
модель
 ↓
prediction
 ↓
loss
 ↓
backpropagation
 ↓
gradient
 ↓
optimizer
 ↓
новые веса
```

PyTorch просто автоматизирует большое количество математических операций.

---

## CPU и GPU

Нейронные сети часто требуют большого количества вычислений.

PyTorch может выполнять операции:

```text
CPU
```

или:

```text
GPU
```

Например:

```python
device = torch.device(
    "cuda" if torch.cuda.is_available()
    else "cpu"
)
```

Затем модель можно переместить:

```python
model = model.to(device)
```

И данные:

```python
x = x.to(device)
y = y.to(device)
```

---

## Почему GPU помогает

GPU хорошо выполняет большое количество однотипных математических операций параллельно.

Нейронные сети содержат огромное количество:

```text
умножений
сложений
матричных операций
```

Поэтому GPU часто оказывается значительно эффективнее CPU при обучении больших моделей.

## Главное

PyTorch не заменяет математическое понимание нейронных сетей.

Он предоставляет инструменты, позволяющие реализовать эти идеи на практике.

Основная схема:

```text
Tensor
  ↓
Model
  ↓
Prediction
  ↓
Loss
  ↓
Backward
  ↓
Optimizer
  ↓
Updated parameters
```

Эта схема будет встречаться практически во всех последующих практических примерах.
