# Нейрон и искусственная нейронная сеть

## Цель

Разобраться, из чего состоит искусственный нейрон и как из множества нейронов строится нейронная сеть.

После урока вы должны понимать:

* что такое искусственный нейрон;
* зачем нейрону нужны входы, веса и смещение;
* как вычисляется взвешенная сумма;
* что такое выход нейрона;
* как несколько нейронов объединяются в слой;
* как слои образуют нейронную сеть;
* почему нейронная сеть может описывать сложные зависимости.

---

## 1. Зачем вообще нужен нейрон

На предыдущих уроках мы рассматривали модель как функцию:

```text
X → модель → результат
```

Теперь нужно заглянуть внутрь одной из таких моделей.

Нейронная сеть состоит из множества небольших вычислительных элементов — **искусственных нейронов**.

Каждый нейрон получает несколько числовых значений, выполняет вычисление и передаёт результат дальше.

Упрощённо:

```text
входы
  ↓
[ нейрон ]
  ↓
выход
```

Один нейрон очень прост.

Сила нейронной сети появляется благодаря объединению большого количества таких элементов.

---

## 2. Входы нейрона

Представим, что нужно оценить состояние двигателя.

Мы можем использовать:

```text
x1 = температура
x2 = ток
x3 = вибрация
```

Нейрон получает эти значения:

```text
x1 ──┐
x2 ──┼──→ [ нейрон ] ──→ y
x3 ──┘
```

Каждый вход содержит некоторое число.

Например:

```text
x1 = 80
x2 = 4.2
x3 = 1.5
```

---

## 3. Веса

Не каждый вход одинаково важен.

Поэтому каждому входу соответствует **вес**.

Например:

```text
x1 → w1
x2 → w2
x3 → w3
```

Получается:

```text
x1 ── w1 ──┐
x2 ── w2 ──┼──→ нейрон
x3 ── w3 ──┘
```

Вес показывает, насколько сильно соответствующий вход влияет на результат вычисления.

Если:

```text
w1 = 2
```

влияние первого входа будет другим, чем при:

```text
w1 = 0.1
```

---

## 4. Взвешенная сумма

Нейрон сначала вычисляет сумму входов с учётом весов:

```text
z = x1w1 + x2w2 + x3w3
```

Например:

```text
x1 = 10
x2 = 2
x3 = 5

w1 = 0.5
w2 = 2
w3 = 0.1
```

Тогда:

```text
z =
10 × 0.5 +
2 × 2 +
5 × 0.1
```

Получаем:

```text
z = 9.5
```

Это промежуточный результат.

---

## 5. Смещение

Кроме весов, у нейрона есть ещё один параметр — **bias**, или смещение.

Обозначим его:

```text
b
```

Тогда формула становится:

```text
z = x1w1 + x2w2 + x3w3 + b
```

Например:

```text
z = 9.5
b = -2
```

получаем:

```text
z = 7.5
```

Смещение позволяет сдвигать результат нейрона.

---

## 6. Почему нужен bias

Без смещения модель имеет дополнительные ограничения.

Представьте простую зависимость:

```text
y = wx
```

Она обязательно проходит через начало координат:

```text
y
↑
│       /
│     /
│   /
│ /
└────────→ x
```

Если добавить смещение:

```text
y = wx + b
```

линия может сдвигаться:

```text
y
↑
│     /
│   /
│ /
│
└────────→ x
```

В нейронных сетях это позволяет модели гибче описывать зависимости.

---

## 7. Функция активации

Пока нейрон вычисляет:

```text
z = x1w1 + x2w2 + ... + b
```

Но обычно на этом вычисление не заканчивается.

Результат передаётся через **функцию активации**:

```text
a = f(z)
```

Получается:

```text
входы
  ↓
взвешенная сумма
  ↓
bias
  ↓
функция активации
  ↓
выход
```

Функции активации позволяют нейронной сети строить нелинейные зависимости.

---

## 8. Почему нелинейность так важна

Представим сеть:

```text
вход
 ↓
слой
 ↓
слой
 ↓
выход
```

Если каждый слой выполняет только линейное преобразование, то объединение таких слоёв всё равно можно свести к одному линейному преобразованию.

То есть добавление большого количества линейных слоёв не даст необходимой выразительности.

Функции активации позволяют сети создавать сложные нелинейные зависимости.

---

## 9. Пример функции ReLU

Одна из самых известных функций активации — **ReLU**.

Она работает очень просто:

```text
если x < 0:
    0

иначе:
    x
```

То есть:

```text
ReLU(x) = max(0, x)
```

Примеры:

```text
ReLU(-5) = 0
ReLU(-1) = 0
ReLU(0)  = 0
ReLU(2)  = 2
ReLU(10) = 10
```

Графически:

```text
y
↑
│        /
│       /
│      /
│     /
│____/────────→ x
```

ReLU очень часто используется внутри современных нейронных сетей.

---

## 10. Один нейрон на Python

Можно написать простой нейрон самостоятельно:

```python
x1 = 10
x2 = 2

w1 = 0.5
w2 = 2.0

b = -1

z = x1 * w1 + x2 * w2 + b

print(z)
```

Добавим ReLU:

```python
activation = max(0, z)

print(activation)
```

Это уже простейшая реализация вычисления одного искусственного нейрона.

---

## 11. Несколько нейронов

Один нейрон обычно недостаточен для сложной задачи.

Поэтому несколько нейронов объединяют в слой.

Например:

```text
x1 ──┬──→ [нейрон 1] ──→ y1
     │
x2 ──┼──→ [нейрон 2] ──→ y2
     │
x3 ──┴──→ [нейрон 3] ──→ y3
```

Каждый нейрон имеет собственные:

```text
weights
bias
```

Поэтому они могут изучать разные зависимости.

---

## 12. Слой

Набор нейронов, работающих параллельно, называют **слоем**.

Например:

```text
Вход:
x1 x2 x3 x4

       ↓

Слой:
● ● ● ● ●

       ↓

Выход:
y1 y2 y3 y4 y5
```

Каждый нейрон получает входные значения и вычисляет свой результат.

---

## 13. Полносвязный слой

В простом **полносвязном слое** каждый нейрон следующего слоя получает значения от всех нейронов предыдущего слоя.

Например:

```text
● ─────┬────→ ●
● ─────┼────→ ●
● ─────┼────→ ●
● ─────┴────→ ●
```

Если есть:

```text
4 входа
3 нейрона
```

каждый из трёх нейронов имеет четыре веса.

Всего:

```text
4 × 3 = 12 весов
```

плюс:

```text
3 bias
```

Итого:

```text
15 обучаемых параметров
```

---

## 14. Несколько слоёв

Теперь можно соединить слои:

```text
Вход
  ↓
[ ● ● ● ● ]
  ↓
[ ● ● ● ]
  ↓
[ ● ● ]
  ↓
Выход
```

Такую сеть называют **многослойной нейронной сетью**.

Первый слой получает исходные данные.

Промежуточные слои преобразуют представление.

Последний слой формирует итоговый результат.

---

## 15. Что делают промежуточные слои

Можно представить это как последовательное преобразование информации.

Например, для изображения:

```text
пиксели
   ↓
простые признаки
   ↓
контуры
   ↓
части объектов
   ↓
объект
```

В реальной нейронной сети внутренние представления гораздо сложнее.

Но общая идея полезна:

> разные уровни сети могут формировать разные представления исходных данных.

---

## 16. Пример с промышленными данными

Предположим, вход:

```text
температура
ток
вибрация
давление
```

Первый слой может формировать комбинации:

```text
температура + ток
вибрация + скорость
давление + температура
```

Следующий слой может использовать их для более сложных зависимостей.

Последний слой выдаёт:

```text
норма
авария
```

Мы не программируем эти комбинации вручную.

В процессе обучения сеть подбирает параметры.

---

## 17. Как сеть обучается

Каждый нейрон содержит:

```text
weights
bias
```

Во время обучения они изменяются.

Например:

```text
до обучения:
w1 = 0.2
w2 = -0.4

после обучения:
w1 = 0.7
w2 = 0.1
```

В большой сети таких параметров могут быть миллионы.

Обновляются они автоматически с использованием градиентов.

---

## 18. Нейронная сеть как функция

Если у нас есть:

```text
X
```

на входе и:

```text
Y
```

на выходе, то всю сеть можно рассматривать как большую функцию:

```text
Y = f(X, W, B)
```

где:

```text
X — входные данные
W — веса
B — смещения
```

Обучение заключается в поиске таких:

```text
W
B
```

при которых результат сети становится достаточно хорошим.

---

## 19. Почему нейронная сеть может быть сложной

Один нейрон выполняет относительно простое преобразование.

Но если объединить:

```text
100 нейронов
```

затем:

```text
100 нейронов
```

затем:

```text
50 нейронов
```

получается модель с большим количеством параметров и сложными внутренними представлениями.

Именно сочетание:

```text
много параметров
+
нелинейные функции
+
обучение
```

делает нейронные сети мощным инструментом.

---

## 20. Не стоит представлять нейрон буквально как мозговую клетку

Название «нейронная сеть» связано с биологическими нейронными сетями.

Но искусственный нейрон — это математическая модель.

Он не является точной копией настоящего нейрона.

Искусственный нейрон выполняет вычисление:

```text
входы
↓
умножение на веса
↓
суммирование
↓
bias
↓
активация
↓
выход
```

Поэтому полезнее думать о нейронной сети как о математической вычислительной системе.

---

## 21. Простая сеть на Python

Можно представить сеть из двух слоёв:

```python
def relu(x):
    return max(0, x)


x1 = 2
x2 = 3

# Первый слой
h1 = relu(x1 * 0.5 + x2 * 0.2 + 1)
h2 = relu(x1 * 0.1 + x2 * 0.8 - 1)

# Второй слой
y = h1 * 0.7 + h2 * 0.4 + 0.2

print(y)
```

Здесь:

```text
x1, x2
```

— входы.

```text
h1, h2
```

— промежуточные нейроны.

```text
y
```

— выход.

Это очень маленькая сеть, но принцип тот же.

---

## 22. Как это выглядит концептуально

```text
Входной слой

●   ●   ●
 \  |  /
  \ | /
   \|/
   ● ● ●
   │││
   │││
   ● ●
    \/
    ●

Выход
```

Важно понимать, что линии между нейронами — это не просто соединения.

Каждое соединение имеет числовой вес.

Именно эти веса обучаются.

---

## 23. Что определяет архитектуру сети

При создании нейронной сети нужно определить:

* количество слоёв;
* количество нейронов в слоях;
* функции активации;
* способ обработки входных данных;
* тип выходного слоя.

Например:

```text
4 входа
↓
16 нейронов
↓
16 нейронов
↓
2 выхода
```

Это одна архитектура.

А:

```text
4 входа
↓
64 нейрона
↓
32 нейрона
↓
2 выхода
```

уже другая.

Архитектура определяет структуру модели.

---

## Практика

Напишите функцию одного искусственного нейрона:

```python
def neuron(x1, x2, w1, w2, b):
    z = x1 * w1 + x2 * w2 + b
    return max(0, z)
```

Проверьте разные значения:

```python
print(neuron(2, 3, 0.5, 0.2, 1))
print(neuron(10, 1, -0.2, 0.8, -1))
```

Затем попробуйте самостоятельно сделать слой из трёх нейронов.

---

## Что нужно запомнить

* Искусственный нейрон получает числовые входы.
* Каждый вход имеет свой вес.
* Нейрон вычисляет взвешенную сумму.
* К результату добавляется смещение `bias`.
* Затем обычно применяется функция активации.
* Несколько нейронов образуют слой.
* Несколько слоёв образуют нейронную сеть.
* Веса и смещения являются обучаемыми параметрами.
* Архитектура определяет структуру сети.
* Нелинейные функции активации позволяют сети описывать сложные зависимости.
* Искусственный нейрон — математическая модель, а не точная копия биологического нейрона.
