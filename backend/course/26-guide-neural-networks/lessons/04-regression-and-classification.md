# Регрессия и классификация

## Цель

Разобраться в двух фундаментальных типах задач машинного обучения — классификации и регрессии.

После урока вы должны понимать:

* чем классификация отличается от регрессии;
* что такое класс;
* что такое бинарная и многоклассовая классификация;
* что такое числовое предсказание;
* как выбрать тип задачи;
* как одна и та же предметная область может содержать разные задачи машинного обучения.

---

## 1. Модель должна что-то предсказывать

Любая задача машинного обучения начинается с вопроса:

> Что именно должна предсказать модель?

Например:

```text
Я хочу определить, есть ли дефект.
```

или:

```text
Я хочу предсказать температуру через 10 минут.
```

Это две разные задачи.

В первой нужно выбрать категорию:

```text
дефект / нет дефекта
```

Во второй нужно получить число:

```text
78.4 °C
```

Первый случай — **классификация**.

Второй — **регрессия**.

---

## 2. Классификация

Классификация — это задача, в которой модель должна определить, к какому классу относится объект.

Например:

```text
изображение детали
        ↓
      модель
        ↓
┌─────────────────┐
│ OK              │
│ DEFECT          │
└─────────────────┘
```

Или:

```text
письмо
  ↓
спам / не спам
```

Или:

```text
состояние двигателя
  ↓
норма / предупреждение / авария
```

В каждом случае существует набор заранее определённых категорий.

---

## 3. Бинарная классификация

Если существует только два класса, задача называется **бинарной классификацией**.

Например:

```text
0 → норма
1 → авария
```

Или:

```text
0 → дефекта нет
1 → дефект есть
```

Модель может вернуть вероятность:

```text
P(defect) = 0.92
```

После этого можно использовать порог:

```text
если P >= 0.5:
    DEFECT
иначе:
    OK
```

Порог не обязательно должен быть именно `0.5`.

Его можно выбирать в зависимости от задачи и стоимости ошибок.

---

## 4. Многоклассовая классификация

Если классов больше двух, возникает многоклассовая классификация.

Например:

```text
0 → стальная деталь
1 → алюминиевая деталь
2 → пластиковая деталь
```

Или для компьютерного зрения:

```text
0 → гайка
1 → болт
2 → шайба
3 → винт
```

Модель может выдать набор вероятностей:

```text
гайка    0.05
болт     0.10
шайба    0.80
винт     0.05
```

Наиболее вероятный класс:

```text
шайба
```

---

## 5. Многоклассовая классификация и несколько объектов

Важно не путать:

```text
многоклассовую классификацию
```

и:

```text
обнаружение нескольких объектов
```

Если на фотографии находится:

```text
гайка
болт
шайба
```

и нам нужно определить только один главный класс изображения, это одна задача.

Если нужно:

```text
найти все объекты
определить их классы
определить их координаты
```

это уже задача детекции объектов.

Мы подробно сталкивались с этим в разделе компьютерного зрения.

---

## 6. Регрессия

При регрессии модель предсказывает числовое значение.

Например:

```text
температура
ток
нагрузка
обороты
        ↓
      модель
        ↓
температура через 10 минут
```

Результат:

```text
83.7
```

Другие примеры:

```text
скорость → тормозной путь
```

```text
площадь → стоимость
```

```text
датчики → уровень жидкости
```

```text
вибрация → остаточный ресурс
```

Во всех случаях модель должна получить число.

---

## 7. Пример с промышленным двигателем

Представим, что у нас есть:

```text
temperature
current
vibration
speed
```

Мы можем поставить разные задачи.

### Задача 1

Предсказать:

```text
норма / авария
```

Это классификация.

### Задача 2

Предсказать:

```text
температуру через 5 минут
```

Это регрессия.

### Задача 3

Предсказать:

```text
остаточный ресурс двигателя в часах
```

Тоже регрессия.

Одна и та же система может использовать несколько моделей для разных задач.

---

## 8. Формальная запись

Пусть:

```text
X
```

— входные признаки.

Для классификации:

```text
X → y
```

где:

```text
y ∈ {0, 1}
```

для бинарной задачи.

Или:

```text
y ∈ {0, 1, 2, 3}
```

для четырёх классов.

Для регрессии:

```text
X → y
```

где:

```text
y ∈ R
```

То есть `y` может принимать числовые значения.

---

## 9. Почему нельзя просто использовать одно и то же обучение

Предположим, модель должна предсказать:

```text
температура = 78.3
```

Если модель выдаст:

```text
77.9
```

это довольно близкий результат.

Но если задача классификации:

```text
OK
DEFECT
```

то результат:

```text
0.51
```

может быть совершенно иначе интерпретирован.

Для разных задач используются разные функции потерь, выходные слои и способы оценки результата.

---

## 10. Функция потерь

Во время обучения модели нужно понимать, насколько её предсказание отличается от правильного ответа.

Для регрессии можно, например, сравнить:

```text
правильное значение = 80
предсказание = 75
```

Ошибка:

```text
5
```

Для классификации ситуация другая.

Например:

```text
правильный класс = DEFECT
модель:
OK     = 0.10
DEFECT = 0.90
```

Здесь модель уверена в правильном классе.

Если же:

```text
OK     = 0.80
DEFECT = 0.20
```

ошибка будет значительно серьёзнее.

Математический способ измерения этой ошибки называется **функцией потерь**.

Позже мы разберём её подробно.

---

## 11. Метрики классификации

После обучения нужно оценить модель.

Самая простая метрика:

```text
accuracy
```

Она показывает долю правильных предсказаний.

Например:

```text
100 объектов
90 предсказаны правильно
```

Тогда:

```text
accuracy = 90%
```

Но accuracy не всегда достаточно.

---

## 12. Матрица ошибок

Для бинарной классификации полезно рассматривать четыре ситуации:

```text
                Реальность
              0          1

Предсказание
0          TN         FN

1          FP         TP
```

Где:

```text
TP — правильно найден положительный объект
TN — правильно найден отрицательный объект
FP — ложное срабатывание
FN — пропущенный положительный объект
```

Для промышленной системы это очень важно.

Например:

```text
DEFECT = 1
OK = 0
```

### FP

Модель сказала:

```text
DEFECT
```

но деталь была хорошей.

### FN

Модель сказала:

```text
OK
```

но деталь была дефектной.

В реальном производстве цена этих ошибок может быть совершенно разной.

---

## 13. Precision и recall

Из матрицы ошибок можно получить другие метрики.

**Precision** показывает, насколько часто найденные моделью положительные объекты действительно положительные.

**Recall** показывает, какую долю настоящих положительных объектов модель смогла обнаружить.

Например, для поиска дефектов:

```text
precision → насколько часто "DEFECT" действительно дефект
recall → сколько реальных дефектов мы нашли
```

Это особенно важно, когда пропуск дефекта значительно хуже ложного брака.

---

## 14. Метрики регрессии

Для регрессии используются другие показатели.

Например, **MAE** — средняя абсолютная ошибка.

Если правильные значения:

```text
100
110
120
```

а модель предсказала:

```text
98
114
117
```

абсолютные ошибки:

```text
2
4
3
```

Средняя:

```text
MAE = (2 + 4 + 3) / 3 = 3
```

То есть модель в среднем ошибается на 3 единицы.

---

## 15. MSE

Ещё одна популярная метрика — **MSE**, средняя квадратичная ошибка.

Сначала каждая ошибка возводится в квадрат.

Например:

```text
ошибки:

2
4
3
```

получаем:

```text
4
16
9
```

Среднее:

```text
MSE = (4 + 16 + 9) / 3
```

Большие ошибки сильнее влияют на MSE из-за возведения в квадрат.

---

## 16. Пример на Python

Для классической машинной классификации можно использовать библиотеку `scikit-learn`.

Например:

```python
from sklearn.tree import DecisionTreeClassifier

X = [
    [50, 2.1],
    [55, 2.4],
    [80, 4.5],
    [85, 4.8],
]

y = [
    0,
    0,
    1,
    1,
]

model = DecisionTreeClassifier()
model.fit(X, y)

prediction = model.predict([[78, 4.2]])

print(prediction)
```

Модель получает:

```text
температура
ток
```

и пытается определить класс:

```text
0 или 1
```

Это простой пример классификации.

---

## 17. Пример регрессии

Для регрессии можно использовать другую модель:

```python
from sklearn.tree import DecisionTreeRegressor

X = [
    [50, 2.1],
    [55, 2.4],
    [80, 4.5],
    [85, 4.8],
]

y = [
    52,
    57,
    83,
    89,
]

model = DecisionTreeRegressor()
model.fit(X, y)

prediction = model.predict([[78, 4.2]])

print(prediction)
```

Теперь `y` — это число.

Модель пытается предсказать числовое значение.

---

## 18. Как определить тип задачи

Задайте простой вопрос:

> Что именно должна вернуть модель?

Если ответ:

```text
одна из категорий
```

то это классификация.

Если ответ:

```text
числовое значение
```

то это регрессия.

Например:

```text
Будет ли авария?
→ классификация
```

```text
Какой будет уровень?
→ регрессия
```

```text
Какой тип детали?
→ классификация
```

```text
Какой будет расход энергии?
→ регрессия
```

---

## 19. Иногда задача сложнее

Не всегда задача сводится к одному числу или одному классу.

Например, на изображении нужно:

```text
найти несколько деталей
определить их классы
определить координаты
```

Это уже задача обнаружения объектов.

Или:

```text
определить каждый пиксель изображения
```

Это сегментация.

Или:

```text
создать текстовое описание изображения
```

Это уже другая постановка.

Поэтому классификация и регрессия — фундаментальные задачи, но далеко не единственные.

---

## 20. Связь с нейронными сетями

Нейронные сети могут решать и классификационные, и регрессионные задачи.

Например:

```text
изображение
    ↓
нейросеть
    ↓
вероятность дефекта
```

Это классификация.

А:

```text
датчики
   ↓
нейросеть
   ↓
температура через 10 минут
```

Это регрессия.

То есть тип задачи определяется не тем, используем ли мы нейронную сеть.

Он определяется тем, **какой результат нам нужен**.

## Практика

Придумайте по пять задач для:

### Классификации

Например:

```text
дефект / нет дефекта
```

### Регрессии

Например:

```text
температура через 10 минут
```

После этого для каждой задачи определите:

```text
входные данные
признаки
целевую переменную
```

Например:

```text
Задача:
определить наличие перегрева.

Признаки:
temperature
current
vibration

Цель:
0 — норма
1 — перегрев
```

---

## Что нужно запомнить

* Классификация предсказывает категорию.
* Регрессия предсказывает числовое значение.
* Бинарная классификация имеет два класса.
* Многоклассовая классификация имеет несколько классов.
* Для классификации важны не только accuracy, но и ошибки разных типов.
* Для регрессии используются числовые метрики, например MAE и MSE.
* Нейронные сети могут решать и классификационные, и регрессионные задачи.
* Тип задачи определяется требуемым результатом, а не выбранным алгоритмом.
