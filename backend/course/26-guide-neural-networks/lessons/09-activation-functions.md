# Функции активации

## Цель

Понять, зачем нейронным сетям нужны функции активации и чем отличаются основные функции: ReLU, sigmoid, tanh и softmax.

После урока вы должны понимать:

* что делает функция активации;
* зачем нейронной сети нужна нелинейность;
* как работает ReLU;
* где используется sigmoid;
* где используется tanh;
* зачем нужен softmax;
* почему функция активации зависит от задачи и положения слоя.

---

## 1. Что происходит после взвешенной суммы

Мы уже знаем, что нейрон сначала вычисляет:

```text
z = w · x + b
```

Но затем результат обычно передаётся в функцию активации:

```text
a = f(z)
```

Получается:

```text
вход
 ↓
веса
 ↓
взвешенная сумма
 ↓
bias
 ↓
функция активации
 ↓
выход
```

Функция активации преобразует результат нейрона перед передачей дальше.

---

## 2. Зачем вообще нужна функция активации

На первый взгляд может показаться, что достаточно:

```text
z = w · x + b
```

Но если объединить несколько слоёв, содержащих только линейные преобразования, вся сеть всё равно будет эквивалентна одному линейному преобразованию.

Например:

```text
x
 ↓
W1
 ↓
W2
 ↓
W3
 ↓
y
```

можно математически объединить в одно преобразование.

Добавление нелинейной функции:

```text
f(...)
```

между слоями позволяет строить значительно более сложные зависимости.

---

## 3. Что такое нелинейность

Линейная зависимость может быть представлена простой прямой:

```text
y = ax + b
```

Но реальные задачи часто гораздо сложнее.

Например:

```text
температура + вибрация
            ↓
        сложная зона
            ↓
          авария
```

Граница между классами может быть нелинейной.

Функции активации позволяют нейронной сети моделировать такие зависимости.

---

## 4. ReLU

Самая простая и очень распространённая функция — **ReLU**.

Она определяется:

```text
ReLU(x) = max(0, x)
```

То есть:

```text
если x < 0 → 0
если x >= 0 → x
```

Примеры:

```text
ReLU(-10) = 0
ReLU(-1)  = 0
ReLU(0)   = 0
ReLU(2)   = 2
ReLU(8)   = 8
```

Графически:

```text
y
↑
│        /
│       /
│      /
│     /
│____/────────→ x
```

---

## 5. Почему ReLU удобна

ReLU очень проста:

```python
def relu(x):
    return max(0, x)
```

Она хорошо работает во многих глубоких сетях.

При положительном значении:

```text
ReLU(x) = x
```

Поэтому вычисление достаточно простое.

ReLU особенно часто встречается во внутренних слоях нейронных сетей.

---

## 6. Проблема ReLU

У ReLU есть особенность.

Для отрицательных значений:

```text
ReLU(x) = 0
```

Градиент в отрицательной области равен нулю.

Если нейрон надолго оказывается в состоянии, когда его значения отрицательные, он может перестать получать полезные обновления.

Эту проблему называют **dying ReLU**.

Она не означает, что ReLU плохая.

Это просто одна из особенностей функции.

---

## 7. Leaky ReLU

Один из вариантов ReLU — **Leaky ReLU**.

Вместо полного обнуления отрицательной части используется небольшой наклон:

```text
если x >= 0:
    y = x

если x < 0:
    y = αx
```

Например:

```text
α = 0.01
```

Тогда:

```text
LeakyReLU(-10) = -0.1
```

вместо:

```text
ReLU(-10) = 0
```

Это позволяет сохранить небольшой градиент в отрицательной области.

---

## 8. Sigmoid

Другая известная функция — **sigmoid**.

Она преобразует любое число в диапазон:

```text
0 ... 1
```

Её формула:

```text
σ(x) = 1 / (1 + e^-x)
```

Примерно:

```text
sigmoid(-10) ≈ 0
sigmoid(-2)  ≈ 0.12
sigmoid(0)   = 0.5
sigmoid(2)   ≈ 0.88
sigmoid(10)  ≈ 1
```

График выглядит как плавная S-образная кривая.

---

## 9. Почему sigmoid полезна

Диапазон:

```text
0 ... 1
```

удобен для интерпретации как вероятность в некоторых задачах.

Например:

```text
sigmoid(output) = 0.92
```

можно интерпретировать как высокую вероятность положительного класса, если модель и функция потерь настроены соответствующим образом.

Поэтому sigmoid часто используется на выходе бинарного классификатора.

---

## 10. Пример бинарной классификации

Пусть модель должна определить:

```text
0 → OK
1 → DEFECT
```

Последний нейрон может выдать:

```text
z = 2.4
```

После sigmoid:

```text
sigmoid(2.4) ≈ 0.92
```

Можно интерпретировать это как высокую вероятность класса `DEFECT`.

Если:

```text
z = -2.4
```

получим значение около:

```text
0.08
```

---

## 11. Почему sigmoid не всегда используют внутри сети

Sigmoid имеет проблему насыщения.

При очень больших положительных или отрицательных значениях её градиент становится очень маленьким.

Например:

```text
x = 20
```

sigmoid почти равна:

```text
1
```

а изменение выхода при небольшом изменении `x` очень мало.

Это может затруднять обучение глубоких сетей.

Поэтому во внутренних слоях современных нейросетей часто используют ReLU и её варианты.

---

## 12. Tanh

Функция **tanh** похожа на sigmoid, но возвращает значения в диапазоне:

```text
-1 ... 1
```

Примеры:

```text
tanh(-∞) → -1
tanh(0)  = 0
tanh(+∞) → 1
```

График также имеет S-образную форму.

Основное отличие:

```text
sigmoid → 0 ... 1
tanh    → -1 ... 1
```

---

## 13. Почему tanh может быть удобной

Если данные естественным образом имеют положительное и отрицательное направление, диапазон:

```text
-1 ... 1
```

может быть удобнее.

Tanh исторически часто использовалась в рекуррентных нейронных сетях.

В современных архитектурах выбор функций активации зависит от конкретной модели.

---

## 14. Softmax

Теперь рассмотрим ситуацию, когда у нас несколько классов.

Например:

```text
кошка
собака
лошадь
```

Модель может выдать три исходных значения:

```text
2.1
1.2
0.1
```

Эти значения сами по себе не являются вероятностями.

Функция **softmax** преобразует их в значения, сумма которых равна:

```text
1
```

Например:

```text
кошка   0.66
собака  0.22
лошадь  0.12
```

Сумма:

```text
0.66 + 0.22 + 0.12 = 1.00
```

---

## 15. Зачем нужен softmax

Softmax особенно полезен для многоклассовой классификации, когда модель должна выбрать один класс из нескольких.

Например:

```text
деталь:
гайка
болт
шайба
винт
```

Модель может выдать:

```text
гайка  = 0.05
болт   = 0.10
шайба  = 0.80
винт   = 0.05
```

Наиболее вероятный класс:

```text
шайба
```

---

## 16. Softmax не просто делит числа на сумму

Формула softmax:

```text
softmax(x_i) = e^(x_i) / Σ e^(x_j)
```

Экспонента делает разницу между значениями более выраженной.

Например:

```text
2
1
0
```

после softmax превращаются примерно в:

```text
0.67
0.24
0.09
```

Получаем распределение по классам.

---

## 17. Выбор функции зависит от задачи

Нельзя сказать:

> «Для любой нейросети нужно использовать ReLU».

Функция зависит от положения и назначения слоя.

Упрощённо:

```text
Внутренние слои
→ часто ReLU или её варианты

Бинарная классификация
→ часто sigmoid на выходе

Многоклассовая классификация
→ часто softmax на выходе

Некоторые архитектуры
→ tanh или другие функции
```

Это не универсальный закон, а распространённые варианты.

---

## 18. Выходной слой

Тип выходного слоя должен соответствовать задаче.

### Бинарная классификация

```text
выход → 1 число
```

Например:

```text
0.92
```

### Многоклассовая классификация

```text
выход → несколько значений
```

Например:

```text
[0.05, 0.15, 0.80]
```

### Регрессия

```text
выход → числовое значение
```

Например:

```text
83.7
```

Для регрессии часто используют линейный выход без ограничивающей активации.

---

## 19. Пример сети

Представим:

```text
вход
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
Sigmoid
 ↓
результат
```

Такая схема может использоваться для бинарной классификации.

Например:

```text
датчики двигателя
       ↓
   нейросеть
       ↓
0.94
       ↓
DEFECT
```

## 20. Простая реализация функций

```python
import math


def relu(x):
    return max(0, x)


def sigmoid(x):
    return 1 / (1 + math.exp(-x))
```

Проверим:

```python
print(relu(-5))
print(relu(5))

print(sigmoid(-5))
print(sigmoid(0))
print(sigmoid(5))
```

---

## 21. Softmax на Python

Простая реализация:

```python
import math


def softmax(values):
    exp_values = [
        math.exp(value)
        for value in values
    ]

    total = sum(exp_values)

    return [
        value / total
        for value in exp_values
    ]


result = softmax([2.1, 1.2, 0.1])

print(result)
print(sum(result))
```

Сумма элементов результата будет близка к:

```text
1.0
```

В реальных библиотеках используются более устойчивые численные реализации, особенно для больших значений.

---

## 22. Функция активации не обучается

Важно не путать функцию активации с параметрами модели.

Например:

```text
weights → обучаются
biases  → обучаются
ReLU    → задана архитектурой
```

Модель изменяет веса и смещения.

Функция активации обычно выбирается разработчиком.

---

## 23. Почему нейросеть без активации слабее

Рассмотрим:

```text
x
 ↓
Linear
 ↓
Linear
 ↓
Linear
 ↓
y
```

Несмотря на три слоя, вся система остаётся линейной.

Добавим:

```text
x
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
y
```

Теперь сеть может моделировать гораздо более сложные зависимости.

Именно поэтому нелинейные функции активации являются фундаментальной частью глубокого обучения.

## Что нужно запомнить

* Функция активации применяется после взвешенной суммы нейрона.
* Нелинейность позволяет нейронной сети моделировать сложные зависимости.
* ReLU обнуляет отрицательные значения и часто используется во внутренних слоях.
* Leaky ReLU сохраняет небольшой отрицательный градиент.
* Sigmoid преобразует значение в диапазон `0...1` и часто используется для бинарной классификации.
* Tanh возвращает значения в диапазоне `-1...1`.
* Softmax преобразует набор выходов в распределение по классам.
* Функция активации выбирается в зависимости от архитектуры и задачи.
* Веса и bias обучаются, а функция активации обычно задаётся заранее.
