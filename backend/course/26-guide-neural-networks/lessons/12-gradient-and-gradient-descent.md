# Градиент и идея градиентного спуска

## Цель

Понять, как нейронная сеть определяет направление изменения своих параметров и почему градиентный спуск позволяет уменьшать ошибку.

После урока вы должны понимать:

* что такое производная;
* что показывает наклон функции;
* что такое градиент;
* почему градиент связан с обучением;
* как работает градиентный спуск;
* что такое learning rate;
* почему слишком большой и слишком маленький шаг могут быть проблемой.

---

## Напомним задачу обучения

У нас есть нейронная сеть.

У неё есть параметры:

```text
w₁
w₂
w₃
...
b
```

Модель делает предсказание.

Функция потерь показывает ошибку.

Теперь возникает главный вопрос:

> Как понять, в какую сторону изменить каждый параметр?

Если просто менять веса случайным образом, обучение будет крайне неэффективным.

Нам нужно математическое направление.

---

## Представим функцию

Начнём с простой функции:

```text
y = x²
```

Если:

```text
x = 2
```

получаем:

```text
y = 4
```

Если:

```text
x = 3
```

получаем:

```text
y = 9
```

График имеет форму чаши:

```text
        /
       /
      /
-----╯-----
```

В нижней точке значение функции минимально.

---

## Что такое производная

Производная показывает, как изменяется функция при небольшом изменении аргумента.

Для:

```text
y = x²
```

производная:

```text
dy/dx = 2x
```

Если:

```text
x = 3
```

то:

```text
dy/dx = 6
```

Если:

```text
x = -3
```

то:

```text
dy/dx = -6
```

Знак производной показывает направление изменения функции.

---

## Интуитивный смысл

Представим склон горы.

Если мы стоим на склоне, нам важно знать:

```text
куда вверх?
куда вниз?
насколько крутой склон?
```

Производная в одном измерении даёт похожую информацию.

Если значение положительное:

```text
функция растёт вправо
```

Если отрицательное:

```text
функция уменьшается вправо
```

Если близко к нулю:

```text
склон небольшой
```

---

## Что нужно нейронной сети

Нейронной сети нужно уменьшать функцию потерь.

Поэтому ей нужно понимать:

> В какую сторону изменить параметр, чтобы loss уменьшился?

Производная позволяет получить эту информацию.

Например:

```text
dLoss/dw > 0
```

означает, что увеличение `w` увеличивает loss.

Чтобы уменьшить loss, логично двигаться в противоположную сторону.

---

## От одного параметра к множеству

У нейронной сети параметров может быть очень много.

Например:

```text
w₁
w₂
w₃
...
w₁₀₀₀₀₀₀
```

Нужно узнать влияние каждого параметра на функцию потерь.

Получается набор производных:

```text
dLoss/dw₁
dLoss/dw₂
dLoss/dw₃
...
```

Этот набор называют **градиентом**.

---

## Что такое градиент

Градиент — это вектор производных функции по её параметрам.

Упрощённо:

```text
gradient =
[
    dLoss/dw₁,
    dLoss/dw₂,
    dLoss/dw₃,
    ...
]
```

Он показывает направление наиболее быстрого роста функции.

Поэтому для уменьшения функции мы движемся в противоположном направлении.

---

## Градиентный спуск

**Градиентный спуск (gradient descent)** — метод оптимизации, при котором параметры изменяются в направлении, противоположном градиенту.

Упрощённо:

```text
новый параметр =
старый параметр - шаг × градиент
```

Например:

```text
w_new = w_old - learning_rate × gradient
```

---

## Learning rate

`learning_rate` определяет размер шага.

Пусть:

```text
w = 2
gradient = 4
learning_rate = 0.1
```

Тогда:

```text
w_new = 2 - 0.1 × 4
```

Получаем:

```text
w_new = 1.6
```

---

## Что будет при большом learning rate

Пусть:

```text
learning_rate = 1
```

Тогда:

```text
w_new = 2 - 1 × 4
       = -2
```

Шаг очень большой.

Если поверхность функции сложная, такие шаги могут приводить к перескакиванию через минимум.

---

## Что будет при маленьком learning rate

Например:

```text
learning_rate = 0.000001
```

Тогда изменения будут очень маленькими.

Это может сделать обучение чрезвычайно медленным.

Поэтому learning rate — один из важных параметров обучения.

---

## Аналогия с горой

Представим, что мы стоим на горе и хотим спуститься в долину.

Мы не видим всю поверхность.

Мы можем оценить локальный наклон.

Если склон идёт вниз вправо:

```text
       ●
        \
         \
          \
```

делаем шаг вправо.

Если вниз влево:

```text
          ●
         /
        /
       /
```

двигаемся влево.

И повторяем процесс.

---

## Минимум функции

Цель градиентного спуска — найти область, где функция принимает небольшое значение.

Условно:

```text
loss
 ^
 |\
 | \
 |  \
 |   \
 |    \____
 |         \__
 +----------------> parameter
```

Самая низкая область соответствует меньшему значению loss.

Но в реальных нейронных сетях пространство параметров может иметь миллионы или миллиарды измерений.

Поэтому визуально представить его невозможно.

Математическая идея при этом остаётся той же.

---

## Локальный минимум

Градиентный спуск не обязательно находит глобально лучший возможный вариант.

Он может оказаться в локальной области минимума.

В современных нейронных сетях ситуация ещё сложнее: поверхность функции потерь может иметь множество особенностей.

Поэтому реальные алгоритмы оптимизации используют дополнительные методы и настройки.

---

## Простейшая реализация на Python

Рассмотрим функцию:

```text
f(x) = x²
```

Её производная:

```text
f'(x) = 2x
```

Попробуем двигаться к минимуму.

```python
x = 10.0
learning_rate = 0.1

for step in range(20):
    gradient = 2 * x
    x = x - learning_rate * gradient

    print(x)
```

Постепенно значение `x` будет приближаться к:

```text
0
```

А:

```text
x²
```

будет уменьшаться.

---

## Почему это похоже на обучение нейронной сети

В примере:

```text
x
```

был всего один параметр.

В нейронной сети параметров намного больше:

```text
w₁
w₂
w₃
...
b
```

Но принцип тот же:

```text
вычислить loss
      ↓
вычислить градиенты
      ↓
изменить параметры
      ↓
повторить
```

---

## Градиент для нескольких параметров

Пусть есть:

```text
w₁ = 1
w₂ = 2
```

и градиент:

```text
gradient = [0.5, -0.2]
```

При:

```text
learning_rate = 0.1
```

получим:

```text
w₁_new = 1 - 0.1 × 0.5
       = 0.95
```

и:

```text
w₂_new = 2 - 0.1 × (-0.2)
       = 2.02
```

Обрати внимание на второй параметр.

Градиент отрицательный, поэтому вычитание отрицательного значения увеличивает параметр.

---

## Что делает оптимизатор

На практике разработчик обычно не реализует формулу обновления вручную.

Библиотеки машинного обучения предоставляют оптимизаторы.

Например, в PyTorch:

```python
import torch

parameter = torch.tensor(
    10.0,
    requires_grad=True
)

optimizer = torch.optim.SGD(
    [parameter],
    lr=0.1
)
```

Далее оптимизатор может выполнять шаги обновления.

---

## Почему градиенты вычисляются автоматически

Современные библиотеки умеют строить вычислительный граф.

Например:

```text
x
 ↓
× w
 ↓
+
 ↓
loss
```

Из этого графа можно вычислить производные.

В PyTorch для этого используется механизм автоматического дифференцирования.

Например:

```python
import torch

x = torch.tensor(3.0, requires_grad=True)

y = x ** 2

y.backward()

print(x.grad)
```

Результат:

```text
6
```

Потому что:

```text
d(x²)/dx = 2x
```

и при:

```text
x = 3
```

получаем:

```text
6
```

---

## Градиент — не ошибка

Важно не путать:

**Loss**

показывает, насколько модель ошибается.

**Gradient**

показывает, как изменение параметров влияет на loss.

То есть:

```text
loss → насколько плохо

gradient → в какую сторону менять параметры
```

---

## Полный цикл

Теперь можем собрать предыдущие уроки:

```text
данные
  ↓
нейронная сеть
  ↓
предсказание
  ↓
функция потерь
  ↓
loss
  ↓
градиент
  ↓
изменение весов
  ↓
новое предсказание
```

Этот цикл повторяется много раз.

---

## Главное

Градиентный спуск — это не какая-то отдельная «нейросетевая магия».

Это метод оптимизации.

Он позволяет постепенно изменять параметры модели таким образом, чтобы функция потерь уменьшалась.

Главная идея:

```text
найти направление уменьшения ошибки
        ↓
сделать небольшой шаг
        ↓
повторить
```

---

## Что нужно запомнить

1. Производная показывает, как меняется функция.
2. Градиент объединяет производные по множеству параметров.
3. Градиент показывает направление наиболее быстрого роста функции.
4. Для уменьшения loss параметры изменяют в противоположном направлении.
5. Градиентный спуск повторяет небольшие шаги к области меньшей ошибки.
6. Learning rate определяет размер шага.
7. Слишком большой шаг может сделать обучение нестабильным.
8. Слишком маленький шаг может сильно замедлить обучение.
9. Современные библиотеки умеют автоматически вычислять градиенты.
10. Loss показывает величину ошибки, а gradient помогает понять, как изменять параметры.
