# Веса, смещения и взвешенная сумма

## Цель

Подробно разобраться в главных вычислениях искусственного нейрона: весах, смещениях и взвешенной сумме.

После урока вы должны понимать:

* что такое вес;
* как вес влияет на входной сигнал;
* зачем нужен bias;
* как вычисляется взвешенная сумма;
* как представить вычисления нейрона в виде вектора и матрицы;
* почему веса являются основными обучаемыми параметрами нейронной сети.

---

## 1. Вспомним устройство нейрона

Упрощённо нейрон можно представить так:

```text
x1 ── w1 ──┐
x2 ── w2 ──┼──→ сумма → bias → активация → y
x3 ── w3 ──┘
```

Здесь:

```text
x1, x2, x3
```

— входные значения.

```text
w1, w2, w3
```

— веса.

```text
bias
```

— смещение.

Внутри нейрона сначала вычисляется:

```text
z = x1w1 + x2w2 + x3w3 + b
```

А затем:

```text
y = f(z)
```

где `f` — функция активации.

---

## 2. Что делает вес

Вес определяет, насколько сильно конкретный вход влияет на результат.

Представим:

```text
x = 10
```

Если:

```text
w = 2
```

то вклад этого входа:

```text
10 × 2 = 20
```

Если:

```text
w = 0.1
```

получаем:

```text
10 × 0.1 = 1
```

Если:

```text
w = -2
```

получаем:

```text
10 × (-2) = -20
```

Таким образом:

```text
положительный вес
→ усиливает положительное влияние входа

маленький вес
→ уменьшает влияние

отрицательный вес
→ меняет направление влияния
```

---

## 3. Пример с температурой и током

Предположим, модель получает:

```text
температура = 80
ток = 4
```

Пусть веса:

```text
w_temperature = 0.05
w_current = 0.8
```

Тогда:

```text
80 × 0.05 = 4
4 × 0.8 = 3.2
```

Общая сумма:

```text
4 + 3.2 = 7.2
```

Если:

```text
bias = -5
```

получаем:

```text
z = 7.2 - 5
z = 2.2
```

---

## 4. Вес не является «важностью» в бытовом смысле

Нельзя всегда интерпретировать вес как:

> «Этот признак важнее другого».

Причин несколько.

Во-первых, значения признаков могут иметь совершенно разные масштабы.

Например:

```text
температура = 80
вибрация = 0.8
```

Вес:

```text
0.05
```

для температуры и:

```text
2
```

для вибрации не обязательно означает, что вибрация «важнее» в простом смысле.

Во-вторых, в глубокой сети веса работают совместно и интерпретировать отдельный вес бывает сложно.

---

## 5. Зачем нужен bias

Представим:

```text
y = wx
```

Если:

```text
x = 0
```

то:

```text
y = 0
```

Независимо от значения `w`.

Добавим:

```text
b
```

Получаем:

```text
y = wx + b
```

Теперь при:

```text
x = 0
```

получим:

```text
y = b
```

Это даёт модели дополнительную свободу.

---

## 6. Геометрическая интерпретация

Для одного входа:

```text
y = wx + b
```

это обычная прямая.

```text
y
↑
│        /
│       /
│      /
│     /
│____/────────→ x
```

Вес:

```text
w
```

определяет наклон.

Bias:

```text
b
```

определяет смещение линии по вертикали.

Если:

```text
w = 2
b = 3
```

получаем:

```text
y = 2x + 3
```

---

## 7. Взвешенная сумма

Рассмотрим три входа:

```text
x1 = 2
x2 = 4
x3 = 1
```

и веса:

```text
w1 = 0.5
w2 = -1
w3 = 2
```

Тогда:

```text
z =
2 × 0.5 +
4 × (-1) +
1 × 2
```

Получаем:

```text
z = 1 - 4 + 2
z = -1
```

Добавим:

```text
b = 3
```

Получаем:

```text
z = 2
```

---

## 8. Векторная запись

Вместо длинной формулы можно использовать векторы.

Вход:

```text
x = [2, 4, 1]
```

Веса:

```text
w = [0.5, -1, 2]
```

Взвешенная сумма без bias — это скалярное произведение:

```text
w · x
```

или:

```text
0.5 × 2
+
(-1) × 4
+
2 × 1
```

После этого добавляется:

```text
b
```

И получается:

```text
z = w · x + b
```

Эта запись очень важна для дальнейшего изучения нейронных сетей.

---

## 9. Почему нейронные сети используют матрицы

Один нейрон может иметь:

```text
10 входов
```

Но слой может содержать:

```text
100 нейронов
```

Если каждый нейрон получает все 10 входов:

```text
10 × 100 = 1000
```

весов.

Вместо того чтобы вычислять каждый нейрон отдельно, эти операции удобно объединять в матрицы.

Например:

```text
X × W + B
```

Это позволяет выполнять огромное количество операций эффективно.

Именно поэтому в машинном обучении так важны:

* векторы;
* матрицы;
* тензоры;
* операции линейной алгебры.

---

## 10. Матрица весов

Представим:

```text
3 входа
2 нейрона
```

Матрица весов может выглядеть так:

```text
W =
[
    [w11, w12],
    [w21, w22],
    [w31, w32]
]
```

Каждый столбец соответствует одному нейрону.

Если:

```text
x = [x1, x2, x3]
```

результат можно вычислить сразу для обоих нейронов.

---

## 11. Bias для слоя

У каждого нейрона обычно есть собственное смещение.

Для двух нейронов:

```text
b = [b1, b2]
```

Тогда:

```text
z = xW + b
```

Результат содержит два значения:

```text
z1
z2
```

После этого к каждому применяется функция активации.

---

## 12. Несколько слоёв

Первый слой:

```text
x
 ↓
W1, b1
 ↓
activation
 ↓
h
```

Второй:

```text
h
 ↓
W2, b2
 ↓
activation
 ↓
y
```

Можно записать:

```text
h = f(xW1 + b1)

y = g(hW2 + b2)
```

Таким образом, сеть представляет собой последовательность преобразований.

---

## 13. Почему веса обучаются

Предположим, модель получила:

```text
x = [2, 4]
```

и должна выдать:

```text
1
```

Но пока выдаёт:

```text
0.2
```

Значит, текущие веса не подходят.

Во время обучения алгоритм определяет, как изменение каждого веса влияет на ошибку.

Затем веса изменяются:

```text
w1 → новое значение
w2 → новое значение
b  → новое значение
```

После множества шагов модель может начать выдавать:

```text
0.95
```

вместо:

```text
0.2
```

---

## 14. Вес как обучаемая связь

Можно представить нейронную сеть как граф:

```text
●──────●
│ \    │
│  \   │
│   \  │
●──────●
```

Каждая линия имеет числовой вес.

Во время обучения сеть фактически изменяет свойства этих связей.

Поэтому в большой нейронной сети обучение может означать изменение миллионов или миллиардов чисел.

---

## 15. Начальные значения

Веса не начинают обучение с идеальных значений.

Обычно они инициализируются некоторым способом.

Например:

```text
w1 = 0.02
w2 = -0.13
w3 = 0.07
```

Затем обучение постепенно изменяет их.

Если все веса инициализировать одинаково, нейроны могут начать вести себя одинаково.

Поэтому используются специальные методы инициализации.

Позже мы подробнее разберём эту тему при изучении практического обучения нейросетей.

---

## 16. Что происходит с отрицательными весами

Отрицательный вес не означает, что вход «плохой».

Он означает, что при увеличении этого входа его вклад в линейную комбинацию направлен в отрицательную сторону.

Например:

```text
x = 10
w = -0.5
```

получаем:

```text
-5
```

Если другой вход даёт:

```text
+8
```

итоговая сумма может быть:

```text
3
```

Нейрон объединяет все влияния.

---

## 17. Нормализация и масштаб признаков

Рассмотрим:

```text
температура = 80
вибрация = 0.4
```

Численные масштабы сильно различаются.

Это может создавать проблемы для некоторых алгоритмов обучения.

Поэтому данные часто преобразуют.

Например, можно привести значения к диапазону:

```text
0 ... 1
```

или стандартизировать их.

Например:

```text
температура:
80 → 0.8

вибрация:
0.4 → 0.4
```

Конкретный способ зависит от данных и модели.

Важно понимать:

> Подготовка входов может существенно влиять на удобство и стабильность обучения.

---

## 18. Простой нейрон на Python

```python
x = [2, 4, 1]

w = [0.5, -1.0, 2.0]

b = 3.0

z = 0

for xi, wi in zip(x, w):
    z += xi * wi

z += b

print(z)
```

Здесь:

```text
x
```

— входы.

```text
w
```

— веса.

```text
b
```

— смещение.

```text
z
```

— результат до функции активации.

---

## 19. Добавим ReLU

```python
activation = max(0, z)

print(activation)
```

Теперь полный вычислительный путь:

```text
x
 ↓
weights
 ↓
weighted sum
 ↓
bias
 ↓
ReLU
 ↓
output
```

---

## 20. Нейрон в виде функции

Можно оформить вычисление как функцию:

```python
def neuron(inputs, weights, bias):
    total = 0

    for x, w in zip(inputs, weights):
        total += x * w

    total += bias

    return max(0, total)
```

Использование:

```python
x = [2, 4, 1]
w = [0.5, -1.0, 2.0]

result = neuron(x, w, 3.0)

print(result)
```

Так постепенно можно перейти от одного нейрона к целой сети.

---

## 21. Что на самом деле обучается

В простой сети:

```text
inputs
 ↓
weights
 ↓
bias
 ↓
activation
```

функция активации обычно задана заранее.

А обучаются:

```text
weights
biases
```

То есть обучение не меняет саму формулу ReLU.

Оно меняет числовые параметры, которые находятся внутри сети.

---

## 22. Параметров может быть очень много

Например:

```text
100 входов
100 нейронов
```

Количество весов:

```text
100 × 100 = 10 000
```

Плюс:

```text
100 bias
```

Итого:

```text
10 100 параметров
```

Если таких слоёв много, число параметров быстро растёт.

Это одна из причин, почему современные нейронные сети требуют значительных вычислительных ресурсов.

## Практика

Напишите функцию:

```python
def neuron(inputs, weights, bias):
    ...
```

которая:

1. принимает список входов;
2. принимает список весов;
3. вычисляет взвешенную сумму;
4. добавляет bias;
5. применяет ReLU;
6. возвращает результат.

Затем попробуйте изменить один вес и посмотреть, как изменится результат.

Например:

```text
weights = [0.5, 1.0, -0.5]
```

а затем:

```text
weights = [1.0, 1.0, -0.5]
```

Посмотрите, насколько изменился выход.

---

## Что нужно запомнить

* Вес определяет вклад конкретного входа в вычисление нейрона.
* Взвешенная сумма складывает входы с учётом их весов.
* Bias добавляет дополнительное смещение.
* Основная формула нейрона имеет вид `z = w · x + b`.
* После взвешенной суммы обычно применяется функция активации.
* Веса и bias являются обучаемыми параметрами.
* Слой можно представить как матричное преобразование.
* Большая нейронная сеть может содержать миллионы и даже миллиарды параметров.
* Изменение параметров во время обучения позволяет модели постепенно подстраиваться под данные.
