# Свёрточные нейронные сети

## Цель

Понять, почему обычные полносвязные сети неудобны для изображений и как свёрточные нейронные сети используют пространственную структуру изображения.

После урока вы должны понимать:

* зачем нужны CNN;
* что такое свёртка;
* что делает ядро свёртки;
* что такое карта признаков;
* зачем нужен pooling;
* как CNN постепенно выделяет признаки изображения;
* как выглядит простая CNN в PyTorch.

---

## Проблема обычной нейронной сети

Рассмотрим изображение:

```text
224 × 224 × 3
```

Количество значений:

```text
224 × 224 × 3 = 150528
```

Если подключить все пиксели к одному слою из 1000 нейронов, получится:

```text
150528 × 1000
```

то есть больше 150 миллионов весов только в одном слое.

Но проблема не только в количестве параметров.

---

## Пространственная структура

Изображение имеет структуру.

Пиксели рядом друг с другом обычно связаны.

Например:

```text
глаз
```

состоит из группы соседних пикселей.

Если полностью перемешать все пиксели, эта пространственная информация теряется.

CNN стараются сохранить её.

---

## Идея свёртки

Свёртка использует небольшую матрицу, которую называют:

```text
kernel
```

или:

```text
filter
```

Например:

```text
3 × 3
```

Она проходит по изображению.

Условно:

```text
┌─────────────┐
│ image       │
│    ┌───┐    │
│    │###│    │
│    └───┘    │
└─────────────┘
```

Для каждого положения вычисляется результат.

---

## Пример ядра

Пусть:

```text
1  0
0 -1
```

Это маленькая матрица.

Она применяется к участкам изображения.

В результате получается новое изображение — **карта признаков**.

---

## Что ищет фильтр

Разные фильтры могут реагировать на разные структуры:

```text
вертикальные границы
горизонтальные границы
диагонали
углы
текстуры
```

На первых слоях CNN обычно обнаруживает простые признаки.

---

## Более глубокие слои

Первые слои:

```text
границы
линии
простые текстуры
```

Следующие:

```text
простые формы
```

Ещё глубже:

```text
части объектов
```

А глубокие слои:

```text
сложные структуры
объекты
```

Это упрощённая, но полезная модель понимания CNN.

---

## Карта признаков

После применения фильтра получается:

```text
feature map
```

Например:

```text
исходное изображение
        ↓
     filter
        ↓
   feature map
```

Каждая карта показывает, где в изображении обнаруживается определённый признак.

---

## Несколько фильтров

CNN обычно использует не один фильтр.

Например:

```text
32 фильтра
```

Первый слой может создавать:

```text
32 feature maps
```

Следующий слой получает их как вход.

---

## Каналы

Цветное изображение имеет:

```text
3 канала
```

RGB:

```text
R
G
B
```

Свёрточный слой работает с несколькими входными каналами одновременно.

Например:

```text
input channels = 3
output channels = 32
```

означает:

```text
RGB изображение
        ↓
32 карты признаков
```

---

## Stride

**Stride** определяет, на сколько пикселей фильтр перемещается за один шаг.

Например:

```text
stride = 1
```

означает движение на один пиксель.

При:

```text
stride = 2
```

фильтр перескакивает через один пиксель.

Больший stride уменьшает пространственный размер результата.

---

## Padding

При обработке изображения края могут обрабатываться иначе, чем центральные области.

Для контроля размера используют:

```text
padding
```

Например:

```text
padding = 1
```

добавляет границу вокруг изображения.

---

## Pooling

После свёрточных слоёв часто используется pooling.

Один из вариантов:

```text
Max Pooling
```

Например:

```text
2 × 2
```

берёт максимальное значение из каждого блока.

```text
1  5
2  3
```

становится:

```text
5
```

---

## Зачем нужен pooling

Pooling может:

* уменьшать размер данных;
* снижать вычислительную нагрузку;
* сохранять наиболее сильные признаки;
* делать представление менее чувствительным к небольшим смещениям.

---

## Типичная CNN

Простейшая структура:

```text
Image
 ↓
Conv
 ↓
ReLU
 ↓
Pooling
 ↓
Conv
 ↓
ReLU
 ↓
Pooling
 ↓
Flatten
 ↓
Linear
 ↓
Output
```

---

## Flatten

После нескольких свёрточных слоёв получается многомерный тензор.

Полносвязному слою часто нужен плоский вектор.

Поэтому используется:

```text
Flatten
```

Например:

```text
64 × 7 × 7
```

преобразуется в:

```text
3136
```

потому что:

```text
64 × 7 × 7 = 3136
```

---

## CNN в PyTorch

Пример:

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(
        in_channels=3,
        out_channels=16,
        kernel_size=3,
        padding=1
    ),
    nn.ReLU(),

    nn.MaxPool2d(2),

    nn.Conv2d(
        in_channels=16,
        out_channels=32,
        kernel_size=3,
        padding=1
    ),
    nn.ReLU(),

    nn.MaxPool2d(2)
)
```

Это пока только свёрточная часть модели.

---

## Что делает `Conv2d`

Например:

```python
nn.Conv2d(
    3,
    16,
    kernel_size=3,
    padding=1
)
```

означает:

```text
3 входных канала
↓
16 выходных каналов
```

с ядром:

```text
3 × 3
```

---

## Почему CNN экономит параметры

Полносвязная сеть может подключать каждый пиксель к каждому нейрону.

CNN использует локальные области.

Кроме того, один и тот же фильтр применяется к разным участкам изображения.

Это называется **разделением параметров**.

Один набор весов может искать один и тот же признак в разных местах изображения.

---

## Смещение объекта

Представим, что объект находится:

```text
слева
```

а затем:

```text
справа
```

Фильтр CNN может обнаружить один и тот же локальный признак в обоих случаях.

Это одно из важных преимуществ свёрточного подхода.

## CNN и компьютерное зрение

CNN долгое время были одной из главных архитектур для задач:

```text
классификация изображений
детекция объектов
сегментация
распознавание
анализ видео
```

Мы уже изучали эти задачи в модуле компьютерного зрения.

Теперь можно понять, какая нейросетевая архитектура может лежать под ними.

---

## Пример из промышленности

Представим камеру на производственной линии.

Нужно определить:

```text
деталь нормальная
```

или:

```text
деталь имеет дефект
```

Изображение:

```text
камера
 ↓
CNN
 ↓
признаки
 ↓
классификация
 ↓
норма / дефект
```

---

## CNN не является готовым детектором

Важно понимать:

```text
CNN
```

— это архитектурный подход.

Для конкретной задачи ещё нужны:

* данные;
* разметка;
* функция потерь;
* обучение;
* подходящая архитектура;
* проверка качества.

---

## CNN и современные модели

CNN остаются важным классом архитектур.

Но современные системы компьютерного зрения также используют:

```text
Vision Transformers
гибридные архитектуры
готовые предобученные модели
```

Поэтому CNN — не единственный современный подход.

---

## Главное

Свёрточная сеть использует пространственную структуру данных.

Вместо того чтобы рассматривать каждый пиксель как полностью независимый вход, она ищет локальные признаки с помощью обучаемых фильтров.

Упрощённая идея:

```text
изображение
 ↓
локальные признаки
 ↓
сложные признаки
 ↓
объект
```

---

## Что нужно запомнить

1. CNN особенно хорошо подходят для пространственных данных.
2. Свёрточный фильтр ищет локальные признаки.
3. Результат применения фильтра называется картой признаков.
4. Разные фильтры могут обнаруживать разные структуры.
5. `stride` определяет шаг перемещения фильтра.
6. `padding` позволяет контролировать обработку границ.
7. Pooling уменьшает пространственный размер представления.
8. CNN используют общие фильтры для разных участков изображения.
9. Более глубокие слои могут формировать более сложные признаки.
10. CNN являются фундаментальной архитектурой компьютерного зрения.
