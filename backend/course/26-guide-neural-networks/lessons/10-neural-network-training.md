# Обучение нейронной сети на практике

## Цель

Собрать все изученные понятия в единый процесс и впервые пройти полный цикл обучения простой нейронной сети.

После урока вы должны понимать:

* из каких этапов состоит обучение нейронной сети;
* как подготовить данные;
* как создать простую модель;
* как выбрать функцию потерь;
* что такое optimizer;
* как проходит цикл обучения;
* как проверять модель на validation данных;
* как использовать обученную модель для новых данных.

---

```text

```

Теперь нужно объединить эти понятия.

Общий процесс выглядит так:


## 2. Задача

Рассмотрим простую задачу.

Пусть модель получает:

```text
x1 = температура
x2 = ток
```

и должна определить:

```text
0 → нормальная работа
1 → перегрузка
```

Например:

| Температура | Ток | Класс |
|---:|---:|---:|
| 40 | 1.5 | 0 |
| 45 | 1.8 | 0 |
| 50 | 2.0 | 0 |
| 60 | 2.5 | 0 |
| 75 | 3.5 | 1 |
| 80 | 4.0 | 1 |
| 90 | 4.5 | 1 |

Это задача бинарной классификации.

---

## 3. Подготовка данных

Создадим данные в Python:

```python
X = [
    [40, 1.5],
    [45, 1.8],
    [50, 2.0],
    [60, 2.5],
    [75, 3.5],
    [80, 4.0],
    [90, 4.5],
]

y = [
    0,
    0,
    0,
    0,
    1,
    1,
    1,
]
```

Здесь:

```text
X
```

содержит признаки.

```text
y
```

содержит правильные ответы.

---

## 4. Почему реальные данные нужно масштабировать

Обратите внимание:

```text
температура ≈ 40...90
ток ≈ 1.5...4.5
```

Масштабы отличаются.

Для многих алгоритмов обучения удобно привести признаки к сопоставимому масштабу.

Один из вариантов — стандартизация:

```text
x' = (x - mean) / std
```

После этого значения обычно оказываются примерно в области:

```text
около -3 ... +3
```

Конкретный диапазон зависит от данных.

---

## 5. Создание модели

Для первого практического примера удобно использовать `PyTorch`.

Установить его можно через официальный способ установки, соответствующий вашей системе и версии Python.

Минимальная структура модели:

```python
import torch
import torch.nn as nn


model = nn.Sequential(
    nn.Linear(2, 8),
    nn.ReLU(),
    nn.Linear(8, 1),
    nn.Sigmoid(),
)
```

Что здесь происходит?

```text
2 входа
 ↓
8 нейронов
 ↓
ReLU
 ↓
1 нейрон
 ↓
Sigmoid
 ↓
вероятность класса 1
```

---

## 6. Что означает Linear

Строка:

```python
nn.Linear(2, 8)
```

означает:

```text
2 входных значения
8 выходных значений
```

Внутри этого слоя находятся:

```text
веса
bias
```

Количество весов:

```text
2 × 8 = 16
```

Плюс:

```text
8 bias
```

Итого:

```text
24 обучаемых параметра
```

---

## 7. Второй слой

Следующий слой:

```python
nn.Linear(8, 1)
```

получает:

```text
8 входов
```

и выдаёт:

```text
1 значение
```

Затем применяется:

```python
nn.Sigmoid()
```

Поэтому итог можно интерпретировать как значение от:

```text
0 до 1
```

---

## 8. Функция потерь

Для бинарной классификации часто используется бинарная кросс-энтропия.

В PyTorch можно использовать:

```python
loss_function = nn.BCELoss()
```

Она сравнивает:

```text
предсказание модели
```

с:

```text
правильным ответом
```

и выдаёт значение ошибки.

---

## 9. Optimizer

Модель знает, насколько она ошиблась.

Но нужно ещё определить, как изменить параметры.

Для этого используется **optimizer**.

Например:

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,
)
```

Здесь:

```text
Adam
```

— алгоритм оптимизации.

А:

```text
lr
```

— learning rate.

---

## 10. Главный цикл обучения

Теперь появляется знакомая последовательность:

```text
предсказание
↓
loss
↓
градиент
↓
обновление параметров
```

В PyTorch это можно записать:

```python
for epoch in range(100):

    prediction = model(X_train)

    loss = loss_function(
        prediction,
        y_train,
    )

    optimizer.zero_grad()

    loss.backward()

    optimizer.step()
```

Разберём каждую строку.

---

## 11. Предсказание

```python
prediction = model(X_train)
```

Данные передаются через сеть.

Получаем:

```text
X
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
Sigmoid
 ↓
prediction
```

Например:

```text
0.12
0.21
0.34
0.48
0.81
0.91
0.96
```

---

## 12. Вычисление ошибки

```python
loss = loss_function(
    prediction,
    y_train,
)
```

Модель сравнивает:

```text
prediction
```

с:

```text
y_train
```

Например:

```text
правильный ответ = 1
предсказание = 0.9
```

Ошибка небольшая.

Если:

```text
правильный ответ = 1
предсказание = 0.1
```

ошибка значительно больше.

---

## 13. Обнуление старых градиентов

Перед вычислением следующего шага:

```python
optimizer.zero_grad()
```

обнуляет накопленные градиенты.

Это важная особенность PyTorch.

Если этого не делать, градиенты будут накапливаться между шагами.

---

## 14. Обратное распространение

Теперь:

```python
loss.backward()
```

PyTorch вычисляет градиенты функции потерь по отношению к параметрам модели.

Упрощённо:

```text
loss
 ↓
градиенты
 ↓
weights
biases
```

То есть система вычисляет:

> Как изменение каждого параметра повлияет на ошибку?

Это и есть основа **backpropagation**, или обратного распространения ошибки.

---

## 15. Обновление параметров

После вычисления градиентов:

```python
optimizer.step()
```

optimizer изменяет веса и bias.

Получается:

```text
старые параметры
      ↓
градиенты
      ↓
optimizer
      ↓
новые параметры
```

Теперь модель немного изменилась.

---

## 16. Повторение

После этого начинается следующий шаг:

```text
данные
 ↓
новое предсказание
 ↓
новый loss
 ↓
новые градиенты
 ↓
новые параметры
```

И так много раз.

Постепенно модель должна уменьшать ошибку.

---

## 17. Epoch

Если полный набор данных проходит через модель один раз, это одна эпоха.

Например:

```python
for epoch in range(100):
```

означает:

```text
100 эпох
```

Но в реальных проектах количество эпох подбирается экспериментально.

Слишком мало:

```text
модель может не успеть обучиться
```

Слишком много:

```text
может начаться переобучение
```

---

## 18. Validation

После обучения на `train` можно проверить модель на `validation`.

Например:

```python
with torch.no_grad():

    validation_prediction = model(X_validation)

    validation_loss = loss_function(
        validation_prediction,
        y_validation,
    )
```

`torch.no_grad()` сообщает PyTorch, что градиенты здесь не нужны.

Мы только проверяем результат.

---

## 19. Почему validation не обновляет модель

При проверке:

```text
validation
 ↓
model
 ↓
prediction
 ↓
loss
```

Но нет:

```text
backward()
optimizer.step()
```

То есть параметры модели не изменяются.

Validation используется для оценки текущего состояния модели.

---

## 20. Пример полного процесса

Упрощённо:

```python
for epoch in range(100):

    model.train()

    prediction = model(X_train)

    loss = loss_function(
        prediction,
        y_train,
    )

    optimizer.zero_grad()

    loss.backward()

    optimizer.step()

    model.eval()

    with torch.no_grad():

        validation_prediction = model(
            X_validation
        )

        validation_loss = loss_function(
            validation_prediction,
            y_validation,
        )

    print(
        epoch,
        loss.item(),
        validation_loss.item(),
    )
```

Это уже очень близко к реальному циклу обучения.

---

## 21. Что мы хотим увидеть

В идеальном случае:

```text
epoch   train loss   validation loss

1       0.68         0.70
2       0.61         0.64
3       0.55         0.59
...
20      0.12         0.18
```

Обе ошибки постепенно уменьшаются.

Но может произойти:

```text
epoch   train loss   validation loss

20      0.12         0.18
30      0.05         0.25
40      0.01         0.48
```

Тогда модель может начать переобучаться.

---

## 22. Режимы train и eval

В PyTorch существуют:

```python
model.train()
```

и:

```python
model.eval()
```

Они переключают модель между режимами обучения и использования.

Это особенно важно для некоторых слоёв, например:

* Dropout;
* Batch Normalization.

Не все модели ведут себя по-разному в этих режимах, но правильная практика — явно переключать режим.

---

## 23. Использование обученной модели

После обучения модель можно использовать на новом объекте.

Например:

```python
new_data = torch.tensor(
    [[82.0, 4.1]]
)
```

Передаём:

```python
model.eval()

with torch.no_grad():
    result = model(new_data)

print(result)
```

Допустим:

```text
0.94
```

Это означает высокую оценку принадлежности к классу `1`.

---

## 24. Преобразование вероятности в класс

Можно использовать порог:

```python
if result.item() >= 0.5:
    print("Перегрузка")
else:
    print("Норма")
```

Но порог:

```text
0.5
```

не является обязательным.

В реальной системе его можно выбирать исходя из стоимости разных ошибок.

---

## 25. Важное отличие обучения от использования

Во время обучения:

```text
данные
 ↓
модель
 ↓
loss
 ↓
backward
 ↓
optimizer
```

При использовании:

```text
новые данные
 ↓
модель
 ↓
результат
```

Никакого изменения параметров происходить не должно.

Это называют **inference**, то есть использованием обученной модели для получения предсказаний.

---

## 26. Что делает PyTorch за нас

Мы не пишем вручную:

```text
градиенты
матрицы
обновление каждого веса
```

PyTorch автоматически выполняет большую часть математических операций.

Но важно понимать, что происходит внутри.

Условно:

```text
PyTorch
  ↓
тензоры
  ↓
операции
  ↓
автоматическое дифференцирование
  ↓
градиенты
  ↓
optimizer
```

Поэтому изучение нейросетей не должно сводиться к запоминанию:

```python
model.fit(...)
```

Важно понимать сам процесс.

```text
learning_rate
```

## 28. Что важно понять после первого обучения

Не нужно ожидать, что первая нейронная сеть будет идеальной.

Главная цель этого этапа — увидеть полный цикл:

```text
данные
 ↓
модель
 ↓
предсказание
 ↓
ошибка
 ↓
градиенты
 ↓
обновление
 ↓
повтор
```

И понять, что обучение нейронной сети — это не магическая операция.

Это итеративная оптимизация большого количества числовых параметров.

---

## Что нужно запомнить

* Нейронная сеть обучается на данных, состоящих из признаков и правильных ответов.
* Во время прямого прохода модель получает предсказание.
* Функция потерь измеряет ошибку.
* `backward()` вычисляет градиенты.
* Optimizer изменяет параметры модели.
* `epoch` — полный проход по обучающим данным.
* `validation` используется для проверки модели без изменения её параметров.
* `model.train()` и `model.eval()` переключают режимы модели.
* После обучения модель можно использовать для новых данных без изменения параметров.
* Использование обученной модели для предсказаний называется inference.
* PyTorch автоматизирует вычисление градиентов и работу с тензорами, но понимание процесса обучения остаётся необходимым.
