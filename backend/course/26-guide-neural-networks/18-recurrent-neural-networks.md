# Рекуррентные нейронные сети и последовательности

## Цель

Понять, чем последовательностные данные отличаются от обычных наборов примеров и как рекуррентные нейронные сети используют информацию о предыдущих состояниях.

После урока вы должны понимать:

* что такое последовательность;
* почему порядок данных может иметь значение;
* что такое скрытое состояние;
* как работает RNN;
* почему обычной нейронной сети недостаточно для последовательностей;
* что такое LSTM и GRU;
* где применяются рекуррентные сети.

---

## Не все данные независимы

Рассмотрим два набора:

```text
10, 20, 30, 40
```

и:

```text
40, 10, 30, 20
```

Если это просто набор чисел, порядок может быть неважен.

Но если это температура оборудования:

```text
10 °C
20 °C
30 °C
40 °C
```

то порядок имеет значение.

Мы видим процесс изменения температуры.

Это уже **последовательность**.

---

## Что такое последовательность

Последовательность — это данные, где порядок элементов имеет значение.

Примеры:

```text
временной ряд
текст
речь
телеметрия
сигнал датчика
движение робота
финансовые данные
```

---

## Пример временного ряда

Допустим, датчик выдаёт:

```text
t1 → 50
t2 → 52
t3 → 55
t4 → 60
```

Последнее значение зависит от истории.

Если модель видит только:

```text
60
```

она теряет часть информации.

Ей может быть полезно знать:

```text
50 → 52 → 55 → 60
```

---

## Обычная нейронная сеть

Обычная сеть может получить:

```text
x₁
x₂
x₃
x₄
```

и обработать их одновременно.

Но ей нужно явно сообщить все значения.

У неё нет встроенного понятия:

> это произошло раньше, а это позже.

---

## Идея RNN

Рекуррентная нейронная сеть обрабатывает последовательность шаг за шагом.

Упрощённо:

```text
x₁ → RNN → h₁
             ↓
x₂ → RNN → h₂
             ↓
x₃ → RNN → h₃
             ↓
x₄ → RNN → h₄
```

Состояние:

```text
h
```

передаётся дальше.

---

## Скрытое состояние

На каждом шаге RNN получает:

```text
текущий вход
+
предыдущее состояние
```

и формирует:

```text
новое состояние
```

Условно:

```text
h_t = f(x_t, h_{t-1})
```

где:

```text
x_t
```

— текущий элемент последовательности,

а:

```text
h_{t-1}
```

— информация, накопленная ранее.

---

## Простая аналогия

Представим человека, читающего предложение.

Он не забывает каждое слово сразу после прочтения.

Информация о предыдущих словах влияет на понимание следующих.

RNN пытается создать похожую математическую идею:

```text
текущий вход
+
контекст из прошлого
```

---

## Пример

Последовательность:

```text
Температура:
50
52
55
60
```

RNN обрабатывает:

```text
50 → состояние
52 + состояние → новое состояние
55 + состояние → новое состояние
60 + состояние → новое состояние
```

Последнее состояние содержит некоторую информацию о предыдущих значениях.

---

## Для чего нужен hidden state

`hidden state` можно рассматривать как внутреннюю память модели.

Но это не память в человеческом смысле.

Это набор числовых значений, которые модель использует для передачи информации между шагами последовательности.

---

## Применение

RNN применялись для:

```text
анализа текста
распознавания речи
прогнозирования временных рядов
обработки сигналов
генерации последовательностей
```

---

## Пример с датчиком

Допустим, система получает:

```text
температура
вибрация
ток
```

каждую секунду.

Тогда последовательность может выглядеть так:

```text
t1 → [50, 1.2, 10]
t2 → [51, 1.3, 10]
t3 → [54, 1.8, 11]
t4 → [60, 3.0, 13]
```

Модель может использовать историю для прогнозирования следующего состояния.

---

## Прогноз следующего значения

Например:

```text
50
52
55
?
```

RNN может использовать предыдущую последовательность для прогноза:

```text
60
```

Конечно, реальное качество зависит от данных и обучения.

---

## Проблема длинной памяти

У простой RNN есть серьёзное ограничение.

Если последовательность очень длинная:

```text
x₁
x₂
x₃
...
x₁₀₀₀
```

информация из начала последовательности может постепенно теряться.

Это связано в том числе с проблемами градиентов.

---

## Исчезающий градиент

При обучении информация проходит через множество шагов.

Производные могут многократно перемножаться.

Если значения небольшие:

```text
0.5 × 0.5 × 0.5 × ...
```

градиент быстро уменьшается.

В результате ранние элементы последовательности оказывают слабое влияние на обучение.

---

## LSTM

Для решения проблемы длинных зависимостей была разработана архитектура:

**LSTM — Long Short-Term Memory.**

LSTM содержит специальные механизмы управления информацией.

Она может условно решать:

```text
что запомнить
что забыть
что передать дальше
```

---

## Идея LSTM

Упрощённо:

```text
новый вход
    ↓
┌─────────────┐
│   LSTM      │
│             │
│ память      │
│ управление  │
└──────┬──────┘
       ↓
 новое состояние
```

Внутри LSTM используется несколько управляющих механизмов, которые называют gates.

---

## GRU

Другой вариант —:

**GRU — Gated Recurrent Unit.**

Она устроена проще LSTM, но также использует механизмы управления состоянием.

GRU часто применяется как более компактная альтернатива.

---

## RNN в PyTorch

Пример:

```python
import torch.nn as nn

rnn = nn.RNN(
    input_size=4,
    hidden_size=16,
    batch_first=True
)
```

Здесь:

```text
4
```

— размер входного признака,

а:

```text
16
```

— размер скрытого состояния.

---

## LSTM

```python
lstm = nn.LSTM(
    input_size=4,
    hidden_size=16,
    batch_first=True
)
```

GRU:

```python
gru = nn.GRU(
    input_size=4,
    hidden_size=16,
    batch_first=True
)
```

---

## Формат последовательности

При:

```python
batch_first=True
```

обычно используется форма:

```text
(batch, sequence, features)
```

Например:

```text
32 × 100 × 4
```

означает:

```text
32 последовательности
100 временных шагов
4 признака на шаг
```

---

## Пример для промышленной системы

Пусть контролируется двигатель.

Каждую секунду получаем:

```text
температура
ток
вибрация
скорость
```

За минуту:

```text
60 временных шагов
```

Можно представить данные:

```text
(batch, 60, 4)
```

RNN/LSTM может анализировать изменение состояния во времени.

---

## Ограничения RNN

Рекуррентная обработка выполняется последовательно:

```text
x₁
 ↓
x₂
 ↓
x₃
 ↓
x₄
```

Это затрудняет эффективную параллельную обработку длинных последовательностей.

Кроме того, даже LSTM не всегда хорошо справляется с очень длинными зависимостями.

---

## Появление Transformer

Эти ограничения стали одной из причин развития архитектуры Transformer.

Transformer использует другой механизм работы с последовательностями:

```text
attention
```

Он позволяет модели напрямую учитывать отношения между разными элементами последовательности.

---

## RNN не бесполезны

Несмотря на появление Transformer, RNN и их варианты всё ещё полезны.

Они могут быть удобны для:

* небольших моделей;
* потоковых данных;
* простых временных рядов;
* систем с ограниченными ресурсами;
* задач, где последовательная обработка естественна.

---

## Главное

Главная идея RNN:

```text
текущий вход
+
предыдущая информация
↓
новое состояние
```

Это позволяет модели учитывать историю.

LSTM и GRU развивают эту идею, улучшая работу с долгосрочными зависимостями.

---

## Что нужно запомнить

1. Последовательность — данные, где порядок элементов имеет значение.
2. RNN обрабатывает последовательность шаг за шагом.
3. Hidden state переносит информацию между шагами.
4. RNN может использовать историю входных данных.
5. Простые RNN могут сталкиваться с проблемой исчезающих градиентов.
6. LSTM использует механизмы управления памятью.
7. GRU — более компактная рекуррентная архитектура.
8. RNN применялись для текста, речи и временных рядов.
9. Для длинных последовательностей рекуррентный подход имеет ограничения.
10. Transformer предлагает другой подход к обработке последовательностей через механизм внимания.
