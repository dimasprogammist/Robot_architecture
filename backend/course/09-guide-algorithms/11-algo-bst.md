# Двоичное дерево поиска (BST)

## Цель

Понять инвариант BST: в левом поддереве ключи меньше, в правом — больше; как из этого следует поиск и вставка за O(h).

## Что уже нужно знать

Бинарное дерево, обходы, O-нотация, понятие высоты.

## Объяснение с нуля

BST (binary search tree) — бинарное дерево, где для каждого узла все ключи левого поддерева меньше ключа узла, а все ключи правого — больше (политику равных ключей оговаривают отдельно). Поиск похож на работу с отсортированной структурой: сравнили с текущим узлом — пошли налево или направо.

Средняя высота случайного BST порядка log n, но вырожденный случай (вставка уже отсортированной последовательности) даёт цепочку и O(n). Поэтому на практике используют сбалансированные деревья. Учебный BST всё равно учит главному — инварианту упорядоченности.

Inorder-обход BST выдаёт ключи по возрастанию. Это удобный способ проверить, не сломали ли дерево после вставок и удалений.

## Термины

- **Инвариант упорядоченности** — правило лево/право относительно ключа.
- **h (высота)** — определяет сложность поиска и вставки.
- **Вырождение** — дерево стало похоже на список.
- **Преемник** — следующий ключ в порядке сортировки (нужен при удалении).

## Внутреннее устройство

Поиск: пока узел не None и ключ не равен — идём left при key < node.key, иначе right. Вставка: ищем место как при неуспешном поиске и вешаем новый лист. Удаление сложнее: у узла может быть 0, 1 или 2 детей; при двух берут преемника или предшественника.

## Пример: построение и поиск

Вставляем ключи `8, 3, 10, 1, 6, 14, 4` по порядку.

### Пошаговый разбор дерева

```text
      8
     / \
    3   10
   / \    \
  1   6    14
     /
    4
```

Поиск 6: 8 → 3 → 6 — три сравнения. Поиск 7: 8 → 3 → 6, справа у 6 пусто → не найден. Вставка 7: дошли до 6, справа пусто → новый узел 7 справа от 6.

### Код на Python

```python
class Node:
    def __init__(self, key: int):
        self.key = key
        self.left: Node | None = None
        self.right: Node | None = None


def search(node: Node | None, key: int) -> Node | None:
    while node is not None and node.key != key:
        node = node.left if key < node.key else node.right
    return node


def insert(node: Node | None, key: int) -> Node:
    if node is None:
        return Node(key)
    if key < node.key:
        node.left = insert(node.left, key)
    elif key > node.key:
        node.right = insert(node.right, key)
    return node


root: Node | None = None
for k in [8, 3, 10, 1, 6, 14, 4]:
    root = insert(root, k)
assert search(root, 6) is not None
assert search(root, 7) is None
```

### Сложность

Поиск и вставка: O(h). Для сбалансированного дерева h = Θ(log n); для вырожденного h = Θ(n). Доп. память рекурсивной вставки O(h) на стеке.

## Практика

Вставьте `[5, 2, 8, 1, 3, 7, 9]` и найдите вручную 7 и 4. Нарисуйте итоговое дерево.

## Типичные ошибки

- Нарушить инвариант при удалении узла с двумя детьми.
- Не определить политику равных ключей.
- Строить BST из отсортированных данных и ждать log n без балансировки.
- Путать BST с кучей: там другой инвариант.

## Что запомнить

BST упорядочен по ключу; скорость равна высоте. Inorder даёт sorted-последовательность. Для гарантий по времени нужен баланс.
