# Deque (двусторонняя очередь)

## Цель

Освоить deque: добавление и удаление с обоих концов за O(1) и типовые сценарии — скользящее окно, стек и очередь в одной структуре, проверка палиндрома.

## Что уже нужно знать

Стек, очередь, амортизированная сложность `list.append`, ограничения `list.insert(0, ...)`.

## Объяснение с нуля

Deque (double-ended queue) разрешает эффективные `appendleft` / `popleft` и `append` / `pop`. В CPython `collections.deque` устроен блоками: операции с концов O(1), а индексация в середине — O(n). Это не «универсальный массив».

Зачем нужен deque: очередь и стек одним типом; задачи со скользящим окном; буфер с выталкиванием с обеих сторон; сравнение концов последовательности. Не стоит ждать от `d[i]` в середине той же скорости, что у `list[i]`.

У `deque` есть параметр `maxlen`: при переполнении элементы молча выбрасываются с противоположного конца — удобно для «последних k событий», опасно, если забыли про эту семантику.

## Термины

- **Двусторонняя очередь** — доступны оба конца.
- **Скользящее окно** — фиксированный размер прохода по последовательности.
- **Блочная реализация** — внутренняя схема CPython deque.
- **maxlen** — ограничение длины с автовыталкиванием.

## Внутреннее устройство

Логически это лента с указателями на левый и правый концы. Стек моделируется только правым концом. Очередь — `append` справа и `popleft` слева. Смешивать концы можно, но контракт операции должен быть ясен читателю кода.

## Пример: палиндром на шести числах

Последовательность: `[1, 4, 6, 6, 4, 1]`.

### Пошаговый разбор

1. Сравниваем концы 1 и 1 — равны, снимаем оба.
2. Сравниваем 4 и 4 — равны, снимаем.
3. Сравниваем 6 и 6 — равны, снимаем.
4. Пусто (или один элемент) → палиндром.

Для `[1, 4, 6, 7, 4, 1]` на шаге с 6 и 7 получаем неравенство → не палиндром.

### Код на Python

```python
from collections import deque


def is_palindrome(vals: list[int]) -> bool:
    d = deque(vals)
    while len(d) > 1:
        if d.popleft() != d.pop():
            return False
    return True


assert is_palindrome([1, 4, 6, 6, 4, 1]) is True
assert is_palindrome([1, 4, 6, 7, 4, 1]) is False

# стек
st: deque[int] = deque()
st.append(10)
st.append(20)
assert st.pop() == 20

# очередь
q: deque[int] = deque()
q.append(10)
q.append(20)
assert q.popleft() == 10
```

### Сложность

Операции с концов: O(1). Построение из списка длины n: O(n). Индекс в середине: O(n). Память O(n).

## Типичные ошибки

- Частый доступ `deque[i]` в середине в горячем цикле.
- Реализовать «deque» через `list.insert(0, ...)` и считать его быстрым.
- Забыть, что `maxlen` молча выбрасывает данные.
- Путать, какой конец — голова очереди в вашей договорённости.

## Что запомнить

Deque = быстрые оба конца, медленная середина. Универсальный инструмент для окон и смешанных LIFO/FIFO сценариев.
