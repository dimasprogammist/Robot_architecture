# Массив

## Цель

Понять массив как непрерывный блок элементов с доступом по индексу за O(1) и дорогими вставками в середину. После урока вы сможете объяснить, почему `list[i]` быстрый, а `list.insert(0, x)` — нет.

## Что уже нужно знать

Индексация с нуля, O-нотация, цикл по индексу, базовый Python `list`.

## Объяснение с нуля

Массив хранит элементы подряд в памяти. Зная адрес начала и размер элемента, процессор вычисляет адрес i-го за константу: base + i × size. Отсюда мгновенный доступ `a[i]`.

Плата за непрерывность: чтобы вставить в середину, нужно сдвинуть хвост. Удаление из середины — тоже сдвиг. Добавление в конец при заранее выделенной ёмкости дёшево; если ёмкость кончилась — выделяют новый блок и копируют. В динамических массивах Python `list` это амортизированно O(1) на `append`.

В Python `list` — динамический массив ссылок, не связный список. Это критично: `lst[i]` быстрый, а `lst.insert(0, x)` и `lst.pop(0)` дорогие. Массив хорош, когда много чтений по индексу и редкие вставки в середину; плох как очередь с частым удалением с головы без `deque`.

## Термины

- **Индекс** — позиция от 0 до n−1.
- **Ёмкость (capacity)** — сколько слотов выделено.
- **Длина (length)** — сколько реально занято.
- **Смещение** — сдвиг элементов при вставке или удалении.
- **Локальность кэша** — соседние элементы лежат рядом и читаются быстрее.

## Внутреннее устройство

Логическая картина: ячейки `[0][1][2]...[n-1]` подряд. Вставка на позицию k сдвигает элементы k..n-1 вправо. Удаление с позиции k сдвигает хвост влево. Поиск значения без дополнительной структуры — линейный проход O(n). Если массив отсортирован, возможен бинарный поиск O(log n).

## Пример: вставка в середину

Массив: `[10, 20, 30, 40, 50, 60]`. Вставить `25` на индекс 2.

### Пошаговый разбор

1. Расширяем длину на один слот.
2. Сдвигаем хвост вправо: 60, затем 50, 40, 30.
3. Кладём 25 на позицию 2.
4. Результат: `[10, 20, 25, 30, 40, 50, 60]`.

Число сдвигов равно числу элементов справа от точки вставки — до O(n).

### Код на Python

```python
def insert_at(a: list[int], index: int, value: int) -> None:
    a.append(0)
    for i in range(len(a) - 1, index, -1):
        a[i] = a[i - 1]
    a[index] = value


xs = [10, 20, 30, 40, 50, 60]
insert_at(xs, 2, 25)
assert xs == [10, 20, 25, 30, 40, 50, 60]
assert xs[4] == 40  # доступ O(1)
```

### Сложность

- Чтение/запись по индексу: O(1).
- Вставка/удаление в середине: O(n).
- `append` в среднем: O(1) амортизированно.
- Поиск значения в неотсортированном массиве: O(n).

## Типичные ошибки

- Путать Python `list` со связным списком.
- Делать очередь через `pop(0)` у `list` в горячем пути.
- Выходить за границы индекса.
- Считать каждый отдельный `append` строго O(1) в худшем шаге без амортизации.
- Зря копировать огромные массивы в каждом вызове функции.

## Что запомнить

Массив: O(1) доступ, O(n) сдвиги в середине, отличная локальность кэша. В Python `list` ≈ динамический массив ссылок.
