# Кратчайшие пути

## Цель

Отличить невзвешенный случай (BFS) от взвешенного с неотрицательными весами (Dijkstra) и пройти Dijkstra руками на маленьком графе.

## Что уже нужно знать

BFS, куча как приоритетная очередь, граф с весами рёбер.

## Объяснение с нуля

«Кратчайший» зависит от метрики. Без весов минимум числа рёбер даёт BFS. С неотрицательными весами минимум суммы весов даёт алгоритм Дейкстры. При отрицательных весах нужен Bellman-Ford; отрицательные циклы — отдельная проблема. Для всех пар вершин на малых графах используют Floyd-Warshall O(V³).

Dijkstra хранит оценки `dist[v]`, стартует с 0 у источника и «бесконечности» у остальных, всегда расширяет вершину с текущим минимальным dist (через кучу). Релаксация ребра u → v: если dist[u] + w < dist[v], обновить dist[v] и предшественника.

Отрицательные веса ломают классический Dijkstra. В упрощённой реализации допустимы повторные записи в кучу: при извлечении устаревшей оценки её пропускают.

## Термины

- **Релаксация** — попытка улучшить dist через ребро.
- **Оценка расстояния** — текущий известный верхний минимум.
- **Предшественник** — для восстановления пути.

## Внутреннее устройство Dijkstra

Пока есть вершины в приоритетной очереди: извлечь u с минимальным d; если d хуже текущего dist[u] — continue; иначе релаксировать все исходящие рёбра. Когда вершина извлечена с актуальной оценкой, её dist окончателен (для неотрицательных весов).

## Пример: Dijkstra на 6 вершинах

Рёбра (u, v, w): (0,1,2), (0,2,5), (1,2,1), (1,3,4), (2,3,1), (3,4,3), (4,5,1), (2,5,9). Старт 0.

### Пошаговый разбор

1. dist[0]=0, остальные ∞. Берём 0. Релаксируем 1←2, 2←5.
2. Берём 1 (dist=2). Через 1→2: 2+1=3 < 5 → dist[2]=3; 1→3: dist[3]=6.
3. Берём 2 (dist=3). 2→3: 3+1=4 < 6 → dist[3]=4; 2→5: dist[5]=12.
4. Берём 3 (dist=4). 3→4: dist[4]=7.
5. Берём 4 (dist=7). 4→5: 7+1=8 < 12 → dist[5]=8.
6. Берём 5. Готово.

Итог: dist = [0, 2, 3, 4, 7, 8]. Путь к 5: 0–1–2–3–4–5.

### Код на Python

```python
import heapq
from collections import defaultdict


def dijkstra(n: int, edges: list[tuple[int, int, int]], src: int) -> list[float]:
    g: dict[int, list[tuple[int, int]]] = defaultdict(list)
    for u, v, w in edges:
        g[u].append((v, w))
    dist = [float("inf")] * n
    dist[src] = 0.0
    pq = [(0.0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist


edges = [(0, 1, 2), (0, 2, 5), (1, 2, 1), (1, 3, 4), (2, 3, 1), (3, 4, 3), (4, 5, 1), (2, 5, 9)]
assert dijkstra(6, edges, 0)[5] == 8
```

### Сложность

С бинарной кучей типично O((V + E) log V). BFS для невзвешенного — O(V + E) и проще.

## Практика

Измените вес ребра 2→5 на 2 и пересчитайте dist[5] вручную. Изменился ли путь?

## Типичные ошибки

- Dijkstra на отрицательных весах.
- Использовать DFS «наугад» как кратчайший.
- Забыть пропускать устаревшие записи кучи.
- Матрица смежности на огромном разреженном графе без нужды.

## Что запомнить

Нет весов → BFS. Веса ≥ 0 → Dijkstra. Ручной проход на 6 вершинах закрепляет релаксацию.
