# Сортировки

Сортировка упорядочивает по ключу. В проде почти всегда берут встроенную. Учебные алгоритмы учат читать чужой код и цену.

Свойства, о которых спорят не зря: **стабильность** — равные ключи сохраняют относительный порядок; **in-place** — мало доп. памяти; **адаптивность** — быстрее на почти отсортированных данных.

Пузырёк — соседние обмены, O(n²), учебный. Вставки — как карты в руке, O(n²), хорош на малых и почти sorted. Слияние — разделяй и властвуй, O(n log n), нужна доп. память. Быстрая — партиция вокруг pivot, средняя O(n log n), худшая O(n²) на неудачных опорах. Python `sorted` / `list.sort` — Timsort: гибрид, O(n log n), стабильный. С него и начинайте в бою.

Вставки держат отсортированный префикс. Очередной ключ сдвигает большие вправо. На почти отсортированном сдвигов мало.

Массив `[5, 2, 4, 6, 1, 3, 2]`: префикс `[5]` → `[2, 5]` → `[2, 4, 5]` → `[2, 4, 5, 6]` → вставка 1 → … → `[1, 2, 2, 3, 4, 5, 6]`.

```python
def insertion_sort(a: list[int]) -> list[int]:
    a = a[:]
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a


assert insertion_sort([5, 2, 4, 6, 1, 3, 2]) == [1, 2, 2, 3, 4, 5, 6]
```

Компаратор — правило сравнения двух элементов. Партиция — разделение относительно опоры. Не пишите свой n² на миллионе строк «чтобы понять»; поймите на семи числах и вызовите Timsort.
