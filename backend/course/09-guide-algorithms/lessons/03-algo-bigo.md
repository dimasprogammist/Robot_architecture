# O-нотация

O(n) — не секунды и не точное число шагов. Это верхняя оценка роста: существует константа C и порог n₀, дальше шагов не больше C·n (или n², log n…). Зачем грубо: взорвётся ли решение при росте данных, а не коэффициент на вашей машине. T(n) = 3n² + 10n + 50 и другой квадрат — оба «квадратичные»; доминирует старший член, константы отбрасывают.

Классы, которые встретите чаще всего:

- O(1) — доступ по индексу массива, арифметика без цикла по n.
- O(log n) — каждый шаг делит область пополам (бинарный поиск). Логарифм здесь обычно по основанию 2: сколько раз можно делить n.
- O(n) — один проход.
- O(n log n) — хорошие сортировки сравнениями.
- O(n²) — типичные вложенные проходы по n.
- O(2ⁿ) — полный перебор подмножеств; на n = 40 уже фантастика.

Ω — нижняя оценка, Θ — плотно с обеих сторон. В разговоре «сложность O(...)» часто имеют в виду Θ. Формально «код есть O(n²)» значит «не хуже квадрата» — он может быть и линейным.

Код в O читают по управлению, не по красоте имён. Один цикл по n без тяжёлого тела — O(n). Цикл в цикле по n — O(n²). На каждой итерации бинарный поиск по тому же массиву — O(n log n). Вызов внутри цикла: если там линейный поиск по всему массиву, это уже не «один цикл».

**Бинарный поиск**, массив `[1, 3, 4, 7, 9, 11, 15, 18]`, цель `11`. Каждый шаг отбрасывает половину: середина 7, затем 11 — два-три сравнения вместо восьми. На миллионе элементов — порядка двадцати, не миллиона.

Не пишите O(n/2): это тот же O(n). Не складывайте «у меня два цикла подряд» в квадрат: два линейных прохода — всё ещё O(n).
