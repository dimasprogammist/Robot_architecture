# Практика и разбор ошибок

Новой структуры здесь нет. Перед кодом — те же вопросы, что в первом уроке, плюс размер и модель.

1. Вход и размер: n до 10² или до 10⁶ меняет алгоритм.
2. Нужны порядок, частоты, связи, минимум «на лету»?
3. Есть ли веса и бывают ли отрицательные?
4. Края: пусто, один элемент, дубликаты, уже отсортировано, несвязный граф?

Шаблон часто торчит из условия: уникальность → `dict`/`set`; скобки и отмена → стек; лабиринт без весов → BFS; зависимости и циклы → DFS; топ-k → куча; много запросов к статическому массиву → sort + бинарный поиск.

Сначала медленный правильный на малом n, потом ускорение. Ручной проход на 6–8 элементах ловит половину логики до запуска.

Отладка: сверка с руками; off-by-one в `lo`/`hi`; в графах visited и направление; в хешах хешируемость ключа; в рекурсии база; не остался ли квадрат на n = 10⁶.

Анаграммы — совпали частоты, не «перебором перестановок»:

```python
from collections import Counter


def anagram(a: str, b: str) -> bool:
    return Counter(a) == Counter(b)


assert anagram("listen", "silent") is True
assert anagram("abc", "ab") is False
```

Узлы уровня k в дереве — BFS с глубиной. Цикл в неориентированном графе — DFS с родителем: сосед visited и не родитель.

| Запрос | Инструмент | Порядок |
| --- | --- | --- |
| доступ i-й | массив | O(1) |
| концы последовательности | deque | O(1) |
| ключ → значение | dict | ср. O(1) |
| мин. приоритет | heap | O(log n) |
| кратчайший без весов | BFS | O(V+E) |
| кратчайший, веса ≥ 0 | Dijkstra | O((V+E) log V) |
| общая сортировка | Timsort | O(n log n) |

Дальше в курсе те же вопросы «как искать» и «сколько стоит» всплывут в SQL: ключи, индексы, план запроса.

## Практика

### Задание 1. Two sum

Два числа с суммой target. Напишите O(n²) и O(n). Сравните память. Дубликаты, пустой вход, пары нет.

### Задание 2. Полный разбор

Любая задача модуля (скобки, BFS-путь, two sum, вставки). Постановка, идея, ручной вход 6–8 элементов, код, сложность, один край. Без списка — не закончено.

### Задание 3. Выбор структуры

Поток событий: последние 100 и быстрая проверка «видели id». Какие две структуры и почему не массив с `insert(0)`?

### Задание 4. n = 10⁶

Все пары с суммой target, длина 10⁶. Почему двойной цикл не взлетит? Какой порядок приемлем?

### Задание 5. Граф

Лабиринт без весов vs карта с километрами. Алгоритм в каждом случае и цена путаницы.
