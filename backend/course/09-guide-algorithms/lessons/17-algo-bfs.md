# Обход в ширину (BFS)

BFS идёт волнами: сначала соседи старта, потом их соседи. Очередь плюс `visited`. Первое достижение вершины в невзвешенном графе — кратчайший путь по числу рёбер. DFS (следующий урок) этого не обещает.

Применения: лабиринт без весов, уровни дерева, двудольность, компоненты. Сложность O(V + E) на списке смежности: каждую вершину и ребро трогают константное число раз.

Помечать visited в момент **добавления** в очередь, не извлечения — иначе дубликаты в очереди. `parent` восстанавливает путь назад к старту. `dist[start] = 0`.

Рёбра 0–1, 0–2, 1–3, 2–3, 3–4, 4–5, старт 0:

```text
шаг  извлекли  очередь
     —         [0]
     0         [1, 2]
     1         [2, 3]
     2         [3]      (3 уже visited)
     3         [4]
     4         [5]
     5         []
```

Порядок 0, 1, 2, 3, 4, 5. Длина до 5 равна 3.

```python
from collections import deque, defaultdict


def bfs(start: int, edges: list[tuple[int, int]]) -> list[int]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    order: list[int] = []
    seen = {start}
    q = deque([start])
    while q:
        v = q.popleft()
        order.append(v)
        for nb in g[v]:
            if nb not in seen:
                seen.add(nb)
                q.append(nb)
    return order


edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
assert bfs(0, edges) == [0, 1, 2, 3, 4, 5]
```

Стек вместо очереди получите DFS-подобный порядок — не волны. Не забудьте несвязные вершины: один старт их не посетит.
