# Графы

Граф G = (V, E): вершины и рёбра. Ориентированное ребро имеет направление; неориентированное — двусторонняя связь. Вес на ребре — длина дороги, задержка, цена. Дерево — связный ациклический граф: частный случай.

Два представления. **Список смежности** — у каждой вершины список соседей. Память O(V + E), удобно когда рёбер мало относительно V². **Матрица смежности** — таблица V×V, проверка ребра O(1), память O(V²). Во взвешенном списке хранят пары (сосед, вес).

Путь — последовательность рёбер. Компонента связности — максимальное связное подмножество. Степень — число инцидентных рёбер. Петля — ребро в себя. В сервисах так моделируют зависимости модулей, сеть, карту.

Рёбра 0–1, 0–2, 1–3, 2–3, 3–4, 4–5:

```text
0: 1, 2
1: 0, 3
2: 0, 3
3: 1, 2, 4
4: 3, 5
5: 4
```

Сумма длин списков равна 2|E| в неориентированном графе. Проверка 2–3: смотрим список 2.

```python
from collections import defaultdict


def adj_list(edges: list[tuple[int, int]]) -> dict[int, list[int]]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    return g


g = adj_list([(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)])
assert 3 in g[2]
```

Не храните матрицу миллиона вершин «на всякий». Не забудьте обратное ребро в неориентированной модели — BFS «потеряет» сторону.
