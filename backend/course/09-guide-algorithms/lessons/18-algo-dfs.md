# Обход в глубину (DFS)

DFS выбирает соседа и погружается, пока возможно, затем откатывается. Явный стек или рекурсия. Порядок — ветки, не волны. Для кратчайшего пути по числу рёбер — BFS. Сложность та же O(V + E) при аккуратном `visited`.

Задачи DFS: циклы, топологическая сортировка в DAG, компоненты, обход деревьев, backtracking. Цвета белый/серый/чёрный ловят обратное ребро в ориентированном графе. В неориентированном ребро к родителю циклом не считается.

Порядок соседей меняет конкретную последовательность, не асимптотику. Лес DFS — несколько стартов, пока есть непосещённые.

Тот же граф, соседи по возрастанию, старт 0: 0 → 1 → 3 → 2 (тупик) → откат → 4 → 5. Порядок обнаружения `0, 1, 3, 2, 4, 5`. У BFS на третьей позиции было 2, не 3.

```python
from collections import defaultdict


def dfs(start: int, edges: list[tuple[int, int]]) -> list[int]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    for v in g:
        g[v].sort()
    order: list[int] = []
    seen: set[int] = set()

    def go(v: int) -> None:
        seen.add(v)
        order.append(v)
        for nb in g[v]:
            if nb not in seen:
                go(nb)

    go(start)
    return order


edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
assert dfs(0, edges) == [0, 1, 3, 2, 4, 5]
```

Итеративный DFS кладёт соседей в стек; порядок может отличаться от рекурсивного, если класть пачку наоборот — это не баг модели, а дисциплина стека.
