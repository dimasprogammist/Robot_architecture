# Куча (heap)

Двоичная min-куча: ключ родителя не больше ключей детей, корень — минимум. Дерево заполняется по уровням слева направо, поэтому живёт в массиве: дети индекса i — `2i+1` и `2i+2`, родитель — `(i-1)//2`. Это не BST: полного «все слева меньше» нет. Произвольный ключ куча не ищет быстро — только верх по приоритету.

`push`: добавить в конец, всплыть (sift up). `pop_min`: корень заменить последним, погрузить (sift down). Обе O(log n), потому что высота почти полного дерева Θ(log n). Построить кучу из массива снизу вверх — O(n), быстрее чем n раз push. Max-куча зеркальна. В Python `heapq` — min-heap поверх списка.

Устаревшие записи в приоритетной очереди иногда оставляют и пропускают при извлечении (упрощение в Dijkstra): достали пару с d хуже текущего dist — continue.

Массив `[1, 3, 2, 7, 6, 4]`, добавляем `0`:

1. В конец: `[1, 3, 2, 7, 6, 4, 0]`, индекс 6.
2. Родитель 2 (значение 2), 0 < 2 → `[1, 3, 0, 7, 6, 4, 2]`.
3. Родитель корня 1, 0 < 1 → `[0, 3, 1, 7, 6, 4, 2]`.

```python
import heapq

h = [1, 3, 2, 7, 6, 4]
heapq.heapify(h)
heapq.heappush(h, 0)
assert h[0] == 0
assert heapq.heappop(h) == 0
```

Приоритетная очередь — абстракция (извлечь минимум / максимум приоритета). Куча — частая реализация. Отсортированный список тоже умеет минимум, но вставка дороже.
