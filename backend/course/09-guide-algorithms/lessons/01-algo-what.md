# Что такое алгоритм

Алгоритм — не «любой код» и не идея в голове. Это точный план: вход, выход, шаги, которые заканчиваются. Программа — запись этого плана на языке машины. Один алгоритм пишут на Python и на C++; один `.py` может прятать разные алгоритмы, если сменить порядок сравнений или способ хранения.

Когда программа тормозит или ломается на краю, ищут не «не тот отступ», а «не тот способ». Пузырёк и быстрая сортировка — разные планы с разной ценой; оба можно написать аккуратно.

План конечен (не крутится вечно без причины), определён (на каждом шаге ясно, что дальше) и результативен (ответ или явно «нет ответа»). Эвристика «попробуй так, иначе иначе» без гарантии завершения — другой класс: там надежда, не доказательство.

Разбор задачи — четыре слоя, и третий нельзя пропускать.

1. Постановка: что на входе, что на выходе, края (пустой список, один элемент, все равны).
2. Идея одним предложением: «идём слева и помним минимум».
3. Ручной проход на 5–8 элементах: состояние после каждого шага.
4. Код и те же примеры плюс края.

Без третьего слоя легко написать то, что «кажется правильным».

**Поиск минимума.** Вход `[7, 2, 9, 2, 5]`, список непустой. Кандидат — первый элемент, сравниваем с остальными, меньшее побеждает.

1. `min_val = 7`
2. `2 < 7` → `2`
3. `9`, второй `2`, `5` — не меньше
4. ответ `2`

Инвариант цикла: «`min_val` — минимум уже просмотренного префикса». В конце префикс — весь список.

```python
def find_min(nums: list[int]) -> int:
    if not nums:
        raise ValueError("пустой список: минимума нет")
    min_val = nums[0]
    for x in nums[1:]:
        if x < min_val:
            min_val = x
    return min_val


assert find_min([7, 2, 9, 2, 5]) == 2
assert find_min([3]) == 3
```

Один проход длины `n`: сравнений порядка `n`. Пишем O(n) по времени и O(1) доп. памяти — точный смысл буквы O в следующих уроках. Сейчас важно: цена растёт предсказуемо с размером входа.

Встроенный `min()` — тоже алгоритм, уже в библиотеке. Каша из `if` без ясного выхода — не алгоритм, даже если «иногда работает».

## Практика

### Задание 1. Чётное есть?

Сформулируйте алгоритм «есть ли в списке хотя бы одно чётное»: вход, выход, идея, края. Не пишите код, пока не проговорите шаги на `[1, 3, 4, 7]`.

### Задание 2. Код и края

Напишите `has_even(nums: list[int]) -> bool`. Пройдите руками `[1, 3, 4, 7]`, затем пустой список и одни нечётные. Оцените число шагов от длины.

### Задание 3. Инвариант

Для `find_min` что ломается без проверки пустого списка? Сформулируйте инвариант цикла своими словами.

### Задание 4. Не алгоритм

Пример «кода без алгоритма»: ветвления без ясного выхода. Чем он отличается от плана с завершаемостью?

Дальше — **сложность**: как сравнивать планы по времени и памяти без слепого секундомера.
