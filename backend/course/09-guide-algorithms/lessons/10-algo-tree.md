# Деревья

Корневое дерево — связная структура без циклов с выделенным корнем. У каждого узла кроме корня один родитель, детей сколько угодно. Путь от корня к узлу единственный. Бинарное — не больше двух детей (левый и правый). Так устроены каталоги файлов, DOM, выражения, оргсхемы. Куча и BST — спецслучаи позже.

Узел бинарного дерева: значение и две ссылки, возможно `None`. Рекурсия ложится на поддеревья; итеративный обход тащит стек или очередь явно.

Порядок посещения — отдельное решение, не «как нарисовано»:

- preorder: узел, затем дети;
- inorder (бинарное): левое, узел, правое;
- postorder: дети, затем узел;
- по уровням: BFS очередью.

Высота критична. Вытянутое дерево как список — многие операции O(n). Более кустое — ближе к O(log n) для поиска в упорядоченных вариантах. Высоту и глубину в команде фиксируют одним определением (рёбра vs узлы), иначе спорят на единицу.

```text
      8
     / \
    3   10
   / \    \
  1   6    14
```

Inorder: влево до упора 8 → 3 → 1, посетить 1, 3, правое 6, вверх 8, правое 10, 14. Результат `1, 3, 6, 8, 10, 14`. Preorder: `8, 3, 1, 6, 10, 14`. Postorder: `1, 6, 3, 14, 10, 8`.

```python
class Node:
    def __init__(self, val: int, left: "Node | None" = None, right: "Node | None" = None):
        self.val = val
        self.left = left
        self.right = right


def inorder(node: Node | None, out: list[int]) -> None:
    if node is None:
        return
    inorder(node.left, out)
    out.append(node.val)
    inorder(node.right, out)


root = Node(8, Node(3, Node(1), Node(6)), Node(10, None, Node(14)))
got: list[int] = []
inorder(root, got)
assert got == [1, 3, 6, 8, 10, 14]
```

Лист — без детей. Поддерево — узел со всеми потомками. Цикл в «дереве» значит, что это уже граф и обход без `visited` зациклится.
