# Стек

Стопка тарелок: снять можно только верхнюю. **Стек** — та же дисциплина для данных: положили последним — заберёте первым (LIFO). Операции узкие специально: `push` на вершину, `pop` с вершины, иногда `peek` — посмотреть, не снимая. Если лезете ко второму сверху как к основной операции, это уже просто список, и рассуждать о стеке бесполезно.

В Python стек почти всегда конец списка: `append` / `pop()` — амортизированно O(1). Связный список с головой-вершиной — та же идея. Учебный стек фиксированной длины может «переполниться»; у `list` он растёт, пока хватает памяти.

Зачем ограничивать доступ. Состояние тогда одномерное: что на вершине, то актуально. Разбор скобок, кнопка «отменить», стек вызовов функций, обход в глубину — все они помнят «незаконченное последнее». Пустой `pop` — нарушение контракта: либо исключение, либо явный отказ, не молчаливый `None`, который потом всплывёт в чужом месте.

Проверка `"(()[])"`:

```text
(    стек: (
(    стек: ( (
)    верх ( — снимаем. стек: (
[    стек: ( [
]    верх [ — снимаем. стек: (
)    снимаем (. стек пуст → да
```

`"([)]"`: после `( [` приходит `)` — на вершине квадратная, типы не сходятся, сразу нет. Не «досмотреть до конца».

```python
def brackets_ok(s: str) -> bool:
    pair = {")": "(", "]": "[", "}": "{"}
    st: list[str] = []
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif ch in ")]}":
            if not st or st[-1] != pair[ch]:
                return False
            st.pop()
    return not st


assert brackets_ok("(()[])") is True
assert brackets_ok("([)]") is False
assert brackets_ok("") is True
```

Один проход, память в худшем случае как все открывающие — O(n). Пустая строка — да: снимать было нечего, и лишнего не осталось.

Редактор: каждый символ — `push`, undo — `pop`. Переворот списка: все `push`, потом все `pop` — получите обратный порядок; сложность линейная, не «магия стека».

Стек вызовов рантайма — тот же LIFO кадров. Рекурсия без базы кладёт кадры, пока не упрётся в лимит. Это тот же объект мысли, только его вам не `append`.

Очередь в следующем уроке забирает **с другого конца**: кто пришёл первым, того и обслужат. Перепутать в обходе графа — получить DFS вместо BFS.
