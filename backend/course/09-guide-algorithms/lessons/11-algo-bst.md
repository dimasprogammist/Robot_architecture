# Двоичное дерево поиска (BST)

BST — бинарное дерево с инвариантом: все ключи слева меньше узла, все справа больше (равные оговаривают отдельно). Поиск — как в отсортированной структуре: сравнили, пошли налево или направо. Средняя высота случайного дерева порядка log n. Вставка уже отсортированной последовательности даёт цепочку и O(n). Поэтому в проде чаще сбалансированные деревья; учебный BST учит инварианту.

Inorder BST выдаёт ключи по возрастанию — дешёвая проверка после вставок.

Поиск: пока узел не пуст и ключ не равен — left если меньше, иначе right. Вставка: тот же спуск до пустого места, новый лист. Удаление: 0 детей — снять лист; 1 — подставить ребёнка; 2 — взять преемника (минимум справа) или предшественника и аккуратно перевесить.

Вставляем `8, 3, 10, 1, 6, 14, 4`:

```text
      8
     / \
    3   10
   / \    \
  1   6    14
     /
    4
```

Поиск 6: 8 → 3 → 6. Поиск 7: 8 → 3 → 6, справа пусто — нет. Вставка 7: новый узел справа от 6.

```python
class Node:
    def __init__(self, key: int):
        self.key = key
        self.left: Node | None = None
        self.right: Node | None = None


def bst_insert(root: Node | None, key: int) -> Node:
    if root is None:
        return Node(key)
    if key < root.key:
        root.left = bst_insert(root.left, key)
    elif key > root.key:
        root.right = bst_insert(root.right, key)
    return root


def bst_find(root: Node | None, key: int) -> bool:
    cur = root
    while cur is not None:
        if key == cur.key:
            return True
        cur = cur.left if key < cur.key else cur.right
    return False


r = None
for k in [8, 3, 10, 1, 6, 14, 4]:
    r = bst_insert(r, k)
assert bst_find(r, 6) is True
assert bst_find(r, 7) is False
```

Не путать BST с кучей: в куче «родитель не больше детей», но слева может быть ключ больше, чем справа. Не ждать O(log n) от вырожденного дерева.
