# Кратчайшие пути

«Кратчайший» зависит от метрики. Без весов минимум числа рёбер — BFS. Неотрицательные веса, минимум суммы — Дейкстра. Отрицательные веса — Bellman-Ford; отрицательный цикл — отдельная болезнь (сумму можно крутить вниз бесконечно). Все пары на малых графах — Floyd-Warshall O(V³).

Дейкстра держит `dist[v]`: у источника 0, у остальных «бесконечность». Всегда расширяет вершину с текущим минимальным dist (куча). **Релаксация** ребра u → v: если `dist[u] + w < dist[v]`, обновить dist и предшественника. Когда вершину извлекли с актуальной оценкой и веса ≥ 0, её dist окончателен. Устаревшие записи в куче пропускают: `if d > dist[u]: continue`. Отрицательные веса классический Dijkstra ломают.

Рёбра (u, v, w): (0,1,2), (0,2,5), (1,2,1), (1,3,4), (2,3,1), (3,4,3), (4,5,1), (2,5,9). Старт 0.

1. Берём 0 → dist 1←2, 2←5
2. Берём 1 (2) → 2←3, 3←6
3. Берём 2 (3) → 3←4, 5←12
4. Берём 3 (4) → 4←7
5. Берём 4 (7) → 5←8
6. Берём 5

dist = [0, 2, 3, 4, 7, 8]. Путь к 5: 0–1–2–3–4–5, не прямой 0–2–5 с девяткой.

```python
import heapq
from collections import defaultdict


def dijkstra(n: int, edges: list[tuple[int, int, int]], src: int) -> list[float]:
    g: dict[int, list[tuple[int, int]]] = defaultdict(list)
    for u, v, w in edges:
        g[u].append((v, w))
    dist = [float("inf")] * n
    dist[src] = 0.0
    pq = [(0.0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in g[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist


edges = [(0, 1, 2), (0, 2, 5), (1, 2, 1), (1, 3, 4), (2, 3, 1), (3, 4, 3), (4, 5, 1), (2, 5, 9)]
assert dijkstra(6, edges, 0)[5] == 8
```

Сложность типичной кучи: O((V+E) log V). Не запускайте Дейкстру «потому что граф», когда весов нет — BFS проще и достаточен.
