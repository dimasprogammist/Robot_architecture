# Deque (двусторонняя очередь)

Стек — один конец. Очередь — два разных конца, но роли жёсткие. **Deque** разрешает дешёвые `append`/`pop` с **обоих** концов. В CPython это блоки, не «массив, который внезапно быстр с головы».

Середина платная: `d[i]` для индекса в глубине — O(n). Это не замена `list`, когда вы часто прыгаете по номеру.

Лента с двумя указателями. Стек — только правый конец. Очередь — `append` справа, `popleft` слева. Смешивать можно, если читатель кода понимает контракт.

Палиндром: снимаете оба конца, пока не встретите неравенство или не останется 0–1 элемент.

```text
[1, 4, 6, 6, 4, 1]  концы равны, снимаем → … → пусто → да
[1, 4, 6, 7, 4, 1]  на 6 и 7 — нет
```

```python
from collections import deque


def is_palindrome(vals: list[int]) -> bool:
    d = deque(vals)
    while len(d) > 1:
        if d.popleft() != d.pop():
            return False
    return True
```

`maxlen`: при переполнении молча вылетает элемент с противоположного конца. Буфер «последние три события» удобен; забыть про выталкивание — потерять данные без исключения.

`list.insert(0)` — не deque: каждый раз сдвиг. Скользящее окно средних: в окне держите deque чисел, с одного конца кладёте новое, с другого выкидываете устаревшее.
