# Обход в глубину (DFS)

## Цель

Освоить DFS: идти вглубь до тупика, затем откатываться; реализация стеком или рекурсией; типичные задачи — циклы, компоненты, обход деревьев.

## Что уже нужно знать

Стек, рекурсия, граф, отличие порядка BFS от «волн».

## Объяснение с нуля

DFS (depth-first search) выбирает соседа и погружается, пока возможно, затем возвращается. Реализация: явный стек или рекурсия (стек вызовов). Порядок посещения другой, чем у BFS: не уровни, а ветки.

Применения: поиск циклов, топологическая сортировка в DAG, компоненты связности, обход деревьев, backtracking. Для кратчайшего пути в невзвешенном графе DFS не подходит — берите BFS. Сложность та же O(V + E) при аккуратном `visited`.

Цвета вершин (белый/серый/чёрный) помогают ловить обратные рёбра в ориентированных графах. В неориентированном графе ребро к родителю циклом не считается.

## Термины

- **Back edge** — ребро к предку в лесу DFS.
- **Время входа/выхода** — метки для запросов «является ли предком».
- **Лес DFS** — набор деревьев обхода при нескольких стартах.

## Внутреннее устройство

Рекурсивная схема: пометить v visited, обработать v, для каждого непосещённого соседа вызвать DFS. Итеративная: класть вершины в стек и имитировать ту же логику. Порядок соседей влияет на конкретную последовательность посещения, но не на асимптотику.

## Пример на том же графе

Рёбра: 0–1, 0–2, 1–3, 2–3, 3–4, 4–5. Старт 0. Соседи отсортированы по возрастанию.

### Пошаговый разбор

1. 0 → берём соседа 1.
2. 1 → берём 3.
3. 3 → берём 2 (0 уже посещён как предок по другой ветке).
4. 2 — новых непосещённых нет, возврат.
5. От 3 идём к 4 → 5.
6. Откат вверх.

Один возможный порядок обнаружения: 0, 1, 3, 2, 4, 5. Сравните с BFS 0, 1, 2, 3, 4, 5 — различие уже на третьей позиции.

### Код на Python

```python
from collections import defaultdict


def dfs(start: int, edges: list[tuple[int, int]]) -> list[int]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    for v in g:
        g[v].sort()
    order: list[int] = []
    seen: set[int] = set()

    def go(v: int) -> None:
        seen.add(v)
        order.append(v)
        for nb in g[v]:
            if nb not in seen:
                go(nb)

    go(start)
    return order


edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
print(dfs(0, edges))
```

### Сложность

Время O(V + E), память O(V) на visited плюс O(h) на стеке рекурсии (h — глубина).

## Типичные ошибки

- Нет visited на неориентированном графе → бесконечная рекурсия.
- Путать «путь найден DFS» с «путь кратчайший».
- Слишком глубокая рекурсия на длинной цепи — нужен итеративный стек.
- Считать ребро к родителю циклом в неориентированном графе.

## Что запомнить

DFS = вглубь, стек или рекурсия, O(V + E). Задачи другие, чем у BFS.
