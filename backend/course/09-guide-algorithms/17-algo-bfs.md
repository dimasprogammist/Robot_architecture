# Обход в ширину (BFS)

## Цель

Освоить BFS очередью: волны по уровням и кратчайший путь по числу рёбер в невзвешенном графе.

## Что уже нужно знать

Очередь, граф как список смежности, множество посещённых вершин.

## Объяснение с нуля

BFS (breadth-first search) сначала посещает всех соседей стартовой вершины, затем соседей этих соседей и так далее. Реализация: очередь + множество `visited`. При первом достижении вершины в невзвешенном графе путь кратчайший по числу рёбер — главное свойство BFS.

Применения: кратчайший маршрут в лабиринте без весов, уровни в дереве, проверка двудольности, поиск компонент. Сложность O(V + E) для списка смежности: каждую вершину и каждое ребро обрабатывают константное число раз.

DFS (следующий урок) идёт вглубь — другой порядок и другие задачи. Для кратчайшего пути по числу рёбер DFS не подходит.

## Термины

- **Уровень / волна** — вершины на одинаковой дистанции от старта.
- **visited** — защита от повторного захода и циклов.
- **parent** — предшественник для восстановления пути.

## Внутреннее устройство

1. Положить старт в очередь, отметить visited, dist[start] = 0.
2. Пока очередь не пуста: достать v, для каждого непосещённого соседа пометить, задать dist и parent, положить в очередь.
3. Помечать visited в момент добавления в очередь (не в момент извлечения), иначе появятся дубликаты.

## Пример на графе из 6 вершин

Рёбра: 0–1, 0–2, 1–3, 2–3, 3–4, 4–5. Старт 0.

### Пошаговый разбор

1. queue = [0], visited = {0}, dist[0] = 0.
2. Достали 0 → соседи 1 и 2 → queue = [1, 2], dist = 1.
3. Достали 1 → сосед 3 → queue = [2, 3].
4. Достали 2 → 3 уже visited.
5. Достали 3 → сосед 4 → queue = [4], dist[4] = 2.
6. Достали 4 → сосед 5 → dist[5] = 3.
7. Достали 5 → конец.

Порядок посещения: 0, 1, 2, 3, 4, 5. Длина пути к 5 равна 3.

### Код на Python

```python
from collections import deque, defaultdict


def bfs(start: int, edges: list[tuple[int, int]]) -> list[int]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    order: list[int] = []
    q: deque[int] = deque([start])
    seen = {start}
    while q:
        v = q.popleft()
        order.append(v)
        for nb in g[v]:
            if nb not in seen:
                seen.add(nb)
                q.append(nb)
    return order


edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
assert bfs(0, edges) == [0, 1, 2, 3, 4, 5]
```

### Сложность

Время O(V + E), память O(V) на очередь и visited.

## Практика

Восстановите путь 0 → 5 через массив parent. Запишите одну из кратчайших цепочек вершин.

## Типичные ошибки

- Стек вместо очереди → получится DFS-порядок.
- Помечать visited поздно и плодить дубликаты в очереди.
- Забыть обратное ребро в неориентированном графе.
- Ждать кратчайший путь по весу — для весов нужен другой алгоритм.

## Что запомнить

BFS = очередь + уровни. O(V + E). Кратчайший путь по числу рёбер в невзвешенном графе.
