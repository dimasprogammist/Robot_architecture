# Графы

## Цель

Научиться моделировать связи как граф: вершины, рёбра, ориентированность, список смежности и матрица смежности.

## Что уже нужно знать

Деревья как частный случай без циклов, очереди и стеки, O-нотация.

## Объяснение с нуля

Граф G = (V, E): V — множество вершин, E — множество рёбер (пар вершин). В ориентированном графе ребро имеет направление; в неориентированном связь двусторонняя. На рёбрах могут быть веса — стоимость перехода (длина дороги, задержка, цена).

Два основных представления:

- **Список смежности** — для каждой вершины список соседей. Память O(V + E), удобно для разреженных графов.
- **Матрица смежности** — таблица V×V. Память O(V²), проверка ребра за O(1).

Деревья — связные ациклические графы. Цикл, компонента связности, путь — базовый словарь для BFS, DFS и поиска кратчайших путей. В сервисах граф часто моделирует зависимости модулей, топологию сети или карту маршрутов.

## Термины

- **Степень вершины** — число инцидентных рёбер.
- **Путь** — последовательность рёбер от одной вершины к другой.
- **Компонента связности** — максимальное связное подмножество вершин.
- **Петля** — ребро из вершины в себя.

## Внутреннее устройство выбора представления

Если рёбер мало относительно V² — берите списки смежности. Если нужны частые проверки «есть ли ребро u–v» и V невелико — матрица уместна. Для взвешенного графа в списке хранят пары (сосед, вес).

## Пример: неориентированный граф из 6 вершин

Рёбра: 0–1, 0–2, 1–3, 2–3, 3–4, 4–5.

### Пошаговый разбор списка смежности

```text
0: 1, 2
1: 0, 3
2: 0, 3
3: 1, 2, 4
4: 3, 5
5: 4
```

Проверка «есть ли ребро 2–3»: смотрим список вершины 2 — да. Сумма длин списков равна 2|E| для неориентированного графа.

### Код на Python

```python
from collections import defaultdict


def build_undirected(edges: list[tuple[int, int]]) -> dict[int, list[int]]:
    g: dict[int, list[int]] = defaultdict(list)
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    return g


edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (4, 5)]
g = build_undirected(edges)
assert 3 in g[2]
assert 5 in g[4]
```

### Сложность

Построение из списка рёбер: O(E). Перечисление соседей вершины: O(deg(v)). Память списка смежности: O(V + E).

## Практика

Добавьте ориентированное ребро 5 → 0 только в одном направлении и перепишите списки. Сколько исходящих рёбер у вершины 5?

## Типичные ошибки

- Забыть обратное ребро в неориентированном графе.
- Смешать оценки сложности матрицы и списка.
- Не зафиксировать нумерацию вершин с нуля или с единицы.
- Искать путь без множества посещённых вершин и зациклиться.

## Что запомнить

Граф = вершины + рёбра. Список смежности — дефолт для разреженных графов. Дальше — обходы и кратчайшие пути.
