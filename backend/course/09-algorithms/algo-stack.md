# Стек

## Цель

Освоить стек (LIFO): операции push и pop с вершины и типичные задачи — проверка скобок, откат действий, основа DFS.

## Что уже нужно знать

Массив или связный список как хранилище, амортизированный O(1) на конец динамического массива.

## Объяснение с нуля

Стек — структура «последним пришёл — первым ушёл» (LIFO). Кладёте тарелки стопкой: снимаете только верхнюю. Основные операции: `push` (положить на вершину), `pop` (снять вершину), `peek`/`top` (посмотреть верх без снятия).

Реализация на динамическом массиве с работой только с концом (`append` / `pop`) даёт амортизированно O(1). Альтернатива — список узлов, где голова — вершина стека.

Зачем ограничивают доступ только вершиной: так проще рассуждать о состоянии. Типичные применения — разбор скобок, калькулятор выражений, команда «отменить», стек вызовов функций, итеративный обход в глубину. Пустой `pop` — ошибка контракта: либо исключение, либо явный пустой результат.

## Термины

- **LIFO** — Last In, First Out.
- **Вершина** — единственный доступный конец.
- **Стек вызовов** — служебный стек рантайма для кадров функций.
- **Переполнение** — в учебном стеке фиксированного размера; у Python `list` стек растёт.

## Внутреннее устройство

Состояние стека — последовательность элементов от дна к вершине. `push(x)` добавляет x наверх. `pop()` забирает верхний. Любая попытка читать «второй сверху» как основную операцию ломает абстракцию — тогда это уже не чистый стек, а просто список.

## Пример: проверка скобок

Вход: `( [ ] )` как строка `"([])"` плюс для длины разберём `"(()[])"` — шесть символов.

### Пошаговый разбор для `(()[])`

1. Символ `(` → кладём в стек. Стек: открывающая круглая.
2. Ещё `(` → стек из двух круглых.
3. `)` → верх должен быть круглой; снимаем. Осталась одна круглая.
4. `[` → кладём квадратную.
5. `]` → верх квадратная; снимаем. Осталась круглая.
6. `)` → снимаем круглую. Стек пуст → скобочная последовательность верна.

Контрпример `([)]`: после открытия круглой и квадратной приходит `)` — типы не совпадают с верхом → сразу ложь.

### Код на Python

```python
def brackets_ok(s: str) -> bool:
    pair = {")": "(", "]": "[", "}": "{"}
    st: list[str] = []
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif ch in ")]}":
            if not st or st[-1] != pair[ch]:
                return False
            st.pop()
    return not st


assert brackets_ok("(()[])") is True
assert brackets_ok("([)]") is False
assert brackets_ok("") is True
```

### Сложность

Один проход по строке длины n: время O(n), память O(n) в худшем случае (все открывающие).

## Типичные ошибки

- Делать `pop` из пустого стека без проверки.
- Использовать стек там, где нужен FIFO (очередь).
- Класть в стек огромные объекты без нужды — часто достаточно индексов.
- Перепутать порядок при выгрузке стека в результирующий список.

## Что запомнить

Стек = LIFO, O(1) push/pop на вершине. Классика — скобки, отмена операций, DFS.
