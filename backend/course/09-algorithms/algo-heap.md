# Куча (heap)

## Цель

Понять бинарную кучу как почти полное дерево в массиве: минимум или максимум наверху за O(1), вставка и извлечение за O(log n).

## Что уже нужно знать

Деревья, массивы, логарифм высоты полного дерева, идея приоритетной очереди.

## Объяснение с нуля

Двоичная min-куча: ключ родителя не больше ключей детей. Корень — минимум. Дерево заполняется уровень за уровнем слева направо, поэтому его удобно хранить в массиве: для индекса i дети — 2i+1 и 2i+2, родитель — (i−1)//2.

Операции: `push` — добавить в конец и «всплыть» (sift up); `pop_min` — заменить корень последним элементом и «погрузить» (sift down). Обе O(log n). Построить кучу из массива можно за O(n) снизу вверх — быстрее, чем n раз делать push.

Max-куча зеркальна. В Python модуль `heapq` — min-heap поверх списка. Куча не даёт быстрый поиск произвольного ключа: только доступ к верху по приоритету.

## Термины

- **Sift up / sift down** — восстановление инварианта кучи.
- **Приоритетная очередь** — абстракция; куча — частая реализация.
- **Почти полное дерево** — заполнение по уровням слева направо.
- **heapify** — построение кучи из произвольного массива.

## Внутреннее устройство

Инвариант поддерживается локальными обменами вдоль пути к корню или к листу. Высота почти полного дерева Θ(log n), поэтому путь короткий. Устаревшие записи в приоритетной очереди на куче иногда оставляют и пропускают при извлечении — упрощённый приём в Dijkstra.

## Пример: push в min-heap

Массив-куча: `[1, 3, 2, 7, 6, 4]`. Добавляем `0`.

### Пошаговый разбор

1. Добавили в конец: `[1, 3, 2, 7, 6, 4, 0]`, индекс нового — 6.
2. Родитель индекса 6 — 2 (значение 2). 0 < 2 → меняем: `[1, 3, 0, 7, 6, 4, 2]`.
3. Родитель индекса 2 — 0 (значение 1). 0 < 1 → меняем: `[0, 3, 1, 7, 6, 4, 2]`.
4. Дошли до корня. Минимум теперь 0.

### Код на Python

```python
import heapq


h = [1, 3, 2, 7, 6, 4]
heapq.heapify(h)
heapq.heappush(h, 0)
assert h[0] == 0
assert heapq.heappop(h) == 0


def sift_up(a: list[int], i: int) -> None:
    while i > 0:
        p = (i - 1) // 2
        if a[p] <= a[i]:
            break
        a[p], a[i] = a[i], a[p]
        i = p
```

### Сложность

- Минимум/максимум на корне: O(1).
- push / pop: O(log n).
- heapify: O(n).
- Поиск произвольного значения: O(n).

## Типичные ошибки

- Путать кучу с BST: полного порядка «все слева меньше» нет.
- Ждать полностью отсортированный массив после heapify.
- Перепутать формулы индексов детей и родителя.
- Искать ключ x в куче как в словаре.
