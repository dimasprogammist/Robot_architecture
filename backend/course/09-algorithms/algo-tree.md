# Деревья

## Цель

Увидеть дерево как иерархию: корень, дети, листья; разные обходы и роль высоты для скорости операций.

## Что уже нужно знать

Связный список как узлы со ссылками, рекурсия на уровне идеи, O-нотация.

## Объяснение с нуля

Дерево в информатике чаще всего — корневое: связная структура без циклов с выделенным корнем. У каждого узла кроме корня один родитель; детей может быть несколько. Путь от корня к любому узлу единственный.

Бинарное дерево — не более двух детей (левый и правый). N-арное — произвольное число детей, обычно списком. Деревья моделируют файловую систему, DOM, синтаксис выражений, оргструктуры. Спецслучаи — куча и двоичное дерево поиска — разберём отдельно.

Обходы задают порядок посещения:

- preorder: узел, затем дети;
- inorder (для бинарных): левое поддерево, узел, правое;
- postorder: дети, затем узел;
- по уровням: BFS очередью.

Высота критична: вытянутое дерево как список даёт операции O(n); более низкое — ближе к O(log n) для многих задач поиска.

## Термины

- **Корень** — узел без родителя.
- **Лист** — узел без детей.
- **Высота / глубина** — меры длины пути; фиксируйте определение в команде.
- **Поддерево** — узел вместе со всеми потомками.

## Внутреннее устройство

Узел бинарного дерева хранит значение и две ссылки: left и right (могут быть None). Рекурсивные алгоритмы естественно ложатся на поддеревья. Итеративные обходы используют стек или очередь явно.

## Пример: inorder на бинарном дереве

```text
      8
     / \
    3   10
   / \    \
  1   6    14
```

### Пошаговый разбор inorder

Идём влево до конца от 8 → 3 → 1; посещаем 1; назад к 3; посещаем 3; правое 6; посещаем 6; назад к 8; посещаем 8; правое 10; посещаем 10; правое 14; посещаем 14.

Результат: `1, 3, 6, 8, 10, 14`.

Preorder: `8, 3, 1, 6, 10, 14`. Postorder: `1, 6, 3, 14, 10, 8`.

### Код на Python

```python
class Node:
    def __init__(self, val: int, left: "Node | None" = None, right: "Node | None" = None):
        self.val = val
        self.left = left
        self.right = right


def inorder(node: Node | None, out: list[int]) -> None:
    if node is None:
        return
    inorder(node.left, out)
    out.append(node.val)
    inorder(node.right, out)


root = Node(8, Node(3, Node(1), Node(6)), Node(10, None, Node(14)))
acc: list[int] = []
inorder(root, acc)
assert acc == [1, 3, 6, 8, 10, 14]
```

### Сложность

Обход всех узлов: время O(n), память O(h) на стеке рекурсии, где h — высота.

## Практика

Нарисуйте дерево из семи узлов и выпишите три обхода вручную. Проверьте, что число посещений равно числу узлов.

## Типичные ошибки

- Создать цикл ссылок и словить бесконечную рекурсию.
- Путать порядок inorder и preorder.
- Считать любое дерево автоматически сбалансированным.
- Забыть обработать `None` у детей.

## Что запомнить

Дерево — иерархия без циклов. Обходы различаются порядком. Высота определяет скорость многих алгоритмов на деревьях.
