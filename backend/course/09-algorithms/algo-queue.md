# Очередь

## Цель

Понять очередь (FIFO): добавление в хвост, изъятие из головы; где она нужна — BFS, буферы событий, обработка задач по порядку прихода.

## Что уже нужно знать

Стек для контраста, массив, почему `list.pop(0)` дорогой по времени.

## Объяснение с нуля

Очередь — «первым пришёл — первым ушёл» (FIFO), как живая очередь в кассу. Операция `enqueue` добавляет в конец, `dequeue` забирает из начала. Иногда добавляют `peek` — посмотреть голову без удаления.

На обычном динамическом массиве удаление из начала требует сдвига всех элементов — O(n). Поэтому используют кольцевой буфер, двусвязный список или `collections.deque` в Python, где операции с обоих концов амортизированно O(1).

Очередь — основа обхода в ширину, обработки сообщений, сглаживания пиков нагрузки. Перепутать со стеком — частая ошибка в задачах на графы: получится другой порядок обхода и другие свойства пути.

## Термины

- **FIFO** — First In, First Out.
- **Голова** — откуда забираем.
- **Хвост** — куда кладём.
- **Кольцевой буфер** — фиксированный массив с индексами по модулю ёмкости.

## Внутреннее устройство

Абстракция очереди скрывает хранилище. Важно только: порядок выхода совпадает с порядком входа. Пустой `dequeue` — ошибка контракта. В многопоточных системах бывают блокирующие очереди; в этом уроке — однопоточная логическая модель.

## Пример: серия операций

Пустая очередь. Делаем enqueue чисел 4, 1, 7, 3, 9, 2; затем три dequeue.

### Пошаговый разбор

1. После всех enqueue голова — 4, хвост — 2, внутри: 4, 1, 7, 3, 9, 2.
2. Первый dequeue → 4; осталось 1, 7, 3, 9, 2.
3. Второй dequeue → 1.
4. Третий dequeue → 7; осталось 3, 9, 2.

Порядок выхода префикса совпал с порядком входа.

### Код на Python

```python
from collections import deque


def demo() -> None:
    q: deque[int] = deque()
    for x in [4, 1, 7, 3, 9, 2]:
        q.append(x)  # enqueue
    out = [q.popleft() for _ in range(3)]  # dequeue
    assert out == [4, 1, 7]
    assert list(q) == [3, 9, 2]


demo()
```

Плохой по производительности, но верный по смыслу вариант: `q: list[int] = []; q.append(x); q.pop(0)`. На больших n он деградирует.

### Сложность

С `deque`: enqueue и dequeue по O(1). С `list.pop(0)`: dequeue O(n). Память O(n) на хранение элементов.

## Практика

Объясните словами, почему BFS использует очередь, а не стек. Возьмите граф из шести вершин и сравните порядок посещения мысленно.

## Типичные ошибки

- Реализовать очередь через `pop(0)` у `list` в горячем пути.
- Перепутать, в какой конец кладут новые элементы.
- Не обработать dequeue из пустой очереди.
- Использовать обычную очередь, когда нужен приоритет (нужна куча).

## Что запомнить

Очередь = FIFO. В Python для очереди берите `deque`. Нужна для BFS и буферов задач.
