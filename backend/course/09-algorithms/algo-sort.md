# Сортировки

## Цель

Разобрать несколько сортировок на одном массиве: идея, шаги, сложность и когда какая уместна. В проде обычно берут встроенную сортировку; учебные алгоритмы учат читать чужой код и понимать цену.

## Что уже нужно знать

Массивы, вложенные циклы, O-нотация, рекурсия для идей merge/quick на уровне схемы.

## Объяснение с нуля

Сортировка упорядочивает элементы по ключу. Важные свойства:

- **стабильность** — равные ключи сохраняют относительный порядок;
- **in-place** — мало дополнительной памяти;
- **адаптивность** — быстрее на почти отсортированных данных.

Краткий обзор:

- **Пузырёк** — соседние перестановки, O(n²), учебный.
- **Вставками** — как карты в руке, O(n²), хорош на малых и почти sorted данных.
- **Слиянием** — разделяй и властвуй, O(n log n), нужна доп. память.
- **Быстрая** — партиция вокруг опорного, средняя O(n log n), худшая O(n²).

В Python `sorted` и `list.sort` используют Timsort: гибрид с гарантией O(n log n) и стабильностью. Для продакшена начинайте с него.

## Термины

- **Компаратор** — правило сравнения двух элементов.
- **Партиция** — разделение относительно опорного элемента (pivot).
- **Стабильность** — равные элементы не меняются местами без нужды.

## Внутреннее устройство сортировки вставками

Поддерживаем отсортированный префикс. Очередной элемент вставляем в нужное место префикса, сдвигая большие элементы вправо. На почти отсортированном массиве сдвигов мало — отсюда адаптивность.

## Пример: вставками на 7 числах

Массив: `[5, 2, 4, 6, 1, 3, 2]`.

### Пошаговый разбор

1. Префикс `[5]`, вставляем 2 → `[2, 5]`.
2. Вставляем 4 → `[2, 4, 5]`.
3. 6 уже на месте → `[2, 4, 5, 6]`.
4. Вставляем 1 → `[1, 2, 4, 5, 6]`.
5. Вставляем 3 → `[1, 2, 3, 4, 5, 6]`.
6. Вставляем 2 → `[1, 2, 2, 3, 4, 5, 6]`.

### Код на Python

```python
def insertion_sort(a: list[int]) -> list[int]:
    a = a[:]
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a


assert insertion_sort([5, 2, 4, 6, 1, 3, 2]) == [1, 2, 2, 3, 4, 5, 6]
assert sorted([5, 2, 4, 6, 1, 3, 2]) == [1, 2, 2, 3, 4, 5, 6]
```

### Сложность

Вставками: время O(n²) в худшем и среднем, O(n) на уже отсортированном; память O(1) доп. Timsort: O(n log n) гарантированно.

## Практика

Пройдите один полный проход пузырька на `[5, 2, 4, 6, 1, 3]` и запишите массив после прохода. Сколько обменов сделали?

## Типичные ошибки

- Писать свою quicksort для продакшена без веской причины.
- Забыть худший случай quicksort на неудачном pivot.
- Ломать стабильность, когда она нужна (многоключевая сортировка).
- Считать массив отсортированным, не проверив компаратор для своих объектов.

## Что запомнить

O(n²) — учебные методы; O(n log n) — практический класс. В Python — `sorted` / `list.sort`. Ручной разбор вставок закрепляет механику сдвига.
