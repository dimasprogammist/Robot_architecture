# Кортежи

## Цель

Понять tuple как неизменяемую упорядоченную последовательность.

Выбирать кортеж для фиксации структуры и хешируемости.

## Что уже пройдено

Вы освоили изменяемые списки.

Кортеж похож, контракт другой.

## Объяснение с нуля

Кортеж хранит упорядоченные ссылки, но не позволяет менять длину и элементы самого кортежа. Один элемент: `(1,)`.

Неизменяемость — контракт «пара координат не удлинится». Кортеж из хешируемых элементов хешируем — ключ dict/элемент set.

Распаковка читается яснее индексов. Важно: неизменяемость кортежа не замораживает изменяемые объекты внутри.

## Термины

- **tuple**.

- **Одноэлементный кортеж `(x,)`**.

- **Хешируемость**.

- **Распаковка**.

- **Гетерогенность**.

- **Вложенная мутабельность**.

- **Ключ словаря**.

## Внутреннее устройство

Кортеж компактнее списка: нет запаса под рост. Литералы часто в константах code object.

Хеш комбинирует хеши элементов; unhashable внутри → кортеж не хешируем. `t[0]=...` → TypeError.

## Пример

```python

point = (10, 20)

x, y = point

key = ("user", 42)

data = {key: "ok"}

print(x, y, data[key])

bad = ([1],)

try:

    s = {bad}

except TypeError as e:

    print("expected:", type(e).__name__)

```

## Разбор

Распаковка привязывает x,y. Ключ из строк/int хешируем.

Вложенный список делает кортеж нехешируемым.

## Ошибки

- `(1)` вместо `(1,)`.

- Думать, что кортеж замораживает list внутри.

- Список как ключ dict.

- Путать скобки вызова и литерал.

- Мутировать содержимое и удивляться «сломанной неизменяемости».

## Что запомнить

Кортеж фиксирует последовательность ссылок.

Хешируемость зависит от элементов.

Неизменяемость контейнера ≠ содержимого.
