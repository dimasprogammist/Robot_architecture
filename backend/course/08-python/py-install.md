# Установка Python

## Цель

Поставить официальный интерпретатор CPython и убедиться, что из терминала вызывается именно он.

После урока вы отличаете язык как правила от конкретной программы-интерпретатора.

## Что уже пройдено

Это первый урок модуля Python.

Достаточно уметь открыть терминал. Синтаксис пока не нужен — нужна карта того, что появляется после установки.

## Объяснение с нуля

Python как язык — грамматика и семантика. Чтобы программа выполнилась, нужна реализация. Самая распространённая — **CPython**: ядро на C, поставка с python.org и через пакетные менеджеры ОС.

Установка даёт исполняемый файл (`python`/`python3`), стандартную библиотеку и часто `pip`. Без этого нельзя открыть REPL и запускать `.py`.

Критично различать «Python установлен» и «в PATH есть команда». Несколько интерпретаторов на одной машине — норма; путаница версий — классический баг среды.

На Windows отметьте Add to PATH и pip. На macOS/Linux часто есть `python3`, но для учёбы удобна 3.11+, а не древняя системная. Проверка: версия печатается, `2+2` даёт `4`.

## Термины

- **CPython** — эталонная реализация на C.

- **Интерпретатор** — процесс исполнения исходника/байткода.

- **PATH** — каталоги поиска программ оболочкой.

- **Версия 3.x** — линейка языка; минор влияет на синтаксис.

- **pip** — установщик пакетов.

- **Стандартная библиотека** — модули «из коробки».

- **sys.executable** — полный путь к запущенному бинарнику.

## Внутреннее устройство

На диск кладётся дерево: бинарник, рантайм, `Lib`, часто `Scripts`/`bin`. Запуск `python` — процесс ОС: загрузка в RAM, куча объектов, встроенные типы.

При старте поднимаются таблицы типов и модуль `builtins`. Версия — свойство конкретного бинарника. Другой путь → другой мир пакетов.

Модель курса: не «один Python на ПК», а N установок. Установка создаёт машину исполнения; ваши программы — файлы, которые она прочитает.

## Пример

```text

python --version

python -c "import sys; print(sys.version); print(sys.executable)"

```

Ожидайте строку `Python 3.x.x` и полный путь к интерпретатору — якорь, если IDE и терминал спорят.

## Разбор

`--version` проверяет среду, не знание языка.

`-c` компилирует строку в байткод без файла. `sys.executable` показывает фактический файл процесса.

«Команда не найдена» — чинить PATH/установку ОС, а не синтаксис.

## Ошибки

- Не добавить в PATH и решить, что язык сломан.

- Путать `python` и `python3`.

- Учиться на слишком старой версии.

- Не проверить интерпретатор вне IDE.

- Ставить пакеты не в ту установку.

- Игнорировать расхождение `sys.executable` между инструментами.

## Что запомнить

Установка = CPython + стандартная библиотека.

Проверяйте версию и путь в том же терминале.

Важна та установка, что реально вызывается командой.
