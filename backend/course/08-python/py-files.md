# Работа с файлами

## Цель

Читать и писать текстовые файлы через open и with.

Различать пути ОС, байты на диске и str в программе.

## Что уже пройдено

Вы ставите пакеты и пишете модули.

Файлы сохраняют данные между запусками процесса.

## Объяснение с нуля

Объекты в куче исчезают с процессом. Файл — долговременные байты. open создаёт файловый объект; with гарантирует закрытие.

Режимы r/w/a и encoding критичны для текста; для бинарного — rb/wb и bytes. pathlib.Path удобнее ручной склейки. Относительные пути — от cwd.

## Термины

- **Файловый объект**.

- **with / контекстный менеджер**.

- **encoding**.

- **Режим открытия**.

- **pathlib.Path**.

- **Буферизация**.

- **cwd**.

## Внутреннее устройство

open просит ОС открыть файл. Текстовый режим делает decode/encode.

with вызывает __enter__/__exit__. Большие файлы читайте построчно, не целиком.

## Пример

```python

from pathlib import Path

path = Path("note.txt")

with path.open("w", encoding="utf-8") as f:

    f.write("hello\n")

with path.open("r", encoding="utf-8") as f:

    text = f.read()

print(text.strip())

```

## Разбор

Запись UTF-8 создаёт/перезаписывает файл. Чтение возвращает str.

Режим w уничтожает старое содержимое — осторожность.

## Ошибки

- open без with.

- Забывать encoding.

- Путать текст и бинарный режим.

- Слепая склейка путей.

- Читать гигабайт целиком.

## Что запомнить

with open безопаснее ручного close.

Для текста указывайте encoding.

Пути и cwd влияют на успех.
