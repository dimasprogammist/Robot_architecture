# Генераторы

## Цель

Освоить функции с yield как ленивую выдачу последовательности.

Понять паузу frame генератора между yield.

## Что уже пройдено

Вы знаете функции, включения и циклы.

Генератор возвращает результат по частям.

## Объяснение с нуля

Обычная функция доходит до return и уничтожает frame. Генераторная содержит yield: вызов возвращает объект-генератор; next/for продолжает до следующего yield.

Зачем: большие потоки без гигантского списка; конвейеры. Генераторное выражение `(...)` — короткий родственник. Исчерпанный генератор не перематывается.

## Термины

- **Генераторная функция / объект-генератор**.

- **yield**.

- **Ленивость**.

- **StopIteration**.

- **Генераторное выражение**.

- **Конвейер**.

- **Одноразовость**.

## Внутреннее устройство

Вызов создаёт объект с приостановленным frame; локальные имена живут между yield.

for вызывает next до StopIteration — тот же протокол итератора. Память: состояние, не вся последовательность.

## Пример

```python

def countdown(n):

    while n > 0:

        yield n

        n -= 1

for x in countdown(3):

    print(x)

squares = (i * i for i in range(5))

print(list(squares))

print(list(squares))

```

## Разбор

countdown выдаёт 3,2,1 по одному yield.

После list генераторное выражение исчерпано — второй list пуст.

## Ошибки

- Думать, что генераторная функция возвращает list.

- Обходить один генератор дважды.

- Путать [] и ().

- Бесконечный генератор без условия остановки потребления.

## Что запомнить

yield приостанавливает frame.

Генератор ленив и обычно одноразовый.

for потребляет генераторы прозрачно.
