# Встроенные типы

## Цель

Ориентироваться в карте встроенных типов: числа, bool, None.

Понять: тип принадлежит объекту, не имени.

## Что уже пройдено

Вы понимаете привязку имён и `is`/`==`.

Теперь — какие базовые типы встречаются с первых программ.

## Объяснение с нуля

Тип определяет допустимые операции. В CPython тип — объект; `type(x)` показывает класс.

`int` произвольной точности, `float` — IEEE, `bool` — подкласс int, `None` — синглтон отсутствия.

Дальше подробно пойдут контейнеры. Динамическая типизация: имя сегодня int, завтра str. Сильная: `"1"+1` не пройдёт молча.

## Термины

- **Тип / экземпляр**.

- **int / float / bool / NoneType**.

- **Динамическая и сильная типизация**.

- **Хешируемость**.

- **Литерал**.

- **Булев контекст**.

- **type(x)** — запрос типа объекта.

## Внутреннее устройство

Заголовок объекта: ссылка на тип, счётчик ссылок, данные. Операции ищутся в type object.

Литералы часто в таблице констант code object. Малые int/строки могут кэшироваться — осторожнее с `is`.

`if x:` использует протокол истинности: 0/None/пустые ложны.

## Пример

```python

values = [0, 1, 3.14, True, None, "hi"]

for v in values:

    print(repr(v), type(v).__name__, bool(v))

```

## Разбор

Цикл показывает имя типа и bool(v). Ноль и None ложны; ненулевые и непустая строка истинны.

`True` имеет тип bool. `repr` отличает `0` от идеи строки.

## Ошибки

- Писать `"1"+1` и ждать автоприведения.

- Путать None, 0, False, "".

- Использовать `is` для чисел «на всякий случай».

- Считать, что имя навсегда «имеет тип».

- Забывать приближённость float.

## Что запомнить

Тип у объекта, не у имени.

Карта типов — фундамент контейнеров.

None — сигнал отсутствия.
