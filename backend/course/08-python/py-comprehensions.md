# Включения

## Цель

Освоить list/set/dict comprehensions.

Понять, когда включение яснее цикла.

## Что уже пройдено

Вы знаете циклы, функции и lambda.

Включения сжимают обход + построение коллекции.

## Объяснение с нуля

`[expr for x in it if cond]` строит новый список. Аналоги для set и dict.

Частый паттерн «прочитать → преобразовать → отфильтровать». Байткод обычно эффективнее наивного append.

Генераторное выражение `(...)` лениво — позже с генераторами. Вложенность больше двух уровней почти всегда хуже явных циклов.

## Термины

- **List/set/dict comprehension**.

- **Фильтр if**.

- **Генераторное выражение**.

- **Целевое выражение**.

- **Область видимости включения**.

- **Читаемость**.

- **Побочный эффект** (избегать).

## Внутреннее устройство

Компилятор порождает специализированный байткод построения.

Переменная цикла во включении в своей области. Тяжёлое выражение скрывает стоимость — тогда явный цикл честнее.

## Пример

```python

nums = range(8)

squares = [n * n for n in nums if n % 2 == 0]

index = {n: n * n for n in squares}

print(squares)

print(index)

```

## Разбор

Фильтр чётных + квадраты → новый список.

Словарное включение строит отображение. Намерение читается сразу.

## Ошибки

- Побочные эффекты во включении.

- Трёхэтажные вложения.

- Путать [] и ().

- Модификация исходной коллекции из выражения.

- Там, где нужен break — лучше for.
