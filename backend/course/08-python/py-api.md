# Вызов HTTP API (базово)

## Цель

Сделать базовый HTTP GET и разобрать JSON-ответ.

Понять запрос как обмен байтами по сети.

## Что уже пройдено

Вы умеете JSON и файлы.

HTTP API часто отдаёт JSON по сети.

## Объяснение с нуля

HTTP: клиент шлёт метод/URL/заголовки/тело; сервер отвечает статусом и телом. Удобно: requests (pip) или urllib.

GET получить, POST отправить. response.json() → dict/list. Проверяйте status и timeout. Сеть неустойчива; не логируйте секреты.

## Термины

- **HTTP-метод / URL**.

- **Статус-код**.

- **Заголовки / тело**.

- **Таймаут**.

- **Клиент**.

- **raise_for_status**.

- **Query-параметры**.

## Внутреннее устройство

Библиотека пишет/читает байты сокета; JSON-парсер строит объекты как loads.

Исключения сети отдельно от HTTP 4xx/5xx. Запрос блокирует поток до ответа.

## Пример

```python

import requests

url = "https://httpbin.org/get"

r = requests.get(url, params={"q": "python"}, timeout=10)

r.raise_for_status()

payload = r.json()

print(payload["args"])

```

## Разбор

get с timeout; raise_for_status на ошибочный код.

json() декодирует тело; args отражает параметры.

## Ошибки

- Игнорировать статус.

- Без timeout.

- Секреты в репозитории.

- Думать, что requests в stdlib.

- Блокировать цикл управления долгим запросом без очередей/async.

## Что запомнить

HTTP API = запрос/ответ + часто JSON.

Проверяйте статус и таймаут.

Ответ → обычные объекты после парсинга.
