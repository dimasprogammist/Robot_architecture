# Что такое backend

## Цель

Понять backend как серверную часть: бизнес-правила, данные, API для клиентов.

## Что уже нужно знать

Клиент-сервер на уровне «браузер ходит в интернет», базовый HTTP.

## Объяснение с нуля

Backend — программы, которые работают на сервере (или в контейнере), принимают запросы, проверяют права, применяют правила, читают и пишут БД, отдают ответы. Frontend рисует UI; backend хранит истину данных и секреты.

Мини-сервис задач: создать задачу, список, отметить done — всё это backend-операции, даже если UI красивый.

## Термины

- **Клиент** — браузер, мобильное приложение, другой сервис.
- **Сервер** — процесс, слушающий порт.
- **API** — контракт запросов и ответов.

## Внутреннее устройство

Клиент → сеть → HTTP-сервер → роутинг → обработчик → сервис → БД → ответ обратно.

## Пример

POST /tasks с JSON {title} → 201 и тело задачи с id.

## Разбор

Сервер проверил JSON, вставил в БД, вернул объект. Без backend браузер не имеет безопасного места для общей БД всех пользователей.

## Код

```text
Клиент: POST /tasks {"title":"Молоко"}
Сервер: 201 {"id":10,"title":"Молоко","done":false}
```

## Типичные ошибки

- Считать backend «только база».
- Класть пароли в frontend-код.
