# JSON в API

## Цель

Сериализовать и принимать JSON без сюрпризов типов.

## Что уже нужно знать

REST.

## Объяснение с нуля

JSON — текст: объекты, массивы, строки, числа, true/false, null. Даты обычно строки ISO. Числа большие id лучше согласовать (int vs string). Невалидный JSON — 400.

Согласуйте snake_case или camelCase и не мешайте.

## Термины

- **Сериализация / десериализация**.
- **Content-Type: application/json**.

## Внутреннее устройство

bytes → json.loads → объекты → проверка схемы → бизнес-логика → dumps.

## Пример

{"id":10,"title":"Молоко","done":false}

## Разбор

done как строка "false" — ошибка схемы, если ждёте boolean.

## Код

```python
import json
payload = json.loads('{"title":"Молоко"}')
assert payload["title"] == "Молоко"
```

## Типичные ошибки

- Молча принимать лишние поля без политики.
- Плывущие типы (то int, то string id).
