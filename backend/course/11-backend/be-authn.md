# Аутентификация

## Цель

Отличать «кто ты» (authentication) от «что тебе можно».

## Что уже нужно знать

JSON/API.

## Объяснение с нуля

Аутентификация устанавливает личность: логин/пароль, сессия, токен, ключ. Результат — идентификатор пользователя в контексте запроса. Без неё все остальные проверки зыбки.

Пароли только как хеш (bcrypt/argon2), никогда в открытом виде.

## Термины

- **Authentication**.
- **Credential**.
- **Principal / current user**.

## Внутреннее устройство

Middleware читает Cookie/Authorization → проверяет → кладёт user в context.

## Пример

Authorization: Bearer <token> или Cookie session_id.

## Разбор

Невалидный токен → 401 Unauthorized.

## Код

```python
# псевдокод
user = auth_service.authenticate(request)
if user is None:
    raise Unauthorized()
```

## Типичные ошибки

- Хранить пароль открытым текстом.
- Путать 401 и 403.
