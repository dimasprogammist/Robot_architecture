# Что такое микроконтроллер

## Цель

Микроконтроллер — это маленькая вычислительная система, помещённая в одну микросхему. Он умеет выполнять программу, читать сигналы от датчиков, управлять выходами и обмениваться данными с другими устройствами.

Микроконтроллеры лежат в основе огромного количества электронных устройств:

* датчиков;
* бытовой техники;
* автомобилей;
* роботов;
* станков;
* контроллеров двигателей;
* измерительных приборов;
* систем автоматизации;
* различных IoT-устройств.

После урока вы должны понимать:

* что такое микроконтроллер;
* из каких основных частей он состоит;
* чем микроконтроллер отличается от обычного компьютера;
* что такое CPU, Flash, RAM и периферия;
* что такое GPIO;
* зачем нужны таймеры, ADC и интерфейсы связи;
* как микроконтроллер взаимодействует с внешним миром.

---

## Микроконтроллер — это компьютер внутри устройства

На первый взгляд микроконтроллер выглядит как обычная микросхема:

```text
┌──────────────────┐
│   МИКРОКОНТРОЛЛЕР│
│                  │
│  CPU             │
│  Flash           │
│  RAM             │
│  GPIO            │
│  Timers          │
│  ADC             │
│  UART            │
│  SPI             │
│  I²C             │
└──────────────────┘
```

Но внутри находится практически всё необходимое для выполнения программы.

В обычном компьютере отдельными компонентами являются:

```text
CPU
RAM
SSD
USB-контроллеры
сетевой контроллер
таймеры
```

У микроконтроллера значительная часть этой периферии уже находится внутри одного кристалла.

Поэтому микроконтроллер можно представить как специализированный маленький компьютер.

---

## Но микроконтроллер отличается от ПК

У обычного компьютера обычно есть:

```text
процессор
оперативная память
накопитель
операционная система
драйверы
графическая система
сеть
```

Микроконтроллер значительно проще.

Например:

```text
микроконтроллер
├── CPU
├── Flash
├── RAM
├── GPIO
├── таймеры
├── ADC
└── интерфейсы
```

Обычно он работает непосредственно с программой пользователя без полноценной операционной системы.

Например, программа может буквально выполнять:

```text
прочитать вход
    ↓
проверить условие
    ↓
включить выход
    ↓
подождать
    ↓
снова прочитать вход
```

И делать это тысячи или миллионы раз.

# Основные части микроконтроллера

Рассмотрим основные блоки.

## CPU

CPU — центральное вычислительное ядро.

Он выполняет инструкции программы:

```text
прочитать данные
     ↓
вычислить
     ↓
сравнить
     ↓
изменить данные
     ↓
управить периферией
```

Например программа может содержать:

```cpp
if (temperature > 50)
{
    fan = true;
}
```

CPU выполняет инструкции, которые реализуют эту логику.

---

## Flash

Flash — энергонезависимая память.

В ней обычно хранится программа микроконтроллера.

После отключения питания содержимое Flash сохраняется.

Упрощённо:

```text
компьютер
   ↓
компиляция
   ↓
прошивка
   ↓
Flash микроконтроллера
```

После включения питания микроконтроллер начинает выполнять код из Flash.

---

## RAM

RAM используется во время работы программы.

В ней могут находиться:

* переменные;
* временные данные;
* стек;
* буферы;
* состояния периферии.

После отключения питания содержимое обычной RAM теряется.

Упрощённо:

```text
Flash
  ↓
программа

RAM
  ↓
данные во время работы
```

---

## GPIO

GPIO — General Purpose Input/Output.

Это универсальные цифровые выводы микроконтроллера.

Они позволяют взаимодействовать с внешним миром.

GPIO может работать как:

```text
INPUT
```

или:

```text
OUTPUT
```

Например:

```text
кнопка → GPIO INPUT
```

и:

```text
GPIO OUTPUT → LED
```

Получается:

```text
внешний мир
    ↓
   GPIO
    ↓
программа
    ↓
   GPIO
    ↓
внешний мир
```

Это один из самых важных механизмов микроконтроллера.

---

# Аналоговый вход

Микроконтроллер может иметь ADC — Analog-to-Digital Converter.

Он преобразует аналоговое напряжение в цифровое значение.

Например датчик выдаёт:

```text
0 ... 3.3 V
```

ADC может преобразовать его в число.

Например:

```text
0 V   → 0
1 V   → 1240
2 V   → 2480
3.3 V → 4095
```

Конкретные числа зависят от разрядности ADC и опорного напряжения.

Получается:

```text
датчик
  ↓
аналоговое напряжение
  ↓
ADC
  ↓
число
  ↓
программа
```

Подробнее ADC будет рассмотрен в отдельном уроке.

---

# Таймеры

Микроконтроллеры имеют аппаратные таймеры.

Они позволяют:

* отсчитывать время;
* создавать периодические события;
* измерять длительность сигналов;
* генерировать PWM;
* считать импульсы.

Например:

```text
таймер
  ↓
каждые 1 мс
  ↓
событие
```

Без аппаратных таймеров многие задачи пришлось бы реализовывать программными задержками, что сильно ограничивало бы возможности системы.

---

# Интерфейсы связи

Микроконтроллеру часто необходимо обмениваться данными с другими устройствами.

Для этого внутри него могут находиться аппаратные интерфейсы:

```text
UART
I²C
SPI
CAN
USB
Ethernet
```

Например:

```text
MCU
 │
 ├── UART → компьютер
 │
 ├── I²C → датчик
 │
 ├── SPI → дисплей
 │
 └── CAN → другой контроллер
```

Каждый интерфейс предназначен для определённых задач.

---

# Как микроконтроллер взаимодействует с миром

Удобно представить микроконтроллер как посредника.

С одной стороны находится физический мир:

```text
температура
давление
кнопки
двигатели
клапаны
светодиоды
датчики
```

С другой — программа.

Между ними находится периферия микроконтроллера:

```text
        ФИЗИЧЕСКИЙ МИР
               │
        ┌──────┴──────┐
        │             │
      входы         выходы
        │             │
        ▼             ▲
      GPIO           GPIO
        │             │
        └──────┬──────┘
               │
          МИКРОКОНТРОЛЛЕР
               │
              CPU
               │
            программа
```

Именно поэтому микроконтроллеры так важны для робототехники и автоматизации.

# Пример: автоматическое включение вентилятора

Представим систему:

```text
датчик температуры
        ↓
    микроконтроллер
        ↓
      MOSFET
        ↓
      вентилятор
```

Программа может работать так:

```text
прочитать температуру
        ↓
температура > 40 °C?
      /       \
    нет        да
     ↓          ↓
  выключить   включить
  вентилятор  вентилятор
```

Микроконтроллер здесь не является источником энергии для вентилятора.

Он только принимает решение и управляет силовой частью.

# Микроконтроллер и электроника

Из предыдущего раздела мы уже знаем основные электронные компоненты.

Теперь можно объединить их.

Например:

```text
MCU
 │
 ├── GPIO ──→ резистор ──→ LED
 │
 ├── GPIO ──→ MOSFET ──→ мотор
 │
 ├── ADC  ←── датчик
 │
 └── I²C  ←→ дисплей
```

Получается полноценное электронное устройство.

# Микроконтроллер и PLC

Микроконтроллер и PLC решают похожую задачу:

```text
получить сигналы
     ↓
обработать
     ↓
управить выходами
```

Но это разные классы систем.

PLC специально разработан для промышленной автоматизации.

Он обычно имеет:

* промышленное исполнение;
* специальные модули ввода-вывода;
* диагностику;
* промышленную связь;
* средства программирования;
* защиту и требования по надёжности.

Микроконтроллер — это более базовый вычислительный компонент.

На его основе можно создать собственное устройство управления.

Например:

```text
микроконтроллер
      ↓
собственная плата
      ↓
собственное устройство
```

# Популярные микроконтроллеры

Существует огромное количество семейств.

Например:

* STM32;
* AVR;
* PIC;
* ESP32;
* RP2040;
* различные ARM Cortex-M;
* микроконтроллеры от Texas Instruments, NXP, Renesas и других производителей.

Arduino — это не конкретный тип микроконтроллера.

Arduino — это экосистема плат, библиотек и инструментов разработки.

Например плата Arduino может использовать микроконтроллер AVR или другой MCU.

Поэтому полезно различать:

```text
микроконтроллер
```

и:

```text
плата / платформа разработки
```

# Что происходит после включения

После подачи питания микроконтроллер проходит начальную последовательность запуска.

Упрощённо:

```text
подача питания
      ↓
reset
      ↓
startup-код
      ↓
инициализация
      ↓
main()
      ↓
основной цикл
```

Например:

```cpp
int main()
{
    init_hardware();

    while (true)
    {
        read_inputs();
        process();
        update_outputs();
    }
}
```

В реальном MCU запуск сложнее, но такая модель хорошо показывает общую идею.

# Микроконтроллер как часть робота

В роботе микроконтроллер может отвечать за:

```text
датчики
   ↓
микроконтроллер
   ↓
драйверы моторов
   ↓
двигатели
```

Например:

```text
энкодер ───────┐
               │
датчик ────────┤
               ▼
          микроконтроллер
               │
          ┌────┴────┐
          ↓         ↓
       мотор 1    мотор 2
```

Он может одновременно:

* читать энкодеры;
* измерять датчики;
* рассчитывать управление;
* формировать PWM;
* обмениваться данными;
* следить за ошибками.

# Главное

Микроконтроллер — это специализированная вычислительная система, предназначенная для управления электронным устройством.

Его можно представить так:

```text
┌─────────────────────────────┐
│       МИКРОКОНТРОЛЛЕР       │
│                             │
│  CPU                        │
│  Flash                      │
│  RAM                        │
│                             │
│  GPIO                       │
│  ADC                        │
│  Timers                     │
│  PWM                        │
│  UART / SPI / I²C / CAN     │
└─────────────────────────────┘
       │       │       │
       ▼       ▼       ▼
    датчики  дисплей  моторы
```

Именно эта комбинация делает микроконтроллер удобным для создания реальных электронных устройств.
