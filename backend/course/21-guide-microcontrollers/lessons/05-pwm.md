# PWM: управление мощностью

## Цель

Микроконтроллер часто должен управлять не только состоянием «включено/выключено», но и мощностью нагрузки. Например, регулировать яркость светодиода или скорость двигателя.

Один из главных способов сделать это — PWM.

После урока вы должны понимать:

* что такое PWM;
* что такое частота;
* что такое период;
* что такое duty cycle;
* как PWM управляет светодиодом;
* как PWM используется для двигателей;
* почему PWM не является настоящим аналоговым напряжением;
* как PWM связан с MOSFET;
* почему частота PWM имеет значение;
* где PWM применяется в автоматике и робототехнике.

---

# Что такое PWM

PWM — Pulse Width Modulation, широтно-импульсная модуляция.

Вместо постоянного изменения напряжения мы очень быстро переключаем выход:

```text
HIGH → LOW → HIGH → LOW → ...
```

Например:

```text
████____████____████____
```

Где:

```text
████ = HIGH
____ = LOW
```

Изменяя соотношение времени HIGH и LOW, можно управлять средней мощностью.

---

# Duty cycle

Главный параметр PWM — duty cycle.

Он показывает, какую долю периода сигнал находится в состоянии HIGH.

Например:

```text
100 %
████████████████
```

```text
50 %
████████________
```

```text
25 %
████____________
```

```text
10 %
██______________
```

Формально:

```text
Duty Cycle = Ton / T × 100%
```

где:

* `Ton` — время HIGH;
* `T` — полный период.

---

# Период и частота

PWM имеет период:

```text
T
```

и частоту:

```text
f
```

Связь:

```text
f = 1 / T
```

Например при:

```text
f = 1000 Hz
```

период:

```text
T = 1 / 1000
T = 0.001 s
T = 1 ms
```

Каждый период длится 1 миллисекунду.

---

# Пример 50 %

Пусть:

```text
f = 1 kHz
T = 1 ms
```

При duty cycle 50%:

```text
HIGH = 0.5 ms
LOW  = 0.5 ms
```

Графически:

```text
████████________
```

Сигнал постоянно переключается, но со стороны нагрузки мы можем наблюдать эффект, зависящий от её физических свойств.

---

# PWM и светодиод

Представим LED.

Если:

```text
100 %
```

он светится максимально ярко.

При:

```text
50 %
```

средняя подводимая мощность меньше.

```text
100% → ████████████████
 50% → ████████________
 10% → ██______________
```

Для человеческого глаза свет может восприниматься как изменение яркости.

Схема:

```text
GPIO PWM
   │
  [R]
   │
  LED
   │
  GND
```

---

# PWM и MOSFET

Для мощной нагрузки микроконтроллер не должен пропускать силовой ток непосредственно через GPIO.

Используют MOSFET:

```text
MCU
 │
 │ PWM
 ▼
Gate
MOSFET
 │
 ▼
нагрузка
```

Например:

```text
+12 V
  │
LED strip
  │
MOSFET
  │
GND

MCU ───── Gate
```

Микроконтроллер быстро открывает и закрывает MOSFET.

В результате средняя мощность нагрузки регулируется PWM.

---

# PWM и DC-мотор

PWM широко используется для управления двигателями постоянного тока.

Например:

```text
MCU
 ↓
PWM
 ↓
MOSFET / driver
 ↓
DC motor
```

Условно:

```text
20 % → небольшая средняя мощность
50 % → средняя
80 % → высокая
```

Но это не означает:

```text
50 % PWM = ровно 50 % скорости
```

Скорость зависит от:

* нагрузки;
* характеристик двигателя;
* напряжения;
* трения;
* момента;
* драйвера.

---

# Почему двигатель не просто останавливается между импульсами

Двигатель обладает механической инерцией.

Он не может мгновенно остановиться при каждом переходе:

```text
HIGH → LOW
```

Поэтому двигатель воспринимает PWM как изменение средней энергии, поступающей в систему.

Условно:

```text
PWM
 ↓
электрическая энергия
 ↓
двигатель
 ↓
механическая инерция
```

Именно поэтому PWM так хорошо подходит для управления двигателями.

---

# PWM — это не аналоговое напряжение

Это важный момент.

Если MCU выдаёт:

```text
3.3 V PWM, duty = 50%
```

на выводе не появляется постоянное:

```text
1.65 V
```

Там всё ещё:

```text
3.3 V
```

и:

```text
0 V
```

которые быстро чередуются.

Если нужен настоящий аналоговый сигнал, используется:

* DAC;
* фильтр;
* другой преобразователь.

---

# Среднее значение

Если PWM идеально переключается между 0 и 3.3 В, его среднее значение при 50% составляет приблизительно:

```text
1.65 V
```

Но это математическое среднее.

Физическая нагрузка может реагировать на него иначе.

Например светодиод, двигатель и нагреватель по-разному воспринимают PWM.

---

# PWM и нагреватель

Нагреватель хорошо подходит для PWM.

Например:

```text
PWM
 ↓
MOSFET
 ↓
нагреватель
```

Из-за тепловой инерции нагреватель не успевает мгновенно остывать между импульсами.

Поэтому изменение duty cycle позволяет регулировать среднюю мощность.

---

# Частота PWM

Частоту нужно выбирать в зависимости от нагрузки.

Слишком низкая частота может привести к:

* видимому мерцанию LED;
* слышимому звуку двигателя;
* рывкам;
* плохому управлению.

Слишком высокая частота может увеличить:

* потери на переключение;
* нагрев транзистора;
* требования к драйверу.

Поэтому нет одной универсальной частоты для всех задач.

---

# Аппаратный PWM

Микроконтроллер может генерировать PWM аппаратно.

То есть CPU не обязан вручную выполнять:

```text
HIGH
ждать
LOW
ждать
HIGH
...
```

Аппаратный таймер делает это самостоятельно.

Упрощённо:

```text
CPU
 │
настройка таймера
 │
 ▼
Timer
 │
 ▼
PWM output
```

Это гораздо эффективнее.

---

# Связь PWM с таймерами

PWM обычно генерируется аппаратным таймером.

Таймер считает:

```text
0
1
2
3
...
```

и сравнивает значение с заданным порогом.

Упрощённо:

```text
counter < compare
    ↓
HIGH

counter >= compare
    ↓
LOW
```

Изменяя `compare`, можно менять duty cycle.

---

# PWM и сервоприводы

Некоторые сервоприводы используют импульсный управляющий сигнал.

Например положение может задаваться шириной импульса.

Это похоже на PWM, но важно понимать, что классический сигнал сервопривода не всегда следует воспринимать как обычный PWM управления мощностью.

Например:

```text
период
┌──────────────────────┐
│                      │
████                   │
```

Ширина импульса может определять положение.

Это отличается от регулирования мощности светодиода или двигателя.

---

# PWM в автоматике

PWM используется для:

* двигателей;
* вентиляторов;
* клапанов;
* нагревателей;
* светодиодов;
* насосов;
* сервоприводов;
* силовых преобразователей.

Например:

```text
PLC / MCU
    ↓
PWM
    ↓
драйвер
    ↓
MOSFET
    ↓
нагрузка
```

---

# Пример управления вентилятором

Пусть вентилятор работает от 12 В.

Нельзя просто подключить его к GPIO.

Используем:

```text
12 V
 │
вентилятор
 │
MOSFET
 │
GND

MCU
 │
PWM
 └──── Gate
```

Программа может устанавливать:

```text
30 %
50 %
80 %
100 %
```

и изменять среднюю мощность вентилятора.

---

# PWM и частотный преобразователь

В промышленной автоматике PWM может использоваться внутри силовой электроники.

Например частотный преобразователь управляет двигателем через быстрое переключение силовых ключей.

Упрощённо:

```text
PLC
 ↓
ПЧ
 ↓
силовые ключи
 ↓
PWM
 ↓
двигатель
```

Внутренняя схема ПЧ намного сложнее обычного PWM GPIO, но общий принцип быстрого управления силовыми ключами остаётся важным.

---

# Главное

PWM — это быстрое переключение сигнала:

```text
HIGH ↔ LOW
```

Главный параметр:

```text
duty cycle
```

Он определяет долю периода, в течение которой сигнал находится в HIGH.

Типичная схема управления мощностью:

```text
MCU
 ↓
PWM
 ↓
MOSFET / драйвер
 ↓
нагрузка
```

PWM особенно полезен для:

* регулирования мощности;
* управления двигателями;
* яркостью;
* нагревом;
* силовой электроникой.

---

## Практика

1. Нарисуйте PWM с duty cycle 25%.
2. Нарисуйте PWM с duty cycle 75%.
3. Рассчитайте период сигнала 1 kHz.
4. Рассчитайте время HIGH при duty cycle 30% и частоте 1 kHz.
5. Объясните, почему PWM 50% не означает постоянное напряжение 1.65 В на GPIO 3.3 В.
6. Подключите LED через MOSFET и управляйте его яркостью PWM.
7. Подключите DC-мотор через драйвер и изменяйте duty cycle.
8. Исследуйте, как изменение частоты PWM влияет на двигатель.
9. Объясните разницу между PWM управления мощностью и управляющим сигналом сервопривода.
10. Нарисуйте цепочку `MCU → PWM → MOSFET → нагрузка`.
