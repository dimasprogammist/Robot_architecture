# GPIO: цифровые входы и выходы

## Цель

GPIO — один из самых первых механизмов, с которым сталкиваются при работе с микроконтроллером. Через GPIO контроллер получает простые цифровые сигналы и управляет внешними устройствами.

После урока вы должны понимать:

* что такое GPIO;
* чем вход отличается от выхода;
* что такое HIGH и LOW;
* почему вход нельзя оставлять плавающим;
* что такое pull-up и pull-down;
* как подключить кнопку;
* как управлять светодиодом;
* что такое debounce;
* почему нельзя превышать допустимый ток GPIO;
* как GPIO связывает программу с реальной электроникой.

---

# Что такое GPIO

GPIO — General Purpose Input/Output.

Это универсальный цифровой вывод микроконтроллера.

Он может использоваться как:

```text
INPUT
```

или:

```text
OUTPUT
```

Например:

```text
кнопка
  ↓
GPIO INPUT
```

и:

```text
GPIO OUTPUT
  ↓
LED
```

---

# Цифровой сигнал

GPIO работает с дискретными логическими уровнями.

Упрощённо:

```text
LOW  → 0
HIGH → 1
```

Но физическое напряжение зависит от конкретного микроконтроллера.

Например MCU с логикой 3,3 В может использовать:

```text
LOW ≈ 0 V
HIGH ≈ 3.3 V
```

Но нельзя считать, что любой сигнал ниже 3,3 В автоматически является LOW, а любой сигнал выше нуля — HIGH.

В документации MCU указаны допустимые диапазоны логических уровней.

---

# GPIO как выход

В режиме OUTPUT микроконтроллер управляет напряжением на выводе.

Упрощённо:

```text
MCU
 │
 GPIO
 │
 ├── LOW
 └── HIGH
```

Например:

```text
GPIO = LOW
```

или:

```text
GPIO = HIGH
```

Можно подключить светодиод через резистор.

```text
GPIO
 │
[R]
 │
LED
 │
GND
```

Когда GPIO устанавливается в HIGH:

```text
GPIO → ток → LED
```

светодиод загорается.

---

# Почему нужен резистор

Светодиод нельзя бездумно подключать непосредственно к GPIO.

Нужен резистор, ограничивающий ток:

```text
GPIO
 │
[R]
 │
LED
 │
GND
```

Например:

```text
VGPIO = 3.3 V
VLED = 2.0 V
I = 0.005 A
```

Тогда приблизительно:

```text
R = (3.3 - 2.0) / 0.005
R = 260 Ω
```

Можно выбрать ближайшее стандартное значение, например 270 Ω, а затем проверить реальный ток.

---

# GPIO как вход

В режиме INPUT микроконтроллер считывает состояние внешнего сигнала.

Например:

```text
кнопка
  │
  ▼
GPIO INPUT
```

Программа может получить:

```text
0
```

или:

```text
1
```

Например:

```cpp
if (button_pressed)
{
    led_on();
}
```

---

# Проблема плавающего входа

Представим:

```text
GPIO INPUT
```

но к нему ничего не подключено.

Можно подумать:

```text
ничего → значит 0
```

Но это неверно.

Вход может находиться в неопределённом состоянии.

Такой вход называют floating input.

На нём могут возникать случайные изменения:

```text
1
0
1
1
0
1
```

даже если мы ничего не делаем.

Причина — вход имеет очень высокое сопротивление и может реагировать на шум и наводки.

---

# Pull-up

Чтобы задать определённое состояние, используют подтягивающий резистор.

Например pull-up:

```text
+3.3 V
   │
  [R]
   │
   ├──── GPIO
   │
 кнопка
   │
  GND
```

Когда кнопка отпущена:

```text
GPIO = HIGH
```

Когда кнопка нажата:

```text
GPIO = LOW
```

Получается инвертированная логика:

```text
кнопка отпущена → 1
кнопка нажата   → 0
```

Это совершенно нормальная схема.

---

# Внутренний pull-up

Во многих микроконтроллерах есть встроенный pull-up.

Тогда внешний резистор может не понадобиться.

Упрощённо:

```text
GPIO
 │
внутренний pull-up
 │
+V
```

Программа включает этот режим.

Конкретный способ зависит от семейства микроконтроллера.

---

# Pull-down

Можно сделать наоборот:

```text
GPIO
 │
 кнопка
 │
+3.3 V
 │
```

и использовать резистор к земле:

```text
GPIO
 │
[R]
 │
GND
```

Тогда:

```text
кнопка отпущена → LOW
кнопка нажата   → HIGH
```

Это pull-down.

---

# Сравнение

### Pull-up

```text
отпущена → HIGH
нажата   → LOW
```

### Pull-down

```text
отпущена → LOW
нажата   → HIGH
```

Оба варианта являются нормальными.

---

# Кнопка

Простейшая схема:

```text
+3.3 V
  │
 [R]
  │
  ├──── GPIO
  │
 кнопка
  │
 GND
```

Программа может выполнять:

```text
прочитать GPIO
      ↓
кнопка нажата?
      ↓
включить LED
```

Получается:

```text
КНОПКА → GPIO → программа → GPIO → LED
```

Это одна из самых полезных первых лабораторных работ с MCU.

---

# Дребезг контактов

Механическая кнопка не переключается идеально один раз.

При нажатии контакты могут быстро замыкаться и размыкаться:

```text
идеально:

───────████████───────


реально:

───────█_█_██_█_████──
```

Это называется дребезгом контактов.

Микроконтроллер работает очень быстро и может увидеть несколько переключений вместо одного.

---

# Программный debounce

Один из простых вариантов:

```text
обнаружили нажатие
        ↓
подождали немного
        ↓
снова проверили
        ↓
если состояние сохранилось
        ↓
считаем кнопку нажатой
```

Например:

```cpp
if (button_changed())
{
    delay(20);

    if (button_is_still_pressed())
    {
        process_button();
    }
}
```

Это простой учебный вариант.

В реальных системах часто используют неблокирующие алгоритмы и таймеры.

---

# Ограничения GPIO

GPIO не является источником большой мощности.

Например нельзя рассуждать:

```text
GPIO = 3.3 V
значит можно подключить мотор 3.3 V
```

Это неверно.

GPIO имеет ограничения по:

* максимальному току;
* напряжению;
* суммарному току группы выводов;
* рассеиваемой мощности;
* режиму работы.

Нужно всегда смотреть документацию конкретного MCU.

---

# Управление мощной нагрузкой

Если нужно управлять двигателем:

```text
GPIO
  ↓
MOSFET / драйвер
  ↓
двигатель
```

Если нужно управлять реле:

```text
GPIO
  ↓
транзистор
  ↓
реле
```

Таким образом GPIO управляет не самой мощной нагрузкой, а электронным ключом.

---

# GPIO и 3.3 V / 5 V

Особенно важный момент — уровни логики.

Один микроконтроллер может работать с:

```text
3.3 V
```

а другое устройство:

```text
5 V
```

Нельзя автоматически соединять их GPIO.

Нужно проверить:

* допустимое входное напряжение;
* логические уровни;
* является ли вход 5 V tolerant;
* нужен ли level shifter.

Например:

```text
3.3 V MCU → 5 V device
```

может потребовать преобразователя уровней.

---

# GPIO в промышленной автоматике

В промышленности вместо простого GPIO используются специализированные входы и выходы.

Например:

```text
датчик 24 V
    ↓
входной модуль PLC
    ↓
программа
    ↓
выход PLC
    ↓
клапан
```

Но логическая идея остаётся похожей:

```text
вход
 ↓
обработка
 ↓
выход
```

Поэтому понимание GPIO помогает понять более сложные системы автоматизации.

---

# Пример: управление лампой

Нельзя делать:

```text
GPIO → 230 V лампа
```

Правильная архитектура:

```text
GPIO
 ↓
драйвер / реле
 ↓
силовая цепь
 ↓
лампа
```

Управляющая и силовая части должны соответствовать требованиям безопасности.

---

# Главное

GPIO — это интерфейс микроконтроллера с цифровым внешним миром.

Основные понятия:

```text
INPUT
OUTPUT
HIGH
LOW
PULL-UP
PULL-DOWN
```

Типичная схема:

```text
Кнопка
  ↓
GPIO INPUT
  ↓
программа
  ↓
GPIO OUTPUT
  ↓
LED
```

Для мощной нагрузки:

```text
GPIO
 ↓
драйвер
 ↓
нагрузка
```

## Практика

1. Подключите LED через резистор к GPIO.
2. Сделайте программу, которая мигает LED.
3. Подключите кнопку с pull-up.
4. Сделайте включение LED при нажатии кнопки.
5. Реализуйте программный debounce.
6. Нарисуйте схему с pull-down.
7. Объясните разницу между floating input и подтянутым входом.
8. Найдите в документации своего MCU максимальный допустимый ток GPIO.
9. Проверьте, допускает ли GPIO вашего MCU входное напряжение 5 V.
10. Нарисуйте схему `GPIO → MOSFET → двигатель`.
