# Транзакции

## Цель

Группировать изменения в транзакцию: commit и rollback.

## Что уже нужно знать

Индексы.

## Объяснение с нуля

Транзакция — единица работы: либо все изменения видны, либо ни одно. BEGIN → операции → COMMIT или ROLLBACK. Перевод денег: уменьшить один счёт, увеличить другой — только вместе.

Без транзакции обрыв сети посередине оставляет полусостояние.

## Термины

- **BEGIN/COMMIT/ROLLBACK**.
- **Автоcommit** — каждая команда сама по себе.

## Внутреннее устройство

Журнал СУБД позволяет откатить или доиграть. Изоляцию разберём в ACID.

## Пример

Списание и зачисление: два UPDATE в одной транзакции.

## Разбор

Если второй UPDATE падает — ROLLBACK вернёт оба счёта.

## Код

```python
conn.execute("BEGIN")
try:
    conn.execute("UPDATE accounts SET bal = bal - 100 WHERE id = 1")
    conn.execute("UPDATE accounts SET bal = bal + 100 WHERE id = 2")
    conn.commit()
except Exception:
    conn.rollback()
    raise
```

## Практика

Где в трекере задач нужна транзакция из нескольких операторов?

## Типичные ошибки

- Commit после каждого микрошага критичной бизнес-операции.
- Долгие транзакции с ожиданием пользователя.
