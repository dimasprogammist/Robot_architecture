# Подзапросы

## Цель

Вкладывать SELECT в WHERE/FROM и понимать результат.

## Что уже нужно знать

GROUP BY.

## Объяснение с нуля

Подзапрос — запрос внутри запроса. В WHERE ... IN (SELECT ...). В FROM как производная таблица. Иногда заменяется JOIN; читаемость и план зависят от случая.

Коррелированный подзапрос ссылается на внешнюю строку и выполняется логически «для каждой».

## Термины

- **Скалярный подзапрос**.
- **Коррелированный подзапрос**.

## Внутреннее устройство

Оптимизатор может переписать подзапрос в join.

## Пример

Задачи пользователей с именем Ann: user_id IN (SELECT id FROM users WHERE name='Ann').

## Разбор

Сначала внутренний SELECT даёт id, затем внешний фильтрует tasks.

## Код

```sql
SELECT title FROM tasks
WHERE user_id IN (SELECT id FROM users WHERE name = 'Ann');
```

## Практика

Перепишите тот же запрос через JOIN.

## Типичные ошибки

- Подзапрос, возвращающий несколько строк, там где ждут скаляр.
- Копировать коррелированные подзапросы без нужды на больших данных.

## Что запомнить

Подзапрос — вложенный SELECT с понятным множеством результата.
