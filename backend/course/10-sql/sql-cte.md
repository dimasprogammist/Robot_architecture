# CTE

## Цель

Писать WITH ... AS для читаемых многошаговых запросов.

## Что уже нужно знать

Подзапросы.

## Объяснение с нуля

CTE (common table expression) именовает промежуточный результат. Удобно для многошаговой логики и рекурсии (иерархии). Это не магия производительности сама по себе — иногда материализуется, иногда нет.

## Термины

- **WITH clause**.
- **Рекурсивный CTE** (кратко).

## Внутреннее устройство

Запрос читается сверху вниз: сначала CTE, потом финальный SELECT.

## Пример

CTE open_tasks → затем агрегация по user_id.

## Разбор

Сначала отфильтровали done=0, затем посчитали.

## Код

```sql
WITH open_tasks AS (
  SELECT user_id, id FROM tasks WHERE done = FALSE
)
SELECT user_id, COUNT(*) FROM open_tasks GROUP BY user_id;
```

## Практика

Разбейте сложный отчёт на 2–3 CTE словами.

## Типичные ошибки

- CTE ради CTE на одном простом SELECT.
- Путать CTE с временной таблицей без нужды.

## Что запомнить

CTE улучшает структуру запроса.
