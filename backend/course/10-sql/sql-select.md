# SELECT

## Цель

Писать SELECT с WHERE, ORDER BY, LIMIT и понимать результат.

## Что уже нужно знать

ACID на уровне идей.

## Объяснение с нуля

SELECT проецирует столбцы и фильтрует строки. ORDER BY задаёт порядок. LIMIT ограничивает выдачу. Без LIMIT на огромной таблице можно убить API.

Всегда думайте: сколько строк вернётся и зачем каждый столбец.

## Термины

- **WHERE**, **ORDER BY**, **LIMIT/OFFSET**.
- **Алиас** таблицы/столбца.

## Внутреннее устройство

Планировщик может использовать индекс по WHERE/ORDER.

## Пример

Данные: (1,'A',0), (2,'B',1), (3,'C',0), (4,'D',0). Запрос done=0 ORDER BY id LIMIT 2 → id 1 и 3.

## Разбор

Почему не 4: LIMIT 2 обрезал.

## Код

```sql
SELECT id, title FROM tasks
WHERE done = 0
ORDER BY id
LIMIT 2;
```

## Практика

Добавьте OFFSET 2 и предскажите строки.

## Типичные ошибки

- SELECT * в горячем API.
- ORDER BY без индекса на больших данных без нужды.

## Что запомнить

SELECT = проекция + фильтр + порядок + лимит.
