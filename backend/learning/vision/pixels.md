# Пиксели

Пиксель — один элемент таблицы. У него есть координаты: столбец и строка. В большинстве библиотек столбец `x` растёт вправо, строка `y` — вниз. Верхний левый угол — `(0, 0)`, не `(1, 1)`.

Значение обычно целое от 0 до 255. 0 — нет сигнала этого канала, 255 — максимум. Это не «процент яркости лампы в комнате», а число в файле.

Соседние пиксели независимы, пока программа сама не начнёт их сравнивать. Край объекта — место, где соседние числа резко отличаются.
