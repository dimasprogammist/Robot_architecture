# Выделение объектов

Простой способ отделить объект от фона — **порог**. Всё светлее порога становится белым, остальное чёрным. Получается маска: таблица из двух значений.

```python
_, mask = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
```

Порог 127 — пример, не закон. Его подбирают по картинке. Если освещение пляшет, один порог перестаёт работать. Тогда сравнивают не с постоянным числом, а с цветом в HSV или с фоном, снятым заранее.

Маска ещё не имя объекта. Это только «здесь пиксель нам интересен».
