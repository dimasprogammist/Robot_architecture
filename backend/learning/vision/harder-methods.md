# Куда идти дальше

Когда цвет и контур уже понятны, появляются следующие инструменты. Их не нужно включать все сразу.

- **Шаблон** (`matchTemplate`) ищет заранее вырезанный кусок картинки. Ломается при другом масштабе и повороте.
- **Особые точки** сравнивают кадр с образцом, если объект немного повернулся.
- **Геометрия камеры** переводит пиксель в направление луча. Без размеров камеры «пиксель» не становится сантиметром на столе.
- **Детектор из примеров** говорит «здесь объект такого класса», если его обучили. Ему нужен набор картинок с правильными ответами.

Каждый следующий метод добавляет условия. Если простой порог решает задачу при стабильном свете, более сложный метод не делает ответ автоматически вернее.
