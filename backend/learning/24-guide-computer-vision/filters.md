# Фильтры

**Фильтр** заменяет пиксель на результат по его соседям.

Размытие усредняет соседей. Шум (случайные яркие точки) слабеет, границы тоже становятся мягче.

```python
blurred = cv2.GaussianBlur(gray, (5, 5), 0)
```

`(5, 5)` — размер окрестности. Число должно быть нечётным. Больше окно — сильнее размытие и больше работы.

Фильтр не «понимает объект». Он только меняет числа. После размытия порог или поиск границы работает устойчивее, потому что одиночный шум уже не выглядит как край.
