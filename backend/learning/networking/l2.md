# Ethernet, PHY, разъёмы

Вибрация + дешёвые RJ45 = плавающие лидары. Промышленные M12.

## Зачем это в робототехнической системе

Камера на манипуляторе — кабель как механический элемент (BOM).

## Синтаксис и контракт

```text
ethtool eth0
```

## Типичные ошибки

- питание камеры только PoE без расчёта бюджета
- U/UTP вдоль силового мотора без меры
