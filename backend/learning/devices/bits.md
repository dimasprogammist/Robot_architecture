# Биты, байты и текст

**Бит** — один выбор: 0 или 1. **Байт** — 8 бит, число от 0 до 255.

Буква на экране — договорённость: какому числу какая буква соответствует. Такая договорённость называется **кодировкой**. Самая частая для русского и английского текста в современных файлах — UTF-8.

Если открыть текстовый файл «не той» кодировкой, буквы превратятся в кракозябры. Файл не сломался: программа неправильно прочитала числа.

## Пример

Английская буква `A` в кодировке, которую унаследовал UTF-8, — это число 65. Для компьютера нет отдельной «буквы», есть число и правило, как его показать.
