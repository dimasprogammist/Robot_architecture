# Зачем нужна операционная система

**Операционная система (ОС)** — программа, которая уже запущена, когда вы включаете компьютер. Она раздаёт память, запускает другие программы и не даёт одной программе напрямую сломать диск другой.

Windows и Linux — две разные ОС. Программа, написанная «для Linux», не обязана запуститься в Windows без дополнительной работы.

Микроконтроллер (плата вроде Arduino) часто работает **без** полноценной ОС: ваша программа — единственная, она сама читает пины. Компьютер вроде Raspberry Pi — уже с Linux.

## Пример

Когда Python открывает файл, он просит об этом ОС. ОС проверяет, есть ли файл и можно ли вам его читать, и только потом отдаёт байты.
