# Диск, файлы и папки

**Файл** — именованный кусок данных на накопителе: текст, фото, программа.

**Папка (каталог)** — контейнер для файлов и других папок. Путь — адрес файла, например `C:/robots/map.json` или `/home/robot/map.json`.

Диск помнит данные без питания. Поэтому калибровку камеры и карту помещения сохраняют в файл, а не только в переменную.

## Пример

Фото с камеры — файл из байтов. Текст заметки — тоже файл из байтов, только байты означают буквы. Программа решает, как эти байты читать.
