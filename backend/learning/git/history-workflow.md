# История и ежедневный порядок

Каждый коммит хранит ссылку на предыдущий. Поэтому история — цепочка, а не папка с версиями «финал», «финал2».

```bash
git log --oneline
```

Покажет короткие имена коммитов и сообщения. Имя коммита — длинное число в шестнадцатеричной записи. Его можно не запоминать: обычно смотрят последние строки.

Рабочий цикл, когда репозиторий уже есть:

```bash
git pull
# правите файлы
git status
git add .
git commit -m "Коротко зачем"
git push
```

`git add .` добавляет изменения в текущей папке. Не добавляйте пароли и огромные случайные файлы: после коммита они останутся в истории, даже если потом удалить их из папки.
