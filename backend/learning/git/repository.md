# Репозиторий и рабочая директория

**Рабочая директория** — то, что вы видите в проводнике: `main.py`, `README.md`.

**Репозиторий** появляется, когда в этой папке выполняют:

```bash
git init
```

Появляется `.git`. Туда Git записывает историю. Сами файлы проекта вы по-прежнему редактируете как обычно. Пока вы не сделали `git add` и `git commit`, правка есть только в рабочей директории и в историю не попала.

Проверка:

```bash
git status
```

Git напишет, какие файлы изменены и какие ещё не добавлены в следующий коммит.
