# Ветки и merge

**Ветка** — указатель на цепочку коммитов. Ветка `main` — обычное имя основной линии, не специальная магия.

Новая ветка нужна, чтобы пробовать изменение, не ломая то, что уже работает:

```bash
git switch -c experiment
```

Коммиты в `experiment` не меняют `main`, пока вы сами не сольёте их.

**Merge** — взять коммиты другой ветки и влить в текущую:

```bash
git switch main
git merge experiment
```

Если одни и те же строки меняли в обеих ветках, Git остановится и попросит выбрать итог. Это называется конфликт. Его решают в файле, затем снова `git add` и `git commit`.
