# Функция потерь

**Loss** — одно число: насколько ответ сети не совпал с правильным.

Для числа «предскажи температуру» часто берут квадрат разницы:

```text
loss = (предсказание - правильное) ** 2
```

Чем больше loss, тем хуже этот пример прошёл. Обучение двигает веса так, чтобы loss в среднем уменьшался.

Ноль на учебных примерах не означает, что задача решена в жизни. Сеть могла запомнить примеры, а не правило.
