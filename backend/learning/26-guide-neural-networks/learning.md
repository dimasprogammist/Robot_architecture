# Что такое обучение

Есть набор примеров. У каждого примера есть вход и правильный ответ.

Один шаг:

1. Посчитать выход сети на входе.
2. Сравнить его с правильным ответом.
3. Немного изменить веса, чтобы в следующий раз ошибка на этом примере стала меньше.

Так повторяют много раз по всему набору. Один полный проход по всем учебным примерам называют **эпохой**.

Сеть не гарантирует верный ответ на новом примере. Она уменьшает ошибку на тех примерах, которые вы ей показали.
