# Функция активации

Если нейрон только складывает входы с весами, много слоёв подряд можно свернуть в одно сложение. Сеть не станет «сложнее».

**Функция активации** ставится после суммы и добавляет изгиб. Простой пример — ReLU: если сумма отрицательная, выход 0, иначе выход равен сумме.

```text
ReLU(x) = 0, если x < 0, иначе x
```

Сигмоида сжимает любое число в диапазон от 0 до 1. Её часто ставят на последнем нейроне, когда ответ читают как «вероятность от 0 до 1».

Активацию выбирают до обучения и обычно не меняют на каждом примере.
