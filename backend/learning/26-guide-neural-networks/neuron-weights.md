# Нейрон и веса

Один **нейрон** в этой модели делает так:

```text
сумма = вес1 * вход1 + вес2 * вход2 + смещение
выход = активация(сумма)
```

**Вес** показывает, насколько сильно этот вход влияет на сумму. Отрицательный вес уменьшает сумму, когда вход большой.

**Смещение** (bias) — ещё одно число, которое прибавляют всегда. Оно сдвигает сумму, даже если все входы нули.

Набор весов — это и есть «память» сети после обучения. Программа хранит их как массив чисел, обычно в файле, чтобы не учить заново при каждом запуске.
