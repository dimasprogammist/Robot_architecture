# Открытие файла

Файл на диске и переменная в программе — разные вещи. **Открыть файл** значит попросить систему дать программе доступ к этим байтам.

```python
f = open("notes.txt", "r", encoding="utf-8")
text = f.read()
f.close()
```

Первый аргумент — путь. `"r"` — режим чтения. `encoding="utf-8"` — как превращать байты в текст.

Режимы, которые нужны вначале:

- `"r"` — читать, файл уже должен существовать;
- `"w"` — записать с нуля, старое содержимое стирается;
- `"a"` — дописать в конец.

Если файла нет, `"r"` завершится ошибкой `FileNotFoundError`. Это нормальный сигнал: путь неверный или файл ещё не создан.
