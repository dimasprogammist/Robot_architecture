# Добавление данных в конец

Журнал событий нельзя каждый раз переписывать с нуля: пропадут старые строки. Режим `"a"` (append) ставит курсор в конец.

```python
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("робот запущен\n")
```

Повторный запуск допишет ещё одну строку под предыдущей.

Если нужен ровно один актуальный файл настроек, а не журнал, используют `"w"`, а не `"a"`.
