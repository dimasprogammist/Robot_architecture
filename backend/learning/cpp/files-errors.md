# Ошибки при работе с файлами

Поток не бросает исключение сам по себе, если файл не открылся. Проверяйте состояние:

```cpp
std::ifstream in("notes.txt");
if (!in) {
    // нет файла, нет прав или неверный путь
}
```

Частые причины:

- путь относительный, а программа запущена из другой папки;
- режим записи без `app` стёр данные, которые вы хотели сохранить;
- текстовый режим открыл двоичный файл и испортил байты при копировании;
- после `fail` поток перестаёт читать, пока ошибку не снимут методом `clear()`.

Пустой файл — не ошибка открытия. Ошибка — это когда открыть не удалось или чтение оборвалось не в конце файла.
