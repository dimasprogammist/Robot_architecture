# Создание проекта

Имя, шаблон (Пустой, Веб, Робот, IoT, Промка). Сразу появляются компоненты, протоколы, связи.

## Зачем это в робототехнической системе

Для робота берите шаблон Робот и наращивайте механику/БД.

## Синтаксис и контракт

```text
Главный экран → Создать проект
```

## Типичные ошибки

- пустой холст и забыть протоколы
- английский UI — интерфейс русский, имена протоколов технические
