# Клавиши и темы

Ctrl+S сохранение, Ctrl+Z/Y история, Ctrl+K поиск, Delete, светлая/тёмная тема. Автосохранение.

## Зачем это в робототехнической системе

Цвета протоколов читаемы в обеих темах.

## Синтаксис и контракт

```text
Ctrl+K поиск сущностей
```

## Типичные ошибки

- набрать в поле и нажать Delete — удалит блок, если фокус не в input — наоборот, в input не удалит граф
