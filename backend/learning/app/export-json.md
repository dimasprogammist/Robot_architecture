# JSON-модель

Семантика компонентов, связей, таблиц, механики. Можно импортировать.

## Зачем это в робототехнической системе

Обмен между машинами, git рядом с кодом.

## Синтаксис и контракт

```text
Экспорт → Скачать JSON / Импорт
```

## Типичные ошибки

- править координаты вручную в JSON без нужды
- импорт как «merge» — сейчас новый проект-копия
