# Библиотека компонентов

Перетащите Python-бэкенд, MQTT, таблицу, механическую систему. Потом переименуйте под проект.

## Зачем это в робототехнической системе

На холсте БД библиотека фильтруется к таблицам.

## Синтаксис и контракт

```text
Двойной клик в библиотеке = добавить
```

## Типичные ошибки

- не искать — библиотека длинная, есть поиск
- забыть категорию MECHANICS

## В Architecture Canvas

Поиск в библиотеке. Режимы Механика/БД фильтруют.
