# Холст

Перетаскивание из библиотеки, зум, сетка, мини-карта. Двойной клик — вложенность.

## Зачем это в робототехнической системе

Раскладка не семантика: координаты не уходят в AI-экспорт по смыслу модели.

## Синтаксис и контракт

```text
DnD из библиотеки, Delete, Ctrl+Z
```

## Типичные ошибки

- считать холст Visio
- удалять блок и оставлять «висящие» ожидания в голове — связи удалятся, документы проверьте
