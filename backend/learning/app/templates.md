# Шаблоны

Сохраните проект как шаблон в Экспорте. Это JSON модели, не скрин.

## Зачем это в робототехнической системе

Команда роботов одного типа.

## Синтаксис и контракт

```text
Экспорт → Сохранить как шаблон
```

## Типичные ошибки

- шаблон без вложенных холстов, если они были нужны
- секреты в шаблоне

## В Architecture Canvas

Шаблоны на главной.
