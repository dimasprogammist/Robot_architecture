# Кодировки

Файл хранит байты. **Кодировка** — правило, какая последовательность байтов какая буква.

Для новых текстовых файлов указывайте UTF-8:

```python
open("notes.txt", encoding="utf-8")
```

Если правило не указать, Python возьмёт кодировку системы. На одном компьютере русский текст откроется, на другом — нет.

Ошибка `UnicodeDecodeError` значит: эти байты нельзя прочитать как выбранную кодировку. Файл не «битый» обязательно. Попробуйте ту кодировку, в которой его записали.
