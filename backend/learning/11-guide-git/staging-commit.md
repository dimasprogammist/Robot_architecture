# Staging area и commit

Сохранить файл в редакторе — записать его на диск. Коммит — отдельно сказать Git: «вот эти изменения войдут в историю».

Между диском и коммитом есть **staging area**. Туда попадает только то, что вы добавили:

```bash
git add main.py
git commit -m "Добавить чтение карты из файла"
```

Сообщение пишут так, чтобы через месяц было понятно, зачем снимок. «fix» почти ничего не объясняет.

Если изменить `main.py` после `git add`, но до `git commit`, в коммит попадёт старая добавленная версия, а новая правка останется не в индексе. Снова `git status`, снова `git add`, если новую правку тоже нужно сохранить в снимке.
