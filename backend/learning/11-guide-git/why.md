# Зачем нужен Git

Папка `проект_финал2` не говорит, чем она отличается от `проект_финал`. Git отвечает на три вопроса:

- что именно изменилось;
- когда;
- зачем (если вы написали сообщение коммита).

Это нужно, даже если вы работаете один. Второй человек — дополнительная причина: двое могут менять одни и те же файлы, и Git помогает соединить результат.

Git не заменяет резервную копию питания и не хранит огромные видео «просто так» удобно. Для обычного кода и текстовых настроек он как раз подходит.
