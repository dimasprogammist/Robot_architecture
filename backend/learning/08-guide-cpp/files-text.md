# Текстовые файлы

По умолчанию `ifstream` и `ofstream` открывают файл как текст. Вы пишете числа и строки, поток переводит их в символы.

```cpp
out << 10;
```

В файле окажутся символы `1` и `0`, а не внутреннее двоичное представление числа.

На Windows текстовый режим может заменить `\n` на пару символов конца строки. Для обычных заметок это ожидаемо. Для файла, где важен каждый байт, текстовый режим не используют.
