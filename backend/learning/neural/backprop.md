# Backpropagation

У сети много слоёв. Ошибка видна на выходе. **Backpropagation** (обратное распространение) — способ перенести эту ошибку назад, слой за слоем, и понять, какой вес за неё отвечает.

Считают локальную производную: «если этот вес чуть увеличить, loss вырастет или упадёт». Дальше оптимизатор делает шаг.

Вручную это длинная арифметика даже для двух нейронов. Библиотеки считают её сами. Понимать нужно направление: ошибка выхода влияет на предыдущие веса, а не только на последний слой.

Без дифференцируемой функции потерь и активаций эта схема в базовом виде не работает.
