# Dataset

**Dataset** — учебный набор: пары «вход, правильный ответ».

Если ответов нет, сеть в этой базовой схеме учить не на чем. Разметить данные значит вручную или другим надёжным способом записать правильный ответ для каждого примера.

Плохой набор ломает результат сильнее, чем «не та активация». Если все фото сделаны в одной комнате, сеть может запомнить комнату, а не объект.

Пример для самой первой сети может быть крошечным: десятки строк чисел в CSV, не миллионы фотографий.
