# Визуальный стандарт математических иллюстраций

## 1. Назначение

Все математические графики и схемы в учебнике должны выглядеть как единая часть интерфейса приложения, а не как изображения, взятые из разных источников.

Иллюстрации должны быть:

- минималистичными;
- техническими;
- учебными;
- математически точными;
- спокойными по цветам;
- легко читаемыми;
- визуально согласованными с дизайном приложения.

Не использовать декоративную инфографику, 3D, градиенты, тени, фотореалистичность или стили, характерные для сторонних математических сервисов.

---

## 2. Основной визуальный стиль

Главный принцип:

> Иллюстрация должна выглядеть так, будто она изначально была создана специально для приложения.

График не должен визуально конкурировать с текстом урока. Его задача — быстро и понятно объяснить одну математическую идею.

Предпочтительный стиль:

- плоская 2D-графика;
- чистые линии;
- спокойный фон;
- минимум элементов;
- достаточное свободное пространство;
- одинаковая толщина и характер линий;
- единая цветовая система во всех уроках.

---

## 3. Основная палитра

Использовать существующую палитру приложения как основу.

### Основные цвета интерфейса

```text
--bg:         #f4f2ec
--bg-accent:  #ece9e0
--surface:    #fcfbf8
--surface-2:  #f7f5ef
--ink:        #1c1b17
--muted:      #6e6b63
--faint:      #9a968c
Основной цвет математической графики
RGB: 47, 93, 80
HEX: #2F5D50
```
#2F5D50 является главным акцентным цветом математических иллюстраций.

Использовать его для:

функций;
основных графиков;
ключевых отрезков;
векторов;
важных точек;
выделенных областей;
основных геометрических объектов.

Не заменять этот цвет стандартным синим, красным или случайным акцентным цветом.

4. Цветовая иерархия

Цвет должен показывать важность элементов.

Основной объект
#2F5D50

Используется для главного математического объекта.

Оси

Использовать #6e6b63 или близкий приглушённый цвет.

Оси не должны визуально конкурировать с графиком.

Сетка

Использовать #9a968c с визуально низкой интенсивностью.

Сетка должна быть заметна только при необходимости.

Подписи

Основной текст:

#1c1b17

Второстепенные подписи:

#6e6b63
Вспомогательные элементы

Для вспомогательных линий допустимо использовать приглушённый вариант основного зелёного цвета или #9a968c.

5. Количество цветов

Не использовать большое количество цветов на одном графике.

Предпочтительно:

основной акцентный цвет;
один-два нейтральных цвета;
фон.

Обычно достаточно 2–4 цветов на всю иллюстрацию.

Разные цвета нельзя использовать просто ради красоты.

Каждый цвет должен иметь смысл.

6. Фон

Основной фон математических иллюстраций:

#F4F2EC

Допустим также:

#FCFBF8

если иллюстрация размещается внутри карточки или светлой поверхности.

Фон должен быть однотонным.

Не использовать:

градиенты;
текстуры;
фотографии;
декоративные узоры;
тени.
7. Координатные графики

Для графиков функций использовать единую систему оформления.

Оси
ось X — горизонтальная;
ось Y — вертикальная;
обе оси имеют стрелки;
начало координат располагается естественно относительно графика;
подписи X и Y оформляются одинаково во всех иллюстрациях.

Оси должны быть тоньше основной линии графика.

Сетка

Сетка:

тонкая;
ненавязчивая;
равномерная;
не должна перекрывать математический объект.

Не рисовать сетку плотнее, чем необходимо для понимания графика.

Деления

Показывать только полезные значения.

Не нужно автоматически подписывать каждую линию сетки.

Если конкретные значения не помогают понять идею, их можно не показывать.

8. Графики функций

График функции должен быть математически точным.

Например, для:

y = x²

парабола должна:

быть симметрична относительно оси Y;
иметь вершину в (0, 0);
иметь корректную форму;
пересекать координатную плоскость в правильных местах;
иметь одинаковый масштаб по соответствующим осям, если это важно для геометрической формы.

Не использовать генеративную графику как источник математической точности.

Если координаты, точки или форма функции имеют математическое значение, их необходимо строить программно или по точным координатам.

9. Точки

Ключевые точки выделять цветом:

#2F5D50

Точка должна быть достаточно крупной, чтобы быть заметной на экране, но не превращаться в большую декоративную окружность.

Если точка имеет координаты, подпись размещать рядом:

A
B
(2, 3)

Не размещать подпись поверх точки.

10. Линии

Основные линии должны иметь единый визуальный характер.

Для главных математических объектов использовать:

#2F5D50

Толщина должна быть заметно больше толщины сетки и осей.

Вспомогательные линии должны быть тоньше основной линии.

Не использовать множество разных толщин без необходимости.

11. Стрелки

Стрелки использовать только там, где они передают смысл:

направление оси;
направление вектора;
направление движения;
продолжение функции;
изменение величины.

Не использовать стрелки как декоративный элемент.

12. Геометрические схемы

Геометрические иллюстрации должны использовать тот же визуальный язык.

Например, для треугольника:

стороны — #2F5D50;
вспомогательные линии — приглушённые;
точки — #2F5D50;
вершины — короткие подписи;
углы — минимальные дуги или обозначения;
размеры — аккуратные подписи рядом с соответствующими сторонами.

Не перегружать рисунок пояснениями.

13. Формулы внутри иллюстраций

Формулу помещать внутрь изображения только тогда, когда она является частью визуального объяснения.

Если формула уже находится непосредственно в тексте урока, не нужно автоматически дублировать её на графике.

Если формула нужна внутри изображения:

использовать математическую типографику;
сохранять привычные математические обозначения;
не превращать формулу в декоративный текст;
обеспечивать достаточный размер для чтения.
14. Текст на графиках

Текст внутри изображения должен быть минимальным.

Предпочтительно использовать:

X;
Y;
A;
B;
O;
координаты;
обозначения величин.

Не помещать внутрь графика длинные объяснения.

Объяснение должно находиться в тексте урока.

15. Типографика

Шрифт подписей должен визуально соответствовать приложению.

Текст:

простой;
современный;
хорошо читаемый;
без декоративных шрифтов.

Не использовать:

Times New Roman для обычных подписей;
рукописные шрифты;
декоративные математические шрифты;
чрезмерно жирный текст.

Математические обозначения должны сохранять привычный математический вид.

16. Размер и формат

Предпочтительный формат:

SVG

SVG предпочтительнее PNG, поскольку:

линии остаются чёткими;
изображение не теряет качество при масштабировании;
можно использовать точные координаты;
файл хорошо подходит для веб-приложения.

Растровые изображения использовать только тогда, когда SVG объективно не подходит.

17. Базовые размеры SVG

Для обычных графиков использовать примерно:

viewBox: 0 0 800 450

Для квадратных геометрических схем:

viewBox: 0 0 600 600

Размер может отличаться, если этого требует конкретная композиция.

Важно не физическое разрешение файла, а единая визуальная система и корректный viewBox.

18. Безопасные поля

Вокруг содержимого должно оставаться свободное пространство.

Не располагать:

стрелки;
подписи;
точки;
линии

вплотную к краям изображения.

Особенно важно оставлять место для стрелок координатных осей и подписей.

19. Один график — одна идея

Главное правило композиции:

Одна иллюстрация должна объяснять одну математическую идею.

Не объединять без необходимости:

несколько независимых функций;
множество точек;
несколько формул;
несколько геометрических конструкций;
длинные пояснения.

Если для объяснения нужны несколько независимых визуальных шагов, лучше сделать несколько простых иллюстраций.

20. Типы математических иллюстраций

Все иллюстрации относятся к одному из основных типов.

A. Координатный график

Используется для:

функций;
точек;
расстояний;
координат;
векторов;
зависимостей.
B. Геометрическая схема

Используется для:

треугольников;
окружностей;
прямоугольников;
углов;
длин сторон;
геометрических построений.
C. Числовая прямая

Используется для:

отрицательных чисел;
дробей;
интервалов;
сравнений;
расстояний между числами.
D. Диаграмма

Используется для:

процентов;
долей;
сравнений;
отношений;
распределений.
E. График зависимости

Используется для:

времени и расстояния;
входа и выхода;
изменения величины;
зависимости одной переменной от другой.
F. Схема математического преобразования

Используется для последовательных преобразований:

дробь → десятичная дробь → процент

или аналогичных математических процессов.

21. Композиция

Главный математический объект должен быть визуально самым заметным.

Иерархия:

главный объект
      ↓
вспомогательные элементы
      ↓
оси / сетка
      ↓
второстепенные подписи

Не допускать ситуации, когда сетка или подписи заметнее самой функции или геометрической фигуры.

22. Масштабирование

Иллюстрация должна хорошо выглядеть:

на обычном мониторе;
на ноутбуке;
при уменьшении ширины страницы;
при увеличении масштаба интерфейса.

Ключевые элементы нельзя делать настолько мелкими, чтобы они исчезали при уменьшении изображения.

23. Математическая точность

Для математических иллюстраций точность важнее красоты.

Нельзя визуально «примерно» изображать:

координаты;
функции;
углы;
длины;
отношения;
точки;
направления;
пересечения;
геометрические свойства.

Если объект имеет математическое значение, его положение должно соответствовать математическим данным.

24. Генерация иллюстраций

Генеративную нейросеть не использовать как единственный источник математической точности.

Для точных графиков предпочтительный процесс:

определить математические данные;
построить геометрию по точным координатам;
оформить её в едином визуальном стиле;
проверить подписи и математические обозначения;
проверить изображение в масштабе, близком к отображению в приложении.

Особенно это относится к:

графикам функций;
координатным системам;
геометрии;
точкам;
числовым прямым;
диаграммам с количественными значениями.
25. Единообразие между уроками

Если один объект уже оформлен определённым образом, тот же визуальный язык необходимо сохранять во всех следующих уроках.

Например:

оси всегда одинаковые;
сетка всегда одинаковая;
основной цвет всегда #2F5D50;
подписи имеют одинаковый размер;
точки имеют одинаковый стиль;
стрелки имеют одинаковый стиль;
вспомогательные линии имеют одинаковую интенсивность.

Нельзя для каждого урока придумывать новый дизайн.

26. Что запрещено

Не использовать:

случайные цвета;
стандартные ярко-синие графики;
кислотные цвета;
3D-графики;
градиенты;
тени;
декоративные рамки;
фотостиль;
лишние легенды;
лишние подписи;
перегруженную сетку;
чрезмерно толстые оси;
случайные шрифты;
визуальные элементы, не имеющие математического смысла.
27. Главный визуальный принцип

Все математические иллюстрации должны восприниматься как единая библиотека.

Основной цвет:

#2F5D50

Фон:

#F4F2EC

Основной текст:

#1C1B17

Приглушённые элементы:

#6E6B63

Сетка и слабые вспомогательные элементы:

#9A968C

Главный объект всегда визуально важнее вспомогательных элементов.

Итоговый стиль:

спокойная, точная, минималистичная математическая графика, визуально встроенная в интерфейс Robot Architecture.
