# Терминология (канон для всех разделов)

Цель — одно слово на одно понятие во всём учебнике. При первом появлении термина в
уроке допустимо дать английский вариант в скобках, дальше — только русский канон.

| Канон | Не использовать как синоним | Примечание |
|---|---|---|
| процессор, CPU | «проц», «камень» | «ядро» — только о ядрах CPU или ядре ОС, различать контекстом |
| оперативная память, RAM | «оперативка» | |
| накопитель (SSD/HDD) | «диск» как общее слово | «диск» допустимо, когда речь именно о HDD или о «диске C:» |
| каталог | «папка» в технических разделах | «папка» допустима в 01–02 при первом знакомстве |
| файловая система | ФС без расшифровки при первом появлении | |
| операционная система, ОС | | |
| ядро ОС | «кернел» | |
| системный вызов | «сисколл» | в коде — `syscall` |
| процесс / поток | «тред», «нить» | |
| планировщик | «шедулер» | |
| переменная окружения | «энв» | |
| оболочка (shell) | «шелл» как основное слово | `bash`, `PowerShell` — имена собственные |
| терминал | путать с оболочкой | терминал показывает, оболочка исполняет |
| стандартный ввод/вывод/поток ошибок | | в коде `stdin/stdout/stderr` |
| репозиторий | «репа» | |
| рабочее дерево / индекс / коммит | «стейдж» как основное | «индекс (staging area)» при первом появлении |
| ветка / слияние / перебазирование | | `merge`, `rebase` в командах |
| запрос / ответ (HTTP) | «реквест/респонс» | |
| маршрут, обработчик | «роут», «хендлер» как основное | `route`, `handler` в коде |
| зависимость (пакет) | | |
| виртуальное окружение | «венв» | каталог `.venv` |
| исключение | «эксепшн» | |
| итератор / генератор / декоратор | | |
| контекстный менеджер | | |
| таблица / строка / столбец (SQL) | «колонка» допустима | выбрать один вариант внутри раздела 12: **столбец** |
| первичный ключ / внешний ключ | «ПК/ВК» | |
| транзакция | | |
| контейнер / образ (Docker) | «имидж» | |
| брокер / топик / партиция / смещение (Kafka) | «оффсет» как основное | `offset` при первом появлении |
| компонент / свойства / состояние (React) | «пропсы/стейт» как основное | `props`, `state` в коде |

Стиль: вы-обращение, без постоянных «давайте представим». Числа и единицы — с пробелом
(16 ГБ, 3,2 ГГц). Код и команды — в блоках с указанием языка.
